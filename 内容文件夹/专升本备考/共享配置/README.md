这里放英语、数学以及后续科目共用的本地配置。

## BAT 报“状态/开科目配置/讯云 不是内部命令”

这是 BAT 被保存成了 **LF 换行**，加上旧版 BAT 自己直接写中文菜单，`cmd.exe` 会把中文行尾当成单独命令。

现在已改成：

```text
同步全部科目.bat
→ 只做 ASCII 的 Python 启动
→ 中文菜单在 sync_launcher.py 里
```

所以即使 BAT 被保存成 LF，也不会再把中文拆成命令。当前菜单由 Python 输出。

解决旧副本：

```text
1. 直接运行项目文件夹里的 同步全部科目.bat
2. 不要运行从网页另存、ZIP 解压或编辑器改成 LF 的旧副本
3. 已加入 .gitattributes：*.bat text eol=crlf
```

如果旧的 BAT 已经被改成 LF，在 `专升本备考` 目录运行：

```powershell
Get-ChildItem . -Recurse -Filter *.bat | ForEach-Object {
    $p = $_.FullName
    $t = [IO.File]::ReadAllText($p, [Text.Encoding]::UTF8)
    $t = $t -replace "`r`n", "`n" -replace "`n", "`r`n"
    [IO.File]::WriteAllText($p, $t, (New-Object Text.UTF8Encoding($false)))
}
```

也可以直接运行：

```text
共享工具/修复BAT换行.ps1
```

## 强制恢复 GitHub 覆盖本地

双击：

```text
专升本备考/强制恢复GitHub.bat
```

或者在 PowerShell 里预览（不会覆盖）：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File "force_restore_github.ps1" -DryRun
```

脚本会：

```text
git fetch origin
→ 备份未提交修改到桌面
→ 备份本地提交分支
→ 确认后 git reset --hard origin/main
→ 不执行 git clean -fdx
```

因此不会删除：

```text
共享配置/口令.txt
共享配置/云端同步.json
英语/数学问答日志
导出记录
部署截图
```

会覆盖所有已跟踪文件，包括本地未提交的代码修复。  
当前修复如果还没提交，请先提交/上传，或恢复后从桌面备份的 patch 重新应用。

### 科目配置

每个科目有独立的 `export_root`：

```text
英语 → 备考专升本英语/导出记录/日期/
数学 → 备考专升本数学/导出记录/日期/
政治 → 备考专升本政治/导出记录/日期/
信息技术 → 备考专升本信息技术/导出记录/日期/
```

英语额外保存：

```text
英语单词待归档-日期-时间.json
```

并自动更新：

```text
单词 HTML
复习清单/data.json
```

数学只导入数学答疑日志，不会写进英语日志。

政治、信息技术默认：

```json
"enabled": false
```

以后加科目：

1. 在 `科目配置.json` 增加一项
2. 配好 `export_root`
3. 实现对应 `import_adapter`
4. Worker 里增加同名 subject

主同步流程不用改。

### 云端连接

第一次运行：

```text
双击 专升本备考/同步全部科目.bat
→ 显示启动菜单
→ 选 1：先同步，再启动英语 8767、数学 8768
→ 未配置时会提示填写主线路 / 备用线路地址和口令
```

菜单：

```text
1. 一键同步并启动全部服务（推荐）
2. 只同步一次，不启动服务
3. 查看上次同步状态
4. 打开科目配置
5. 配置主线路云端
6. 配置备用线路云端（腾讯云 SCF）
7. 使用腾讯云 SCF 作为主线路
8. 把已保存的备用线路切为主线路
0. 退出
```

原来的云端设置入口全部保留，直接选 `5` / `6` / `7` / `8`。
第一次也可以选 `7` 把 SCF 设为主线路。

关闭同步窗口会同时结束两个服务；也可以在那之前按 `Ctrl+C`。

不会自动轮询，不会常驻后台。口令输入时会明文显示。

国内网络访问 Cloudflare 不稳定时：

```text
主线路：https://...workers.dev
主线路口令：Worker 的 TUTOR_ACCESS_TOKEN

备用线路：腾讯云 SCF Function URL
备用口令：SCF 的 PROXY_TOKEN
```

同步会先走主线路；失败后自动尝试备用线路。

会生成：

```text
共享配置/云端同步.json
```

该文件包含访问口令，已被 `.gitignore` 忽略，不要上传。

### 运行方式

```text
双击 同步全部科目.bat
→ 显示启动菜单
→ 选 1：先同步一次（拉取云端、保存 JSON、生成归档）
→ 同步完成后启动英语 8767、数学 8768
→ 自动打开两个答疑页面
→ 关闭这个同步窗口时，两个服务一起结束
```

顺序固定为：**先同步，后启动服务**。启动服务后不会重复拉取。

只同步、查看状态或配置线路：

```text
菜单选 2：只同步
菜单选 3：查看状态
菜单选 4：打开科目配置
菜单选 5：配置主线路
菜单选 6：配置备用线路
菜单选 7：SCF 设为主线路
菜单选 8：备用线路切为主线路
```

菜单：

```text
1. 一键同步并启动全部服务
2. 只同步一次
3. 查看上次同步状态
4. 打开科目配置
5. 配置主线路云端
6. 配置备用线路云端（腾讯云 SCF）
7. 使用腾讯云 SCF 作为主线路（推荐国内）
8. 把已保存的备用线路切为主线路（不重输令牌）
0. 退出
```

没有自动轮询，没有间隔，不会常驻后台。

如果不开 VPN，建议选 7：
SCF 变主线路，原有的 Cloudflare 自动转为备用线路。

重新配置时直接选 5、6 或 7：

- 选 5 只改主线路，不会清掉备用线路
- 选 6 只改备用线路，不会清掉主线路
- 选 7 把 SCF 放主线路，原来的主线路转备用
- 选 8 把已保存的备用线路直接切为主线路

同步只拉取、保存、导入，不会导入后立即删除云端。  
云端记录由 Worker 的 `LOG_RETENTION_HOURS=24` 保留 24 小时。

同步结束会逐项显示：

```text
云端答疑 N 条（单词解释 X 条、作文 Y 条……）
本地新增 N 条，重复跳过 N 条
待归档单词 N 个（单词列表）
归档 N 个，已存在 N 个，失败 N 个
实际使用线路：腾讯云 SCF / Cloudflare
```

同时生成静态历史归档：

```text
备考专升本英语/英语答疑/答疑历史.json
备考专升本数学/数学答疑/答疑历史.json
备考专升本英语/添加日志/添加日志.json
```

把这三个 JSON 提交 GitHub 后，页面会合并“云端新记录 + 静态旧历史”，不再受 24 小时云端保留限制。原始 JSONL 现在也可上传（会公开问答原文），归档 JSON 同样公开。
`添加日志.html` 在 GitHub 上读取静态归档；本地服务在线时仍读取实时日志。它只负责展示，不负责写入词库。
