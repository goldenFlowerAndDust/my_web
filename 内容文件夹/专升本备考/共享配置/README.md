# 专升本共享配置

这里放英语、数学以及后续科目共用的本地配置。

## DeepSeek API Key

文件：

```text
共享配置/API.txt
```

内容只放一行：

```text
sk-你的DeepSeekKey
```

不要加变量名、引号或说明文字。

读取顺序：

1. 环境变量 `DEEPSEEK_API_KEY`
2. `共享配置/API.txt`（推荐）
3. 数学工具自己的 `数学工具/API.txt`（仅数学，备用）
4. 英语旧的 `词素工具/API.txt`（兼容）
5. 用户目录旧 Key

英语 8767 和数学 8768 都会读这里，所以只需要维护一份。

## 安全

- `共享配置/API.txt` 已被 `.gitignore` 忽略
- 不要上传 GitHub
- 不要写进 HTML / JS / README
- 不要把 Key 发给别人

## 全部科目同步

文件：

```text
共享配置/科目配置.json
共享配置/云端同步.json
共享配置/sync_all_subjects.py
```

### 科目配置

每个科目有独立的 `export_root`：

```text
英语 → 备考专升本英语/导出记录/日期/
数学 → 备考专升本数学/导出记录/日期/
政治 → 备考专升本政治/导出记录/日期/
信息技术 → 备考专升本信息技术/导出记录/日期/
```

英语额外保存：

```text
英语单词待归档-日期-时间.json
```

并自动更新：

```text
单词 HTML
复习清单/data.json
```

数学只导入数学答疑日志，不会写进英语日志。

政治、信息技术默认：

```json
"enabled": false
```

以后加科目：

1. 在 `科目配置.json` 增加一项
2. 配好 `export_root`
3. 实现对应 `import_adapter`
4. Worker 里增加同名 subject

主同步流程不用改。

### 云端连接

第一次运行：

```text
双击 专升本备考/同步全部科目.bat
→ 直接显示菜单，不自动同步
→ 国内推荐先选 6：腾讯云 SCF 作为主线路
→ 或选 4 配置主线路、选 5 配置备用线路
→ 选 1 立即同步
```

以后双击：

```text
→ 直接显示菜单
→ 选 1 才拉取
```

不会启动即同步，不会自动轮询，不会常驻后台。

口令输入时会明文显示，方便核对。

国内网络访问 Cloudflare 不稳定时：

```text
主线路：https://...workers.dev
主线路口令：Worker 的 TUTOR_ACCESS_TOKEN

备用线路：腾讯云 SCF Function URL
备用口令：SCF 的 PROXY_TOKEN
```

同步会先走主线路；失败后自动尝试备用线路。

会生成：

```text
共享配置/云端同步.json
```

该文件包含访问口令，已被 `.gitignore` 忽略，不要上传。

### 运行方式

```text
双击 同步全部科目.bat
→ 直接显示菜单
→ 未配置：先选 4/5/6 配置
→ 选 1 才拉取全部启用科目一次
→ 保存、导入、写状态
→ 回到菜单
```

菜单：

```text
1. 立即同步全部科目
2. 查看上次同步状态
3. 打开科目配置
4. 配置主线路云端
5. 配置备用线路云端（腾讯云 SCF）
6. 使用腾讯云 SCF 作为主线路（推荐国内）
0. 退出
```

没有自动轮询，没有间隔，不会常驻后台。

如果不开 VPN，建议直接选 6：
SCF 变主线路，原有的 Cloudflare 自动转为备用线路。

重新配置时直接选 4、5 或 6：

- 选 4 只改主线路，不会清掉备用线路
- 选 5 只改备用线路，不会清掉主线路
- 选 6 把 SCF 放主线路，原来的主线路转备用
- 备用线路地址留空可以清除备用线路

同步只拉取、保存、导入，不会导入后立即删除云端。  
云端记录由 Worker 的 `LOG_RETENTION_HOURS=24` 保留 24 小时。

同步结束会逐项显示：

```text
云端答疑 N 条（单词解释 X 条、作文 Y 条……）
本地新增 N 条，重复跳过 N 条
待归档单词 N 个（单词列表）
归档 N 个，已存在 N 个，失败 N 个
实际使用线路：腾讯云 SCF / Cloudflare
```

同时生成静态历史归档：

```text
备考专升本英语/英语答疑/答疑历史.json
备考专升本数学/数学答疑/答疑历史.json
备考专升本英语/添加日志/添加日志.json
```

把这三个 JSON 提交 GitHub 后，页面会合并“云端新记录 + 静态旧历史”，不再受 24 小时云端保留限制。原始 JSONL 不上传，归档 JSON 会公开。
`添加日志.html` 在 GitHub 上读取静态归档；本地服务在线时仍读取实时日志。它只负责展示，不负责写入词库。

## 目录与备份

每个科目的导出记录：

```text

└─ 2026-10-31/

   ├─ 英语单词待归档-2026-10-31-2010.json

```

导出记录默认被 `.gitignore` 忽略，留作本地备份。  
每天最后需要把清洗过的归档单独上传 GitHub 时，注意去掉清理令牌和访问口令。
