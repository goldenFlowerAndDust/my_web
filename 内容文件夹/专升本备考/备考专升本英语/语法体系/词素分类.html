单词结构分类

一、五种类型的定义

【原子词】 不可拆，本身就是一个整体 例：apple / book / table / abandon 【本体词】 能独立存在，且能接前后缀（词根） 例：use / care / law / help 【变体】 本体词 + 前后缀 派生出来的新词 例：usable / careless / lawful / helpful 【词根族】 词根不能独立成词，必须整族一起记 例：intelligent / intelligence / intelligible 【复合词】 两个（或更多）能独立成词的词根，拼成新词 例：notebook / homework / sunflower / law-breaker

二、五者关系

原子词 本体词 变体 │ │ │ │ │ + 后缀 │ │ ├────────────────>│ │ │ + 前缀 │ │ ├────────────────>│ │ │ │ 独立记忆 核心 + 规则 从本体推导 ───────────────────────────────────────── 词根族（词根不能独立，整族一起记） │ └─→ intelligent / intelligence / intelligible ───────────────────────────────────────── 复合词（两个独立词根拼合） │ ├─→ notebook = note + book ├─→ homework = home + work └─→ law-breaker = law + break + er

用编程类比：

  • 原子词 = 硬编码的常量，改不动，只能记
  • 本体词 = 基础函数，能独立跑，也能被调用扩展
  • 变体 = 函数调用后的返回值，由本体 + 参数（前后缀）生成
  • 词根族 = 私有内部模块，不能单独调用，必须整包引入
  • 复合词 = 两个模块组合成一个新模块，各自还能独立调用

三、对比表

类型 词根能独立吗 结构 能否派生 记忆方式 例子
原子词 —（无词根） 不可拆 ❌ 不能 归类 / 造句 / 记搭配 apple, book, table
本体词 ✅ 能 本身是词根 ✅ 能接前后缀 记本意 + 扩展变体 use, care, law
变体 ✅ 能（追溯到本体） 本体 + 词缀 ⚠️ 少数能再派生 反推本体 + 后缀规则 usable, careless, lawful
词根族 ❌ 不能 词根（不独立）+ 词缀 ⚠️ 整族扩展 整族一起记 + 后缀对应 intelligent, intelligence
复合词 ✅ 都能 词 + 词 ✅ 能再接词缀 拆成两个词分别记 notebook, law-breaker

四、为什么这样分

  1. 原子词 (没有可拆的词素，本身就是一个整体) 遇到这种词，别硬拆。按语义场 / 句子 / 搭配记
  2. 本体词 (是最小的、能独立使用的词根) 它是整个词族的核心，所有变体都从它派生
  3. 变体 (本体 + 前缀 / 后缀 组成的新词) 能拆就拆，拆不动就当特例单独记
  4. 词根族 (词根不能独立成词，但整族共享一个词根) 不能从本体推，要记后缀对应关系。如 -ent → -ence
  5. 复合词 (两个能独立成词的词根，拼成新词) 拆成两部分分别记，意思往往不是简单相加

五、判断流程

拿到一个单词 │ ├─ 能拆成两个独立单词吗？ │ │ │ ├─ 能 → 【复合词】→ 分别记两个词的本意 │ │ │ └─ 不能 → 往下 │ ├─ 能看出本体 + 前后缀吗？ │ │ │ ├─ 能 → 【变体】→ 反推本体，验证后缀规则 │ │ │ └─ 不能 → 往下 │ ├─ 它能独立成词吗？ │ │ │ ├─ 能 → 能接前后缀吗？ │ │ │ │ │ ├─ 能 → 【本体词】→ 记本意 + 拆变体 │ │ │ │ │ └─ 不能 → 【原子词】→ 归类 / 造句 │ │ │ └─ 不能 → 【词根族】→ 整族一起记

六、复合词的三种写法

写法 例子 说明
合写 notebook / bedroom / homework 最常见
连字符 law-breaker / well-known / hard-working 常见于形容词、部分名词
空格 New York / ice cream / high school 松散的复合，看成一个整体记

七、举例

单词 分类 原因 处理方式
law 本体词 能接 -ful / -less / -yer 拆：lawful / lawless / lawyer
usable 变体 use + able 反推 use，验证“去 e + able”
apple 原子词 拆不动 归类到“食物”语义场
abandon 原子词 拆不动 放句子里记：abandon the plan
care 本体词 能接 -ful / -less / -ing 拆：careful / careless / caring
careless 变体 care + less 反推 care，验证“直接加”
intelligent 词根族 词根 intellig- 不能独立 整族记：intelligence / intelligible
notebook 复合词 note + book，两个都能独立 拆成 note 和 book 分别记
law-breaker 复合词 law + break + er 既是复合（law + break），又是派生（+ er）

八、记忆口诀

原子词：拆不动，就归类 本体词：能拆，就全力拆 变体： 看得出拆法，就反推验证 词根族：词根不独立，整族一起记 复合词：两个独立词，分开记再加合

九、剩下的特殊情况

以下三类数量少，不用单独建分类，当原子词记就行：

类型 说明 例子
缩略词 截取原词一部分 phone (telephone) / exam (examination)
首字母词 首字母拼成 TV / DNA / UN / CPU
混成词 两个词各取一半 brunch (breakfast + lunch) / smog (smoke + fog)
