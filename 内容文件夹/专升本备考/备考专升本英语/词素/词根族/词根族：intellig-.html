intellig- 词根族

词根本体：intellig-（理解）

词根不能独立成词，整族一起记。

  1. intelligent(形容词(adj.)：聪明的、有理解能力的) intellig- + ent (形容词后缀)
  2. intelligence(名词(n.)：智力、理解力、情报) intellig- + ence (名词后缀：ent ————> ence)
  3. intelligently(副词：聪明地) intelligent + -ly
  4. intelligible(形容词：可理解的、易懂的) intellig- + -ible（可……的）
  5. unintelligible(形容词：无法理解的) un- + intelligible
  6. intellectual(形容词：智力的；名词：知识分子) intellect- + -ual（……的）
  7. intellect(名词：智力、才智、理解力) 词根的另一个变体 intellect-，本身可独立成词

后缀对应规律

形容词 名词 规律
intelligent intelligence -ent → -ence
different difference -ent → -ence
patient patience -ent → -ence
confident confidence -ent → -ence
important importance -ant → -ance
distant distance -ant → -ance

整族关系

  intellig-（词根：理解，不能独立）
  │
  ├─ + -ent → intelligent（聪明的）
  │ │
  │ └─ + -ly → intelligently（聪明地）
  │
  ├─ + -ence → intelligence（智力、情报）
  │
  ├─ + -ible → intelligible（可理解的）
  │ │
  │ └─ un- → unintelligible（无法理解的）
  │
  └─ 变体 intellect-
  │
  ├─ intellect（智力）
  └─ + -ual → intellectual（智力的 / 知识分子）

易混点

  • intelligence (不是词根，是 intellig- + -ence 的派生词) 词根永远是 intellig-，不是 intelligence
  • intelligent vs intellectual (intelligent：聪明的（天生能力）；intellectual：智力的（学术、思维层面）) a smart student = intelligent；intellectual 更多指学术/知识分子
  • intelligence 的两种意思 (① 智力 ② 情报) CIA = Central Intelligence Agency（中央情报局）
