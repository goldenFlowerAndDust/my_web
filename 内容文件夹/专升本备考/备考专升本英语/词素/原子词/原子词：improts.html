原子词：improts

原子词：不可再分，直接整体记忆。

improts 不是标准英语单词，无法可靠拆分；若视为 imports 的误拼，则为 import + -s（复数/第三人称单数）。

  1. improtsn.超纲
    • n.
      • ①进口；进口商品（若为 imports 的误拼） imports and exports进出口

        例The country's imports rose sharply last year.

        该国去年的进口量大幅上升。

    improts 不是标准英语单词，无法可靠拆分；若视为 imports 的误拼，则为 import + -s（复数/第三人称单数）。

  2. importn. 进口；进口商品；进口（动词） 超纲

    The import of oil is expensive.

    石油的进口很昂贵。

    im-（进入）+ port（携带）
  3. importsn. 进口商品（复数）；进口（第三人称单数） 超纲

    Imports from Asia have increased.

    来自亚洲的进口商品增加了。

    import + -s
  4. improvev. 改善；提高 超纲

    We must improve our English.

    我们必须提高英语水平。

    易与 import 混淆
