# 专升本英语词性统一与核心词汇页重构计划

## 一、约束

1. 所有代码、配置、页面引用必须使用相对路径，不写死盘符。
2. 保持现有底层逻辑不变：
   - 生词器检查、修复、重建机制不变；
   - AI 答疑新窗口/新对话机制不变；
   - 同步、归档、启动流程不变。
3. `data.json` 为唯一词库数据源。
4. 核心词汇页、生词器、复习清单、添加日志的词性和义项必须来自同一套数据。
5. 每个阶段完成后立即验收，发现偏离目标先停下修正，不继续叠加。

## 二、现状结论

- `专升本英语核心词汇通关.html` 目前按 17 个词族/前后缀分组，共 300+ 词。
- 页面每个词最多显示一个 `word_pos`，义项列表中没有逐条词性。
- 生词器对新增词可以追加，但不会统一重排已有词，也不会修复旧卡片中的词性结构。
- `data.json` 已有 `pos` 和部分 `senses`，但缺少统一的 `pos_zh`，部分旧词义项没有逐条词性。
- 复习清单和添加日志只消费部分字段，尚未统一词性显示。

## 三、词性标准

| 缩写 | 中文 |
|---|---|
| n. | 名词 |
| v. | 动词 |
| vt. | 及物动词 |
| vi. | 不及物动词 |
| adj. | 形容词 |
| adv. | 副词 |
| pron. | 代词 |
| prep. | 介词 |
| conj. | 连词 |
| num. | 数词 |
| art. | 冠词 |
| interj. | 感叹词 |
| aux. | 助动词 |
| modal | 情态动词 |
| phrase | 短语 |

范围：现代英语和专升本考试常见词性；不收录古义、废弃义和极生僻义。

## 四、目标数据结构

```json
{
  "name": "import",
  "pos": "v. / n.",
  "senses": [
    {
      "pos": "v.",
      "pos_zh": "动词",
      "zh": "进口；输入",
      "example": "...",
      "example_zh": "..."
    },
    {
      "pos": "n.",
      "pos_zh": "名词",
      "zh": "进口；进口商品",
      "example": "...",
      "example_zh": "..."
    }
  ]
}
```

规则：

- 每个 sense 必须有 `pos` 和 `pos_zh`。
- 同一词的不同词性拆成不同 sense。
- 不把多个词性合并成一条中文释义。
- 页面显示为 `v. 动词`、`n. 名词`，不只显示缩写。

## 五、核心页结构

保留原 URL 和 `#word-xxx` 锚点，改为同页双视图：

1. 词性视图（默认）
   - 名词、动词、形容词、副词、其他。
   - 每个词只出现一次，卡片内列出全部词性和义项。
2. 词族视图
   - 保留现有 17 组词族/前后缀结构。
   - 保留原有例句、笔记、词族说明。
3. 两个视图共用同一份 `data.json`。
4. 生成前备份旧页面；旧锚点必须可访问。

## 六、实施阶段

### 阶段 0：备份与盘点

- 备份 `data.json` 和核心词汇页。
- 统计词数、页面卡片数、缺失词性数、多词性数、页面与数据不一致项。
- 输出盘点报告。

验收：报告数字与页面/数据实际一致，不改业务文件。

### 阶段 1：词性规范与迁移报告

- 建立统一 POS 映射。
- 扫描所有词条，分类：
  - A：可自动补 `pos_zh`；
  - B：有词性但义项未拆；
  - C：多词性共用中文，无法自动判断；
  - D：完全缺词性；
  - E：页面与 data 不一致。
- 生成 `词性迁移报告.json`，不自动猜 B/C/D。

验收：每个词都有分类结果，歧义词可追踪。

### 阶段 2：data.json 迁移

- A 类自动补 `pos_zh`。
- B/C/D 类按 AI 重分析结果补齐，保留原义项和例子。
- 每个词至少一个合法 sense。
- 备份原文件，支持回滚。

验收：全部 sense 有 pos/pos_zh/zh；无重复词；词数不减少。

### 阶段 3：核心页双视图重建

- 用统一渲染器从 `data.json` 生成页面。
- POS 视图按主要词性分组，卡片显示全部词性。
- 词族视图保留原有词族分组和说明。
- 保留原 URL、`#word-xxx` 锚点、搜索、显示/隐藏中文。
- 生成后自动检查卡片数、锚点数、重复词。

验收：页面可打开；词数不丢；锚点可用；两个视图数据一致。

### 阶段 4：生词器改造

- 查询返回全部词性和义项。
- AI 分析强制返回全部常见词性，每词性单独义项。
- 检查/修复/重建机制保留，只把数据结构和显示统一。
- 新增/覆盖/修复后更新 `data.json`，并重新渲染核心页对应卡片。
- 添加日志记录词性和义项。

验收：查询、分析、写入、修复四条路径都不破坏原有机制。

### 阶段 5：复习清单和添加日志

- 复习卡显示词性和中文标签。
- 添加日志显示词性、中文词性、对应义项。
- 旧记录兼容，不因字段新增而报错。

验收：旧数据可显示；新数据四处一致。

### 阶段 6：全链路回归

- 查询 import、maybe、helpful。
- 新增一个测试词并回滚。
- 修复一个旧词。
- 复习一次。
- 查看添加日志。
- 打开核心页两个视图，检查锚点。
- 检查所有改动文件无绝对路径。

验收：全部通过后再提交。
