01三分钟上手

第一次使用，只做这三步。之后每天直接从“开始今日复习”进入。

最重要的一步：先启动本地服务。 复习清单要读取 data.json，完成打卡时还要把结果写回它； AI 工具要调用 DeepSeek。这些都需要 8767 服务。双击 HTML 文件是打不开完整功能的。
最省事：双击项目根目录的 启动词素服务.bat。 它会自动使用 DeepSeek Harness 自带的 Python 启动 8767 服务，不要求系统 PATH 里有 python。如果双击没用，再在 cmd 里运行： python 词素工具/server.py（需要 Python 3.10+ 已加入 PATH）。
  1. 启动服务
    双击 启动词素服务.bat，看到“词素自动归档服务已启动”后，不要关闭这个窗口。
  2. 打开复习清单
    http://127.0.0.1:8767/复习清单/核心词汇复习清单.html
  3. 需要加词时打开工具
    http://127.0.0.1:8767/单词模块/词汇代码生成器.html
如果你原来有自己的静态服务器： 可以继续用它打开单词页/复习页；但 AI 自动收词仍要启动 8767 服务， 因为浏览器不会直接携带 API Key。英语答疑还可以选择部署云端 Worker。
GitHub Pages 是静态托管，线上页面不能改仓库文件。 自动写回只发生在“本地 8767 服务 + 本地 data.json”。部署到 GitHub 后， 线上复习的进度只存在当前浏览器；要更新 GitHub 上的 data.json，需要先在本地复习， 再 git add / commit / push（或用 GitHub Desktop 上传）。 英语答疑如果需要线上使用，可部署 cloudflare-worker/ 的 Worker， Key 放 Cloudflare Secret，不进 GitHub。

03每天怎么学：15 分钟流程

顺序很重要：先复习旧词，再学新词。复习页已经把“今日复习”放在“今日新词”上面。

  1. 0–7 分钟：复习旧词。 打开复习清单，先看“今日复习”。每个词先回忆中文，再点英文核对；想起不来就点开看。
  2. 7–8 分钟：完成复习。 每个词点“复习完成”。系统会按 1 / 3 / 7 / 15 / 30 / 60 / 90 天安排下一次。
  3. 8–15 分钟：学新词。 看“今日新词”，点英文看中文、搭配和例句。学完一个点“学完”，明天进入第一次复习。
  4. 最后 1 分钟：确认。 看“今日已打卡”有没有增加；点“保存”把未同步记录写入 data.json；需要时打开 11 月日历看一眼。
每天只做 20 + 20。 如果显示“还有 X 个待学/到期”，不用一次做完；页面会顺延，明天继续。 先保证连续，再追求数量。
中文默认隐藏。 点英文单词可以显示/隐藏中文；这是为了先回忆，而不是先看答案。

04怎么添加一个新单词

只加你真正遇到的词：阅读、真题、作文里碰到的词，比盲目背 3000 更有效。

  1. 输入单词
    可填中文提示；不确定词义时填一下，AI 判断会更准。
  2. 先点“AI 分析”
    只预览，不写文件；看分类、目标、例句和卡片预览。
  3. 确认后“分析并写入”
    真正写入单词页或词素页，并追加复习数据。
已经实际跑通的两个例子：
friendship → 核心词汇页新建 -ship 词族；
sunflower → 词素/复合词/复合词：sunflower.html；
两个词都排入 2026-11-13。新词不一定当天出现，系统会排到最近一个不足 20 词的日期。
不想调用 API？ 先点“检查是否已录入”。这个按钮只查词库、词素页和 data.json，不调用 DeepSeek； 如果已录入，会直接提示，并可以一键插队到下一次复习。
写入后在哪里看？ 结果区可以直接“打开写入页面”；也可以在复习清单的“全部词条”里找到它。 当天新词列表只显示今天到期的词，未到日期的在“全部词条”里。
已录入的词不会重复创建。 工具会先检查词库、词素页和 data.json；如果已经存在，会提示“已录入”， 然后把该词插队到下一次复习清单，并显示“插队”标记。 它不会新建第二张词卡。

05AI 是怎么分类的

AI 看的是真实构词，不是只看结尾字母。分错时，先“只分析”检查，再决定要不要写入。

AI 判断写入哪里例子
后缀派生核心词汇页对应词族；没有就新建friendship = friend + -ship
前缀派生核心词汇页的 un- / re- 等词族unhappy = un- + happy
自由词根 / 本体-变体词素/词根-本体-变体【派生词】/law → lawyer / lawful
黏着词根词素/词根族/intellig- → intelligent
复合词词素/复合词/sunflower = sun + flower
原子词词素/原子词/corner 不能硬拆成 -er
不会硬拆： corner、flower 这类词不会被当成“动词 + -er”； 只有构词和词义都对得上，才会归入后缀族。

写入核心词页后，页头数字、词族导航、分组计数会自动重算； 不需要手工改 HTML。新词族会出现在“自动补充”导航行。

06复习清单的规则

你只需要记住：每天最多 20 个新词，最多 20 个旧词复习。

项目规则
每日新词最多 20 个；超出部分显示“顺延”，不丢词
每日复习最多 20 个到期旧词；超出部分同样顺延
复习间隔1 / 3 / 7 / 15 / 30 / 60 / 90 天
新词日程排到最近一个不足 20 词的日期；排满自动下一天
全部词条所有分类都显示；旧页面条目也在，但不占每日 20 词
统计口径“词库总数”只算词；“全部词条”包含旧页面条目
当前快照： 核心词 307 个；加上词素里的 sunflower、deep 等词级条目，复习词 309 个； 再加 13 个旧页面条目，全部词条 322 条。数字会随收词自动变化，以页面为准。
三个按钮： “保存”会把当前未同步的打卡写入 data.json；“撤销上一步/全部”会恢复操作并同步写回； “导出 data.json”只作为备份或手动迁移用，日常不需要再手动覆盖。
data.json 是主数据，浏览器只是离线兜底： 服务开启时，完成/撤销/保存都会自动写入 复习清单/data.json； 刷新日历或原复习页就能看到。服务没开时，记录先暂存在浏览器 localStorage， 启动服务后打开复习清单或点“保存”就会自动同步，不会丢。

08API Key 与备份

Key 已移到用户目录：%USERPROFILE%\.word_archiver_api_key。 项目文件夹里不再有 Key，所以上传整个项目到 GitHub 也不会带 Key。 网页不会读取这个文件；本机 Python 服务会自动读取它。 你之后直接删除这个用户目录文件即可停用。

也可以不用文件，改用环境变量 DEEPSEEK_API_KEY。 不要把 Key 写进 HTML、JS 或 Markdown。

每次写入前自动备份

工具会备份到 词素工具/backups/时间戳/，并在 词素工具/归档日志.jsonl 记录这次归档。 如果写错了，可以用备份恢复被改动的页面和 data.json。

不要直接运行旧的索引脚本： 复习清单/生成json索引.js 和 重排计划.js 只理解页面级索引， 直接运行可能覆盖当前的词级数据。需要重建时先备份，并保留 核心词汇通关、词素/... 和所有 kind: "word" 条目。

09常见问题

复习清单一直加载，或提示“无法读取 data.json”

不要双击 HTML。先在项目根目录双击 启动词素服务.bat，再用 http://127.0.0.1:8767/复习清单/核心词汇复习清单.html 打开。

完成复习后 data.json 没变，提示“未同步”

说明 8767 服务没启动，或页面通过 file:// / 旧静态服务器打开且请求失败。 先双击 启动词素服务.bat，再打开复习清单；页面会自动把浏览器里的 本地记录同步到 data.json。也可以在复习清单里点一次“保存”。

部署到 GitHub Pages 后，线上点复习会改 GitHub 里的 data.json 吗？

不会。GitHub Pages 是静态托管，浏览器没有写仓库的权限。线上点复习只会改当前浏览器的 localStorage；只有本地 8767 服务会写本地 data.json。 要让 GitHub 上的版本更新，需要本地复习完 → git add / commit / push （或 GitHub Desktop 上传）→ Pages 重新部署。

AI 工具显示“本地服务未连接”

说明 8767 服务没启动，或端口被占用。双击 启动词素服务.bat，看到“已启动”后回到页面点“重新检测”。

显示“缺少 API Key”

把 Key 写入用户目录 %USERPROFILE%\.word_archiver_api_key，或设置环境变量 DEEPSEEK_API_KEY。保存后点“重新检测”，不需要重启服务。

AI 分析超时 / 连接被重置

这是网络波动。工具在失败时不会写入任何文件；直接再点一次“AI 分析”或“分析并写入”。 如果连续失败，检查网络或 Key 余额。

写入成功了，但今天的新词列表里没有它

新词会排到最近一个不足 20 词的日期，不一定在今天。工具结果区会显示“复习日程”； 也可以到复习清单的“全部词条”里找到它。当前日程已排到 11 月 13 日。

提示“已经存在”，但我没看到

它可能已经在词素页、核心词页或 data.json 里。工具不会重复创建，而是把已有词 插队到下一次复习清单。用“检查是否已录入”按钮或复习清单的“全部词条”可以确认。

词库页的数字还是 306 / 17

刷新页面。页头数字由页面脚本按实际卡片自动重算；如果刚写入新词，刷新后会变成最新的 307 / 18 或更多。不要手工改这些数字。

能不能一次加很多词？

可以逐个加，但不建议一次性批量调用 API。先把每天 20 个新词坚持下来， 比一次性塞 3000 个更有效。工具也按“一次一个词”设计，便于检查和回滚。
