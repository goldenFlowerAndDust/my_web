# DSH 笔记站 · 使用说明

一套「Markdown 笔记 → 静态网页」的最小系统。写好 `.md`，跑一次构建，就得到可搜索、可翻页、可离线打开的笔记站。

---

## 一、目录结构

```text
DSH-woker/
├─ 共享配置/                     ← 所有科目共用
│  ├─ css/notes.css              ← 目录页 + 阅读页样式
│  ├─ js/index.js                ← 目录页：搜索、分类筛选、统计
│  ├─ js/reader.js               ← 阅读页：按需取正文、目录、翻页、字号、主题
│  ├─ vendor/katex/              ← 本地 KaTeX（公式渲染，含字体）
│  └─ tools/
│     ├─ build.mjs               ← 构建脚本（Node）
│     └─ 构建笔记.bat            ← 双击即构建
├─ 英语/
│  ├─ index.html                 ← 目录页（只加载元数据索引）
│  ├─ view.html                  ← 阅读页（点击后才取正文）
│  ├─ data.js / data.json        ← 索引：标题、分类、摘要、字数、日期、正文文件名
│  ├─ content/                   ← 正文：每篇一个 js 文件，点谁加载谁
│  ├─ 语法/  v+ing、-ly
│  ├─ 后缀/  -less、-ful
│  ├─ 词根/  quire、tank、port
│  └─ 构词/  re+n、grand
├─ 数学/      公式速查/高数常用公式速查.md
├─ 信息技术/
└─ 政治/
```

**规则**：`index.html`、`view.html`、`data.js`、`data.json`、`content/*.js` 全部由脚本生成，不要手改。

---

## 二、新增一篇笔记

1. 把 `.md` 放进对应科目的**分类目录**：

   ```text
   DSH-woker/英语/词根/spect词根详解.md
   ```

2. 双击 `共享配置/tools/构建笔记.bat`，或执行 `node build.mjs`

3. 刷新 `英语/index.html`，新笔记自动出现。

分类名就是文件夹名；直接放在科目根目录的 md 归到「未分类」。

---

## 三、笔记写作约定

- 首行 `# 标题` 作为笔记标题（正文里不再重复显示）
- `##`、`###` 自动进入阅读页左侧目录
- 写了「## 目录」这一节会被自动跳过，避免与左侧导航重复
- 支持：标题、段落、有序/无序列表（含嵌套）、引用块、代码块、行内代码、粗体/斜体/删除线、链接、图片、表格、分隔线
- 公式用 `$...$`（行内）与 `$$...$$`（独立），交给 KaTeX 渲染
- 摘要取正文第一段，超过 96 字截断

---

## 四、数据怎么分流（为什么加载快）

早期方案是把所有正文塞进一个 `docs.js`，英语 9 篇就有 171 KB，笔记一多会拖慢首屏。现在拆成两层：

- **索引 `data.js`**：只有元数据，不含正文。实测英语 9 篇 = **3.7 KB**，约 **0.4 KB/篇**
- **正文 `content/<哈希>.js`**：每篇一个文件，点击时才用 `<script>` 动态加载，加载过的会缓存在内存里

体量估算（单科）：

- 100 篇 → 索引约 40 KB
- 500 篇 → 索引约 200 KB
- 1000 篇 → 索引约 400 KB

**建议上限**：单科索引控制在 500 KB 以内（约 1200 篇）。超过时在 `build.mjs` 里按分类再拆成多份索引即可，正文层已天然分流。

正文单篇通常 5–40 KB，点开即读；即使上百篇也不会影响目录页打开速度。

---

## 五、四个主页怎么接的

每个科目主页只放一个入口，指向该科目的 `index.html`：

- **英语**：顶部快捷链接「DSH 笔记」+ 底部 `07 · DSH NOTES` 板块
- **数学**：目录列表首位「DSH 笔记」
- **信息技术 / 政治**：页面顶部的 `DSH 笔记库` 卡片

已有内容一律未改动。

## 六、常见问题

**目录页空白 / 提示「清单还没生成」**
说明 `data.js` 不存在，先在 `tools` 下运行一次构建。

**点开笔记一直转圈**
`content/` 下缺少对应文件，或 `data.js` 与 `content/` 不是同一次构建的产物。重新构建即可。

**公式没渲染**
确认写法是 `$...$` 或 `$$...$$`；再确认 `vendor/katex/` 下的 js、css 与 `fonts/` 齐全。

**手机上目录挡住正文**
阅读页宽度 ≤ 980px 时目录收进顶栏「目录」按钮，点一下展开。

**想加新科目**
在 `build.mjs` 顶部的 `SUBJECTS` 里加一项（目录名、显示名、返回主页路径、简介），重新构建。
