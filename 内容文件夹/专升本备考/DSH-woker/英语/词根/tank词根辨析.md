# tank 词根辨析

> **一句话结论**：`tank-` **不是词根**。它是印度语言借来的自由词，核心义是“装液体、气体的大型容器”（水池、罐、槽、箱），不是 box 那种小箱子；拉丁、希腊词根表里查不到它。真正长得像、而且该背的是 **-tain（握）**、**-tang（触）**、**-tend（伸）** 三个词根。

---

## 词性标注说明

- **n.** = noun 名词
- **v.** = verb 动词
- **adj.** = adjective 形容词
- **adv.** = adverb 副词
- **prep.** = preposition 介词
- **conj.** = conjunction 连词

## 一、结论：tank- 不是词根

- 拉丁语、希腊语的构词词根表里**没有 tank-** 这一条
- 它不能作为构词成分，粘在别的词上造出一族词
- 它是**自由词干**：能独立成词，也能少量派生，但不成“词根家族”

对比一下就清楚了：

- `-tain` 不能单说，却能带出 contain / maintain / obtain / retain / sustain / detain……——这是词根
- `tank` 能单说，却只带出 tanker / tankful / tankage——这是词

---

## 二、判断词根的两条标准

1. **不能独立成词**：`-tain`、`-quire`、`-tang`、`-tend` 都不能单独使用
2. **能带出一族同源词**：同一词根加不同前缀、后缀，构成一组意义相关的词

两条都满足才算词根。`tank` 一条都不满足，所以不是词根。

---

## 三、tank 的词源

- 葡萄牙语 **tanque** ← 古吉拉特语 **tānk**、马拉地语 **tank**（水池、蓄水池），可能上溯梵语
- 17 世纪进入英语，本义“水池、水槽、蓄水池”
- “坦克”义：1915 年英军为新式装甲车保密，代号叫 **tank**（水箱），此后固定沿用

所以 `tank` 是**印度语言借词**，与拉丁、希腊的词根系统没有血缘关系。

---

## 四、tank 的本义：为什么是“大型容器”而不是 box

### 1. 从词源看，它一开始就是“水池”

tānk 的本义是**蓄水池**，不是“箱子”。也就是说，`tank` 从进入英语的第一天起，核心义就是“装流体的、大体积的容器”。

### 2. 与 box 的四点区别

- **尺度**：box 小，能抱在怀里；tank 大，通常一个人搬不动
- **是否固定**：box 可搬动；tank 多固定安装（水塔、化粪池）或装在车上、船上
- **装什么**：box 装固体物品；tank 装液体、气体
- **有无盖**：box 有可开合的盖；tank 多为敞口或密封管道连接

所以：

- box *n.* 盒子、箱子：a **box** of books（一箱书）
- tank *n.* 大容器、罐、槽、池：a water **tank**（水箱）、an oil **tank**（油罐）、a fish **tank**（鱼缸）、a septic **tank**（化粪池）

### 3. 为什么中文会译成“箱”

- water tank → “水箱”，中文借“箱”字表示**大容器**，并不等于“箱子”
- 中文译名本身就不统一：水箱、油箱、鱼缸、化粪池、油罐——同一个 tank，中文用了箱、缸、池、罐四种字
- 这正说明 `tank` 的核心是“能装流体的大容器”，不是“箱”这个形状

**翻译造成的错觉**：看到“水箱”的“箱”，就以为 tank = box。其实“水箱”是固定的大容器，“箱子”是能搬动的小方盒。

### 4. 一个简单判断法

- 能搬动、有盖、装杂物 → **box** *n.*
- 固定或车载、装水油气体 → **tank** *n.*

## 五、tank 的词性：名词为主，动词为引申

### 作名词 *n.*（本义，最先出现）

- 大容器：water **tank**、oil **tank**、fish **tank**、septic **tank**
- 坦克：a **tank** battalion（坦克营）
- 美式俚语：监狱（the **tank**）

### 作动词 *v.*（后起的引申义）

- 加满油、装罐：**tank** up before the long drive.（长途开车前加满油。）
- 暴跌、惨败：The market **tanked** yesterday.（市场昨天暴跌。）

**结论**：`tank` 首先是**名词**，动词义是 20 世纪的引申。所以在 `tanker` 里，`tank` 是**名词词干**，不是动词。

---

## 六、tanker 怎么来的：n + -er 的构词分析

### 1. tanker 的构成

- **tank** *n.*（罐）＋ **-er** → **tanker** *n.*
- 字面义：a ship or vehicle fitted with tanks（装有罐的船或车）
- 汉译：油轮、罐车

你问“tank 是名词还是动词”——在 tanker 里它是**名词**。

### 2. 你说的 -er 规则，要补两条

你的两条大体对，但 `tanker` 正好是例外，所以规则得说全：

**规则一：v + er = 施动者（人或物）**

- 人：teacher *n.*、worker *n.*、driver *n.*、singer *n.*、writer *n.*、player *n.*
- 物：computer *n.*、printer *n.*、cooker *n.*（炊具）、boiler *n.*（锅炉）、recorder *n.*、scanner *n.*、container *n.*

**规则二：n + er = 与某地、某身份、某特征有关的人**

- New Yorker *n.* 纽约人、Londoner *n.* 伦敦人、villager *n.* 村民、northerner *n.* 北方人
- teenager *n.* 青少年、banker *n.* 银行家、hatter *n.* 帽匠、gardener *n.* 园丁、prisoner *n.* 囚犯

**规则三：n + er = 与某物有关的工具或运载工具（数量少）**

- **tanker** *n.* 油轮、罐车（载着 tank 的船车）
- **freighter** *n.* 货船（freight 货物）
- **steamer** *n.* 汽船（steam 蒸汽）
- **trailer** *n.* 拖车（trail 拖）

所以 `tanker` 属于**规则三**：名词 ＋ -er，指“载有该物的运载工具”，不是指人。规则二管“人”，规则三管“物”，两者都是 n + er，靠语义区分。

### 3. 别忘 -er 还有第三个功能

- **比较级**：bigger、faster、taller
- 这个 -er 与构词后缀 -er 同形不同功能，别混

### 4. 同义后缀

- **-or**：actor *n.* 演员、visitor *n.* 访客、inventor *n.* 发明者
- **-ar**：liar *n.* 说谎者、beggar *n.* 乞丐
- **-ist**：artist *n.* 艺术家、scientist *n.* 科学家
- **-ian**：musician *n.* 音乐家、historian *n.* 历史学家

### 5. 一条警告

不要把 -er 当公式硬造词。英语里能不能加 -er，取决于该词有没有被语言共同体接受：

- ✓ **container**（contain + er）
- ✗ *waterer*（虽然 water 是动词，但“浇水的人”不说 waterer）
- ✗ *booker*（“订票的人”说 booker 只在特定行业用）

**规则用来理解，不用来生成。** 这是英语构词最麻烦、也最不需要死磕的地方。

## 七、tank 的派生与复合词

- **tanker** *n.* 油轮、罐车：an oil **tanker**（油轮）
- **tankful** *n.* 一箱之量：a **tankful** of petrol（一箱汽油）
- **tankage** *n.* 储罐容量
- **think tank** *n.* 智库（复合词，不是词根构词）
- **tank top** *n.* 背心
- **tank car** *n.* 罐车
- **tank farm** *n.* 油库
- **tank engine** *n.* 蒸汽机车
- **tank trap** *n.* 反坦克壕

注意：`think tank` 是“思想 + 罐子”的复合，不能反过来推 **tank = 思想**。

## 八、被误认的三个真词根

### 1. -tain / -ten-（拉丁 tenere：握、持、保持）

- **contain** *v.* 包含、容纳：The box **contains** ten books.（盒子里装了十本书。）
- **maintain** *v.* 维持、维护：**maintain** a healthy diet（保持健康饮食）
- **obtain** *v.* 获得：**obtain** permission（获得许可）
- **retain** *v.* 保留：**retain** the original meaning（保留原意）
- **sustain** *v.* 支撑、维持：**sustain** economic growth（维持经济增长）
- **detain** *v.* 拘留、耽搁：The police **detained** him.（警察拘留了他。）
- **pertain** *v.* 关于、属于：documents **pertaining to** the case（与本案有关的文件）
- **abstain** *v.* 戒除、弃权：**abstain** from alcohol（戒酒）
- **entertain** *v.* 招待、使娱乐：**entertain** guests（招待客人）
- **tenant** *n.* 房客；**tenet** *n.* 信条；**tenure** *n.* 任期
- **continent** *n.* 大陆（连成一片）；**continue** *v.* 继续

### 2. -tang / -tact-（拉丁 tangere：触、摸）

- **tangent** *n.* 切线；*adj.* 相切的
- **tangible** *adj.* 可触摸的、有形的：**tangible** benefits（实实在在的好处）
- **tactile** *adj.* 触觉的
- **contact** *n./v.* 接触、联系
- **contagious** *adj.* 传染性的：a **contagious** disease（传染病）
- **contagion** *n.* 传染
- **intact** *adj.* 完好无损的：The vase remained **intact**.（花瓶完好无损。）
- **attain** *v.* 达到、获得：**attain** one's goal（达到目标）

### 3. -tend / -tens-（拉丁 tendere：伸展）

- **extend** *v.* 延伸、延长：**extend** the deadline（延长截止日期）
- **intend** *v.* 打算：I **intend** to leave.（我打算离开。）
- **attend** *v.* 出席、照料：**attend** a meeting（出席会议）
- **contend** *v.* 竞争、主张
- **pretend** *v.* 假装（“向前伸” → 声称 → 假装）：He **pretended** to be asleep.（他假装睡着了。）
- **tension** *n.* 紧张、张力
- **intense** *adj.* 强烈的；**extensive** *adj.* 广泛的

## 九、三组词根对比与易错点

### 1. attain / obtain / contain 三词不同源

- **attain** *v.* 达到 ← ad + **tangere**（触到）→ 归 -tang-
- **obtain** *v.* 获得 ← ob + **tenere**（握到）→ 归 -tain-
- **contain** *v.* 包含 ← con + **tenere**（握在一起）→ 归 -tain-

三个词都像“得到”，但 **attain 属“触”，obtain 属“握”**。词根书里常把 attain 错归到 -tain，这是常见错误。

### 2. tenant 与 tenet 拼写陷阱

- **tenant** *n.* 房客（ten + ant，持有一处房产的人）
- **tenet** *n.* 信条（ten + et，被坚持的原则）

拼写只差一个字母，词义完全无关。

### 3. tank 与 tang 同形异源

- **tank** *n.* 罐子 ← 印度语借词
- **tang** *n.* 强烈的气味、味道 ← 古诺尔斯语 tangi

`tang` 与词根 `-tang`（触）也只是拼写相同，来源不同。英语里这种“同形异源”极多，判断时看**能不能独立成词、能不能带出一族词**。

---

## 十、三步判断法

1. **能不能独立成词？** 能 → 大概是词，不是词根（tank、tang、quire 的“刀”义）
2. **能不能带出一族同源词？** 不能 → 不是词根
3. **去掉前缀后，剩下的部分还有意义吗？** 有 → 可能是真词根（obtain → tain 握）

三步走完，`tank` 在第一步就被排除。

## 十二、专升本提示

- `tank` 只需认识“大容器、水箱、坦克”，**不考词根**，也不必纠结中文为什么译成“箱”
- box 与 tank 的区别是**尺度与用途**，不是“都是箱子”：box 小、可搬、装固体；tank 大、固定或车载、装流体
- `-er` 三条规则记牢：v + er 指人指物，n + er 多指人，n + er 少数指工具车辆（tanker、freighter、steamer）
- 高频词根是 **-tain**：contain、obtain、maintain、retain、sustain、detain，六个词覆盖阅读与完形
- 次高频是 **-tang / -tact**：contact、tangible、contagious、intact、attain
- 高频还有 **-tend / -tens**：extend、intend、attend、pretend、tension
- 拼写陷阱两组：**attain / obtain**、**tenant / tenet**
- 记忆线：**tain 握得住，tang 摸得到，tend 伸得开**——`tank` 只是路过
