- 数
  - 实数(R)
    - 有理数
      - 整数或分数
    - 无理数
      - 无限不循环的小数
      - 两个特殊的无理数
        - Π ： 3.1415926
        - e ： 2.71828
  - 相反数
    - a 的相反数为 -a
  - 绝对值
    - |a|
      - a （a > 0）
      - 0   (a = 0)
        - 整个过程叫：去绝对值
      - -a  (a < 0)
  - 倒数
    - a(a≠0) 的倒数 为 : \frac{1}{a}
      - 注意
        - 0没有倒数，因为0不能作为分母：
          - $\begin{aligned}\frac{1}{0} \text{没有意义} \end{aligned}$
        - 倒数就是a的-1次方：
          - $\begin{aligned}\frac{1}{a} = a^-1\end{aligned}$
  - 数轴
    - 原点左边为负数，右边为正数
    - 实心：能被取到，空心：无法取到
    - 区间表示法
      - $\begin{aligned}-2 \le x < \ 1 \Longrightarrow [-2,1)\end{aligned}$
    - 大括号表示
      - $\begin{aligned}\{x| -2 \le x < 1 \}\end{aligned}$
  - 复数
    - 形如：a + bi 的数， 表示为：Z = a + bi
    - 其中 a 为 实部， b 为虚部， i 是虚数单位
    - $\begin{aligned}i ^ 2 = -1\end{aligned}$
    - $\begin{aligned}\text{复数的模 = }|Z| = \sqrt{a ^ 2 + b ^ 2}\end{aligned}$
    - 共轭复数 ： 实部相等，虚数互为相反数
      - $\begin{aligned}Z = a + bi  \text{和} B = a - bi  \text{互为共轭复数}\end{aligned}$
