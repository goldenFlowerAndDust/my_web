## 🌉 基础知识衔接

本章会用到平面几何、平面直角坐标系、三角函数、向量初步、二次方程和行列式。下面快速复习关键工具。

### 1. 平面几何与相似

**常用面积公式**

\[
S_{\text{三角形}}=\frac12 ah,
\qquad
S_{\text{平行四边形}}=ah.
\]

勾股定理：

\[
a^2+b^2=c^2.
\]

相似三角形对应边成比例。空间中的距离、投影和截面问题经常回到平面几何。

### 2. 平面直角坐标系

两点

\[
P_1(x_1,y_1),\qquad P_2(x_2,y_2)
\]

之间的距离：

\[
|P_1P_2|
=
\sqrt{(x_2-x_1)^2+(y_2-y_1)^2}.
\]

中点坐标：

\[
\left(\frac{x_1+x_2}{2},\frac{y_1+y_2}{2}\right).
\]

空间中的公式只是多一个 \(z\) 坐标。

### 3. 一元二次方程

\[
ax^2+bx+c=0
\]

的判别式：

\[
\Delta=b^2-4ac.
\]

配方：

\[
ax^2+bx+c
=
a\left(x+\frac{b}{2a}\right)^2
+\frac{4ac-b^2}{4a}.
\]

研究球面、柱面、锥面和二次曲面时，经常需要配方。

### 4. 三角函数

\[
\sin^2\theta+\cos^2\theta=1,
\]

\[
\cos\theta=\frac{\text{邻边}}{\text{斜边}},
\qquad
\sin\theta=\frac{\text{对边}}{\text{斜边}},
\]

\[
\tan\theta=\frac{\sin\theta}{\cos\theta}.
\]

向量的方向余弦、夹角和投影都要用到三角函数。

### 5. 行列式

二阶行列式：

\[
\begin{vmatrix}
a&b\\
c&d
\end{vmatrix}
=ad-bc.
\]

三阶行列式可按第一行展开：

\[
\begin{vmatrix}
a_1&a_2&a_3\\
b_1&b_2&b_3\\
c_1&c_2&c_3
\end{vmatrix}
=
a_1
\begin{vmatrix}
b_2&b_3\\
c_2&c_3
\end{vmatrix}
-a_2
\begin{vmatrix}
b_1&b_3\\
c_1&c_3
\end{vmatrix}
+a_3
\begin{vmatrix}
b_1&b_2\\
c_1&c_2
\end{vmatrix}.
\]

向量积和混合积都离不开行列式。

### 6. 平面向量初步

平面向量

\[
\vec a=(a_x,a_y)
\]

的模：

\[
|\vec a|=\sqrt{a_x^2+a_y^2}.
\]

数量积：

\[
\vec a\cdot\vec b
=
a_xb_x+a_yb_y.
\]

空间向量只是多一个分量。

<a id="一向量及其线性运算"></a>

## 一、向量及其线性运算

### 1.1 向量的概念

既有大小又有方向的量叫做**向量**。向量常用

\[
\vec a,\qquad \vec b,\qquad \overrightarrow{AB}
\]

表示。

向量的大小叫做**模**，记作

\[
|\vec a|.
\]

模为 \(1\) 的向量叫做**单位向量**；模为 \(0\) 的向量叫做**零向量**，记作 \(\vec 0\)。

### 1.2 空间直角坐标系

在空间直角坐标系中，取三个两两垂直的单位向量

\[
\mathbf i,\qquad \mathbf j,\qquad \mathbf k,
\]

分别沿 \(x\) 轴、\(y\) 轴、\(z\) 轴正方向。任意向量可以表示为

\[
\boxed{
\vec a=a_x\mathbf i+a_y\mathbf j+a_z\mathbf k
}
\]

或简写为

\[
\vec a=(a_x,a_y,a_z).
\]

模：

\[
\boxed{
|\vec a|=\sqrt{a_x^2+a_y^2+a_z^2}
}.
\]

### 1.3 由两点确定向量

若

\[
A(x_1,y_1,z_1),\qquad B(x_2,y_2,z_2),
\]

则

\[
\boxed{
\overrightarrow{AB}
=
(x_2-x_1,\ y_2-y_1,\ z_2-z_1)
}.
\]

注意：终点坐标减起点坐标。

### 1.4 向量的线性运算

设

\[
\vec a=(a_x,a_y,a_z),\qquad
\vec b=(b_x,b_y,b_z),
\]

则

\[
\vec a\pm\vec b
=
(a_x\pm b_x,\ a_y\pm b_y,\ a_z\pm b_z),
\]

\[
\lambda\vec a
=
(\lambda a_x,\lambda a_y,\lambda a_z).
\]

向量加法满足交换律、结合律；数乘满足分配律。

### 1.5 平行、共线与共面

若存在实数 \(\lambda\)，使得

\[
\vec a=\lambda\vec b,
\]

则 \(\vec a\) 与 \(\vec b\) 平行（共线）。

三个向量共面，当且仅当它们的混合积为零（后面会讲）。

### 1.6 单位向量与方向余弦

若 \(\vec a\ne\vec0\)，则与 \(\vec a\) 同方向的单位向量为

\[
\boxed{
\vec e_a=\frac{\vec a}{|\vec a|}
}.
\]

设 \(\vec a\) 与 \(x,y,z\) 轴正方向的夹角分别为 \(\alpha,\beta,\gamma\)，则

\[
\cos\alpha=\frac{a_x}{|\vec a|},
\qquad
\cos\beta=\frac{a_y}{|\vec a|},
\qquad
\cos\gamma=\frac{a_z}{|\vec a|}.
\]

这三个余弦叫做**方向余弦**，并且

\[
\boxed{
\cos^2\alpha+\cos^2\beta+\cos^2\gamma=1
}.
\]

### 1.7 定比分点

若点 \(P\) 分有向线段 \(AB\) 的比为

\[
\frac{AP}{PB}=\lambda,
\]

则

\[
\boxed{
P=\frac{A+\lambda B}{1+\lambda}
}
\]

（按坐标分别计算）。当 \(\lambda=1\) 时就是中点公式。

<a id="二数量积与向量积"></a>

## 二、数量积与向量积

### 2.1 数量积的定义

两个向量 \(\vec a,\vec b\) 的**数量积**（点积）定义为

\[
\boxed{
\vec a\cdot\vec b
=
|\vec a||\vec b|\cos\theta
},
\]

其中 \(\theta\) 是两向量的夹角，\(0\le\theta\le\pi\)。

数量积的结果是一个**数**，不是向量。

### 2.2 坐标公式

若

\[
\vec a=(a_x,a_y,a_z),\qquad
\vec b=(b_x,b_y,b_z),
\]

则

\[
\boxed{
\vec a\cdot\vec b
=
a_xb_x+a_yb_y+a_zb_z
}.
\]

### 2.3 数量积的性质

\[
\vec a\cdot\vec b=\vec b\cdot\vec a,
\]

\[
\vec a\cdot(\vec b+\vec c)
=
\vec a\cdot\vec b+\vec a\cdot\vec c,
\]

\[
(\lambda\vec a)\cdot\vec b
=
\lambda(\vec a\cdot\vec b),
\]

\[
\vec a\cdot\vec a=|\vec a|^2.
\]

### 2.4 夹角与垂直

\[
\boxed{
\cos\theta
=
\frac{\vec a\cdot\vec b}{|\vec a||\vec b|}
}.
\]

因此

\[
\boxed{
\vec a\perp\vec b
\iff
\vec a\cdot\vec b=0
}.
\]

### 2.5 投影

向量 \(\vec a\) 在 \(\vec b\) 方向上的投影为

\[
\boxed{
\operatorname{Prj}_{\vec b}\vec a
=
\frac{\vec a\cdot\vec b}{|\vec b|}
}.
\]

它是一个数。若需要投影向量，则再乘以 \(\vec b\) 的单位向量：

\[
\left(\frac{\vec a\cdot\vec b}{|\vec b|^2}\right)\vec b.
\]

### 2.6 数量积的物理意义

恒力 \(\vec F\) 作用在位移 \(\vec s\) 上所做的功为

\[
W=\vec F\cdot\vec s.
\]

### 2.7 向量积的定义

两个向量 \(\vec a,\vec b\) 的**向量积**（叉积）记作

\[
\vec a\times\vec b.
\]

它是一个向量，满足：

1. 模为
   \[
   \boxed{
   |\vec a\times\vec b|
   =
   |\vec a||\vec b|\sin\theta
   };
   \]
2. 方向同时垂直于 \(\vec a\) 和 \(\vec b\)，方向由右手法则确定；
3. \(|\vec a\times\vec b|\) 等于以 \(\vec a,\vec b\) 为邻边的平行四边形面积。

### 2.8 向量积的坐标公式

\[
\boxed{
\vec a\times\vec b
=
\begin{vmatrix}
\mathbf i&\mathbf j&\mathbf k\\
a_x&a_y&a_z\\
b_x&b_y&b_z
\end{vmatrix}
}.
\]

即

\[
\vec a\times\vec b
=
(a_yb_z-a_zb_y)\mathbf i
-(a_xb_z-a_zb_x)\mathbf j
+(a_xb_y-a_yb_x)\mathbf k.
\]

### 2.9 向量积的性质

\[
\vec a\times\vec b=-\vec b\times\vec a,
\]

\[
\vec a\times\vec a=\vec0,
\]

\[
\vec a\times(\vec b+\vec c)
=
\vec a\times\vec b+\vec a\times\vec c.
\]

并且

\[
\boxed{
\vec a\parallel\vec b
\iff
\vec a\times\vec b=\vec0
}.
\]

### 2.10 面积公式

以 \(\vec a,\vec b\) 为邻边的平行四边形面积：

\[
S=|\vec a\times\vec b|.
\]

以 \(\vec a,\vec b\) 为两边的三角形面积：

\[
\boxed{
S_{\triangle}
=
\frac12|\vec a\times\vec b|
}.
\]

### 2.11 混合积

三个向量的混合积定义为

\[
\boxed{
[\vec a,\vec b,\vec c]
=
(\vec a\times\vec b)\cdot\vec c
}.
\]

坐标形式：

\[
[\vec a,\vec b,\vec c]
=
\begin{vmatrix}
a_x&a_y&a_z\\
b_x&b_y&b_z\\
c_x&c_y&c_z
\end{vmatrix}.
\]

几何意义：它的绝对值等于以 \(\vec a,\vec b,\vec c\) 为棱的平行六面体体积。

\[
\boxed{
\vec a,\vec b,\vec c\text{ 共面}
\iff
[\vec a,\vec b,\vec c]=0
}.
\]

## 三、平面及其方程

### 3.1 点法式方程

若平面过点

\[
P_0(x_0,y_0,z_0),
\]

且法向量为

\[
\vec n=(A,B,C),
\]

则对平面上任意点 \(P(x,y,z)\)，向量 \(\overrightarrow{P_0P}\) 与 \(\vec n\) 垂直：

\[
\vec n\cdot\overrightarrow{P_0P}=0.
\]

即

\[
\boxed{
A(x-x_0)+B(y-y_0)+C(z-z_0)=0
}.
\]

### 3.2 一般式方程

\[
\boxed{
Ax+By+Cz+D=0
}
\]

其中 \((A,B,C)\) 是平面的一个法向量。

反过来，任何形如上式且 \(A,B,C\) 不全为零的方程都表示一个平面。

### 3.3 截距式

若平面在 \(x,y,z\) 轴上的截距分别为 \(a,b,c\)，且都不为零，则

\[
\boxed{
\frac xa+\frac yb+\frac zc=1
}.
\]

### 3.4 过三点的平面

已知三点 \(A,B,C\)，先求

\[
\vec n=\overrightarrow{AB}\times\overrightarrow{AC},
\]

再用点法式写出平面方程。

### 3.5 两平面的夹角

两平面

\[
A_1x+B_1y+C_1z+D_1=0,
\]

\[
A_2x+B_2y+C_2z+D_2=0
\]

的法向量分别为

\[
\vec n_1=(A_1,B_1,C_1),\qquad
\vec n_2=(A_2,B_2,C_2).
\]

两平面夹角 \(\theta\) 满足

\[
\boxed{
\cos\theta
=
\frac{|\vec n_1\cdot\vec n_2|}
{|\vec n_1||\vec n_2|}
}.
\]

### 3.6 平行与垂直

\[
\text{两平面平行}
\iff
\vec n_1\parallel\vec n_2,
\]

\[
\text{两平面垂直}
\iff
\vec n_1\cdot\vec n_2=0.
\]

### 3.7 点到平面的距离

点 \(P(x_0,y_0,z_0)\) 到平面

\[
Ax+By+Cz+D=0
\]

的距离为

\[
\boxed{
d=
\frac{|Ax_0+By_0+Cz_0+D|}
{\sqrt{A^2+B^2+C^2}}
}.
\]

<a id="四空间直线及其方程"></a>

## 四、空间直线及其方程

### 4.1 点向式与参数式

若直线过点

\[
P_0(x_0,y_0,z_0),
\]

方向向量为

\[
\vec s=(l,m,n),
\]

则直线的参数方程为

\[
\boxed{
\begin{cases}
x=x_0+lt,\\
y=y_0+mt,\\
z=z_0+nt,
\end{cases}
\quad(t\in\mathbb R)
}.
\]

消去 \(t\)，得对称式（点向式）：

\[
\boxed{
\frac{x-x_0}{l}
=
\frac{y-y_0}{m}
=
\frac{z-z_0}{n}
}.
\]

如果某个方向分量为零，例如 \(l=0\)，则写成

\[
x=x_0,\qquad
\frac{y-y_0}{m}=\frac{z-z_0}{n}.
\]

### 4.2 两点式

过两点 \(A,B\) 的直线，方向向量取

\[
\vec s=\overrightarrow{AB}.
\]

### 4.3 一般式

空间直线可以看成两个平面的交线：

\[
\boxed{
\begin{cases}
A_1x+B_1y+C_1z+D_1=0,\\
A_2x+B_2y+C_2z+D_2=0.
\end{cases}
}
\]

直线的方向向量为

\[
\vec s=\vec n_1\times\vec n_2.
\]

### 4.4 两直线的夹角

两直线的方向向量为 \(\vec s_1,\vec s_2\)，夹角 \(\theta\) 满足

\[
\boxed{
\cos\theta
=
\frac{|\vec s_1\cdot\vec s_2|}
{|\vec s_1||\vec s_2|}
}.
\]

两直线平行：

\[
\vec s_1\parallel\vec s_2.
\]

两直线垂直：

\[
\vec s_1\cdot\vec s_2=0.
\]

### 4.5 直线与平面的夹角

直线方向向量 \(\vec s\)，平面法向量 \(\vec n\)，直线与平面的夹角为 \(\theta\)，则

\[
\boxed{
\sin\theta
=
\frac{|\vec s\cdot\vec n|}
{|\vec s||\vec n|}
}.
\]

这里用正弦，因为直线与平面的夹角等于直线与平面法线夹角的余角。

### 4.6 直线与平面的交点

把直线参数方程代入平面方程，解出 \(t\)，再代回直线方程即可。

### 4.7 点到直线的距离

点 \(P\) 到过点 \(P_0\)、方向向量为 \(\vec s\) 的直线的距离为

\[
\boxed{
d=
\frac{|\vec s\times\overrightarrow{P_0P}|}{|\vec s|}
}.
\]

### 4.8 两直线的位置关系

两直线可能：

- 相交；
- 平行；
- 重合；
- 异面（既不平行也不相交）。

若两直线分别过 \(P_1,P_2\)，方向向量为 \(\vec s_1,\vec s_2\)，则

\[
[\overrightarrow{P_1P_2},\vec s_1,\vec s_2]=0
\]

时，两直线共面；否则为异面直线。

异面直线的距离：

\[
\boxed{
d=
\frac{|[\overrightarrow{P_1P_2},\vec s_1,\vec s_2]|}
{|\vec s_1\times\vec s_2|}
}.
\]

<a id="五曲面及其方程"></a>

## 五、曲面及其方程

### 5.1 曲面方程的概念

若曲面上的点 \((x,y,z)\) 都满足方程

\[
F(x,y,z)=0,
\]

且不在曲面上的点不满足，则称该方程为曲面的方程。

也可以写成

\[
z=f(x,y).
\]

### 5.2 球面

以 \((x_0,y_0,z_0)\) 为球心、\(R\) 为半径的球面：

\[
\boxed{
(x-x_0)^2+(y-y_0)^2+(z-z_0)^2=R^2
}.
\]

一般形式

\[
x^2+y^2+z^2+Dx+Ey+Fz+G=0
\]

配方后可判断是否为球面，并求球心和半径。

### 5.3 柱面

若方程中缺少某个变量，通常表示柱面。例如

\[
x^2+y^2=R^2
\]

表示母线平行于 \(z\) 轴的圆柱面。

类似地，

\[
y^2=2px
\]

表示母线平行于 \(z\) 轴的抛物柱面。

### 5.4 旋转曲面

曲线绕某轴旋转所得曲面，可以把曲线方程中的相应变量替换成“到轴的距离”。

例如曲线

\[
y=f(x)
\]

绕 \(x\) 轴旋转，得到

\[
\boxed{
y^2+z^2=[f(x)]^2
}.
\]

### 5.5 常见二次曲面

| 方程 | 名称与形状 |
|---|---|
| \(\dfrac{x^2}{a^2}+\dfrac{y^2}{b^2}+\dfrac{z^2}{c^2}=1\) | 椭球面 |
| \(\dfrac{x^2}{a^2}+\dfrac{y^2}{b^2}=z\) | 椭圆抛物面 |
| \(\dfrac{x^2}{a^2}-\dfrac{y^2}{b^2}=z\) | 双曲抛物面（马鞍面） |
| \(\dfrac{x^2}{a^2}+\dfrac{y^2}{b^2}-\dfrac{z^2}{c^2}=1\) | 单叶双曲面 |
| \(\dfrac{x^2}{a^2}+\dfrac{y^2}{b^2}-\dfrac{z^2}{c^2}=-1\) | 双叶双曲面 |
| \(\dfrac{x^2}{a^2}+\dfrac{y^2}{b^2}=\dfrac{z^2}{c^2}\) | 圆锥面 |

识别二次曲面时，先看变量的次数、符号和是否有常数项，再结合截痕法理解形状。

### 5.6 截痕法

用平面 \(x=x_0\)、\(y=y_0\) 或 \(z=z_0\) 去截曲面，得到截痕曲线，从而判断曲面形状。

例如

\[
z=x^2+y^2
\]

用 \(z=z_0>0\) 截，得到圆

\[
x^2+y^2=z_0,
\]

说明它是开口向上的旋转抛物面。

### 5.7 柱坐标与球坐标（拓展）

柱坐标：

\[
x=r\cos\theta,\qquad
y=r\sin\theta,\qquad
z=z.
\]

球坐标：

\[
x=\rho\sin\varphi\cos\theta,
\qquad
y=\rho\sin\varphi\sin\theta,
\qquad
z=\rho\cos\varphi.
\]

其中 \(\rho\ge0\)，\(0\le\varphi\le\pi\)。

<a id="六空间曲线及其方程"></a>

## 六、空间曲线及其方程

### 6.1 参数方程

空间曲线常用参数方程表示：

\[
\boxed{
\begin{cases}
x=x(t),\\
y=y(t),\\
z=z(t).
\end{cases}
}
\]

例如螺旋线：

\[
x=a\cos t,\qquad
y=a\sin t,\qquad
z=bt.
\]

### 6.2 一般方程

空间曲线也可以看成两个曲面的交线：

\[
\boxed{
\begin{cases}
F(x,y,z)=0,\\
G(x,y,z)=0.
\end{cases}
}
\]

### 6.3 曲线在坐标平面上的投影

把曲线投影到 \(xy\) 平面，就是消去 \(z\)，得到关于 \(x,y\) 的方程。

例如球面

\[
x^2+y^2+z^2=4
\]

与平面

\[
z=1
\]

的交线是平面 \(z=1\) 上的圆

\[
x^2+y^2=3.
\]

它在 \(xy\) 平面上的投影是圆

\[
\begin{cases}
x^2+y^2=3,\\
z=0.
\end{cases}
\]

### 6.4 空间曲线的切向量

若曲线由参数方程给出，则切向量为

\[
\boxed{
\vec T=(x'(t),y'(t),z'(t))
}.
\]

切线方程为

\[
\frac{x-x_0}{x'(t_0)}
=
\frac{y-y_0}{y'(t_0)}
=
\frac{z-z_0}{z'(t_0)}.
\]

<a id="七典型例题"></a>

## 七、典型例题

### 例 1：向量基本运算

已知

\[
A(1,2,3),\qquad B(3,0,1),
\]

求 \(\overrightarrow{AB}\)、\(|\overrightarrow{AB}|\)、与 \(\overrightarrow{AB}\) 同方向的单位向量，以及方向余弦。

**解**

\[
\overrightarrow{AB}
=
(3-1,0-2,1-3)
=
(2,-2,-2).
\]

\[
|\overrightarrow{AB}|
=
\sqrt{2^2+(-2)^2+(-2)^2}
=
\sqrt{12}
=
2\sqrt3.
\]

单位向量：

\[
\vec e
=
\frac{1}{2\sqrt3}(2,-2,-2)
=
\left(\frac1{\sqrt3},-\frac1{\sqrt3},-\frac1{\sqrt3}\right).
\]

方向余弦：

\[
\cos\alpha=\frac1{\sqrt3},
\qquad
\cos\beta=-\frac1{\sqrt3},
\qquad
\cos\gamma=-\frac1{\sqrt3}.
\]

### 例 2：数量积与向量积

设

\[
\vec a=(1,2,2),\qquad \vec b=(2,-1,0).
\]

求 \(\vec a\cdot\vec b\)、\(\vec a\times\vec b\)、两向量夹角，以及以它们为邻边的平行四边形面积。

**解**

\[
\vec a\cdot\vec b
=
1\cdot2+2\cdot(-1)+2\cdot0
=
0.
\]

所以两向量垂直，夹角为 \(90^\circ\)。

\[
\vec a\times\vec b
=
\begin{vmatrix}
\mathbf i&\mathbf j&\mathbf k\\
1&2&2\\
2&-1&0
\end{vmatrix}
=
(2,4,-5).
\]

平行四边形面积：

\[
S=|\vec a\times\vec b|
=
\sqrt{2^2+4^2+(-5)^2}
=
3\sqrt5.
\]

### 例 3：过三点的平面

求过

\[
A(1,0,0),\qquad B(0,1,0),\qquad C(0,0,1)
\]

的平面方程。

**解**

\[
\overrightarrow{AB}=(-1,1,0),
\qquad
\overrightarrow{AC}=(-1,0,1).
\]

法向量：

\[
\vec n=\overrightarrow{AB}\times\overrightarrow{AC}
=
\begin{vmatrix}
\mathbf i&\mathbf j&\mathbf k\\
-1&1&0\\
-1&0&1
\end{vmatrix}
=
(1,1,1).
\]

取点 \(A(1,0,0)\)，点法式：

\[
1(x-1)+1(y-0)+1(z-0)=0.
\]

所以

\[
\boxed{x+y+z=1}.
\]

### 例 4：空间直线方程

求过点

\[
P(1,2,3)
\]

且方向向量为

\[
\vec s=(2,-1,3)
\]

的直线方程，并求该直线与平面 \(x+y+z=6\) 的夹角。

**解**

参数方程：

\[
\begin{cases}
x=1+2t,\\
y=2-t,\\
z=3+3t.
\end{cases}
\]

对称式：

\[
\frac{x-1}{2}
=
\frac{y-2}{-1}
=
\frac{z-3}{3}.
\]

平面法向量：

\[
\vec n=(1,1,1).
\]

设直线与平面夹角为 \(\theta\)，则

\[
\sin\theta
=
\frac{|\vec s\cdot\vec n|}
{|\vec s||\vec n|}
=
\frac{|2-1+3|}
{\sqrt{14}\sqrt3}
=
\frac4{\sqrt{42}}.
\]

所以

\[
\theta=\arcsin\frac4{\sqrt{42}}.
\]

### 例 5：点到平面的距离

求点

\[
P(1,2,3)
\]

到平面

\[
2x-y+2z=3
\]

的距离。

**解**

写成

\[
2x-y+2z-3=0.
\]

\[
d=
\frac{|2\cdot1-2+2\cdot3-3|}
{\sqrt{2^2+(-1)^2+2^2}}
=
\frac{|3|}{3}
=
1.
\]

### 例 6：球面方程

判断方程

\[
x^2+y^2+z^2-2x+4y-6z=0
\]

表示什么曲面，并求球心和半径。

**解**

配方：

\[
(x-1)^2-1
+(y+2)^2-4
+(z-3)^2-9
=0.
\]

所以

\[
(x-1)^2+(y+2)^2+(z-3)^2=14.
\]

这是球面，球心

\[
(1,-2,3),
\]

半径

\[
\boxed{R=\sqrt{14}}.
\]

### 例 7：识别二次曲面

判断下列方程表示什么曲面：

\[
x^2+y^2=4,
\]

\[
z=x^2+y^2,
\]

\[
\frac{x^2}{4}+\frac{y^2}{9}+z^2=1.
\]

**解**

1. \(x^2+y^2=4\) 中缺少 \(z\)，表示母线平行于 \(z\) 轴的圆柱面，半径 \(2\)。
2. \(z=x^2+y^2\) 是开口向上的旋转抛物面。
3. \(\dfrac{x^2}{4}+\dfrac{y^2}{9}+z^2=1\) 是椭球面。

### 例 8：两直线的位置关系

判断直线

\[
L_1:\quad x=y,\quad z=0
\]

与

\[
L_2:\quad x=1,\quad y=z
\]

的位置关系，并求它们之间的距离。

**解**

两直线分别过

\[
P_1(0,0,0),\qquad P_2(1,0,0),
\]

方向向量为

\[
\vec s_1=(1,1,0),\qquad \vec s_2=(0,1,1).
\]

\[
\overrightarrow{P_1P_2}=(1,0,0).
\]

\[
\vec s_1\times\vec s_2
=
(1,-1,1).
\]

混合积：

\[
[\overrightarrow{P_1P_2},\vec s_1,\vec s_2]
=
(1,0,0)\cdot(1,-1,1)=1\ne0.
\]

所以两直线异面。距离：

\[
d=
\frac{|1|}{\sqrt{1^2+(-1)^2+1^2}}
=
\frac1{\sqrt3}.
\]

<a id="八易错点提示"></a>

## 八、易错点提示

### 1. 把点与向量混为一谈

点 \((x,y,z)\) 表示位置，向量 \((a,b,c)\) 表示有大小和方向的量。两点之差才是向量。

### 2. 向量减法方向写反

\[
\overrightarrow{AB}=B-A,
\]

不是 \(A-B\)。

### 3. 数量积与向量积混淆

- 数量积 \(\vec a\cdot\vec b\) 是数；
- 向量积 \(\vec a\times\vec b\) 是向量。

### 4. 向量积顺序交换忘记变号

\[
\vec a\times\vec b=-\vec b\times\vec a.
\]

### 5. 三角形面积忘记二分之一

\[
S_{\triangle}=\frac12|\vec a\times\vec b|.
\]

### 6. 法向量与方向向量混淆

平面方程 \(Ax+By+Cz+D=0\) 中，\((A,B,C)\) 是法向量；直线方程中的 \((l,m,n)\) 是方向向量。

### 7. 点到平面距离忘记绝对值

\[
d=\frac{|Ax_0+By_0+Cz_0+D|}{\sqrt{A^2+B^2+C^2}}.
\]

### 8. 直线与平面夹角用余弦

直线与平面夹角用

\[
\sin\theta
=
\frac{|\vec s\cdot\vec n|}{|\vec s||\vec n|}.
\]

两平面夹角才用余弦。

### 9. 对称式分母为零时不会处理

若方向向量的某个分量为零，不能写成分母为零的对称式，应单独写成

\[
x=x_0
\]

等形式。

### 10. 球面配方漏掉常数

配方时要把常数项移到右边，最后半径为平方根。

### 11. 柱面与旋转面混淆

缺少变量的方程通常是柱面；旋转曲面要根据旋转轴把变量配对。

### 12. 异面直线距离公式记错

异面直线距离：

\[
d=
\frac{|[\overrightarrow{P_1P_2},\vec s_1,\vec s_2]|}
{|\vec s_1\times\vec s_2|}.
\]

分子是混合积的绝对值，分母是方向向量叉积的模。

### 13. 空间曲线投影忘记说明所在平面

投影到 \(xy\) 平面后，应写成

\[
\begin{cases}
F(x,y)=0,\\
z=0,
\end{cases}
\]

不能只写 \(F(x,y)=0\)。

### 14. 不会用草图判断位置关系

空间解析几何题应先画草图，判断平行、垂直、相交或异面，再代公式。

## 十一、公式速查

### 11.1 向量

\[
\overrightarrow{AB}=B-A,
\]

\[
|\vec a|=\sqrt{a_x^2+a_y^2+a_z^2},
\]

\[
\cos\alpha=\frac{a_x}{|\vec a|},\quad
\cos\beta=\frac{a_y}{|\vec a|},\quad
\cos\gamma=\frac{a_z}{|\vec a|}.
\]

### 11.2 数量积

\[
\vec a\cdot\vec b
=
|\vec a||\vec b|\cos\theta
=
a_xb_x+a_yb_y+a_zb_z.
\]

\[
\vec a\perp\vec b\iff\vec a\cdot\vec b=0.
\]

### 11.3 向量积

\[
\vec a\times\vec b
=
\begin{vmatrix}
\mathbf i&\mathbf j&\mathbf k\\
a_x&a_y&a_z\\
b_x&b_y&b_z
\end{vmatrix}.
\]

\[
S_{\text{平行四边形}}=|\vec a\times\vec b|,
\qquad
S_{\triangle}=\frac12|\vec a\times\vec b|.
\]

### 11.4 平面

\[
A(x-x_0)+B(y-y_0)+C(z-z_0)=0,
\]

\[
Ax+By+Cz+D=0,
\]

\[
d=\frac{|Ax_0+By_0+Cz_0+D|}
{\sqrt{A^2+B^2+C^2}}.
\]

### 11.5 直线

\[
\frac{x-x_0}{l}
=
\frac{y-y_0}{m}
=
\frac{z-z_0}{n},
\]

\[
\sin\theta=
\frac{|\vec s\cdot\vec n|}{|\vec s||\vec n|}
\quad\text{（线面角）}.
\]

### 11.6 曲面

球面：

\[
(x-x_0)^2+(y-y_0)^2+(z-z_0)^2=R^2.
\]

圆柱面：

\[
x^2+y^2=R^2.
\]

旋转抛物面：

\[
z=x^2+y^2.
\]

椭球面：

\[
\frac{x^2}{a^2}+\frac{y^2}{b^2}+\frac{z^2}{c^2}=1.
\]

## 结语

向量代数与空间解析几何的核心是“几何关系代数化”：

1. **向量**：用坐标表示大小和方向；
2. **数量积**：处理夹角、投影、垂直和功；
3. **向量积**：处理垂直方向、面积和法向量；
4. **平面**：点 + 法向量；
5. **直线**：点 + 方向向量；
6. **曲面与曲线**：先看方程结构，再用截痕和投影理解形状。

做题时先画草图，把“平行、垂直、相交、异面”翻译成向量关系，再代入公式，最后检查符号和绝对值。
