## 一、导数到底是什么

### 1.1 从平均变化率到瞬时变化率

先看一个最直观的例子。物体自由落体，位移 `s(t) = t²`（单位：米；时间：秒）。从时刻 `t₀` 到 `t₀ + Δt`，平均速度是：

`平均速度 = [s(t₀ + Δt) - s(t₀)] / Δt`

取 `t₀ = 2`，有：

`[s(2 + Δt) - s(2)] / Δt = [(2 + Δt)² - 4] / Δt = (4 + 4Δt + Δt² - 4) / Δt = 4 + Δt`

当 `Δt` 越来越接近 0，平均速度越来越接近 4。这个“让时间间隔趋于 0 后的极限”就是瞬时速度，也就是导数：

`v(2) = lim_{Δt→0} [s(2 + Δt) - s(2)] / Δt = 4`

所以，导数最朴素的意思就是：**函数在某一点附近的变化快慢**。平均变化率是“一段路”，导数是“某一瞬间”。

### 1.2 导数的定义

设函数 `y = f(x)` 在 `x₀` 的某个邻域内有定义。如果下面的极限存在：

`f'(x₀) = lim_{Δx→0} [f(x₀ + Δx) - f(x₀)] / Δx`

就称 `f(x)` 在 `x₀` 处可导，这个极限值就是 `f(x)` 在 `x₀` 处的导数。

等价的写法是：

`f'(x₀) = lim_{x→x₀} [f(x) - f(x₀)] / (x - x₀)`

如果把 `x₀` 换成任意的 `x`，就得到导函数：

`f'(x) = lim_{Δx→0} [f(x + Δx) - f(x)] / Δx`

注意区分两个概念：

- `f'(x)` 是**导函数**，本质上是一个函数。
- `f'(x₀)` 是**导数值**，本质上是一个数。

### 1.3 几何意义

在曲线 `y = f(x)` 上取两点 `P(x₀, f(x₀))` 和 `Q(x₀ + Δx, f(x₀ + Δx))`，割线 `PQ` 的斜率是：

`k_PQ = [f(x₀ + Δx) - f(x₀)] / Δx`

当 `Δx → 0` 时，点 `Q` 沿着曲线靠近点 `P`，割线趋于切线。因此：

**导数 `f'(x₀)` 就是曲线在点 `P` 处切线的斜率。**

切线方程：

`y - f(x₀) = f'(x₀)(x - x₀)`

法线方程（当 `f'(x₀) ≠ 0` 时）：

`y - f(x₀) = -[1 / f'(x₀)](x - x₀)`

如果 `f'(x₀) = 0`，切线是水平线 `y = f(x₀)`，法线是竖直线 `x = x₀`。

导数的符号还能告诉我们曲线的走向：

- `f'(x) > 0`：曲线在该点附近上升。
- `f'(x) < 0`：曲线在该点附近下降。
- `f'(x) = 0`：切线水平，可能是极值点，也可能只是“拐一下”。

### 1.4 物理意义

导数在物理中就是“变化率”：

- 位移对时间求导：`s'(t) = v(t)`，速度。
- 速度对时间求导：`v'(t) = a(t)`，加速度。
- 电荷对时间求导：`q'(t) = i(t)`，电流。
- 功对时间求导：`W'(t) = P(t)`，功率。
- 浓度对时间求导：反应速率。

更一般地说，只要一个量随另一个量变化，导数就描述“前者相对后者变化得有多快”。

### 1.5 可导与连续的关系

重要结论：

**函数在某点可导，则它在该点一定连续；但连续不一定可导。**

直观理解：可导要求曲线在该点足够“光滑”，不能断开；但连续只要求曲线不断开，允许出现尖角、竖直切线或剧烈振荡。

证明思路：若 `f'(x₀)` 存在，则

`Δy = f(x₀ + Δx) - f(x₀) = ([f(x₀ + Δx) - f(x₀)] / Δx) · Δx → f'(x₀) · 0 = 0`

所以 `Δx → 0` 时 `Δy → 0`，即 `f(x)` 在 `x₀` 连续。

反过来不成立，常见反例见 1.7 节。

### 1.6 左右导数

有些函数在一点的两侧“走势”不同，需要分别看左、右导数：

左导数：

`f'_-(x₀) = lim_{Δx→0⁻} [f(x₀ + Δx) - f(x₀)] / Δx`

右导数：

`f'_+(x₀) = lim_{Δx→0⁺} [f(x₀ + Δx) - f(x₀)] / Δx`

结论：

**`f(x)` 在 `x₀` 处可导，当且仅当左导数和右导数都存在且相等。**

例如 `f(x) = abs(x)` 在 `x = 0` 处：

- 左导数：`lim_{Δx→0⁻} (abs(Δx) - 0) / Δx = -1`
- 右导数：`lim_{Δx→0⁺} (abs(Δx) - 0) / Δx = 1`

左右导数不相等，所以 `abs(x)` 在 `0` 处不可导。

分段函数在分界点处，必须特别检查左右导数。例如：

`f(x) = x² (x ≤ 1)`，`f(x) = ax + b (x > 1)`

若要 `f(x)` 在 `x = 1` 处可导，先要连续：

`1 = a + b`

再要左右导数相等：

- 左导数：`(x²)'` 在 `x = 1` 处为 `2`。
- 右导数：`(ax + b)' = a`。

所以 `a = 2`，再由连续性得 `b = -1`。

### 1.7 常见不可导的情况

**第一类：尖点。**

`f(x) = abs(x)` 在 `x = 0` 处，左导数为 `-1`，右导数为 `1`，不相等。

**第二类：竖直切线。**

`f(x) = x^(1/3)` 在 `x = 0` 处连续，但差商：

`[f(Δx) - f(0)] / Δx = (Δx)^(1/3) / Δx = 1 / (Δx)^(2/3) → +∞`

导数不存在（趋于无穷），曲线在该点有竖直切线。

**第三类：间断点。**

函数在该点不连续，自然不可导。例如阶跃函数在跳变点处。

**第四类：剧烈振荡。**

例如 `f(x) = x sin(1/x)`（`x ≠ 0`），规定 `f(0) = 0`。它在 `0` 处连续，但差商：

`[f(0 + h) - f(0)] / h = sin(1/h)`

当 `h → 0` 时没有极限，所以不可导。

更高级的例子是魏尔斯特拉斯函数：它处处连续，却处处不可导。这说明“连续”离“光滑”还很远。

### 1.8 导数的记号

| 记号 | 读法 | 含义 |
|---|---|---|
| `f'(x)` | f prime x | 导函数 |
| `y'` | y prime | `y` 对 `x` 的导数 |
| `dy/dx` | d y d x | 莱布尼茨记号，表示 `y` 对 `x` 的导数 |
| `d/dx f(x)` | d over dx of f | 对 `f(x)` 施加求导运算 |
| `f'(x₀)` | f prime at x zero | 在 `x₀` 处的导数值，是一个数 |
| `f^(n)(x)` | f n-th derivative | `f` 的 `n` 阶导数 |
| `d²y/dx²` | d squared y d x squared | 二阶导数 |

需要提醒：`dy/dx` 是一个整体记号，不是普通分数。但在微分形式下，`dy = f'(x) dx`，它可以像分数一样参与运算，这正是链式法则看起来像“约分”的原因。

### 2.5 几个特别常用的“组合型”导数

下面这些公式本质上都是链式法则，但出现频率极高，可以当成二级结论：

`(e^{f(x)})' = e^{f(x)} f'(x)`

`(a^{f(x)})' = a^{f(x)} ln a · f'(x)`

`(ln f(x))' = f'(x) / f(x)`（要求 `f(x) > 0`）

`(ln abs(f(x)))' = f'(x) / f(x)`（要求 `f(x) ≠ 0`）

`(√f(x))' = f'(x) / (2√f(x))`（要求 `f(x) > 0`）

`(1/f(x))' = -f'(x) / f²(x)`（要求 `f(x) ≠ 0`）

`(abs(f(x)))' = [f(x)/abs(f(x))] · f'(x)`（要求 `f(x) ≠ 0`）

## 三、四则运算求导法则

### 3.1 常数倍法则

`(C f(x))' = C f'(x)`

常数可以提到导数外面。例如：

`(3x²)' = 3 · 2x = 6x`

### 3.2 和差法则

`(u ± v)' = u' ± v'`

可以推广到任意有限项：

`(u₁ + u₂ + ... + uₙ)' = u₁' + u₂' + ... + uₙ'`

例如：

`(3x² - 2x + 5)' = 6x - 2`

和差法则是四则运算中最“省事”的：可以逐项求导，再保持加减号。

### 3.3 乘积法则

若 `u = u(x)`，`v = v(x)`，则：

`(uv)' = u'v + uv'`

口诀：**前导后不导，加前不导后导。**

三个函数相乘时：

`(uvw)' = u'vw + uv'w + uvw'`

一般地，`n` 个函数相乘，每次只对其中一个求导，其余保持不变，然后把所有情况相加：

`(u₁u₂...uₙ)' = Σᵢ u₁...uᵢ'...uₙ`

例子：

`(x² eˣ)' = 2x eˣ + x² eˣ = x eˣ(x + 2)`

`(x sin x)' = sin x + x cos x`

`((x²+1)(x³-2))' = 2x(x³-2) + 3x²(x²+1) = 5x⁴ + 3x² - 4x`

### 3.4 商法则

若 `v(x) ≠ 0`，则：

`(u/v)' = (u'v - uv') / v²`

口诀：**上导下不导，减上不导下导，除以分母平方。**

特别地，倒数函数的导数：

`(1/v)' = -v'/v²`

例子：

`(sin x / x)' = (x cos x - sin x) / x²`

`((x²+1)/(x-1))' = [(2x)(x-1) - (x²+1)] / (x-1)² = (x² - 2x - 1) / (x-1)²`

商法则的分子顺序不能反：是“上导下不导”减去“上不导下导”，不是反过来。

### 3.5 四则法则最容易错的地方

最常见的两个错误：

`(uv)' ≠ u'v'`

`(u/v)' ≠ u'/v'`

只有和差法则可以“拆开分别求导”。乘积和商必须使用对应公式。

另外，常数倍可以提出来，但“常数加”不能提出来：

`(C f)' = C f'`

`(C + f)' = f'`

## 四、复合函数求导：链式法则（重点）

### 4.1 一句话理解

复合函数就是“函数套函数”。例如 `sin(x²)` 是“先平方，再取正弦”；`e^{3x}` 是“先乘 3，再取指数”。

链式法则的一句话版本：

**外层函数对它的输入求导，再乘以内层函数对 `x` 的导数。**

可以想象成齿轮传动：内层齿轮转一圈，带动外层齿轮转若干圈；总传动比等于各级传动比相乘。

### 4.2 链式法则公式

设 `y = f(u)`，`u = g(x)`，且 `g` 在 `x` 处可导，`f` 在 `u = g(x)` 处可导，则：

`dy/dx = dy/du · du/dx`

写成函数形式：

`[f(g(x))]' = f'(g(x)) · g'(x)`

口诀：**由外向内，逐层求导，层层相乘。**

注意：链式法则是“乘”，不是“加”；也不是把内外层导数分别算出来就结束了，内层导数必须乘上去。

### 4.3 多层复合

如果是三层复合：

`y = f(g(h(x)))`

则：

`y' = f'(g(h(x))) · g'(h(x)) · h'(x)`

更多层同理，像剥洋葱一样，从最外层开始，一层一层向里求导，最后把所有层的导数乘起来。

### 4.4 怎样判断外层和内层

判断方法：**从最外层开始看，问自己“这个函数最外面在做什么运算”。**

- `sin(3x² + 1)`：最外层是 `sin`，内层是 `3x² + 1`。
- `e^{cos x}`：最外层是 `e^u`，内层是 `cos x`。
- `ln(√(x²+1))`：最外层是 `ln`，中间层是 `√u`，最内层是 `x² + 1`。
- `(1 + sin x)^4`：最外层是 `u⁴`，内层是 `1 + sin x`。
- `arctan(2x)`：最外层是 `arctan`，内层是 `2x`。

先识别结构，再动笔，比一上来就套公式更不容易错。

### 4.5 典型例题

**例 1：** `y = (2x + 3)^5`

外层是 `u^5`，内层是 `u = 2x + 3`：

`y' = 5(2x + 3)^4 · 2 = 10(2x + 3)^4`

**例 2：** `y = sin(x²)`

外层是 `sin u`，内层是 `u = x²`：

`y' = cos(x²) · 2x = 2x cos(x²)`

**例 3：** `y = e^{3x}`

`y' = e^{3x} · 3 = 3e^{3x}`

**例 4：** `y = ln(cos x)`

`y' = (1/cos x) · (-sin x) = -tan x`

**例 5：** `y = √(1 + x²)`

`y' = [1/(2√(1 + x²))] · 2x = x/√(1 + x²)`

**例 6：** `y = arctan(2x)`

`y' = [1/(1 + (2x)²)] · 2 = 2/(1 + 4x²)`

**例 7：** `y = sin²x`

这里 `sin²x` 表示 `(sin x)²`，外层是平方，内层是 `sin x`：

`y' = 2 sin x · cos x = sin 2x`

**例 8：** `y = e^{sin(x²)}`

三层复合：外层 `e^u`，中层 `sin v`，内层 `v = x²`：

`y' = e^{sin(x²)} · cos(x²) · 2x = 2x cos(x²) e^{sin(x²)}`

**例 9：** `y = ln(√(x² + 1))`

可以先化简：`ln(√(x²+1)) = (1/2)ln(x²+1)`，所以：

`y' = (1/2) · [2x/(x²+1)] = x/(x²+1)`

也可以直接三层求导，结果相同。

**例 10：** `y = a^{x²}`

`y' = a^{x²} ln a · 2x = 2x a^{x²} ln a`

**例 11：** `y = (1 + sin x)^4`

`y' = 4(1 + sin x)^3 · cos x`

**例 12：** `y = cos(1/x)`

`y' = -sin(1/x) · (-1/x²) = sin(1/x)/x²`

**例 13：** `y = √(sin x)`

`y' = [1/(2√(sin x))] · cos x = cos x/(2√(sin x))`

**例 14：** `y = ln(ln x)`

`y' = (1/ln x) · (1/x) = 1/(x ln x)`，要求 `x > 1`。

**例 15：** `y = tan(3x)`

`y' = sec²(3x) · 3 = 3sec²(3x)`

### 4.6 复合函数与四则运算：区别对照表

| 结构 | 例子 | 使用的法则 | 结果 |
|---|---|---|---|
| 和差 | `x² + sin x` | 和差法则 | `2x + cos x` |
| 常数倍 | `3x²` | 常数倍法则 | `6x` |
| 乘积 | `x² sin x` | 乘积法则 | `2x sin x + x² cos x` |
| 商 | `sin x / x` | 商法则 | `(x cos x - sin x)/x²` |
| 复合 | `sin(x²)` | 链式法则 | `2x cos(x²)` |
| 乘积加复合 | `x² e^{3x}` | 先乘积，再链式 | `2x e^{3x} + 3x² e^{3x}` |
| 商加复合 | `e^{2x}/(x+1)` | 先商，再链式 | `[2e^{2x}(x+1) - e^{2x}]/(x+1)²` |

最核心的区别：

- **四则运算**处理的是“函数与函数之间的加、减、乘、除”，法则是“分别求导后加减”或“按乘积/商公式组合”。
- **复合函数**处理的是“函数套函数”，法则是“外层导数乘以内层导数”。

### 4.7 最容易混淆的几组写法

| 表达式 | 含义 | 导数 |
|---|---|---|
| `sin(x²)` | 先平方，再取正弦 | `2x cos(x²)` |
| `sin²x` | 先取正弦，再平方 | `2 sin x cos x = sin 2x` |
| `sin(2x)` | 先乘 2，再取正弦 | `2 cos(2x)` |
| `e^{x²}` | 指数是 `x²` | `2x e^{x²}` |
| `(eˣ)²` | 等于 `e^{2x}` | `2e^{2x}` |
| `ln(x²)` | 先平方，再取对数 | `2/x` |
| `(ln x)²` | 先取对数，再平方 | `2 ln x / x` |
| `√(x²+1)` | 根号里是 `x²+1` | `x/√(x²+1)` |
| `(√x)² + 1` | 化简后等于 `x+1`（`x ≥ 0`） | `1` |

这组对比非常重要。很多错误不是不会公式，而是**看错了函数结构**。

### 4.8 链式法则为什么成立

直观推导：当 `x` 有一个很小的变化 `Δx` 时，`u = g(x)` 先产生变化：

`Δu ≈ g'(x) Δx`

然后 `y = f(u)` 再根据 `Δu` 产生变化：

`Δy ≈ f'(u) Δu`

把第一式代入第二式：

`Δy ≈ f'(u) g'(x) Δx`

两边除以 `Δx` 并令 `Δx → 0`，就得到：

`dy/dx = f'(u) g'(x)`

严格证明需要处理 `Δu = 0` 等细节，但核心思想就是“变化率的接力”：内层把 `x` 的变化放大 `g'(x)` 倍，外层再把 `u` 的变化放大 `f'(u)` 倍，总放大倍数就是两者相乘。

### 4.9 用微分理解链式法则

因为 `dy = f'(u) du`，而 `du = g'(x) dx`，所以：

`dy = f'(u) g'(x) dx`

于是：

`dy/dx = f'(u) g'(x)`

这就是一阶微分形式不变性：无论 `u` 是自变量还是中间变量，`dy = f'(u) du` 的形式都一样。链式法则之所以看起来像“分数约分”，原因就在这里。

### 4.10 复合函数的高阶导数

复合函数的高阶导数没有像一阶链式法则那样简单的统一公式，通常要反复使用乘积法则和链式法则。

例如 `y = sin(x²)`：

`y' = 2x cos(x²)`

再求一次导：

`y'' = 2 cos(x²) + 2x · [-sin(x²) · 2x] = 2 cos(x²) - 4x² sin(x²)`

又如 `y = e^{2x}`：

`y^(n) = 2ⁿ e^{2x}`

高阶导数在泰勒展开、物理振动和数值分析中非常重要，后面还会专门讲。

## 五、其他常用求导方法

除了直接套基本公式、四则法则和链式法则，还有一些“特殊结构”需要专门方法。

### 5.1 隐函数求导

当函数关系写成 `F(x, y) = 0`，而不是显式的 `y = f(x)` 时，可以用隐函数求导。

方法：**把 `y` 看成 `x` 的函数 `y(x)`，等式两边同时对 `x` 求导，遇到 `y` 时用链式法则，最后解出 `y'`。**

**例 1：** `x² + y² = 25`

两边对 `x` 求导：

`2x + 2y y' = 0`

所以：

`y' = -x/y`（`y ≠ 0`）

继续求二阶导：

`y'' = -(y - x y')/y²`

代入 `y' = -x/y`：

`y'' = -(y + x²/y)/y² = -(x² + y²)/y³ = -25/y³`

**例 2：** `x² + xy + y² = 3`

两边对 `x` 求导：

`2x + y + x y' + 2y y' = 0`

整理：

`y'(x + 2y) = -(2x + y)`

所以：

`y' = -(2x + y)/(x + 2y)`

隐函数求导也可以写成公式：

`dy/dx = -F_x/F_y`（要求 `F_y ≠ 0`）

其中 `F_x` 是把 `y` 当常数对 `x` 求偏导，`F_y` 是把 `x` 当常数对 `y` 求偏导。这个公式在多元微积分中会正式证明。

### 5.2 对数求导法

当函数是“很多因子相乘除”或“底数和指数都含 `x`”时，先取对数往往更简单。

适用场景：

- 幂指函数，如 `xˣ`、`(sin x)^x`。
- 多个因子连乘、连除，如 `x²√(x+1)/(x-2)³`。
- 指数上有复杂表达式。

步骤：

1. 两边取对数，尽量写成加减形式。
2. 两边对 `x` 求导，左边得到 `y'/y`。
3. 解出 `y'`，再把 `y` 代回去。

**例 1：** `y = xˣ`（`x > 0`）

取对数：

`ln y = x ln x`

两边求导：

`y'/y = ln x + x · (1/x) = ln x + 1`

所以：

`y' = xˣ(ln x + 1)`

**例 2：** `y = (sin x)^x`（`sin x > 0`）

取对数：

`ln y = x ln(sin x)`

求导：

`y'/y = ln(sin x) + x · (cos x/sin x) = ln(sin x) + x cot x`

所以：

`y' = (sin x)^x [ln(sin x) + x cot x]`

**例 3：** `y = x²√(x+1)/(x-2)³`

取对数：

`ln abs(y) = 2 ln abs(x) + (1/2)ln abs(x+1) - 3 ln abs(x-2)`

求导：

`y'/y = 2/x + 1/[2(x+1)] - 3/(x-2)`

因此：

`y' = y · [2/x + 1/(2(x+1)) - 3/(x-2)]`

对数求导法特别适合“乘除很多”的函数，因为取对数能把乘除变成加减。

### 5.3 参数方程求导

如果曲线由参数方程给出：

`x = x(t)`，`y = y(t)`

且 `x'(t) ≠ 0`，则：

`dy/dx = (dy/dt)/(dx/dt) = y'(t)/x'(t)`

二阶导数公式：

`d²y/dx² = (x'y'' - y'x'')/(x')³`

注意：二阶导数**不是** `y''/x''`，必须使用上面的公式，或者先求出 `dy/dx` 再对 `t` 求导并除以 `x'(t)`。

**例：** `x = t²`，`y = t³`

`dy/dx = (3t²)/(2t) = (3/2)t`（`t ≠ 0`）

二阶导数：

`d²y/dx² = (d/dt[(3/2)t])/(dx/dt) = (3/2)/(2t) = 3/(4t)`

**例：** `x = t - sin t`，`y = 1 - cos t`

`dy/dx = sin t/(1 - cos t) = cot(t/2)`

再求二阶导：

`d²y/dx² = [d/dt cot(t/2)]/(1 - cos t) = [-(1/2)csc²(t/2)]/[2sin²(t/2)] = -1/[4sin⁴(t/2)]`

参数方程在物理学中很常见，例如抛体运动、摆线、行星轨道等。

### 5.4 反函数求导

如果 `y = f(x)` 在 `x` 处可导且 `f'(x) ≠ 0`，它的反函数 `x = f⁻¹(y)` 在对应点可导，并且：

`(f⁻¹)'(y) = 1/f'(x)`

几何意义：原函数与反函数的图像关于 `y = x` 对称，切线斜率互为倒数。

**例 1：** `y = arcsin x`

设 `x = sin y`，则：

`dx/dy = cos y = √(1 - sin²y) = √(1 - x²)`

所以：

`dy/dx = 1/√(1 - x²)`

**例 2：** `y = x³`，反函数 `x = y^(1/3)`

`dx/dy = 1/(3y^(2/3))`

这也说明为什么 `x^(1/3)` 在 `x = 0` 处导数为无穷大：原函数 `y = x³` 在 `x = 0` 处切线水平，反函数在对应点切线竖直。

二阶导数公式（了解即可）：

`(f⁻¹)''(y) = -f''(x)/[f'(x)]³`

### 5.5 分段函数在分界点求导

分段函数在每一段内部通常可以直接求导，但在分界点必须特别小心。标准步骤：

1. 先检查分界点处是否连续。不连续一定不可导。
2. 分别计算左导数和右导数，建议用定义计算。
3. 左右导数都存在且相等，才可导；否则不可导。

**例：** `f(x) = x² (x ≤ 1)`，`f(x) = ax + b (x > 1)`

连续性要求：

`1 = a + b`

左导数：

`f'_-(1) = lim_{h→0⁻} [(1+h)² - 1]/h = 2`

右导数：

`f'_+(1) = a`

所以 `a = 2`，`b = -1`。

**更微妙的例子：** `f(x) = x² sin(1/x)`（`x ≠ 0`），`f(0) = 0`。

在 `0` 处：

`f'(0) = lim_{h→0} [h² sin(1/h) - 0]/h = lim_{h→0} h sin(1/h) = 0`

所以它在 `0` 处可导。但当 `x ≠ 0` 时：

`f'(x) = 2x sin(1/x) - cos(1/x)`

当 `x → 0` 时，`cos(1/x)` 不停振荡，`f'(x)` 没有极限。因此：**函数处处可导，并不意味着导函数连续。** 这是高等微积分中非常重要的反例。

### 5.6 含绝对值函数的求导

基本公式：

`(abs(x))' = x/abs(x)`（`x ≠ 0`）

更一般地，若 `g(x) ≠ 0`，则：

`(abs(g(x)))' = [g(x)/abs(g(x))] · g'(x)`

在 `g(x) = 0` 的点，必须单独用左右导数判断，不能直接套公式。

**例：** `y = abs(x² - 1)`

可以分段：

- 当 `abs(x) > 1` 时，`y = x² - 1`，`y' = 2x`。
- 当 `abs(x) < 1` 时，`y = 1 - x²`，`y' = -2x`。
- 在 `x = 1` 和 `x = -1` 处，函数有尖角，不可导。

含绝对值的函数，最稳妥的方法就是先分段去掉绝对值，再分别求导。

### 5.7 高阶导数

二阶导数是一阶导数的导数：

`f''(x) = (f'(x))'`

类似地，`n` 阶导数是：

`f^(n)(x) = (f^(n-1)(x))'`

常见函数的 `n` 阶导数：

| 函数 | `n` 阶导数 |
|---|---|
| `x^m` | `m(m-1)...(m-n+1)x^(m-n)`（`n ≤ m`） |
| `e^{ax}` | `aⁿ e^{ax}` |
| `aˣ` | `aˣ (ln a)ⁿ` |
| `sin x` | `sin(x + nπ/2)` |
| `cos x` | `cos(x + nπ/2)` |
| `ln x` | `(-1)^(n-1) (n-1)! / xⁿ` |
| `1/x` | `(-1)ⁿ n! / x^(n+1)` |

**例：** `y = x eˣ`

`y' = eˣ + x eˣ = eˣ(x + 1)`

`y'' = eˣ(x + 1) + eˣ = eˣ(x + 2)`

可以归纳出：

`y^(n) = eˣ(x + n)`

注意：一阶导数存在，不代表二阶导数存在。例如 `f(x) = x abs(x)` 在 `0` 处一阶可导，但二阶导数不存在。

### 5.8 莱布尼茨公式

两个函数乘积的 `n` 阶导数，有类似二项式展开的公式：

`(uv)^(n) = Σ_{k=0}^{n} C(n,k) u^(k) v^(n-k)`

其中 `C(n,k)` 是组合数，`u^(0) = u`，`v^(0) = v`。

**例：** 求 `(x² eˣ)^(n)`。

因为 `x²` 的三阶及以上导数都是 0，所以只需看前三项：

- `k = 0`：`x² eˣ`
- `k = 1`：`n · 2x · eˣ`
- `k = 2`：`C(n,2) · 2 · eˣ = n(n-1)eˣ`

所以：

`(x² eˣ)^(n) = eˣ[x² + 2nx + n(n-1)]`

莱布尼茨公式在求高阶导数、泰勒系数和微分方程中很有用。

### 5.9 用定义求导

以下情况优先考虑用定义：

- 分段函数在分界点。
- 含绝对值的函数在零点。
- 题目给出抽象函数或只给某点信息。
- 需要证明某点可导或不可导。
- 差商形式的极限题。

**例 1：** 用定义求 `f(x) = x²` 在 `x = 2` 处的导数。

`f'(2) = lim_{h→0} [(2+h)² - 4]/h = lim_{h→0} (4h + h²)/h = 4`

**例 2：** 若 `f(0) = 0`，`f'(0) = 2`，求 `lim_{x→0} f(x)/x`。

因为：

`f'(0) = lim_{x→0} [f(x) - f(0)]/(x - 0) = lim_{x→0} f(x)/x`

所以答案是 `2`。

**例 3：** 若 `f'(x₀)` 存在，求 `lim_{h→0} [f(x₀ + 2h) - f(x₀)]/h`。

把 `2h` 看成一个整体：

`lim_{h→0} [f(x₀ + 2h) - f(x₀)]/(2h) · 2 = 2f'(x₀)`

这类题的关键是“凑出导数的定义式”。

### 5.10 求导方法选择流程

```text
拿到一个函数
├─ 是基本初等函数？        → 直接查基本导数表
├─ 是加减结构？            → 逐项求导
├─ 是常数倍？              → 常数提到外面
├─ 是乘积？                → 乘积法则
├─ 是商？                  → 商法则
├─ 是函数套函数？          → 链式法则（由外向内）
├─ 是隐函数？              → 两边对 x 求导，解出 y'
├─ 是参数方程？            → dy/dx = y'(t)/x'(t)
├─ 是幂指函数？            → 对数求导法
├─ 是分段点或绝对值零点？  → 用定义或左右导数
└─ 是抽象函数？            → 凑导数定义
```

实际做题时，一个函数往往同时包含多种结构。原则是：**先看整体结构，再局部处理；从最外层开始，逐层拆解。**

## 六、微分与近似

### 6.1 微分是什么

如果 `y = f(x)` 在 `x` 处可导，当自变量有微小增量 `Δx` 时，函数增量为：

`Δy = f(x + Δx) - f(x)`

它可以写成：

`Δy = f'(x)Δx + o(Δx)`

其中 `f'(x)Δx` 是 `Δy` 的线性主部，称为函数在 `x` 处的微分，记作：

`dy = f'(x)dx`

这里 `dx = Δx`。所以：

`dy/dx = f'(x)`

微分和导数的区别：

- 导数 `f'(x)` 是变化率，是一个“倍数”。
- 微分 `dy` 是变化量的线性近似，是一个“增量”。

**例：** `y = x²`，在 `x = 1` 处，取 `Δx = 0.01`。

`dy = 2x dx = 2 × 1 × 0.01 = 0.02`

实际增量：

`Δy = (1.01)² - 1² = 1.0201 - 1 = 0.0201`

`dy` 与 `Δy` 非常接近，误差是 `0.0001`，属于 `o(Δx)`。

### 6.2 一阶微分形式不变性

无论 `u` 是自变量还是中间变量，一阶微分都满足：

`dy = f'(u)du`

例如 `y = sin(u)`，则 `dy = cos(u)du`。如果 `u = 3x`，则 `du = 3dx`，于是 `dy = 3cos(3x)dx`，这与链式法则完全一致。

一阶微分形式不变性是换元积分、隐函数求导和链式法则的共同基础。

### 6.3 线性近似

当 `Δx` 很小时：

`f(x₀ + Δx) ≈ f(x₀) + f'(x₀)Δx`

这就是用切线代替曲线，也叫一阶泰勒近似。

**例 1：** 估算 `√1.02`。

取 `f(x) = √x`，`x₀ = 1`，`Δx = 0.02`，`f'(1) = 1/2`：

`√1.02 ≈ 1 + (1/2)(0.02) = 1.01`

实际值约为 `1.00995`，非常接近。

**例 2：** 估算 `sin 0.01`。

取 `f(x) = sin x`，`x₀ = 0`，`f'(0) = 1`：

`sin 0.01 ≈ 0 + 1 × 0.01 = 0.01`

**例 3：** 估算 `ln 1.01`。

取 `f(x) = ln x`，`x₀ = 1`，`f'(1) = 1`：

`ln 1.01 ≈ 0 + 1 × 0.01 = 0.01`

### 6.4 误差估计

若测量量 `x` 有误差 `dx`，由 `y = f(x)` 计算出的 `y` 的误差近似为：

`dy = f'(x)dx`

相对误差：

`dy/y = [f'(x)/f(x)]dx`

**例：** 球的体积 `V = (4/3)πr³`。

`dV = 4πr² dr`

相对误差：

`dV/V = (4πr² dr)/[(4/3)πr³] = 3(dr/r)`

也就是说，半径的相对误差会被体积放大 3 倍。这类“误差传播”在实验物理和工程中非常重要。

### 6.5 使用近似时的注意事项

- `Δx` 必须足够小，否则线性近似误差会很大。
- 近似点应选在容易计算、且函数性质良好的地方。
- 需要更高精度时，可以使用二阶或更高阶泰勒展开。
- 注意单位和定义域，尤其是根号、对数、反三角函数。

## 七、导数与函数性态

### 7.1 单调性

设 `f(x)` 在区间 `I` 上可导：

- 若在 `I` 上 `f'(x) > 0`，则 `f(x)` 在 `I` 上严格递增。
- 若在 `I` 上 `f'(x) < 0`，则 `f(x)` 在 `I` 上严格递减。
- 若在 `I` 上 `f'(x) = 0`，则 `f(x)` 在 `I` 上为常数。

更精细的结论：如果 `f'(x) ≥ 0`，且 `f'(x) = 0` 的点是孤立的，那么 `f(x)` 仍然严格递增；递减同理。

**例：** `f(x) = x³ - 3x`

`f'(x) = 3x² - 3 = 3(x - 1)(x + 1)`

符号分析：

- `x < -1`：`f'(x) > 0`，递增。
- `-1 < x < 1`：`f'(x) < 0`，递减。
- `x > 1`：`f'(x) > 0`，递增。

所以单调递增区间是 `(-∞, -1)` 和 `(1, +∞)`，单调递减区间是 `(-1, 1)`。

注意：单调区间通常分开写，不要随意写成并集，因为函数在 `(-∞, -1)` 和 `(1, +∞)` 之间并不是一直递增的。

### 7.2 极值

**必要条件：** 若 `f(x)` 在 `x₀` 处可导，且在 `x₀` 处取得局部极值，则：

`f'(x₀) = 0`

满足 `f'(x₀) = 0` 的点叫驻点。但驻点不一定是极值点，例如 `f(x) = x³` 在 `x = 0` 处导数为 0，却不是极值点。

此外，极值也可能出现在导数不存在的点，例如 `f(x) = abs(x)` 在 `x = 0` 处。

所以，**可能的极值点 = 驻点 + 导数不存在的点**。

**一阶导数判别法：**

| `f'(x)` 在 `x₀` 两侧的符号 | 结论 |
|---|---|
| 由正变负 | 局部极大值 |
| 由负变正 | 局部极小值 |
| 符号不变 | 不是极值点 |

**二阶导数判别法：**

若 `f'(x₀) = 0`：

- `f''(x₀) > 0`：局部极小值（曲线开口向上）。
- `f''(x₀) < 0`：局部极大值（曲线开口向下）。
- `f''(x₀) = 0`：无法判断，需要改用一阶导数判别法或更高阶导数。

**例：** `f(x) = x³ - 3x`

`f'(x) = 3(x - 1)(x + 1)`，驻点为 `x = -1` 和 `x = 1`。

`f''(x) = 6x`

- `f''(-1) = -6 < 0`，所以 `x = -1` 是局部极大值，极大值为 `f(-1) = 2`。
- `f''(1) = 6 > 0`，所以 `x = 1` 是局部极小值，极小值为 `f(1) = -2`。

### 7.3 闭区间上的最值

求 `f(x)` 在闭区间 `[a, b]` 上的最大值和最小值，步骤：

1. 求 `f'(x)`，找出区间内的驻点和导数不存在的点。
2. 计算这些点以及端点 `a`、`b` 处的函数值。
3. 比较所有函数值，最大的是最大值，最小的是最小值。

**例：** 求 `f(x) = x³ - 3x` 在 `[-2, 2]` 上的最值。

驻点：`x = -1, 1`。

计算：

- `f(-2) = -8 + 6 = -2`
- `f(-1) = -1 + 3 = 2`
- `f(1) = 1 - 3 = -2`
- `f(2) = 8 - 6 = 2`

所以最大值为 `2`，最小值为 `-2`。

注意：局部极值和全局最值不是一回事。闭区间最值必须比较端点和所有可疑点。

### 7.4 凹凸性与拐点

设 `f(x)` 二阶可导：

- `f''(x) > 0`：曲线凹向上（开口向上，也称凸函数）。
- `f''(x) < 0`：曲线凹向下（开口向下，也称凹函数）。

拐点：曲线凹凸性发生改变的点。拐点处 `f''(x) = 0` 或 `f''(x)` 不存在，但这只是必要条件，不是充分条件。

**例 1：** `f(x) = x³`

`f''(x) = 6x`

- `x < 0`：`f''(x) < 0`，凹向下。
- `x > 0`：`f''(x) > 0`，凹向上。

所以 `(0, 0)` 是拐点。

**例 2：** `f(x) = x⁴`

`f''(x) = 12x²`，在 `x = 0` 处 `f''(0) = 0`，但 `f''(x)` 在两侧都大于 0，凹凸性没有改变，所以 `(0, 0)` 不是拐点。

### 7.5 渐近线

**竖直渐近线：** 若 `x → a` 时 `f(x) → ±∞`，则 `x = a` 是竖直渐近线。

**水平渐近线：** 若 `x → +∞` 或 `x → -∞` 时 `f(x) → b`，则 `y = b` 是水平渐近线。

**斜渐近线：** 若：

`k = lim_{x→±∞} f(x)/x`

存在且不为 0，并且：

`b = lim_{x→±∞} [f(x) - kx]`

存在，则 `y = kx + b` 是斜渐近线。

**例：** `f(x) = (x² + 1)/x = x + 1/x`

- 当 `x → 0` 时，`f(x) → ±∞`，所以 `x = 0` 是竖直渐近线。
- 当 `x → ±∞` 时，`f(x) - x = 1/x → 0`，所以 `y = x` 是斜渐近线。

### 7.6 切线与法线

曲线 `y = f(x)` 在点 `(x₀, f(x₀))` 处：

切线：

`y - f(x₀) = f'(x₀)(x - x₀)`

法线（`f'(x₀) ≠ 0`）：

`y - f(x₀) = -[1/f'(x₀)](x - x₀)`

**例：** 求 `y = x²` 在 `(1, 1)` 处的切线和法线。

`f'(x) = 2x`，所以 `f'(1) = 2`。

切线：

`y - 1 = 2(x - 1)`，即 `y = 2x - 1`

法线：

`y - 1 = -(1/2)(x - 1)`，即 `y = -x/2 + 3/2`

### 7.7 函数作图的基本步骤

1. 确定定义域。
2. 检查奇偶性、周期性。
3. 求与坐标轴的交点。
4. 求 `f'(x)`，确定单调区间和极值。
5. 求 `f''(x)`，确定凹凸区间和拐点。
6. 求渐近线。
7. 列表汇总，描点作图。

导数让我们不必大量描点，就能较准确地画出函数图像。

### 7.8 相关变化率

当两个量都随时间变化时，可以先建立它们之间的关系式，再对时间 `t` 求导。

**例：** 圆的面积 `A = πr²`，半径以 `dr/dt` 的速度变化，则：

`dA/dt = 2πr · dr/dt`

若 `r = 5`，`dr/dt = 2`，则：

`dA/dt = 2π × 5 × 2 = 20π`

相关变化率的关键是：**先写关系式，再对时间求导，最后代入已知量。**

### 7.9 曲率与曲率半径

导数还能描述曲线弯曲的程度。对于曲线 `y = f(x)`，曲率公式为：

`κ = abs(f''(x)) / [1 + (f'(x))²]^(3/2)`

曲率越大，曲线弯得越厉害；曲率越小，曲线越接近直线。曲率半径：

`R = 1/κ`（`κ ≠ 0`）

**例：** `y = x²` 在 `x = 0` 处，`y' = 0`，`y'' = 2`，所以：

`κ = 2/[1 + 0]^(3/2) = 2`

曲率半径为 `R = 1/2`。

圆的曲率处处等于半径的倒数：半径为 `r` 的圆，`κ = 1/r`。曲率在道路设计、光学镜片、计算机图形学和机器人路径规划中都有应用。

### 7.10 用导数证明不等式

导数可以用来证明不等式。基本思路是：

1. 把不等式移项，构造辅助函数 `F(x)`。
2. 求 `F'(x)`，判断单调性或求最小值。
3. 证明 `F(x) ≥ 0` 或 `F(x) ≤ 0`。

**例 1：证明 `eˣ ≥ 1 + x` 对任意实数 `x` 成立。**

令 `F(x) = eˣ - 1 - x`，则：

`F'(x) = eˣ - 1`

当 `x < 0` 时，`F'(x) < 0`；当 `x > 0` 时，`F'(x) > 0`。所以 `F(x)` 在 `x = 0` 处取得最小值：

`F(0) = 1 - 1 - 0 = 0`

因此 `F(x) ≥ 0`，即 `eˣ ≥ 1 + x`。

**例 2：证明 `ln(1 + x) ≤ x` 对 `x > -1` 成立。**

令 `F(x) = x - ln(1 + x)`，则：

`F'(x) = 1 - 1/(1 + x) = x/(1 + x)`

当 `-1 < x < 0` 时，`F'(x) < 0`；当 `x > 0` 时，`F'(x) > 0`。所以 `F(x)` 在 `x = 0` 处取得最小值 `F(0) = 0`，从而 `F(x) ≥ 0`。

### 7.11 用导数研究方程根的个数

研究方程 `f(x) = 0` 的实根个数，可以先分析函数的单调性、极值和两端趋势。

**例：** 讨论 `x³ - 3x + 1 = 0` 的实根个数。

令 `f(x) = x³ - 3x + 1`，则：

`f'(x) = 3x² - 3 = 3(x - 1)(x + 1)`

- 在 `x = -1` 处取得局部极大值 `f(-1) = 3`。
- 在 `x = 1` 处取得局部极小值 `f(1) = -1`。
- 当 `x → -∞` 时，`f(x) → -∞`；当 `x → +∞` 时，`f(x) → +∞`。

极大值为正、极小值为负，结合单调性可知，函数图像穿过 `x` 轴三次，所以方程有三个不同的实根。

## 八、中值定理、洛必达与泰勒

### 8.1 罗尔定理

若 `f(x)` 满足：

1. 在 `[a, b]` 上连续；
2. 在 `(a, b)` 内可导；
3. `f(a) = f(b)`；

则至少存在一点 `ξ ∈ (a, b)`，使得：

`f'(ξ) = 0`

几何意义：如果曲线两端高度相同，那么中间至少有一处切线水平。

### 8.2 拉格朗日中值定理

若 `f(x)` 在 `[a, b]` 上连续，在 `(a, b)` 内可导，则至少存在一点 `ξ ∈ (a, b)`，使得：

`f'(ξ) = [f(b) - f(a)]/(b - a)`

几何意义：曲线上至少有一点的切线，与连接两端点的割线平行。

**例：** `f(x) = x²` 在 `[1, 3]` 上。

`[f(3) - f(1)]/(3 - 1) = (9 - 1)/2 = 4`

令 `f'(ξ) = 2ξ = 4`，得 `ξ = 2`，确实在 `(1, 3)` 内。

常用推论：

- 若在区间上 `f'(x) = 0`，则 `f(x)` 为常数。
- 若在区间上 `f'(x) > 0`，则 `f(x)` 严格递增。
- 若 `abs(f'(x)) ≤ M`，则 `abs(f(b) - f(a)) ≤ M abs(b - a)`。

### 8.3 柯西中值定理

若 `f(x)`、`g(x)` 在 `[a, b]` 上连续，在 `(a, b)` 内可导，且 `g'(x) ≠ 0`，则至少存在一点 `ξ ∈ (a, b)`，使得：

`[f(b) - f(a)]/[g(b) - g(a)] = f'(ξ)/g'(ξ)`

它是拉格朗日中值定理的推广（取 `g(x) = x` 即可得到拉格朗日形式），也是洛必达法则的理论基础。

### 8.4 洛必达法则

对于 `0/0` 或 `∞/∞` 型未定式，在一定条件下可以转化为导数之比的极限：

`lim_{x→a} f(x)/g(x) = lim_{x→a} f'(x)/g'(x)`

使用条件（简化版）：

1. 原极限是 `0/0` 或 `∞/∞` 型。
2. `f`、`g` 在 `a` 附近可导，且 `g'(x) ≠ 0`。
3. 右边导数之比的极限存在或为 `±∞`。

**例 1：**

`lim_{x→0} sin x/x = lim_{x→0} cos x/1 = 1`

**例 2：**

`lim_{x→0} (eˣ - 1)/x = lim_{x→0} eˣ/1 = 1`

**例 3：**

`lim_{x→+∞} ln x/x = lim_{x→+∞} (1/x)/1 = 0`

**其他未定式：** `0·∞`、`∞-∞`、`1^∞`、`0⁰`、`∞⁰` 不能直接用洛必达，通常要先变形或取对数。

例如：

`lim_{x→0⁺} x ln x = lim_{x→0⁺} ln x/(1/x)`

这是 `∞/∞` 型，用洛必达得：

`lim_{x→0⁺} (1/x)/(-1/x²) = lim_{x→0⁺} (-x) = 0`

再如 `lim_{x→0⁺} xˣ`：

先取对数，`ln(xˣ) = x ln x → 0`，所以原极限为 `e⁰ = 1`。

使用洛必达的注意事项：

- 先检查类型，不是 `0/0` 或 `∞/∞` 不能用。
- 有时需要连续使用多次。
- 有时导数之比的极限不存在，但原极限存在，此时洛必达失效，应换方法。
- 不要对离散变量（如数列）直接使用洛必达，应先转化为连续函数。

### 8.5 泰勒公式

如果函数足够光滑，可以用多项式在某点附近近似它：

`f(x) = f(x₀) + f'(x₀)(x - x₀) + f''(x₀)/2! (x - x₀)² + ... + f^(n)(x₀)/n! (x - x₀)ⁿ + R_n(x)`

其中 `R_n(x)` 是余项。

带拉格朗日余项的泰勒公式：

`R_n(x) = f^(n+1)(ξ)/(n+1)! (x - x₀)^(n+1)`

其中 `ξ` 介于 `x₀` 和 `x` 之间。

当 `x₀ = 0` 时，称为麦克劳林公式。

泰勒公式的核心思想：**用函数在某点的各阶导数信息，重建函数在这一点附近的形状。**

### 8.6 常用麦克劳林展开

| 函数 | 展开式 | 收敛范围或备注 |
|---|---|---|
| `eˣ` | `1 + x + x²/2! + x³/3! + ...` | 全体实数 |
| `sin x` | `x - x³/3! + x⁵/5! - x⁷/7! + ...` | 全体实数 |
| `cos x` | `1 - x²/2! + x⁴/4! - x⁶/6! + ...` | 全体实数 |
| `ln(1+x)` | `x - x²/2 + x³/3 - x⁴/4 + ...` | `-1 < x ≤ 1` |
| `1/(1-x)` | `1 + x + x² + x³ + ...` | `abs(x) < 1` |
| `(1+x)^α` | `1 + αx + α(α-1)x²/2! + ...` | 视 `α` 而定，通常 `abs(x) < 1` |

**例：** 估算 `e^0.1`。

取前三项：

`e^0.1 ≈ 1 + 0.1 + 0.1²/2 = 1.105`

取前四项：

`e^0.1 ≈ 1 + 0.1 + 0.005 + 0.0001667 ≈ 1.1051667`

实际值约为 `1.1051709`，已经非常接近。

### 8.7 泰勒公式与导数的关系

一阶泰勒公式就是线性近似：

`f(x) ≈ f(x₀) + f'(x₀)(x - x₀)`

二阶泰勒公式加入了曲率信息：

`f(x) ≈ f(x₀) + f'(x₀)(x - x₀) + f''(x₀)/2 (x - x₀)²`

阶数越高，近似通常越精确，但计算量也越大。泰勒展开在极限、误差估计、数值计算和机器学习中都有广泛应用。

### 8.8 导数与积分、微分方程

导数与积分由微积分基本定理连接。若 `F'(x) = f(x)`，则：

`∫_a^b f(x)dx = F(b) - F(a)`

也就是说，**积分是导数的逆运算**：导数研究瞬时变化率，积分研究累积量。不定积分可以写成：

`∫ f(x)dx = F(x) + C`

导数还用于描述微分方程。例如：

`y' = ky`

的通解是：

`y = C e^{kx}`

它描述指数增长或指数衰减，例如人口增长、放射性衰变、复利和冷却过程。

二阶微分方程：

`y'' + ω²y = 0`

的通解是：

`y = A cos(ωx) + B sin(ωx)`

它描述简谐振动。导数是连接函数、变化率和物理规律的桥梁。

## 九、多元函数导数（拓展）

### 9.1 偏导数

对多元函数 `z = f(x, y)`，把 `y` 看成常数，对 `x` 求导，得到对 `x` 的偏导数：

`∂z/∂x = f_x(x, y)`

同理：

`∂z/∂y = f_y(x, y)`

**例：** `z = x²y + y³`

`z_x = 2xy`

`z_y = x² + 3y²`

偏导数描述的是“只让一个变量变化时，函数的变化率”。

### 9.2 全微分

若 `z = f(x, y)` 可微，则：

`dz = f_x dx + f_y dy`

全微分描述所有自变量同时微小变化时，函数的总变化量。

### 9.3 多元链式法则

若 `z = f(x, y)`，而 `x = x(t)`，`y = y(t)`，则：

`dz/dt = f_x · dx/dt + f_y · dy/dt`

**例：** `z = x² + y²`，`x = cos t`，`y = sin t`。

`dz/dt = 2x(-sin t) + 2y(cos t) = -2cos t sin t + 2sin t cos t = 0`

这符合直觉：`z = cos²t + sin²t = 1`，是常数，所以导数为 0。

### 9.4 梯度与方向导数

梯度定义为：

`∇f = (f_x, f_y)`

梯度方向是函数增长最快的方向，梯度的模是最大方向导数。

沿单位向量 `u = (cos θ, sin θ)` 的方向导数：

`D_u f = ∇f · u`

在机器学习中，梯度下降就是沿着负梯度方向更新参数：

`θ_new = θ - η ∇L(θ)`

其中 `η` 是学习率，`L` 是损失函数。

### 9.5 多元隐函数求导

若 `F(x, y, z) = 0` 确定隐函数 `z = z(x, y)`，且 `F_z ≠ 0`，则：

`z_x = -F_x/F_z`

`z_y = -F_y/F_z`

**例：** `x² + y² + z² = 1`。

`F_x = 2x`，`F_y = 2y`，`F_z = 2z`，所以：

`z_x = -x/z`，`z_y = -y/z`

### 9.6 多元极值与 Hessian 矩阵

多元函数在内部点取得极值的必要条件是：

`f_x = 0`，`f_y = 0`

这样的点称为驻点。判断驻点类型需要看二阶偏导数组成的 Hessian 矩阵：

`H = [[f_xx, f_xy], [f_xy, f_yy]]`

- `H` 正定：局部极小值。
- `H` 负定：局部极大值。
- `H` 不定：鞍点。
- `H` 半正定或半负定：二阶判别法可能失效，需要更高阶分析。

**例：** `f(x, y) = x² + y²`

驻点为 `(0, 0)`，Hessian 为 `[[2, 0], [0, 2]]`，正定，所以是局部极小值。

**例：** `f(x, y) = x² - y²`

驻点为 `(0, 0)`，Hessian 为 `[[2, 0], [0, -2]]`，不定，所以是鞍点。

### 9.7 导数与机器学习

机器学习中的训练，本质上是在最小化损失函数。梯度告诉我们“参数往哪个方向调，损失下降最快”：

- 一阶导数/梯度：梯度下降、反向传播。
- 二阶导数/Hessian：牛顿法、二阶优化。
- 泰勒展开：理解损失函数的局部近似。
- 链式法则：反向传播算法的核心。

所以，导数是理解现代优化算法的基础工具。

## 十、数值求导（拓展）

### 10.1 三种基本差分公式

当函数表达式复杂、或者只有离散数据时，可以用差分近似导数。

**前向差分：**

`f'(x) ≈ [f(x + h) - f(x)]/h`

**后向差分：**

`f'(x) ≈ [f(x) - f(x - h)]/h`

**中心差分：**

`f'(x) ≈ [f(x + h) - f(x - h)]/(2h)`

中心差分通常比前向、后向差分更精确。若函数足够光滑：

- 前向、后向差分的误差约为 `O(h)`。
- 中心差分的误差约为 `O(h²)`。

二阶导数的中心差分：

`f''(x) ≈ [f(x + h) - 2f(x) + f(x - h)]/h²`

### 10.2 步长怎么选

`h` 太大，截断误差大；`h` 太小，浮点数的舍入误差会被放大。实际计算中要选择一个折中的步长，而不是盲目取“越小越好”。

### 10.3 数值求导、符号求导与自动微分

- **符号求导**：直接对表达式做代数运算，得到精确公式。适合公式推导，但表达式可能迅速膨胀。
- **数值求导**：用差分近似，适合只有数据或函数黑箱的情况，但存在误差。
- **自动微分**：利用链式法则和计算图，既精确又高效，是现代深度学习框架的核心技术。

自动微分不是数值差分，也不是符号推导，而是“带着导数信息一起计算”。反向传播就是反向模式自动微分的典型应用。

## 十一、常见易错点总清单

1. **把导数和导数值混淆。** `f'(x)` 是函数，`f'(x₀)` 是数。
2. **误以为 `(uv)' = u'v'`。** 正确公式是 `u'v + uv'`。
3. **误以为 `(u/v)' = u'/v'`。** 正确公式是 `(u'v - uv')/v²`。
4. **链式法则漏乘内层导数。** 例如 `sin(x²)` 的导数不是 `cos(x²)`，而是 `2x cos(x²)`。
5. **把 `sin²x` 和 `sin(x²)` 当成一回事。** 前者是 `(sin x)²`，后者是 `sin(x²)`。
6. **把 `e^{x²}` 和 `(eˣ)²` 当成一回事。** 后者等于 `e^{2x}`。
7. **把 `ln(x²)` 和 `(ln x)²` 当成一回事。** 前者可化简为 `2ln abs(x)`。
8. **记错对数导数。** `(ln x)' = 1/x`，不是 `ln x/x`。
9. **混淆指数函数导数。** `(eˣ)' = eˣ`，而 `(aˣ)' = aˣ ln a`。
10. **记错三角函数导数。** `(tan x)' = sec²x`，`(sec x)' = sec x tan x`，两者不要混。
11. **忽略反三角函数定义域。** `arcsin x` 和 `arccos x` 只在 `abs(x) < 1` 内可导。
12. **忽略绝对值在零点的不可导性。** `abs(x)` 在 `0` 处不可导。
13. **把“连续”当成“可导”。** 连续不一定可导，例如 `abs(x)` 在 `0` 处。
14. **分段函数在分界点只看两侧表达式。** 必须检查连续性，并用左右导数判断。
15. **隐函数求导忘记 `y'`。** 对 `y` 求导时要用链式法则，多出一个 `y'`。
16. **参数方程二阶导算成 `y''/x''`。** 正确公式是 `(x'y'' - y'x'')/(x')³`。
17. **把 `f^(n)(x)` 理解成 `[f(x)]ⁿ`。** 前者是 `n` 阶导数，后者是函数值的 `n` 次方。
18. **认为极值点一定满足 `f'=0`。** 导数不存在的点也可能是极值点。
19. **认为 `f'=0` 一定是极值点。** `f(x)=x³` 在 `0` 处导数为 0，但不是极值点。
20. **认为 `f''=0` 一定是拐点。** `f(x)=x⁴` 在 `0` 处二阶导数为 0，但凹凸性没有改变。
21. **单调区间随便写并集。** 函数在不同区间上单调性可能不同，应分开写。
22. **使用洛必达前不检查条件。** 只有 `0/0` 或 `∞/∞` 型才能直接用。
23. **混淆驻点、极值点、最值点。** 驻点是 `f'=0` 的点；极值点是局部概念；最值点是全局概念。
24. **切线斜率不存在时硬套点斜式。** 此时切线是竖直线 `x = x₀`。
25. **混淆微分 `dy` 和增量 `Δy`。** `dy` 是线性近似，`Δy` 是实际变化量。
26. **求导后忘记定义域。** 例如 `ln x` 要求 `x > 0`，`arcsin x` 要求 `abs(x) ≤ 1`。
27. **对数求导忘记绝对值和定义域。** 含负数或零时要特别小心。
28. **三个以上函数相乘漏项。** `n` 个因子相乘，共有 `n` 项。
29. **反函数求导忘记取倒数。** `(f⁻¹)'(y) = 1/f'(x)`。
30. **只背公式，不看结构。** 求导最重要的是先识别“这是四则运算还是复合运算”。

## 十二、速查表与口诀

### 12.1 求导口诀

- 常数导数为零，幂函数降一次。
- 指数函数原样保留，再乘 `ln a`；以 `e` 为底时不用乘。
- 对数函数导数是倒数。
- 正弦变余弦，余弦变负正弦。
- 乘积：前导后不导，加前不导后导。
- 商：上导下不导，减上不导下导，除以分母平方。
- 复合：由外向内，逐层求导，层层相乘。
- 隐函数：两边求导，`y'` 当未知数。
- 参数方程：上下分别对 `t` 求导，再相除。
- 幂指函数：先取对数，再求导。
- 分段点：先看连续，再算左右导数。

### 12.2 高频公式速查

| 公式 | 结果 |
|---|---|
| `(x^α)'` | `αx^(α−1)` |
| `(aˣ)'` | `aˣ ln a` |
| `(eˣ)'` | `eˣ` |
| `(ln x)'` | `1/x` |
| `(sin x)'` | `cos x` |
| `(cos x)'` | `-sin x` |
| `(tan x)'` | `sec²x` |
| `(arcsin x)'` | `1/√(1-x²)` |
| `(arctan x)'` | `1/(1+x²)` |
| `(uv)'` | `u'v + uv'` |
| `(u/v)'` | `(u'v - uv')/v²` |
| `[f(g(x))]'` | `f'(g(x))g'(x)` |
| `(f⁻¹)'(y)` | `1/f'(x)` |
| `dy/dx`（参数方程） | `y'(t)/x'(t)` |
| `y = u^v` | `y' = u^v(v' ln u + v u'/u)` |

### 12.3 解题检查清单

1. 这个函数的定义域是什么？
2. 整体结构是加减、乘积、商，还是复合？
3. 是否需要先化简，例如 `ln(x²) = 2ln abs(x)`？
4. 链式法则有没有漏乘内层导数？
5. 商法则的分子顺序有没有写反？
6. 绝对值、分段点、隐函数是否需要单独讨论？
7. 结果能否用另一种方法验证？
8. 答案是否符合定义域和实际意义？

## 十三、练习题与参考答案

### 13.1 练习题

1. 求 `y = (3x² + 2)^4` 的导数。
2. 求 `y = e^{2x} sin 3x` 的导数。
3. 求 `y = ln(x² + 1)` 的导数。
4. 求 `y = x/(x² + 1)` 的导数。
5. 求 `y = arctan√x` 的导数。
6. 求 `y = √(sin x)` 的导数。
7. 已知 `x³ + y³ = 6xy`，求 `y'`。
8. 求 `y = x^(1/x)` 的导数。
9. 已知 `x = t - sin t`，`y = 1 - cos t`，求 `dy/dx` 和 `d²y/dx²`。
10. 求 `y = (cos x)^x` 的导数。
11. 求 `y = sin(e^{x²})` 的导数。
12. 求 `y = abs(x² - 1)` 的导数，并指出不可导点。
13. 求 `y = x² ln x` 的导数。
14. 求 `y = tan(3x)` 的导数。
15. 求 `y = x³ - 2x` 在 `x = 1` 处的切线和法线方程。
16. 求 `lim_{x→0} (1 - cos x)/x²`。
17. 设 `f(x) = x² (x ≤ 1)`，`f(x) = ax + b (x > 1)`。求使 `f(x)` 在 `x = 1` 处可导的 `a`、`b`。
18. 设 `f(x) = x³ - 3x`，求单调区间、极值、凹凸区间和拐点。
19. 用定义证明 `f(x) = x² sin(1/x)`（`x ≠ 0`），`f(0) = 0` 在 `0` 处可导，并求 `x ≠ 0` 时的 `f'(x)`。
20. 若 `f'(x₀) = 3`，求 `lim_{h→0} [f(x₀ + 2h) - f(x₀ - h)]/h`。

### 13.2 参考答案

**1.** 外层是 `u⁴`，内层是 `3x² + 2`：

`y' = 4(3x² + 2)³ · 6x = 24x(3x² + 2)³`

**2.** 用乘积法则，两项都含复合：

`y' = 2e^{2x} sin 3x + 3e^{2x} cos 3x = e^{2x}(2sin 3x + 3cos 3x)`

**3.** 链式法则：

`y' = [1/(x² + 1)] · 2x = 2x/(x² + 1)`

**4.** 商法则：

`y' = [(1)(x² + 1) - x(2x)]/(x² + 1)² = (1 - x²)/(x² + 1)²`

**5.** 外层 `arctan`，内层 `√x`：

`y' = [1/(1 + x)] · [1/(2√x)] = 1/[2√x(1 + x)]`

**6.** 外层 `√u`，内层 `sin x`：

`y' = [1/(2√(sin x))] · cos x = cos x/(2√(sin x))`

**7.** 两边对 `x` 求导：

`3x² + 3y² y' = 6y + 6x y'`

整理：

`y'(3y² - 6x) = 6y - 3x²`

所以：

`y' = (2y - x²)/(y² - 2x)`

**8.** 取对数：

`ln y = (1/x)ln x`

求导：

`y'/y = (1 - ln x)/x²`

所以：

`y' = x^(1/x) · (1 - ln x)/x²`

**9.** 先求一阶导：

`dy/dx = sin t/(1 - cos t) = cot(t/2)`

再求二阶导：

`d²y/dx² = [d/dt cot(t/2)]/(1 - cos t) = -1/[4sin⁴(t/2)]`

**10.** 取对数：

`ln y = x ln(cos x)`

求导：

`y'/y = ln(cos x) + x · (-tan x)`

所以：

`y' = (cos x)^x [ln(cos x) - x tan x]`

**11.** 三层复合：

`y' = cos(e^{x²}) · e^{x²} · 2x = 2x e^{x²} cos(e^{x²})`

**12.** 分段：

- `abs(x) > 1` 时，`y = x² - 1`，`y' = 2x`。
- `abs(x) < 1` 时，`y = 1 - x²`，`y' = -2x`。
- 在 `x = ±1` 处不可导。

**13.** 乘积法则：

`y' = 2x ln x + x² · (1/x) = 2x ln x + x = x(2ln x + 1)`

**14.** 链式法则：

`y' = sec²(3x) · 3 = 3sec²(3x)`

**15.** `y' = 3x² - 2`，在 `x = 1` 处斜率为 `1`，点为 `(1, -1)`。

切线：

`y + 1 = 1(x - 1)`，即 `y = x - 2`

法线：

`y + 1 = -(x - 1)`，即 `y = -x`

**16.** 这是 `0/0` 型，用洛必达：

`lim_{x→0} (1 - cos x)/x² = lim_{x→0} sin x/(2x) = 1/2`

**17.** 连续性要求 `1 = a + b`。左导数为 `2`，右导数为 `a`，所以 `a = 2`，`b = -1`。

**18.** `f'(x) = 3x² - 3 = 3(x - 1)(x + 1)`。

- 递增区间：`(-∞, -1)` 和 `(1, +∞)`。
- 递减区间：`(-1, 1)`。
- 局部极大值：`f(-1) = 2`。
- 局部极小值：`f(1) = -2`。
- `f''(x) = 6x`，凹向下区间 `(-∞, 0)`，凹向上区间 `(0, +∞)`。
- 拐点：`(0, 0)`。

**19.** 在 `0` 处：

`f'(0) = lim_{h→0} [h² sin(1/h) - 0]/h = lim_{h→0} h sin(1/h) = 0`

当 `x ≠ 0` 时：

`f'(x) = 2x sin(1/x) - cos(1/x)`

**20.** 凑导数定义：

`[f(x₀ + 2h) - f(x₀ - h)]/h = [f(x₀ + 2h) - f(x₀)]/h + [f(x₀) - f(x₀ - h)]/h`

第一项趋于 `2f'(x₀)`，第二项趋于 `f'(x₀)`，所以总极限为 `3f'(x₀) = 9`。

## 十四、总结：把导数串成一张图

导数的核心可以概括为三句话：

1. **导数是瞬时变化率。** 它描述函数在某一点附近变化得有多快。
2. **导数是切线斜率。** 它把曲线在一点附近“拉直”，用直线近似曲线。
3. **导数是线性近似。** `f(x₀ + Δx) ≈ f(x₀) + f'(x₀)Δx`，这是一切近似、优化和数值方法的基础。

求导的整套方法可以串成一条线：

`基本公式 → 四则法则 → 链式法则 → 隐函数/参数方程/对数求导 → 高阶导数 → 应用`

其中最重要的是分清两类结构：

- **四则运算**：加减乘除，分别处理，按公式组合。
- **复合运算**：函数套函数，由外向内，层层相乘。

最后记住三个习惯：

- 先看定义域，再看结构，最后动笔。
- 每写一步，问自己“这里用的是哪条法则，为什么能用”。
- 做完后检查符号、分母、根号、绝对值和特殊情况。

导数不是一堆孤立的公式，而是一套描述“变化”的语言。理解了这个核心，公式就不再需要死记硬背。
