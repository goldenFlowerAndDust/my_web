# 共享工具

## 答疑历史归档

脚本：

```text
共享工具/归档答疑历史.py
```

作用：

- 读取本地数学/英语 `*.jsonl` 答疑日志；
- 按“分类 / 日期”生成静态 HTML；
- 自动更新数学/英语主页的“AI 答疑历史”板块。

手动执行：

```powershell
python 共享工具/归档答疑历史.py all
python 共享工具/归档答疑历史.py math
python 共享工具/归档答疑历史.py english
```

自动执行：

- 启动 `启动词素服务.bat` 时自动归档英语；
- 启动 `启动数学答疑服务.bat` 时自动归档数学；
- 每次答疑成功/删除记录后也会刷新对应归档和主页板块。

归档位置：

```text
备考专升本数学/数学答疑/归档/<知识分类>/<日期>.html
备考专升本英语/英语答疑/归档/<分类>/<日期>.html
```

主页板块位于：

```text
专升本数学.html  → AI 答疑历史
专升本英语.html  → AI 答疑历史
```

不要手动修改 `<!-- AI_ARCHIVE_START -->` 到 `<!-- AI_ARCHIVE_END -->` 之间的内容；下次归档会被覆盖。
