以[er]结尾的单词

英语构词法常用规则之一：动词或名词加上后缀[er]变成“人”或“物”

以下四种结构

  • 动词 + er = 做这个动作的人(最常见)

    如
    1. teach(教)——————> teacher(教师/老师)
    2. work(工作)——————>worker(工人)
    3. drive(驾驶)——————>driver(司机)

  • 动词 + er = 工具/物品(极易丢分)

    如
    1. compute(计算)——————>computer(计算机，不是“计算员”)
    2. print(打印)————————>printer(打印机)
    3. cook(烹饪)————————>cooker(炊具/电饭煲) 不是厨师！，厨师是：cook
    4. wash(洗)————————>washer(洗衣机)

  • 名词/形容词 + er = 具有某些特征的人

    如
    1. foreign(外国的)——————>foreigner(外国人)
    2. strange(奇怪的)——————>stranger(陌生人) 不是更奇怪的人
    3. New York ——————> New Yorker(纽约人)

  • 形容词/副词 + er = 比较级(完全不是人)

    如
    1. tall(高的)——————>taller(更高的)
    2. fast(快的)——————>faster(更快的)
    3. 当然，如果是 worker 加 er 变成 workerer 是不存在的，比较级和名词后缀通常不会同时出现。

  • 特殊的情况——有些单词既能做名词也能做动词

    如
    1. fish(名词：鱼，动词：捕鱼、捞鱼、抓鱼)——————>fisher(渔夫) 其实是动词+[er]，指的是捕鱼的人
    2. water(名词：水，动词：浇水)——————>waterer(浇水的人/烧水壶) 同样动词语义+er
    3. paint(名词：油漆，动词：粉刷/画画)——————>painter(画家/油漆工) 同样是动词语义+er
    4. farm(名词：农场，动词：务农)————>farmer(农夫) 动词语义+er
    5. cook(名词：厨师（本身已经是人），动词：烹饪)——————>cooker(炊具/电饭煲) 动词语义+er，指的是工具，而非人
