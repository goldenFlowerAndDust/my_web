## 一、核心知识点提炼（按语言分类）

### 1.1 Python 语言核心

#### ① 数据类型与运算体系

| 维度 | 核心要点 |
|------|---------|
| **字面量** | `int / float / bool / str / None`；`bool` 是 `int` 子类，`True==1`、`False==0` |
| **类型查询** | `type()` 返回类型对象；`isinstance()` 返回布尔值，支持元组多类型判断 |
| **隐式转换** | **Python 无隐式转换**（与 JS/MySQL 本质区别），`"5"+5` 直接 `TypeError` |
| **整除与取余** | `//` 向下取整；`%` 符号随**除数**（JS/MySQL 随被除数，因商向零取整） |
| **位运算** | `& | ^ ~` 同时支持整数位运算与集合交/并/对称差；`~x == -x-1` |
| **逻辑运算** | `and/or` 返回**操作数本身**（短路求值），`not` 返回布尔值 |
| **身份 vs 相等** | `is` 比较内存地址（`id()`），`==` 比较值；`None` 判断必须用 `is` |

#### ② 流程控制

- **条件分支**：`if-elif-else`；`match-case` 无穿透、支持 `|` 多值匹配与 `case x if 守卫`
- **循环**：`for-in` 唯一形式（迭代元素本身，非索引）；`while-else` / `for-else` 独有结构（非 `break` 退出才执行 `else`）
- **`range()`**：左闭右开，步长非零
- **循环辅助**：`break` 只跳出最近一层，`return` 可强制退出多层嵌套

#### ③ 函数体系（重点）

```
参数优先级：位置参数 > 默认参数 > *args > 强制关键字 > **kwargs
```

| 参数类型 | 关键规则 |
|---------|---------|
| 位置参数 | 按定义顺序一一对应 |
| 默认参数 | 定义时求值（**可变对象单例陷阱**），必须放在普通形参后 |
| 关键字参数 | 调用时指名赋值，必须在位置参数后，不可重复赋值 |
| `*args` | 收集多余位置参数 → 元组；其后形参变为**强制关键字** |
| `**kwargs` | 收集多余关键字参数 → 字典；键必须为 `str`，只能在最后 |

- **返回值**：无 `return` 返回 `None`；多值自动组包元组
- **作用域 LEGB**：`Local → Enclosing → Global → Built-in`；修改需 `global` / `nonlocal`
- **匿名函数**：`lambda` 仅单表达式，不能写语句（`try/if/for`），常用于 `sort(key=)` / `filter` / `map`
- **递归**：`return 自身` + 终止条件；默认深度 1000；本质是**入栈挂起 + 出栈计算 + 逐层传递**
- **高阶函数**：函数可作为参数传递（`calc(oper, *args)` 计算器模式）

#### ④ 数据容器（五大容器对比）

| 容器 | 有序 | 可变 | 去重 | 索引 | 典型场景 |
|------|------|------|------|------|---------|
| `list` | ✅ | ✅ | ❌ | ✅ | 通用序列 |
| `tuple` | ✅ | ❌ | ❌ | ✅ | 不可变记录、多返回值 |
| `str` | ✅ | ❌ | ❌ | ✅ | 文本 |
| `set` | ❌ | ✅ | ✅ | ❌ | 去重、集合运算 |
| `dict` | ✅(插入序) | ✅ | 键唯一 | 键访问 | 键值映射 |

**关键机制**：
- **切片**：`[start:stop:step]` 左闭右开；负索引转正向（`len+负值`）；步长与方向矛盾则为空
- **解包**：`*` 收集剩余 → 列表；`*` 在左从左取、在右从右取；`a,b=b,a` 本质是组包+解包
- **推导式**：`[expr for x in it if cond]`；生成器 `(expr for ...)` 惰性求值，内存极小
- **字典去重**：`list(dict.fromkeys(data))` 保序去重（优于 `set` 乱序）
- **字典视图**：`keys()/values()/items()` 返回**动态视图**，随原字典实时更新

#### ⑤ 异常处理（防御性编程）

```
try → except 具体异常 as e → else（无异常执行）→ finally（必执行）
```

- **异常继承树**：`BaseException → Exception → ValueError/TypeError/...`；`SyntaxError` 运行前检测，`try` 无法捕获
- **裸 `except` 危害**：会吞掉 `KeyboardInterrupt`，应指定具体类型
- **`raise` 三场景**：`try` 内（被捕获）、`except` 内（终止程序，常配 `raise New from old`）、`try` 外（直接终止）
- **`finally` 禁用 `return`**：会覆盖原异常
- **异常传递**：沿栈帧逐层上报，最外层未捕获则终止

#### ⑥ 文件操作

| 模式 | 读 | 写 | 文件不存在 | 光标 |
|------|----|----|-----------|------|
| `r/rt/rb` | ✅ | ❌ | 报错 | 开头 |
| `w/wt/wb` | ❌ | ✅ | 创建 | 开头（清空） |
| `a/at/ab` | ❌ | ✅ | 创建 | 末尾 |
| `r+` | ✅ | ✅ | 报错 | 开头（覆盖写） |
| `w+` | ✅ | ✅ | 创建 | 开头（清空） |
| `a+` | ✅ | ✅ | 创建 | 末尾 |

- **编码**：`str` 是 Unicode，`bytes` 是压缩编码；`encode()` 压缩、`decode()` 解压；Windows 默认 GBK、Linux 默认 UTF-8，**建议显式 `encoding='utf-8'`**
- **`with` 语句**：自动 `close()`，省略资源释放
- **`seek(offset, whence)`**：`whence` 仅 0/1/2；文本模式建议只用 `seek(0)` / `seek(0,2)`
- **`readline()` 末尾返回 `''` 非 `None`**；`readlines()` 返回列表

#### ⑦ 面向对象

- **类 = 蓝图**，实例 = 具体对象；`__init__` 是初始化（非构造），`__new__` 才是创建
- **`self`** = 实例本身，方法第一参数，调用时自动传入
- **属性查找链**：实例 `__dict__` → 类 `__dict__`（经 `__class__`）→ 父类 `__dict__`（经 `__bases__`）→ `object`
- **实例属性 vs 类属性**：实例独立、类共享；`实例.类属性=值` 会在实例 `__dict__` 新建副本，不影响类
- **魔法方法**：`__str__`（print）、`__repr__`（交互环境）、`__add__`（运算符重载，返回新对象，不支持时返回 `NotImplemented`）、`__eq__`（链式比较拆分为 `and`）
- **三大特性**：封装（`__私有` + `@property` + `__slots__`）、继承（`super()` + MRO C3 线性化）、多态（重写 + 鸭子类型）
- **三种方法**：实例方法（`self`）、类方法（`@classmethod` + `cls`）、静态方法（`@staticmethod`，无自动参数）

#### ⑧ 模块与包

- **模块** = `.py` 文件；**包** = 含 `__init__.py` 的文件夹
- **导入方式**：`import m` / `import m as a` / `from m import f` / `from m import *`（受 `__all__` 控制）
- **`__name__ == "__main__"`**：直接运行才执行，被导入时跳过（安全防护）
- **模块搜索顺序**：`sys.path[0]`（当前目录）→ `PYTHONPATH` → 系统库
- **`sys.path.append()`** 可插入锚点实现跨目录导入

#### ⑨ 类型注解

- 变量：`name: str = "x"`；容器：`list[int]`、`dict[str,int]`、`tuple[int,...]`
- 函数：`def f(a: int) -> float:`
- 多类型：`int | str` 或 `Union[int,str]`；任意类型 `Any`
- **仅提示不强制**，不按注解赋值不报错

## 二、踩坑记录分析（现象 → 根因 → 解法）

### 坑 1：`int()` 转换浮点字符串报错

- **现象**：`int("3.14")` 抛 `ValueError`，但 `int(3.14)` 正常返回 3
- **根因**：`int()` 接受数字或**纯整数字符串**，不接受含小数点的字符串；JS 的 `parseInt("3.14")` 会截断
- **解法**：`int(float("3.14"))` 先转浮点再截断；或明确业务是否需要小数

### 坑 2：`all()` 误用导致校验失效

- **现象**：成绩合法性校验 `all(s > 100 or s < 0 for s in scores)` 永远为假，非法成绩被放过
- **根因**：`all()` 要求**全部为真**才返回真；此处应判断"是否存在越界"，逻辑应为 `any()`
- **解法**：`if any(s > 100 or s < 0 for s in scores):` 越界拦截

### 坑 3：元音判断未加引号

- **现象**：`if v in (aeiou)` 报 `NameError`，变量未定义
- **根因**：把字符 `'a'` 写成变量名 `a`，Python 无隐式字符串化
- **解法**：`if v in ('a','e','i','o','u',...)` 或 `if v in 'aeiouAEIOU'`

### 坑 4：`map()` 后误用下标访问

- **现象**：`for s in map(lambda x: x["score"]+5, students): print(s['name'])` 报 `TypeError: 'int' object is not subscriptable`
- **根因**：`map` 返回的是**映射后的值**（此处为数字），不是原字典
- **解法**：`map(lambda x: {"name":x["name"],"score":x["score"]+5}, students)` 返回新字典

### 坑 5：`int(float())` 与 `int(str())` 混淆

- **现象**：笔记明确记录"`int(float())` 截断小数可行，`int(str())` 遇非整数数字报错"
- **根因**：`int()` 对 float 截断，对 str 要求纯整数格式
- **解法**：字符串先 `float()` 再 `int()`；或 `int(Decimal(s))`

### 坑 6：`finally` 中 `return` 覆盖异常

- **现象**：`finally` 内 `return` 导致原异常被吞
- **根因**：`finally` 的 `return` 会覆盖 `try/except` 的返回与异常
- **解法**：`finally` 只做资源清理，禁止 `return`

### 坑 7：`except` 裸捕获吞掉 `KeyboardInterrupt`

- **现象**：`Ctrl+C` 无法中断程序
- **根因**：裸 `except:` 捕获 `BaseException` 子类（含 `KeyboardInterrupt`）
- **解法**：`except Exception as e:` 或指定具体异常类型

### 坑 8：`SyntaxError` 无法被 `try` 捕获

- **现象**：`try: if True print(1) except: ...` 仍直接报错
- **根因**：`SyntaxError` 在**编译期**检测，`try` 在运行期才生效
- **解法**：语法错误只能靠编辑器/静态检查提前发现

### 坑 9：文件写入模式误用

- **现象**：`w` 模式打开后 `read()` 返回空字符串
- **根因**：`w` 打开即清空文件，光标在开头但内容已空
- **解法**：需读写用 `w+`，且先 `write()` 再 `seek(0)` 才能读到

### 坑 10：`a` 模式读取需先 `seek(0)`

- **现象**：`a+` 模式 `read()` 读不到内容
- **根因**：追加模式光标在末尾
- **解法**：`seek(0)` 移到开头再读，写完再 `seek(0,2)`

### 坑 11：`readline()` 末尾返回 `''` 非 `None`

- **现象**：`while line is not None` 死循环
- **根因**：`readline()` 到末尾返回空字符串 `''`
- **解法**：`while line != '':` 或 `while line:`

### 坑 12：`seek()` 文本模式乱移

- **现象**：`seek(1)` 后读取中文乱码/报错
- **根因**：`seek` 以**字节**为单位，中文占多字节，移到字符中间导致解码失败
- **解法**：文本模式只用 `seek(0)` / `seek(0,2)`

### 坑 13：默认参数可变对象陷阱

- **现象**：`def f(a, lst=[])` 多次调用共享同一列表
- **根因**：默认参数在**定义时求值一次**，可变对象被复用
- **解法**：`def f(a, lst=None): lst = lst or []`

### 坑 14：`append` vs `extend` 混淆

- **现象**：`lst.append([1,2])` 得到嵌套列表而非合并
- **根因**：`append` 整体添加，`extend` 遍历逐个添加
- **解法**：合并用 `extend` 或 `[*a, *b]`；`append` 只加单元素

### 坑 15：`extend` 传数字报错

- **现象**：`lst.extend(5)` 抛 `TypeError: 'int' object is not iterable`
- **根因**：`extend` 要求可迭代对象
- **解法**：`lst.append(5)` 或 `lst.extend([5])`

### 坑 16：`sort()` 返回 `None`

- **现象**：`new = lst.sort()` 得到 `None`
- **根因**：`sort()` 原地排序无返回值；`sorted()` 才返回新列表
- **解法**：`new = sorted(lst)` 或先 `lst.sort()` 再用 `lst`

### 坑 17：`sort(key=)` 传调用结果而非函数

- **现象**：`lst.sort(key=len(x))` 报错
- **根因**：`key` 接收**函数对象**，不是调用结果
- **解法**：`lst.sort(key=len)` 或 `key=lambda x: len(x)`

### 坑 18：`set()` 去重乱序

- **现象**：`list(set(data))` 顺序被打乱
- **根因**：`set` 无序
- **解法**：保序去重 `list(dict.fromkeys(data))`

### 坑 19：字典视图无下标

- **现象**：`d.keys()[0]` 报 `TypeError: 'dict_keys' object is not subscriptable`
- **根因**：`keys()/values()/items()` 返回视图非列表
- **解法**：`list(d.keys())[0]`

### 坑 20：`dict.fromkeys` 共享可变默认值

- **现象**：`dict.fromkeys(keys, [])` 所有键共享同一列表
- **根因**：默认值对象被复用
- **解法**：`{k: [] for k in keys}` 推导式

### 坑 21：`for` 循环中删除列表元素漏删

- **现象**：`for x in lst: if cond: lst.remove(x)` 部分元素未删
- **根因**：删除导致索引前移，迭代跳过元素
- **解法**：倒序遍历 `for i in range(len(lst)-1,-1,-1)` 或 `while x in lst: lst.remove(x)` 或推导式重建

### 坑 22：`lambda` 内写语句

- **现象**：`lambda x: try: ... except: ...` 语法错误
- **根因**：`lambda` 只能单表达式
- **解法**：改用 `def` 或把异常处理外移

### 坑 23：`__init__` 拼写错误

- **现象**：`def __init___(self)` 三下划线，实例无属性
- **根因**：魔法方法名必须精确双下划线
- **解法**：`__init__`

### 坑 24：实例方法赋值覆盖

- **现象**：`obj.method = 值` 后方法失效
- **根因**：实例属性覆盖了类方法
- **解法**：避免给方法名赋值

### 坑 25：`super().__init__()` 遗漏

- **现象**：子类实例缺少父类属性
- **根因**：子类 `__init__` 未调用父类初始化
- **解法**：`super().__init__(...)`

### 坑 26：`__add__` 抛异常而非返回 `NotImplemented`

- **现象**：`student + dict` 直接崩溃，未给右侧反向方法机会
- **根因**：应返回 `NotImplemented` 让 Python 尝试 `__radd__`
- **解法**：`return NotImplemented`

### 坑 27：`__del__` 执行时机不确定

- **现象**：链式运算中临时对象 `__del__` 调用顺序难预测
- **根因**：依赖引用计数与 GC，Python 不保证严格顺序
- **解法**：不在 `__del__` 中写关键逻辑

### 坑 28：模块与系统库重名

- **现象**：自定义 `random.py` 覆盖标准库，功能异常
- **根因**：`sys.path[0]` 优先于系统库
- **解法**：自定义模块避免与标准库同名

### 坑 29：包导入路径错误

- **现象**：`from 包 import 模块` 报 `ModuleNotFoundError`
- **根因**：包必须与主程序同级，或 `sys.path` 未包含父目录
- **解法**：`sys.path.append(r'父目录')` 或设置源根/`PYTHONPATH`

### 坑 30：`__all__` 未定义导致通配符导入污染

- **现象**：`from m import *` 导入大量非预期名称
- **根因**：无 `__all__` 时导入所有非下划线开头名称
- **解法**：显式定义 `__all__ = [...]`，或避免通配符导入

### 坑 31：`f-string` 内反斜杠报错

- **现象**：`f"{'\n'.join(x)}"` 报 `SyntaxError`
- **根因**：Python 3.12 前 f-string 大括号内不允许反斜杠
- **解法**：先赋值变量 `sep='\n'`，再 `f"{sep.join(x)}"`

### 坑 32：`print` 中 `:.2f` 用于字符串

- **现象**：`f"{'abc':.2f}"` 报 `ValueError`
- **根因**：格式说明符 `:.2f` 仅适用于数字
- **解法**：确保格式化对象为数值类型

### 坑 33：`input()` 返回字符串直接运算

- **现象**：`input()+1` 报 `TypeError`
- **根因**：`input` 恒返回 `str`
- **解法**：`float(input())` / `int(input())`，并配 `try-except`

### 坑 34：`is` 比较整数/字符串

- **现象**：`a=1000; b=1000; a is b` 结果不稳定
- **根因**：小整数缓存（-5~256）与字符串驻留机制，`is` 比较地址不可靠
- **解法**：值比较用 `==`，仅 `None/True/False` 用 `is`

### 坑 35：`round()` 银行家舍入

- **现象**：`round(2.5)` 得 2 而非 3
- **根因**：Python 3 采用银行家舍入（四舍六入五成双）
- **解法**：需传统四舍五入用 `Decimal` + `ROUND_HALF_UP`

### 坑 36：浮点精度丢失

- **现象**：`0.1+0.2 != 0.3`
- **根因**：二进制无法精确表示部分小数
- **解法**：`math.isclose()` 或 `Decimal`

### 坑 37：`match-case` 变量捕获陷阱

- **现象**：`case x:` 会匹配一切并绑定变量，而非比较
- **根因**：`case` 后裸标识符是**捕获模式**，非常量比较
- **解法**：用字面量 `case "a":` 或 `case 1 | 2:`，需比较变量用守卫 `case _ if x == y:`

### 坑 38：`while True` 缺 `break` 死循环

- **现象**：程序卡死
- **根因**：循环条件恒真且无退出
- **解法**：确保内部有 `break` / `return`，或设置边界条件

### 坑 39：缩进混用 Tab 与空格

- **现象**：`IndentationError` 或逻辑错乱
- **根因**：Python 用缩进定义代码块，混用导致解析歧义
- **解法**：统一 4 空格，编辑器设置"Tab 转空格"

### 坑 40：`del` 删除后访问

- **现象**：`del lst` 后 `print(lst)` 报 `NameError`
- **根因**：`del` 删除对象引用，非清空
- **解法**：清空用 `lst.clear()`，删除对象才用 `del`

### 坑 41：`remove()` 元素不存在报错

- **现象**：`lst.remove(x)` 抛 `ValueError`
- **根因**：`remove` 要求元素存在
- **解法**：先 `if x in lst:` 或 `try-except`

### 坑 42：`pop()` 空列表报错

- **现象**：`[].pop()` 抛 `IndexError`
- **根因**：空列表无元素可删
- **解法**：先判空 `if lst:`

### 坑 43：`index()` 找不到报错

- **现象**：`lst.index(x)` 抛 `ValueError`
- **根因**：元素不存在
- **解法**：`if x in lst:` 或用 `try-except`，或 `next((i for i,v in enumerate(lst) if v==x), -1)`

### 坑 44：`+` 拼接非字符串

- **现象**：`"age:"+20` 报 `TypeError`
- **根因**：Python 无隐式转换
- **解法**：`f"age:{20}"` 或 `"age:"+str(20)`

### 坑 45：`join()` 元素非字符串

- **现象**：`','.join([1,2])` 报 `TypeError`
- **根因**：`join` 要求元素均为 `str`
- **解法**：`','.join(map(str, [1,2]))`

### 坑 46：`split()` 传空字符串

- **现象**：`"abc".split("")` 报 `ValueError`
- **根因**：分隔符不能为空
- **解法**：`list("abc")` 或 `"abc".split()`

### 坑 47：`replace()` 未接收返回值

- **现象**：`s.replace("a","b")` 后 `s` 未变
- **根因**：字符串不可变，`replace` 返回新串
- **解法**：`s = s.replace("a","b")`

### 坑 48：`strip()` 只去首尾

- **现象**：`" a b ".strip()` 得 `"a b"`，中间空格仍在
- **根因**：`strip` 只处理两端
- **解法**：去所有空格 `"".join(s.split())` 或 `s.replace(" ","")`

### 坑 49：`isdigit()` 对负数/小数返回 False

- **现象**：`"-5".isdigit()` 为 `False`
- **根因**：`isdigit` 只认纯数字字符
- **解法**：`try: float(s)` 判断

### 坑 50：`for-else` 误判

- **现象**：`for` 正常结束也执行 `else`，被误认为"未找到"
- **根因**：`else` 在**非 `break` 退出**时执行
- **解法**：理解语义——`else` 是"循环完整跑完"的标志，配合 `break` 表示"找到即停"
