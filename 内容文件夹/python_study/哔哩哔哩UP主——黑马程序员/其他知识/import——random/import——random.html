其他知识——random模块

随机数模块 · JavaScript vs Python

对比维度 JavaScript Python
模块/对象 全局对象 Math（无需导入） random 模块（需导入）
import random
生成 [0, 1) 浮点数 Math.random()
返回 0 ≤ x < 1 		random.random()
返回 0.0 ≤ x < 1.0
生成指定范围整数 需手动计算：
Math.floor(Math.random() * (max - min + 1)) + min
含两端，需配合 Math.floor() 		random.randint(min, max)
含两端，直接返回整数
例：random.randint(1, 100) → 可拿到 100
生成指定范围浮点数 Math.random() * (max - min) + min
含左不含右（近似） 		random.uniform(min, max)
理论含两端（浮点精度影响）
从序列中随机选一个 需手动计算索引：
arr[Math.floor(Math.random() * arr.length)] 		random.choice(arr)
一行搞定
随机选多个（不重复） 需手动实现（洗牌或抽选逻辑） random.sample(arr, k)
返回 k 个不重复元素
打乱列表顺序（洗牌） arr.sort(() => Math.random() - 0.5)
⚠️ 不严谨，分布不均匀 		random.shuffle(arr)
原地打乱，真随机洗牌
类 range 随机整数 无原生方法，需手动 Math.floor() random.randrange(start, stop[, step])
左闭右开，同 range() 规则
例：randrange(1, 100) → 取不到 100
随机种子（可复现） 不支持（无原生种子机制） random.seed(a)
设置种子后，随机序列可复现

区间规则速查

函数 区间规则 示例 是否包含右边界
Math.random() (JS) [0, 1) Math.random() ❌ 不包含
random.random() (Py) [0.0, 1.0) random.random() ❌ 不包含
random.randint(a, b) (Py) 全闭 [a, b] randint(1, 100) ✅ 包含
random.randrange(start, stop) (Py) 左闭右开 [start, stop) randrange(1, 100) ❌ 不包含
random.uniform(a, b) (Py) [a, b]（理论全闭，浮点精度影响） uniform(1.5, 2.5) ⚠️ 理论包含，实际近似
Math.floor(Math.random() * (max - min + 1)) + min (JS) 全闭 [min, max] 手动实现 ✅ 包含

记忆口诀

  • Python：
    · 要整数 → randint（全闭）
    · 要范围步长 → randrange（左闭右开）
    · 要随机选 → choice / sample / shuffle
  • JavaScript：
    · 只有 Math.random()（左闭右开）
    · 整数、选元素、洗牌 → 全部手动封装
  • 核心区别：
    · Python 功能丰富，自带种子、洗牌、抽样
    · JavaScript 只有基础随机数，其他需自己实现
