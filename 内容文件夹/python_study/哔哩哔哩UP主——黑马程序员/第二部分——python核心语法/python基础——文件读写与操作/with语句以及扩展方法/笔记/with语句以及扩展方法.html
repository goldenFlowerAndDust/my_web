with语句以及扩展啊方法

with语句

  • 已知每次用open()都需要使用close()关闭释放资源
  • with主要作用是省略close()步骤
  • 语法：with open('文件地址',mode='',encodeing='') as 字面量
  • 字面量存储文件对象

扩展方法

  • 扩展方法——seek()

    1. 指定光标位置
    2. 语法：seek(偏移量,whence)
    3. 偏移量：正整数：向右/向后/向文档末尾方向移动。负整数：向左/向前/向文档首方向移动。0：不移动
    4. 偏移量参数不能是：字符串、浮点数，否则会报错：TypeError
    5. 起始位置三个参数固定：whence 参数：0（默认，相对于文件开头）、1（相对于当前位置）、2（相对于文件末尾）。在文本模式下，建议只使用 whence=0，避免因编码问题导致光标位置错乱。
    6. 第二参数除：【0、1、2】均报错，TypeError
    7. seek(0,1)一般很少用，主要搭配：tell()、输出光标坐标
    8. seek() 以 字节 为单位移动光标。在文本模式下，建议只使用 seek(0)（移到开头）或 seek(0, 2)（移到末尾），避免移动到非 ASCII 字符中间导致解码错误。

  • 扩展方法——tell()

    1. 返回当前光标的位置
    2. 语法：tell()
    3. 不能传参，否则：TypeError
    4. 会受到：seek()影响

  • 扩展方法——readlines()

    1. 将读取的文本/二进制转成列表，以换行符为基准，每一行代表一个元素
    2. 语法：readlines(size)
    3. 注意：readlines() 适用于文件不大且需要随机访问各行的场景。如果文件很大，建议用 for line in f: 逐行读取，更节省内存。
    4. 常用于：筛选等等
    5. size：可选参数且只能传整数参数，只能传一个参数。意思是：size：，表示读取大约 size 个字节的数据，然后返回这些数据中包含的所有行（不精确，一般不建议传参）
    6. 所以一般不建议传参、直接获取整行组成列表即可
    7. 多行读取

  • 扩展方法——readline()

    1. 读取光标所在的那一行的文本
    2. 语法：readline(size)
    3. 返回值是字符串，而不是：readines()返回的是列表
    4. size：可以传整数参数，且只能传一个参数。意思是：readline(size) 表示“读取当前行的前 size 个字节”。由于中文字符可能占多个字节，建议不要依赖这个参数来精确按字符读取。
    5. readline() 读取到末尾时返回空字符串 ''，不是 None。这个在写“逐行处理”时很关键，
    6. 光标由：seek()控制，光标是以字节移动，正常情况，无法准确识别每行字符个数，所以光标位置不可控
    7. 所以一般使用：seek()控制光标位置
    8. 而是使用：for i in range(n-1) : return f.readline()提前提过前面的行数，只打印需要的行数
    9. 单行读取

  • 扩展方法——writelines()

    1. 将指定的字符串或二进制，写入文件(注意：不会自动添加符号)。
    2. 语法：writelines(可迭代对象（如列表、元组、生成器等)
    3. 注意：不会自动添加符号，需要自行写：换行：\n、制表：\t...
    4. r：光标在最前面、w：光标在最前面、a：光标在最后面
    6. writelines() 只接受一个参数，必须是一个可迭代对象（比如列表、元组、生成器），每个元素是要写入的一行内容。不能同时传入多个独立的字符串。
    7. 注意写入没有：writeline()

文件处理方法扩展

分类 方法/属性 说明 示例 备注
文件状态检查 closed 判断文件是否已关闭 f.closed 返回 True 或 False
mode 文件打开模式（只读） f.mode 如 'r'、'w' 等
readable() 检查文件是否可读 f.readable() 返回 True 或 False
writable() 检查文件是否可写 f.writable() 返回 True 或 False
指针操作 tell() 返回当前光标位置（字节数） pos = f.tell() 从文件开头算起的字节偏移量
seek(offset, whence) 移动光标到指定位置 f.seek(0) 回到开头 文本模式只能从开头偏移（whence=0）
seekable() 检查是否支持随机访问（seek()） f.seekable() 管道、终端等可能返回 False
数据读写 read(size) 读取指定字符数/字节数 data = f.read(10) 负数或省略 = 读取全部
readline(size) 读取一行（含换行符 \n） line = f.readline() 返回空字符串 '' 表示文件结束
readlines(hint) 读取所有行，返回字符串列表 lines = f.readlines() 可传 hint 限制读取的字节数
write(str) 写入字符串（文本模式） f.write('hello') 返回写入的字符数
writelines(lines) 写入字符串列表（不自动加换行） f.writelines(['a\n', 'b\n']) 需要自己添加 \n
flush() 将缓冲区数据强制写入硬盘 f.flush() 通常不需要手动调用，close() 会自动执行
truncate(size) 将文件截断到指定长度 f.truncate(10) 从文件开头保留前 10 个字节，其余删除
底层接口 fileno() 返回操作系统的文件描述符（整数） fd = f.fileno() 底层编程时使用，二级不涉及
终端检查 isatty() 检查文件是否连接到终端设备 f.isatty() 通常用于交互式输入，考试基本不涉及
迭代读取 for line in f 逐行遍历文件（内存友好） for line in f: print(line) 推荐方式，自动处理换行
上下文管理 with open(...) as f 自动关闭文件，即使发生异常也会释放资源 with open('info.txt', 'r') as f: data = f.read() 推荐始终使用，避免忘记 close()
