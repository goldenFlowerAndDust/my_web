读文件及注意事项

文件操作

  • 在学习文件操作之前，需要先回顾编码与数据类型相关的知识

  • 字符串类型

    1. 字符串类型(str)：在程序中用于表示文档信息，本质上是：Unicode编码中的二进制
    2. 如：name = 'YLH'

  • 字节类型

    1. 字节类型(bytes):可表示文字信息，本质上是：utf-8/gbk等编码的二进制，[对 Unicode进行压缩，方便文件存储和网络传输]

    2. name = '你好'

      data = name.encode('utf-8') # encode 将Unicode编码压缩成对应编码。

      print(data) # 输出结果是： b'\xe4\xbd\xa0\xe5\xa5\xbd'

      result = data.decode('utf-8') # decode 将其他编码，转为Unicode编码

      print(result) # 输出结果是：你好
    3. 可表示原始二进制(图片、文件等信息)
    4. 以上案例：encode:将Unicode编码压缩成对应编码,
      decode将其他编码，转为Unicode编码

读取文件

  • 先要了解：绝对地址与相对地址

  • 绝对地址

    1. 绝对地址：从本地盘符开始，直到文件的地址
    2. 好处：一步到位，直接复制可用
    3. 坏处：一但定义，当文件移动位置，原本路径失效，需要自行再次更改
    4. 常用于本地读取，上传到：GitHub等静态托管会出大问题

  • 相对地址

    • 相对地址：通过 ./（当前目录）、../（上级目录）或直接写文件夹名来定位文件。例如：./data/file.txt 表示当前目录下的 data 文件夹中的 file.txt。
    • 好处：一但定义，当文件移动位置，原本路径会跟着改变，无需后续再次更改
    • 坏处：坏处：当脚本的运行目录发生变化时（例如被其他位置的脚本调用），相对路径的基准会改变，可能导致文件找不到。项目内嵌套过深时，路径可读性会下降。
    • 自认为这是最好的写法，一劳永逸，上传网页也不会出大问题
  • 需要注意的是：模块引用地址与文件引用地址有区别

  • 打开文件方式

    1. 打开文件：使用open(路径,mode='读取模式',encoding='解码类型')的方式打开文件
    2. rb：表示读取文件原始二进制
    3. r,rt：表示读取文件文本，最好需要通过：encoding指定解码类型
    4. b：二进制：binary:，单写一个'b',不会报错，等价于'rb'
    5. 使用open打开文件，默认解码与操作系统挂钩，Windows默认是：GBK,Linux默认是：utf-8

    6. 也就是设文件以：utf-8存储：

      1. Windows:必须写：encding='utf-8'
      2. Linux：可以不写：encoding='utf-8'
      3. 当文件存储是：GBK：则 Windows不需要、Linux需要
      4. 其余任何编码格式都需要：写：encoding('解码类型')
      5. 未指定解码类型则报错：UnicodeDecodeError

    7. 文件的整个过程

      1. 所有模式(r,rb,rt)最开始都是读取硬盘上的原始二进制
      2. rb模式：直接输出原始二进制，不会进行后续解码
      3. 其他模式：后续会自动解码，默认解码器与操作系统挂钩
      4. Windows默认：GBK、Linux默认：utf-8
      5. 其实最好的写法是：都写encoding指定解码类型,默认有这个概念即可
      6. 最重要的是：过程
    8. 注意：当文件路径不存在或输入错误，会报错：FileNotFoundError

  • 读文本文件

    1. 可以用：rb，但是后续需要自行：decode()转成字符串

    2. file_object = open('info.txt',mode='rb') # 打开文件，指定模式为只读二进制

      data = file_object.read() # 读取文件，并赋值给 data

      file_object.close() # 当文件操作结束后，用 close()关闭文件，释放资源
      print(data) # 打印的是压缩的编码
      text = data.decode('utf-8') # 通过decode('utf-8')，重新转成字符串

      print(text) 打印读取的文件
    3. 以上方法极其麻烦：当只要读取文本，因为：open()在Windows默认是GBK解码，当不是GBK编码文件，后续要通过：decode()，转成可见的字符串
    4. 所以读文件一般用：r,rt

    5. file_object = open('info.txt',mode='rt',encoding='utf-8') # 打开文件，并指定模式，只读，原始二进制、还是后续的写入

      data = file_object.read() # 读取文件，并赋值给 data

      file_object.close() # 当文件操作结束后，用 close()关闭文件，释放资源


      print(data) 打印读取的文件

  • 读图片等非文本内容

    1. 读非文本文内容必须：rb

    2. file_object = open('info.png',mode='rb') # 打开文件，并指定模式，只读，原始二进制、还是后续的写入

      data = file_object.read() # 读取文件，并赋值给 data

      file_object.close() # 当文件操作结束后，用 close()关闭文件，释放资源


      print(data) 打印读取的文件
