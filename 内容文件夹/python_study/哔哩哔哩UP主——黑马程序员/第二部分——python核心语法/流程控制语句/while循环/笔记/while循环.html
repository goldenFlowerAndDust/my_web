  • JavaScript写法

    1. while (循环条件){
        # 循环条件可以设置为True(但是内部需要break退出，否则陷入死循环)，也可以自行设置边界，达到某个阈值便停止循环
          代码块
          break

        }

    2. num = 0 // 初始化变量
      do { // do-while，特性：不管条件是否成立，代码块都会执行一次
        console.log(num)
        if (num === 20){
          break;
        }
        num++
      }while (循环条件)

    3. 总结：

      1. 同样循环停止有两种方法：
      2. 在写入循环条件时：规定好边界，达到阈值退出循环
      3. 循环条件写为：True，代码块内部由：break关键字退出循环
      4. JavaScript有但python没有：do-while结构，不管循环条件是否成立，都会执行一次代码块。
  • 综上所述：python的循环条件不需要括号，代码由缩进控制。JavaScript的循环条件小括号，代码块由大括号包裹
