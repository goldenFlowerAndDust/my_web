if基础语法

  • 正常情况，代码都是从上到下依次执行
  • if语法：可以理解为，开辟一个或多个分支，通过判断，运行具体分支

  • 形式一：

    1. if-else
    2. 先判断if内的条件，如果符合则，执行if内的代码块，否则执行else内的代码块
    3. 当然 else并不是必须写的，当条件不成立，会跳过 if 内的代码块，继续向下执行

    形式二：

    1. if-elif-...-else
    2. 同样先判断if，然后依次判断elif，以上均不成立，则执行else内的代码块
    3. 同样，else不是必须的，以上条件均不成立，会跳过条件分支，继续向下执行

    python的条件分支与JavaScript条件分支的区别

    1. 多条件分支，python的写法是：elif，JavaScript的写法是：else if
    2. 在JavaScript中每个独立分支都是一个作用域，作用域内的：除去var关键字声明的变量，只在作用域内有效
    3. python的条件分支语句，没有作用域，条件分支内的变量，外部同样可以访问。
    4. JavaScript存在第二种分支语句：switch-case-default，python并没有
    5. JavaScript条件分支语句

    对比维度 python JavaScript
    基本语法 if 条件：
      代码块     		if (条件) {
      代码块 }
    多分支写法 elif else if(注意有空格)
    结束标记 缩进(取消缩进即结束) 花括号({})
    分支是否生成作用域 ❌ 不生成。if 内部变量外部可访问 ✅ 生成（let/const）。if 内部变量外部访问会报错
    变量泄露问题 if内声明的变量会泄露到外部作用域 用let/const不会泄露;但用var会泄露(函数级作用域)
    条件表达式(三元) a if 条件 else b 条件 ? a : b
    switch替代方案 python 3.10+ 有 match-case，一般使用：if-elif-else 有switch-case-default,支持穿透效果
    条件中类型转换 不会自动转换类型，如：if '5' == 5 ————> False 宽松相等 == 会隐式转换，严格相等===不会
    真值/假值规则 False、None、0、""、[]、()、{}、set()为假，其余为真 false、null、undefined、0、""、NaN为假，其余为真(包括[]和{})
    链式比较 ✅ 支持：if 10 < num < 20 ❌ 不支持，必须拆开：if (10 < num && num < 20)
    缩进敏感 ✅ 缩进错误会导致 IndentationError ❌ 缩进不影响逻辑，仅影响可读性
    代码块结构 冒号 : + 缩进 花括号 {}（可省略但强烈不推荐）

    避坑指南(从JS转python最容易踩的雷)
    坑 说明 正确做法
    忘记写冒号 : python的 if行尾必须有冒号 if 条件 :
    缩进不一致 混用Tab和空格会报错 统一用4个空格

    习惯写 switch python没有(3.10前) 用 if-elif-else代替
