for循环

自行总结

  • 关于JavaScript的 for循环几种形式

    1. 默认形式

      • 语法：for (初始化变量; 循环条件; 步长更新){代码块}
      • 初始化变量：声明变量并赋值。主要为后续循环条件与改变逻辑做参考
      • 循环条件：退出循环的条件
      • 步长更新：一般与初始化变量有关，主要与循环条件配合，步长更改变量值， 变量值影响循环条件，最终达到循环条件，退出循环
      • 需要注意事项
        1. 三个参数，非必须写
        2. 初始化变量可以是外部变量
        3. 循环条件：省略不写/true如果代码块内部没有break 则陷入死循环
        4. 步长更新：省略不写，或故意往循环条件反向更新如果代码块内部没有break 则陷入死循环
        5. 支持：for (;;;){代码块}写法，内部没有break同样死循环
        6. 所以最好：循环条件为true + 内部break或则三个参数写全，从而避免死循环
        7. 可以嵌套：
          for (let i=0; i < 10 ; i++){
            for (let j = 0; j < 10 ; j++){代码块) }
          通过嵌套可以解决多层问题，比如画一个三角形(分外层和内层，这就需要用到双层循环)....

    2. for-in形式

      • 语法：for (声明变量 in 需要迭代的容器){代码块}
      • 声明变量：声明变量不要赋值，主要用于接受索引，索引从0开始，随着迭代次数增加而自增
      • 需要迭代(遍历)的容器：可以是数组、字符串、对象、Set()....
      • 需要注意事项
        1. 声明变量是必须要操作的，不能忽略，主要用于计入索引，方便后续调用对象、字符串、数组
        2. in关键字不能忽略
        3. 迭代器必须存在
        4. 默认for循环，需要步长更新，来规划循环次数，for-in不需要，他的循环次数由迭代容器的长度决定
        5. 其实只要记住：for-in的返回值是索引，需要调用原迭代容器。

    3. for-of形式

      • 语法：for (声明变量 of 需要迭代的容器){代码块}
      • 声明变量：声明变量不要赋值，主要用于接受每次迭代的元素
      • 需要迭代(遍历)的容器：可以是数组、字符串、对象、Set()....
      • 需要注意事项
        1. 声明变量是必须要操作的，不能忽略，主要用于临时存储，当前迭代次数的元素
        2. of关键字不能忽略
        3. 迭代器必须存在
        4. 默认for循环，需要步长更新，来规划循环次数，for-of不需要，他的循环次数由迭代容器的长度决定
        5. 其实只要记住：for-of的返回值是当前迭代的元素，可以直接使用

python的 for循环的几种显示效果

  • python的for的循环没有JavaScript有那么多形式

  • 第一种写法，标准写法(for-in)

    1. 标准写法：for 变量 in 迭代容器
    2. 变量：变量不赋值，主要用于接收，迭代元素，迭代出的元素就是容器内的原数据类型(list、dict、set、str......)
    3. 迭代容器：可以是任何可迭代对象，list、dict、set、str.....

    4. 注意事项

      • 在标准写法中，变量接收的是元素，而非索引
      • 当迭代容器中，包含多种数据类型，如：["hello",20,{"name":"张三"}]，通过迭代，结果依次是：str、int、dict数据类型
        当我们要对其中一个数据类型进行操作的时候，需要先判断数据类型，使用方法：isinstance(变量,数据类型)
        第一个参数：需要判断的变量，第二个参数：需要判断的数据类型。
        返回值是布尔值，符合条件返回 True，否则 False
        可以同时判断多个数据类型：isinstance(变量,(int,str,dict...))，只要变量符合其中一种，就返回True

  • 第二种写法：变体(for-in-range())

    1. 写法：for 变量 in range()
    2. 该写法：变量接收的是索引
      • range(起始值,结束值,步长)
      • 起始值、步长非必要写，结束值必须写
      • 起始值：顾名思义就是迭代过程中，开头值(能取到(默认为0))
      • 结束值：顾名思义就是迭代过程中，结束的值(取不到，在当前值前一个值结束(必须写))
      • 步长：就是每一次迭代值的变化，负数则递减，正数则递增，0则直接报错(默认为1)
      • 其实只要记住：结束值必须写，值区间：左开右闭，步长不为零即可
      • for循环同样支持，for-else功能与while-else一致
    4. 总结：python的 for循环只有for...in一种形式，
      具体的变化是，最后的辅助工具的不同，所迭代的结果不同，如：range()结果为索引

pythonfor循环总结
对比维度 for...in(直接迭代) for ... in range(...)（按索引） 配套工具
核心用途 直接遍历可迭代对象的元素本身 按range()生成的数值序列循环 辅助迭代、增强灵活性
适用对象 列表、元组、字符串、字典、集合、生成器、文件对象等一切可迭代对象 range() 生成数值序列 enumerate()、zip()、reversed()、sorted() 等
迭代内容
  • 元素本身（字典为键，集合为元素）
  • 在python中字典是通过键名查找值，本质与JavaScript的对象一致
  • 在python中列表，字符串，集合都是通过数字索引直接提取对应元素，与JavaScript数组有本质区别
  • python不存在隐式转换，JavaScript数组是一个对象，键名是字符串，且会隐式转换，所以：
  • JavaScript：arr["0"] 等价于arr[0]
  • python：arr["0"] 不等于 arr[0]，强行写会报错[TypeError]
range() 生成的数值序列（0, 1, 2, ...） 索引+元素、多序列并行、反向、排序等
能否修改原数据 ❌ 不可以直接修改（但可通过其他方式操作原对象） ❌ 不可以（range 生成新序列，不修改原对象） 视具体工具而定
控制步长方式 自动按迭代器顺序 手动：range(起始, 结束, 步长) 自动或手动结合
break / continue ✅ 支持 ✅ 支持 ✅ 支持
典型写法 for item in my_list: for i in range(len(arr)): for i, item in enumerate(arr):
配套工具 可配合 enumerate()、zip()、reversed()、sorted() 使用 range() 本身就是一个工具 enumerate()、zip()、reversed()、sorted()
使用建议 大多数情况下的首选写法 需要索引或精确控制次数时使用 根据需求灵活组合
for循环同样支持，for-else功能与while-else一致
