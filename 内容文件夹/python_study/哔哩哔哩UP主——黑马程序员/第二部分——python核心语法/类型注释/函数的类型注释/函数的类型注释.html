函数的类型注释

  • 定义：为函数的参数和返回值添加类型注解

  • 语法


    def calc(score: list[int]) -> float: # 注释形参列表元素数据类型，-> float表示返回值的数据类型
      return sum(score)/len(score)

    def calc_data(scores: list[int]) -> tuple[int,int,float]: list[int]注释列表元素数据类型，->注释返回值的数据类型
      max_v = max(scores)
      min_v = min(scores)
      avg_v = sum(scores) / len(scores)
      return max_v, min_v, avg_v

  • 总结

    1. 如上代码所见：函数的注释主要在：参数注释、返回值注释(提醒)
    2. 参数注释与普通注释一致
    3. 可以单个注释，也可以多个注释，多个注释用|隔开，或Union[]。
    4. 元组规则一致：逗号隔开：对应下标注释、|或Union[]：对应下标元素多个数据类型注释、...后续元素匹配前一个数据类型
    5. ...必须放在最后面，且只能出现一次
    6. 返回值注释：形参后面添加：-> 普通注释
  • 注意：默认参数类型推断机制，默认参数的字面量的类型注释就是值的数据类型

扩展——不定长参数的注释

  • 不定长参数——位置参数

    1. 常规注释：def calc(*args: int) -> float
    2. 含义：每个多余的实参都应是 int 类型
    3. 也可写成：def calc(*args: tuple[int, ...]) -> float（但不如上面的写法常用）
    4. 同样：类型固定且多个可以用：|或Union[]，如果类型不固定可以用：Any

  • 不定长参数——关键字参数

    1. 常规注释：def student(**kwargs: int) -> tuple[list[str], list[int]]
    2. 表示多余的关键字参数，键默认为str类型、值注释为int类型
    3. Python 3.12+ 可写成：def student(**kwargs: dict[str, int]) -> ...
    4. 如果值类型不固定，用 def student(**kwargs: Any)/def student(**kwargs:dict[str,Any])
    5. 也就是：类型固定且多个可以用：|或Union[]，如果类型不固定可以用：Any，但是仅限于值的注释，键必须是：str类型——不定长参数——关键字的硬性要求
