类型注解——价绍

  • 类型注解是：python的一种语法特征，用于(明确标识变量、函数参数和返回值的数据类型)，从而使代码更清晰、更安全、更易维护
  • 语法结构(变量)：字面量:数据类型 = 变量值
  • 语法结构(容器[列表])：字面量:list[数据类型] = 值
  • 语法结构(容器[集合])：字面量:set[数据类型] = 值
  • 语法结构(容器[字典])：字面量:dict[【键】数据类型,【值】数据类型] = 值
  • 语法结构(容器[元组])：字面量:tuple[下标1数据类型,下标2数据类型, ...] = 值
  • 扩展：可以使用或运算符【|】或 导入模块[from typing import Union]，语法：[Union[str,int,...]]
  • Any关键字，关闭python类型检查，暂时理解为：所有数据类型都可以

  • 关于...的规范

    1. ...不能当作类型使用，要想规定元素可以是多种数据类型，只能单独列出来，|隔开，或 Union()
    2. 但是：...在tuple有特殊作用：表示后续所有元素，匹配符号前一个数据类型。
    3. 注意：其他容器没有...，要想定义所有数据类型用Any
    4. tuple可以使用：...，但是只能在最后一个，且只能出现一次

  • 注意事项

    1. 所有结构都能使用：或运算符【|】或 Union达成一个元素可以是多种数据类型
    2. 包括键和值(同样是可以指定多个数据类型)：但是注意键必须是可哈希的，必须是不可变的，比如：(str、int、float、tuple...)

    3. 在非使用多种数据类型写法状态下：

      1. 字面量、list、set、dict对应的变量值、元素、键和值必须是指定的数据类型
      2. tuple同样是使用【|或Union】指定单个元素的多种数据类型，逗号分隔是指定对应下标的数据类型，这是元组独有的
    4. 注释不能作用于解包场景：比如：(name:str , age:int = "YLH",20)直接报错/(name, age:int = "YLH", 20)同样继续报错
    5. 整个过程是注释的过程，重在提醒操作或调用者需要赋值或传参的数据类型，并不是规定数据类型，不按指定的数据类型赋值或传参，并不会报错
    6. 同一个字面量的注释,后面的会覆盖前面的

python——类型推断

  • 类型推断是指：python解释器自动推断出变量，表达式或函数返回值的数据类型的能力，而无需开发者显示声明
  • 通过值的数据类型，推断出字面量的数据类型
  • 在对变量进行直接赋值，或涉及到变量的运算，容器的推导式等场景时，解释器会自动推导出变量的类型
  • 所以正常写代码可以不必写注释，主要是：函数参数的注释
