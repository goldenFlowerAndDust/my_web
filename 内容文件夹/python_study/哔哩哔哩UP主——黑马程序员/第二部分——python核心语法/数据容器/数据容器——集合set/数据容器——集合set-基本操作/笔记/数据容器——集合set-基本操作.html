集合set-基本操作

集合set概念

  • 集合：同样是可以存储多个数据类型
  • 特点：同一个集合内，元素不能重复
  • 不能重复：同一种数据类型，且值相同

  • 概念

    1. 集合(set)是一种无序的、不可重复、可修改的容器
    2. 既然无序，则不存在序列，也不能使用索引访问元素
    3. 定义集合：字面量 = {元素1, 元素2, ...}
    4. 定义空集合：字面量 = set()，注意：字面量 = {}，是创建空字典，并不是空集合
    5. 集合推导式(不添加条件)：字面量 = {s for s in 可迭代容器}
    6. 集合推导式(添加条件)：字面量 = {s for s in 可迭代容器 if 条件}
    7. 推导式都分为：无条件与有条件两种写法

    8. 注意：

      • 方法：set()，只能传一个参数，这个参数可以是：单个元素，也可以是一个可迭代对象
      • 因为无法获取具体元素，所以修改元素值只能：remove() + add()

两个集合之间的关系

difference() 求取两个集合的差集(包含在第一个集合但不包含第二个集合的元素) s1.difference(s2) 等价于 s1 - s2
union() 求两个集合的并集(两个集合当中，所有元素，自动去重) s1.union(s2) 等价于 s1 | s2
intersection() 求取两个集合的交集(两个集合，都存在的元素) s1.intersection(s2) 等价于 s1 & s2
symmetric_difference() 求取两个集合的对称差集(保留两个集合，各自独有的元素(去掉共有的元素)) s1.symmetric_difference(s2) 等价于 s1 ^ s2
集合运算(判断支持多个参数的方法)——注意：下列方法均有返回值，不更改原集合，需要字面量接收返回值
方法 支持多参数吗 示例
union() ✅ 是 s1.union(s2, s3, s4)
intersection() ✅ 是 s1.intersection(s2, s3, s4)
difference() ✅ 是 s1.difference(s2)
symmetric_difference() ❌ 否 s1.symmetric_difference(s2)（只能一个）
集合运算，更改原列表注意：下列方法均无返回值，更改原集合
集合运算 方法 示例
并集 update()，因为自身，迭代添加元素特性，天然适配并集 s1.update(s2)
交集 intersection_update() s1.intersection_update(s2, s3, s4)
差集 difference_update() s1.difference_update(s2)
对称差集 symmetric_difference_update() s1.symmetric_difference_update(s2)（只能一个）
以上方法，本质与正常集合运算并无差别，唯一区别，更改原列表

总结
Python 集合：功能丰富，支持交集、并集、差集、对称差集、子集判断等原生运算，适合数学集合操作。
JavaScript Set：基础功能完整，但集合运算需要手动实现，适合存储唯一值，但不适合复杂集合操作。
