字典dict-介绍

  • 现实字典本意：通过[字/词语]，找到对应的 [解释]
  • 在python中字典：【字/词语】定义为 【键】，【解释】定义为 【值】
  • 所以，字典的元素称为 【键值对】，通过 【键】访问对应的【值】

  • 字典的特点

    1. 定义字典：字面量 = {key:value,key:value, ...}
    2. 定义空字典：字面量 = dict()或字面量 = {}
    3. 字典存储的是：键值对——key:value，key:键、value：值
    4. 通过键，访问对应的值
    5. 键值对存储、键不能重复、可修改、值可以是任何数据类型

    字典的注意事项

    1. 键必须是唯一的，同一个字典，不能出现两个或多个完全相同的键
    2. 字典的键，必须是可(哈希的)
    3. 哈希值：它是通过算法：哈希函数计算出来的，哈希值是唯一的
    4. 每当定义一个键，就会执行一次函数，存储哈希值，每当访问一个键，会先将键转哈希值，然后通过哈希值，查找对应的值
    5. 已知哈希值必须是不变的，所以可哈希的有：字符串、元组(内部元素必须不可变)、数字,不可哈希的有：列表、集合
    6. 值：与变量值一致，可以是任何数据类型、容器
    7. 总结来说：键——哈希值：就是值的身份证，通过身份证找到对应的值、而每个人的身份证都不一致，所以键——哈希值也是唯一，不能随意更改的
    8. 不能通过下标访问，字典没有序列
是否能作为键
可以作为键(可哈希) 不可以作为(不可哈希)
✅ int、float、bool ❌ list（可变，哈希值会变）
✅ str、bytes ❌ dict（可变，哈希值会变）
✅ tuple（但必须内部元素都是可哈希的） ❌ set（可变，哈希值会变）
✅ frozenset（不可变集合）
✅ None
额外补充：❌ 自定义对象（默认是可哈希的，但如果实现了 __eq__ 而未实现 __hash__，则不可哈希
