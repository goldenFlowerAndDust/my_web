字典的增删改查
类型 操作 含义 示例
增(添加) 字典名称[key] = value
  1. 往指定字典中添加key-value键值对
  2. 键在原列表必须不存在，否则修改操作
 dict1["姓名"] = "name"
删(删除) 字典名称.pop(key) 删除字典中指定的key,并返回该key对应的value name = dict1.pop("name")
del 字典名称[key] 删除字典中指定的键值对 del dict["name"]
改(修改) 字典名称[key] = 新值
  1. 修改字典中指定的key对应的值
  2. 键必须存在，否则就是添加操作
 dict["name"] = "小明"
查(查询) 字典名称[key]
  1. 通过键访问(查询)对应的值
  2. 注意：键必须存在，否则报错
 name = dict["name"]
字典名称.get(key)
  1. 通过键访问(查询)对应的值
  2. 注意：键不是必须存在，当键不存在不会报错
 name = dict.get("name")
字典名称.keys()
  1. 获取所有的键(key)，并返回动态视图
  2. 动态视图目前暂定理解为字典方法(keys()、values()、items())存在
  3. 动态视图(keys())：与字典的变化而产生变化，当原字典的键更改，动态视图会实时更新
  4. 可以直接理解为：实时查看所有键
 view = dict.keys()
字典名称.values()
  1. 获取所有的值(values)，并返回动态视图
  2. 动态视图目前暂定理解为字典方法(keys()、values()、items())存在
  3. 动态视图(values()):与字典的变化而产生变化，当原字典值更改，动态视图会实时更新
  4. 可以直接理解为：实时查看所有值
 view = dict.values()
字典名称.items()
  1. 获取所有的键值对(key:values)，并返回动态视图
  2. 动态视图目前暂定理解为字典方法(keys()、values()、items())存在
  3. 动态视图(values()):与字典的变化而产生变化，当原字典值、键更改，动态视图会实时更新
  4. 可以直接理解为：实时查看所有键值对(但是是以元组形式：(key,value))
  5. 元组本身无法修改，但是视图是字典的一个动态窗口，它会随字典的变化而实时更新。
view = dict.items()

    dict1.update(dict2) 合并另一个字典到当前字典(有相同键则覆盖)

Python 字典 vs JavaScript 对象 vs Map 完整对比表

一、概念与定义
维度 Python 字典 JavaScript 对象 / Map
本质 内置数据类型 对象（Object）/ 内置对象（Map）
定义方式 d = {"name": "张三"} 对象：let obj = {name: "张三"}
Map：let map = new Map([["name", "张三"]])
空容器 d = {} 或 d = dict() 对象：let obj = {}
Map：let map = new Map()
键的类型 必须是可哈希的（不可变类型） 对象：只能是字符串或 Symbol
Map：可以是任意类型
键是否保持顺序 ✅ 保持插入顺序（Python 3.7+） 对象：字符串键保持插入顺序，数字键会排序
Map：✅ 保持插入顺序

二、增删改查
操作 Python 字典 JavaScript 对象 / Map
增/改 d["key"] = value 对象：obj["key"] = value 或 obj.key = value
Map：map.set("key", value)
查（键存在时） d["key"]（键不存在报错） 对象：obj["key"]（不存在返回 undefined）
Map：map.get("key")（不存在返回 undefined）
查（安全方式） d.get("key")（不存在返回 None） 对象：obj["key"] ?? defaultValue
Map：map.get("key")（可配合 ??）
删除指定键 del d["key"] 或 d.pop("key") 对象：delete obj["key"]
Map：map.delete("key")
删除并返回 d.pop("key") Map：map.delete("key")（返回布尔值）
对象：无原生方法
清空 d.clear() 对象：obj = {} 或逐属性删除
Map：map.clear()

三、查询与遍历
操作 Python 字典 JavaScript 对象 / Map
检查键是否存在 "key" in d 对象："key" in obj 或 obj.hasOwnProperty("key")
Map：map.has("key")
获取所有键 d.keys()（返回视图） 对象：Object.keys(obj)（返回数组）
Map：map.keys()（返回迭代器）
获取所有值 d.values()（返回视图） 对象：Object.values(obj)（返回数组）
Map：map.values()（返回迭代器）
获取所有键值对 d.items()（返回视图） 对象：Object.entries(obj)（返回数组）
Map：map.entries()（返回迭代器）
遍历 for key in d:
for key, value in d.items():		 对象：for (let key in obj) {}（需配合 hasOwnProperty）
Map：for (let [key, value] of map) {}

四、其他常用方法
操作 Python 字典 JavaScript 对象 / Map
合并/更新 d1.update(d2) 对象：Object.assign(obj1, obj2) 或 {...obj1, ...obj2}
Map：new Map([...map1, ...map2])
创建新对象/字典 dict.fromkeys(iterable, value) 对象：手动创建
Map：new Map() 配合循环
获取大小 len(d) 对象：Object.keys(obj).length
Map：map.size
浅拷贝 d.copy() 对象：{...obj} 或 Object.assign({}, obj)
Map：new Map(map)

总结
Python 字典：键必须可哈希，保持插入顺序，支持丰富的视图操作（keys()、values()、items()）。
JavaScript 对象：键只能是字符串或 Symbol，适合作为数据容器，但遍历时需要小心原型链。
JavaScript Map：键可以是任意类型，保持插入顺序，是 Python 字典最接近的对应结构，但方法命名不同。
