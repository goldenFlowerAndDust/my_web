五、增操作
操作 python列表 JavaScript数组
末尾添加单个元素
  • append(x)
  • 整体添加，可迭代对象为一个元素
  • 更改原列表，无返回值
  • 只能接收一个参数
  1. push(item, item2...)
    • 可以添加多个元素，均在末尾按顺序逐个添加
    • 非展开添加，可迭代对象为一个元素
    • 无返回值，更改原数组
  2. push(...arr)
    1. ...JavaScript的扩展运算符
    2. 与python的*/**类似
    3. 在这理解就是：将可迭代对象拆开，然后逐个添加
    4. 更改原数组
首添加单个元素 insert(0, item) unshift()
指定位置插入
  • insert(index, item)
  • 整体添加，可迭代对象为一个元素
  • 更改原列表
  1. splice(start,deleteCount)：
        从start删除 deleteCount个元素
  2. splice(start,deleteCount, item, item2...)：
        从start删除 deleteCount个元素,然后逐个添加元素item
  3. splice(start, 0, item, item2...)：
        从 start后，逐个插入元素item不删除元素
  4. splice(start):
        删除start后所有元素
  5. 一般情况，第二个参数 deleteCount不能忽略，但是splice(start)例外
  6. 更改原数组
末尾添加多个元素 extend(iterable),briterable:可迭代对象 push(...arr)或concat()
  1. push(...arr)更改原数组，无返回值
  2. concat()创建新数组对象，不更改原数组，有返回值
合并列表 +/extend()/[*a, *b] concat()/[...a, ...b]
返回值 增方法大多的返回None push()返回新长度

七、改操作
操作 python列表 JavaScript数组
索引赋值 lst[index] = 新值 arr[index] = 新值
切片赋值 ✅ lst[1:3] = [a, b] ❌ 不支持（可用 splice 替代）
排序
  1. 升序：sort()(原地)数字排序，容器内必须是数字类型
  2. 降序：sort(reverse = True)(原地)数字排序，容器内必须是数字类型
 sort()(原地)，不传函数，默认按：unicode编码正序排序
反转 reverse()(原地) reverse()(原地)
自定义排序 sort(key = 函数)具体按什么排序由函数决定
  • 升序：sort((a, b) => a - b)数字升序
  • 降序：sort((a, b) => b - a)数字降序

十、遍历方式

总结
Python 列表：功能集中在“增删改查 + 切片 + 推导式”，强调简洁直观，适合数据处理。
JavaScript 数组：：功能集中在“方法链 + 函数式编程”，强调灵活操作，适合前端交互。
