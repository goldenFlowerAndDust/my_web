列表推导式

  1. 语法：[表达式 for x in 可迭代对象 if 条件]
  2. 如：[x ** 2 for x in list_1 if x % 2 == 0]
  3. 等价于：
    list_1 = [30, 31, 50, 20, 40, 33, 11]
    list_2 = []
    for x in list_1:
      if x % 2 == 0:
         list_2.append(x ** 2)
  4. 其中表达式的结果就是列表的元素
  5. 说白了，就是将遍历、判断、输出结果压缩，一行写完
  6. 比起单纯的for循环，代码更简介、易懂

扩展

关于推导式其他容器的使用方法
写法 名称 结果类型
[x**2 for x in range(10)] 列表推导式 列表 list
(x ** 2 for x in range(10)) 生成器表达式 生成器对象(惰性求值)
{x**2 for x in range(10)} 集合推导式 集合 set
{x: x**2 for x in range(10)} 字典推导式 字典 dict
