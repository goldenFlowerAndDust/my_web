列表list-解包

解包概念

  • 解包本质：将一个可迭代对象(如:列表、元组)中的元素，按位置————赋值给多个变量

  • 最简单的解包形式

    1. 右侧的容器被"拆开"，里面的每个元素依次赋值给左侧的变量
    2. 如：
      # 元组解包
      a, b, c = (1, 2, 3)
      # a=1, b=2, c=3

      # 列表解包
      x, y = [10, 20]
      # x=10, y=20

    核心规则

    1. 左侧变量数量必须等于右侧容器元素数量，否则会报错

      如：a, b = [1, 2, 3] # ValueError: too many values to unpack

    2. 适用于任何可迭代对象：列表、元组、字符串、集合、字典(解包的是键)等

      如：first, second, third = "abc" # first='a', second='b', third='c'

    3. *可以收集多余元素(打包成列表)


      先将左右分配完，*左边就按正序分，*右边就按倒序分，*最后将剩余元素，重新打包成列表
      同一个解包，不能出现多个*不然会报错 如：first, *middle, last = [1, 2, 3, 4, 5]
      # first=1, middle=[2,3,4], last=5
    4. *的两种用法
      位置 用途 示例
      左侧（解包赋值） 收集剩余元素 first, *middle, last = [1,2,3,4,5]
      右侧（列表/元组字面量） 展开可迭代对象 [*list1, *list2]
      右侧的 * 在 Python 3.5+ 中引入，主要用于将多个列表合并成一个新列表。它的优势是保持原列表不变，同时可以灵活地插入多个元素

    常见使用场景

    1. 变量交换(无需中间变量)

      如：a, b = b, a

    2. 函数返回多个值

      如：name, age = get_user_info()

    3. 遍历字典(同时获取键和值)

      如：for key, value in dict.items():
        print(key, value)

    总结

    1. 解包本质就是"批量赋值"，它让代码更简洁，也让数据的提取和分配更直观。
    2. 在处理列表、元组、字典频繁使用
