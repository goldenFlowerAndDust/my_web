传参方式 — 总结

本页只列要点，详细示例请参阅下方链接。

  • 传参方式总览

    • 位置参数：按形参定义顺序一一对应传入。
    • 默认参数：定义时给形参赋默认值，调用时可省略。
    • 关键字参数：调用时指名道姓赋值，顺序可打乱。
    • 不定长参数：
      • *args —— 收集多余位置参数，打包为元组。
      • **kwargs —— 收集多余关键字参数，打包为字典。
    • 强制关键字参数：在 * 或 *args 之后的形参只能通过关键字传参。
    • 参数优先级：位置参数 > 默认参数 > * > 强制关键字 > **

  • 合法定义方式（速查）

    • def f(a, *b): ✅
    • def f(a, **b): ✅
    • def f(a, *b, **c): ✅
    • def f(a, *, b, **c): ✅
    • def f(a, *b, *c): ❌（两个 * 冲突）
    • def f(a, **b, *c): ❌（顺序反了）

课后总结

  • 位置参数

    1. 调用函数时，传入的实参的顺序与定义函数形参的顺序完全一致

  • 关键字参数

    1. 调用函数时，通过 "形参名 = 值"的形式传递参数，顺序没有要求
    2. 如果同时存在位置参数与关键字参数，位置参数在前，关键字参数在后

  • 默认值参数

    1. 默认值参数也称为缺省参数，用于在定义函数时，为参数提供默认值，调用函数时，可以不传递有默认值的参数
    2. 默认值参数必须放在没有默认值的参数列表的后面，一个函数可以设置多个默认值
    3. 函数调用时，如果默认参数传递了值。则会修改默认的参数值，如果没有传递参数，则直接使用默认值

  • 无定长参数

    1. 不定长参数也叫 可变参数，用于函数定义及调用时参数个数不确定(零或多个)的场景
    2. 类型一(无定长参数——位置参数)：*args，多余位置参数收集，组包成元组，然后赋值给形参。位置不固定，但是符号后面，均为强制关键字参数。
    3. 类型二(无定长参数——关键字参数)：**kwargs,多余关键字参数收集，组包成字典，然后赋值给形参，位置固定最后一个
    4. 优先级：* > 强制关键字 > **
    5. 无定长参数——关键字参数 一定在无定长参数——位置参数 后面
    6. 无定长参数——关键字参数(附加规则)
      • 一般字典的键名：必须是可哈希的(不可变对象)、数字、字符串、元组均是可以作为键名的
      • 但是无定长参数：添加一条硬性规则：键名必须是字符串

  • 传参方式的适用场景

    1. 一切以代码结构清晰为主(可读性)、便于维护(维护性)为目标
    2. 如果参数比较少(不超过三个)，可直接使用位置参数
    3. 如果参数数量较多，建议使用关键字参数。
    4. *args适用于处理数量不确定的数据
    5. **kwargs适用于处理数量不确定的选型(函数的配置参数，用来定制函数的行为)
  • 额外注意事项：只要多出数据被无定长参数收集，要么是元组，要么是字典。
    也就是说：尽管是一个位置参数，同样是元组。
    一个关键字参数，同样是字典。
