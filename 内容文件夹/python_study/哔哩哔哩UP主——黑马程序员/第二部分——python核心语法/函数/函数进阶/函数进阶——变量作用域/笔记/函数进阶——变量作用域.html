变量作用域

  • 变量的作用域指的是：变量的作用范围(标识这个变量在哪里可以使用，在哪里不能使用)
  • 说白了，就是变量的存活周期

    1. 全局作用域

      • 全局作用域也叫：全局变量
      • 全局变量：在函数之外定义的变量，称之为全局变量
      • 特点：存活周期：整个文件(包括函数内)都可以使用(全局变量始终在顶层)

    2. 局部作用域

      • 局部作用域也叫：局部变量
      • 局部变量：在函数内部定义的变量，称之为局部变量
      • 特点：存活周期：只在函数才能使用的变量

    3. 注意

      • 变量有严格的作用域划分
      • 局部变量，外部绝对无法访问

      • 函数访问变量的坑

        1. 函数内部，可以访问，全局变量，正常情况只是能访问，不能修改

        2. 函数修改外部变量的方法

          • 修改全局变量：使用关键字：global

          • x = 10
            def num():
              global x
              x = 20
            num()
            print(x) # 最后结果为 20
          • 内层函数修改外层函数变量的局部变量：使用关键字：nonlocal

          • def num1():
              x = 50
              def nun2():
                nonlocal x
                x = 30
              num2()
              print(x)
            num1() 最后的输出结果是 30

作用域核心对比
对比维度 JavaScript Python 核心差异
作用域类型
  • 全局作用域（Global）
  • 函数作用域（Function）
  • 块级作用域（Block，ES6+，由 let/const 创建）
  • 全局作用域（Global）
  • 函数作用域（Function）
  • ❌ 没有块级作用域（if、for 等不创建作用域）
 JS 有块级作用域（let/const），Python 没有块级作用域
变量提升
  • var 声明的变量会提升（Hoisted），初始化前值为 undefined
  • let/const 也会提升，但进入暂时性死区（TDZ），声明前访问报错
  • 函数声明会整体提升（函数体也提升）
  • ❌ 没有变量提升
  • 变量必须先定义后使用，否则报 NameError
  • 函数定义（def）在运行时执行，必须先定义后调用
 JS 有变量提升（尤其是 var 和函数声明），Python 完全没有
全局变量修改
  • 在全局声明的变量，在函数内部可直接修改（无需关键字）
  • 如果函数内部使用 var/let/const 重新声明同名变量，则创建局部变量，不影响全局
  • 在函数内部读取全局变量无需关键字
  • 在函数内部修改全局变量需使用 global 关键字
  • 否则会在函数内部创建新的局部变量
 JS 修改全局变量无需关键字（但需注意重新声明会遮蔽），Python 必须用 global
闭包中修改外层变量
  • 在嵌套函数中，直接修改外层函数的变量无需关键字
  • 但如果在外层作用域中重新声明同名变量，则会遮蔽外层变量
  • 闭包会“记住”外层变量
  • 在嵌套函数中，读取外层函数变量无需关键字
  • 在嵌套函数中，修改外层函数变量需使用 nonlocal 关键字
  • 否则会在当前函数内部创建新的局部变量
 Python 修改外层变量必须用 nonlocal，JS 无需关键字（但要避免遮蔽）
局部变量外部访问
  • 函数内部的局部变量（var/let/const）外部无法访问
  • 但可通过 返回值、闭包 或 全局变量 间接暴露
  • 函数内部的局部变量外部无法访问
  • 但可通过 返回值 或 闭包 间接暴露
  • 无法通过全局变量暴露（除非显式声明 global）
 两者局部变量外部都无法直接访问，但都有间接方式传递数据
变量查找顺序
  • 作用域链：当前作用域 → 外层作用域 → 全局作用域 → 报错
  • 没有类似 LEGB 的官方缩写，但逻辑一致
  • LEGB 规则：
  • Local → Enclosing → Global → Built-in
 Python 明确规定了 LEGB 顺序，JS 则是隐式的作用域链，但本质相同
块级作用域（if / for）
  • ES6+ 中，let/const 在 {} 内创建块级作用域
  • var 忽略块级作用域，只受函数作用域限制
  • ❌ if、for、while 等不创建作用域
  • 在块内定义的变量，在块外依然可访问
 JS 有块级作用域（let/const），Python 完全没有
严格模式
  • "use strict" 禁止隐式全局变量，避免意外创建全局变量
  • 其他影响：禁止重复参数名、禁止 with 等
  • Python 默认就是“严格”的，没有隐式全局变量（赋值即声明）
  • 函数内部赋值未声明的变量会创建局部变量，而非全局
 JS 需要 "use strict" 来避免隐式全局，Python 天生如此
全局对象
  • 浏览器环境：window（或 globalThis）
  • Node.js 环境：global
  • 在全局作用域声明的变量会成为全局对象的属性
  • Python 没有“全局对象”的概念
  • 全局变量存储在内置的 globals() 字典中，但一般不直接操作
 JS 有明确的全局对象（window/global），Python 无类似概念

🎯 一句话总结
JavaScript 作用域灵活，有块级作用域和变量提升，修改外层变量无需关键字，但需小心 var 的遮蔽和提升陷阱。
Python 作用域严格，无块级作用域和变量提升，修改全局变量需 global，修改外层函数变量需 nonlocal，规则明确，不易出错。
核心差异 JS 更灵活（但坑多），Python 更严谨（但规则清晰）。两者闭包机制相似，但修改外层变量的方式完全不同。
