匿名函数

  • 什么是匿名函数：没有名字的函数，需要通过 lambda表达式来声明函数，可以简化简单函数的缩写(单行表达式)
  • 含参数(可以是多个，英文逗号间隔)语法：sqrt = lambda 参数: 函数体
  • 不含参数语法：sqrt = lambda : 函数体
  • 字面量接收的是函数对象，不能直接print(字面量)
  • 无参调用： result = lambda :'|'*50
    print(result()) # 调用无参函数
  • 有参调用： result = lambda x,y,z:(x+y+z) ** 0.5
    print(result(10,50,30)) # 调用有参函数,需要传参
  • 直接打印字面量： result = lambda x,y,z:(x+y+z) ** 0.5
    print(result) # 打印的是函数对象，一串地址。

  • 特点

    1. 没有函数名，只有关键字lambda
    2. lambda 参数:函数体
    3. 不需要return关键字，传递返回值，本身就可以
    4. 可以字面量接收返回值，或直接调用
    5. 只能一行写完，有点类似于：元组生成器的函数版本
    6. 局限性：不能写语句：try-except，if-elif-else，for...
    7. 但是可以内部调用函数和方法：print()、len()、自定义函数、...

匿名函数（lambda）与相关核心用法总结表
知识点 核心语法/作用 关键特点
lambda基础 lambda 参数:返回值 单行函数，无需def和return
lambda VS def def可以多行、有函数名，lambda是匿名表达式 def更灵活，lambda更简洁
sort/ sorted() + key
  • list.sort(key=lambda x: x["score"],reverse = True)
  • new_list = sorted(list,key=lambda x: x["score"])
  1. 知识回顾：sort(key=None,reverse=False)
  2. key默认None,reverse默认False(升序)
  3. 注意：key接收的是函数对象，而不是函数调用结果
  4. 新知识(sorted)：sorted(iteration,key=None,reverse)
  5. 与sort不同，它有返回值，不更改原容器
  6. 主要作用：指定排序依据，不改变元素结构(只排序)
filter() + lambda filter(lambda x:x["score"] >= 80, dict)
  1. 筛选符合条件的元素，返回迭代器，想要正确显示结果需要转成容器，或遍历
  2. 只是筛选，返回值是原容器数据类型
map() + lambda students = map(lambda s:{'name':s["name"],'score':s['score'] + 5},iteration)
  1. 映射原列表，并通过函数，更改原容器数据
  2. 映射新容器，不会更改原容器，需要字面量接收返回值(迭代器)
  3. 返回数据类型，以函数更改的数据类型为主(可以理解为以返回值类型为主)。
  4. 所以需要注意：到底需要map返回什么？
lambda与推导式/生成器的关系
  1. 推导式是"批量生成"
  2. 与生成器：(x for i in range(5))都是"输出一个结果"
  3. 与生成器的区别：lambda 是函数对象，生成器是惰性迭代器
  4. 与生成器不同的是：它没有惰性与急性之分，在定义匿名函数的时候，对象就一直生成，等待调用执行
  5. 但是会受到：filter()/map()等高阶函数，影响是惰性的，
    因为 filter()/map()只有在被遍历或打印才会操作
lambda的限制 不能包含语句(如：print)，不能有 if-else复杂分支 只能写表达式
