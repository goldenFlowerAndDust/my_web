就是方法内部使用生成器（函数式编程）

 max() / min() / sum() 直接接收生成器表达式作为参数，无需先构造列表 新知识
  • max(score[subj] for score in students.values())
  • sum(score["数学"] for score in students.values())

生成器

 (s for s in iteration (if ...)可选) 老知识 巩固
特点
  • 惰性：只有被 for或 sum()...方法消费时才逐个产生
  • 没有元组推导式，可以使用：tuple(s for s in iteration)，强制转元组
  • 内存占用：极小(只存一个元素)

推导式
  • 列表推导式：[s for s in iteration (if ...)可选]
  • 集合推导式：{s for s in iteration (if ...)可选}
  • 字典推导式：{s:default for s in iteration (if ...)可选}
 老知识：巩固
特点
  • 急性：立即生成全部
  • 内存占用：巨大（存一百万个元素）
