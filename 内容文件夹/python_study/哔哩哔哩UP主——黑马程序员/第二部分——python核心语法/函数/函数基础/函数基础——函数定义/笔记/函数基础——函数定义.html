函数基础——函数定义

  • 定义函数与调用函数

  • 定义函数(有参函数)


    def 函数名(参数列表):
      函数体
      ......
      return 返回值

    # 调用函数
    函数名(参数)

  • 定义函数(无参函数)


    def 函数名():
      函数体
      ......

    # 调用函数
    函数名()

  • return关键字

    1. 作用：退出函数，并返回结果，唯一途径
    2. 特征：return后面代码，均不会被执行
    3. 语法：return 返回值
    4. 返回值：可以是一个单独的数字、也可以是变量、也可以是容器
    5. 同样也可以，多个变量、容器同时返回，用英文逗号隔开，会组包成元组，后续需要(遍历、下标、切片、解包)按需处理....
    6. 若没有关键字(return)或只写(return)，函数默认返回值是None
    7. 因为退出函数这个特性，当函数内部出现多层循环，因为关键字break、continue 都是只对最近一个循环分支起效，所以想要退出怎个循环，非常麻烦，但是使用 return， 直接退出函数，会强制退出整个循环，不管嵌套的有多深
    8. 💡 补充说明： return 的本职是“退出函数并返回结果”，
      利用它跳出多层循环只是“副作用”。如果函数内还有其他代码需要执行，用 return 就不合适了。
    9. 一个函数，在未使用条件分支语句(if、match-case)， 只能出现一次return，因为return后续所有代码，均不会被执行

  • 注意

    1. 函数定义时的参数列表与返回值语句是可有可无的(由需求确定)、函数必须先定义后调用执行(函数定义时，内部代码未执行，在调用时才执行)
    2. 🔍 Python 是“运行时解析”语言：函数定义语句被执行后，函数名才会被创建。 因此必须 先定义，后调用，否则报 NameError
    3. 先定义，后调用是python的规则、JavaScript 的声明式函数，可以先调用，后定义(专业术语叫：声明提升)

课堂小结——函数使用的注意事项

  • 函数必须先定义，在调用
  • 函数定义，并不会执行，只有在调用函数时，函数体的逻辑才会运行
  • 函数中通过缩进来描述归属关系
