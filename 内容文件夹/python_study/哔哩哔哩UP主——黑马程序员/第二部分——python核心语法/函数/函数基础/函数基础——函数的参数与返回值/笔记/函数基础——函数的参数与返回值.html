函数基础——函数的参数与返回值

函数的参数种类

  • 位置参数

    1. 函数的传递参数是有顺序的，位置参数优先级最高
    2. 在定义函数的时候：def num(a, b, c, d)其中，a, b, c, d这个整体就是位置参数传入实参的顺序，严格按照定义顺序
    3. 在调用函数的时候：num(10, 50, 100, "hello")，其中，10, 50, 100, "hello"这个整体就是位置参数 传入实参的顺序，严格遵守定义形参的顺序

  • 默认参数

    1. 顾名思义：定义函数的时候，形参的默认值
    2. def num(a, b, c=10):其中，c的默认值是10, c = 10这个整体就是一个默认参数——形参
    3. 特点：只在定义函数有此概念，且永远在位置参数后面，后续会被传入的实参覆盖，未被传入实参，则取默认值
    4. 因为有默认参数兜底，只要实际传参数量 <= 形参数量，就不会报错
    5. 一但：实际传参数量 > 形参数量，照样报错

  • 关键字参数

    1. 在调用函数的时候有此概念，直接指定关键字(形参)，然后为其赋值
    2. 位置参数优先级最高，会先匹配位置参数，然后匹配关键字参数
    3. python规则：已经被传参的形参，不能再次被传参，所以关键字避免与被传参的形参一致
    4. 关键字参数始终在位置参数后面，且顺序可以打乱(只是关键字参数可以打乱，前面的位置参数不能)
    5. 关键字参数的形式：键值对、key = value表达式，除此之外均是位置参数

    6. def num(a, b, c, d):
        return
      num(10, 50, d=30, c=10)
      # 先匹配位置参数 a = 10 , b =50, 然后匹配关键字参数，c = 10 , d = 30

      错误示范1：num(10, d=30, 30, c=10)
      # 位置参数必须在关键参数之前，10，30为位置参数，键值对或key = value形式为关键字参数，报错：语法错误：SyntaxError

      错误示范2：num(10, 30, b=50, c=10)
      # 先位置参数赋值，a = 10, b=30, 然后关键字参数， 请注意：b已经被传入过实参，后面的 b = 50，重新赋值，python不支持，报错：运行错误：TypeError
    7. 提醒：最好全部使用关键字参数，或定义函数时，将需要传关键字参数的形参放在后面,能有效避免，重复传参而报错

  • 无定长参数

    1. 在定义函数的时，收集多余实参组包成容器的形参

    2. 无参函数(*)

      • 多余位置参数 ，打包成元组
      • 写在形参内部：*字面量

      • def num(a, b, c, *tuples):
          return
        num(10, 50, 100, 30, *[30, 40, 50], *(60, 70, 80), *{60, 70, 80}, *"hello")
        # 原本定义的形参是：a, b, c共三个，但是传参明显超过三个
        按照python规则：在实际传参数量 > 形参数量，直接报错
        🍊🍊🍊🍊因为有：无定长参数：*tuples的存在，多余的非关键字参数，会被收集，打包成元组，赋值给tuple这个字面量
        🍊🍊🍊🍊不难看出，*在当前案例有两个作用，在形参中作用：组包成元组，在调用函数中作用：解包，展开容器
      • 以上案例，具体的执行流程
        1. 先解包，每个容器元素单独领出来：num(10, 50, 100, 30, 30, 40, 50, 60, 70, 80, 60, 70, 80, "h", "e", "l", "l", "o")
        2. 然后先赋值位置参数：a = 10 , b = 50, c = 100
        3. 多余的其他位置参数，会被重新打包成元组，赋值给字面量：tuples = (30, 30, 40, 50, 60, 70, 80, 60, 70, 80, "h", "e", "l", "l", "o")
        4. 说白了：就是将多余的，非键值对、key = value表达式，重新打包成元组，并赋值给字面量
      • 注意事项
        1. 一个函数只能出现，一次，*
        2. 位置不固定，但是在，*后面的参数，全部会被转化为：强制关键字参数
        3. 强制关键字参数：被转化为强制关键字参数，意味着，该形参只能接收关键字参数，不能接收位置参数
        4. 正常使用*，为多余的位置参数兜底：def num(a, b, *tuples):
        5. 使用位置参数 + 关键字参数组合：def num(a, *tuple, b, c):
            b, c 都被强制关键字参数，只能接收关键字参数,所以对应的传参是：num(10, *(50, 100, 30, 40), {'b':50}, c=40)注意：关键字不能与已传参形参相同

      无参函数(**)

      • 多余关键字参数 ，打包成字典
      • 写在形参内部：**字面量
      • 关键字参数：key = value表达式中，key 对应 字典的键,value对应字典的值
      • 写法：def num(a, b, *dicts):
      • 注意事项
        1. 一个函数只能出现一次，且只能在最后一个形参
        2. 只会打包关键字参数：键值对，key = value表达式

    3. 关于无定长参数，合法与不合法
      定义方式 是否合法 说明
      def f(a, *b): ✅ 合法 只有一个
      def f(a, **b): ✅ 合法 只有一个
      def f(a, *b, **c): ✅ 合法 经典组合，顺序正确
      def f(a, *, b, **c): ✅ 合法 带有强制关键字分隔符
      def f(a, *b, *c): ❌ 报错 两个 * 冲突
      def f(a, **b, *c): ❌ 报错 顺序反了
  • 最后补充参数优先级规则：位置参数 > 默认参数 > * > 强制关键字 > **

课堂注意事项

  • 函数定义时，如果有多个参数，多个参数之间使用英文逗号(,)分隔
  • return语句只有返回功能，没有输出打印的功能，如果要输出，需要结合print()函数来实现。
  • 形参（形式参数）：函数定义时括号里的参数，只能在函数内使用(局部变量)
  • 实参（实际参数）：函数调用时括号内的参数，通常给形参赋值
  • 实参与形参顺序一一对应，位置参数
  • 多个返回值，用英文逗号，结果会组包成元组。<
