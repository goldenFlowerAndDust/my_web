函数基础——函数说明文档

  • 函数的说明文档(Docstring)是写在函数开头，用三个引号包裹的字符串， 用户解释函数的功能、参数、返回值等信息，方便调用者清楚函数的具体作用及细节
  • 主要用于，解释函数功能、参数、返回值

  • 查看函数说明文档：

    • 使用help函数：help(函数名)
    • 鼠标悬浮在函数上，自动展示(推荐)
  • 注意：好的文档，能让你的代码更容易理解、使用和维护！！

  • 例如


    def judge_number(num):
    """
      该函数用于判断，数据类型是否为数字
      :num:为需要判断的数据
      :return:是数字，返回原数据，不是则返回None
    """
      try:
         num = float(num)
         return num
      expect ValueError:
         return None
    num = 20
    fault = judge_number(num)
    if fault：
      print(f"{num}是数字")
    else:
      print(f"{num}不是数字")
