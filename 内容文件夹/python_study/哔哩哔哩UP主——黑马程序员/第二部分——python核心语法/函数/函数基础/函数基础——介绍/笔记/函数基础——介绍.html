函数基础——介绍

  • 函数是组织好的，可重复使用的、用来实现特定功能的代码片段
  • 定义函数：def 函数名(形参)
  • 实参个数：内置函数由函数决定、自定义函数由编码者决定、实参个数 = 形参个数

  • 函数分类

    1. 内置函数

      • python自带的函数
      • 提前定义好的
      • 可以重复使用
      • 实现特定功能
      • 比如：input()、print()、max()、min()、len()、sum()、...
      • 函数调用：函数名(传参)
      • 参数的具体个数，传什么，由函数决定，编码者无法自行更改

    2. 自定义函数

      • 用户通过关键字(def)定义的函数
      • 与内置函数不同，函数功能由编码者自定义
      • 非提前定义好的
      • 可以重复使用
      • 实现特定功能(编码者自定义)

      • 编码者自定义的函数有两种

        1. 无参函数
          • 定义：def 函数名()
          • 特点：不写形参
          • 调用方式：函数名()、注意无参函数，不用传实参
        2. 有参函数
          • 定义：def 函数(形参,形参...)
          • 特点：需要写形参，形参个数自定义
          • 形参的作用：调用时，传入参数——另一个名字实参，函数内部可以通过传入的实参，在内部进行操作
          • 调用方式：函数名(实参,实参...)、实参个数由函数决定，实参个数 == 形参个数（默认参数除外，默认参数可以不传）

    3. 函数作用域

      • 在python中，函数会生成作用域
      • 作用域：函数内部的代码片段、函数内部的变量，外部无法直接访问

      • 函数内部变量与外部变量之间关系
        操作 是否可行 说明
        函数内部读取外部变量 ✅ 可以
        • 直接使用即可

        • x = 20
          def num():
            print(x) # 内部未定义变量，可访问外部变量
          num() # 值为20
        函数内部修改外部变量 ⚠️ 需要 global关键字
        • 否则会创建局部变量
        • 如：
          x = 10
          def num():
            # 需要先使用关键字声明
            global x
            x = 20
          print(x) # 结果为20
        • 不使用关键字：
          x = 10
          def num():
            # 不声明关键字，就是在函数内部重新创建变量
            x = 20
          print(x) # 结果为10
        内部变量外部访问 ❌ 不可以
        • 局部变量只在函数内部有效

        • def num():
            x = 20
          print(x) # 如果外部没有变量x，则会直接报错
        • 可以通过return关键字传回返回值
          def num():
            x = 20
            return x
          print(num()) # 结果为 20
          # 尽管使用return关键字将值传到外部，但是变量名始终外部无法访问
        嵌套函数修改外层函数变量 ⚠️ 需要 nonlocal关键字
        • 仅适用于嵌套函数

        • def num():
            x = 10 # 初次赋值为 10
            def num2():
               # 声明关键字 nonlocal 更改外层变量的值
               nonlocal x
               x = 20 # 重新赋值为20
            return x # return 关键字：传函数返回值
          print(num()) # 最后的结果是 20
        • 不使用关键字
          def num():
            x = 10 # 初次赋值为 10
            def num2():
               # 不声明关键字 nonlocal
               x = 20 # 重新定义变量，赋值为20
               return x
            return x # return 关键字：传函数返回值
          print(num()) # 最后的结果是 10 num2()在 num()内部，无法直接访问

函数的返回值 —— return

  • return 用于将函数内部的计算结果“传回”到函数外部

  • Python 与 JavaScript 返回值对比

    特性 Python JavaScript
    无 return 默认返回 None 默认返回 undefined
    返回单个值 return 10 return 10
    返回多个值 自动打包成 元组
    return a, b → (a, b)    		 需要手动包成 对象/数组
    return {a, b} 或 return [a, b]
    return 执行后 函数立即终止，后续代码不再执行
    • Python 示例：
      def calc(a, b):
        return a + b, a - b # 返回 (和, 差)
      result = calc(10, 5)
      print(result) # (15, 5)
      print(result[0]) # 15
    • JS 类比：
      function calc(a, b) {
        return [a + b, a - b]; // 返回数组
      }
      const result = calc(10, 5);
      console.log(result); // [15, 5]

Python 参数进阶（基础）

  • 默认参数

    • 定义时给形参赋默认值，调用时若未传实参，则使用默认值
    • def greet(name="游客"): print(f"你好，{name}")
    • 调用：greet() → 你好，游客   |   greet("小明") → 你好，小明
    • ⚠️ 默认参数必须放在普通形参的 后面，如 def func(a, b=10) ✅    def func(a=10, b) ❌
    • JS 类比：function greet(name = "游客") { ... }，语法几乎一样

  • 位置实参 vs 关键字实参（调用时）

    • 位置实参：按形参定义的顺序一一对应传值，如 add(3, 5)
    • 关键字实参：指名道姓传值，顺序可打乱，如 add(b=5, a=3)
    • ⚠️ 混用时，位置实参必须 在前，关键字实参在后，如 add(3, b=5) ✅    add(a=3, 5) ❌
    • JS 中没有关键字实参，只能传对象模拟：add({ a: 3, b: 5 })

📌 本节小结（适合贴在手边复习）

  • 返回值：Python 用 return，无则返 None；多个值自动打包元组
  • 默认参数：定义时赋值，必须放在普通形参后面
  • 传参方式：位置实参按顺序，关键字实参按名字，混用时位置在前
  • 与 JS 最大不同：Python 支持关键字实参，且多返回值自动打包

形参与实参

形参（Parameter）与 实参（Argument）—— 区别与联系

对比维度 形参（Parameter） 实参（Argument）
大白话 定义函数时写的“占位符” 调用函数时传进去的“具体值”
出现位置 写在 def 函数名( ... ) 的括号里 写在 函数名( ... ) 调用的括号里
本质 变量名（本身不存数据，只占引用） 具体数据（数字、字符串、列表等）
数量关系 定义时声明几个，调用时通常要传几个 必须与形参一一对应（位置或关键字方式）
生命周期 函数被调用时创建，调用结束自动销毁 传入函数后，随形参一起存活，函数结束释放
联系（传参过程） “实参 → 形参” 的值传递过程：
调用时，实参的值被拷贝（或引用传递）给对应的形参变量，
函数内部通过形参操作数据，实参本身不受影响（可变对象除外）。
代码示例 def add(a, b): ← 这里的 a 和 b 是形参
add(3, 5) ← 这里的 3 和 5 是实参
调用时，3 → a，5 → b，完成了“实参 → 形参”的绑定
  • 💡 记忆口诀： “形参是空位，实参是值；定义时摆空位，调用时填值”
  • ⚠️ 与 JavaScript 的差异： JS 函数调用时，实参个数可以少于形参（未传的形参自动为 undefined）；
    Python 必须实参个数 = 形参个数（除非使用了默认参数），否则会报 TypeError。
