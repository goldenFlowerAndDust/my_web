类与对象

怎么定义类

  • 语法：class 类名: 代码块
  • 类名建议：正常来说，类名与字面量规则一致，但是为了方便识别，尽量首字母大写
  • 命名开发者社区约定

  • 实例对象操作

    1. 创建实例对象(重点)

      • 对象名 = 类名()
      • 这个对象名，就是实例对象，后续操作通过它来完成
      • 前提是类必须存在
      • 一个类中，实例对象可以是无数个，重名则覆盖

    2. 创建(添加)实例属性(了解即可)

      • 对象名.属性名 = 属性值
      • 支持动态添加属性(前提是属性名本身未定义)
      • 执行该操作需要先创建实例对象

    3. 输出(查询)实例对象属性/属性值(独特场景会用到)

      • 对象名.属性：只适用单个属性查询，返回值是属性值
      • 注意直接打印实例对象，结果是内存地址而不是打印所有属性值
      • 可以使用：_dict__以字典形式打印出来 属性名为键，属性值为值
      • 执行该操作需要先创建实例对象

    4. 修改实例对象属性值(独特场景会用到)

      • 对象名.属性名 = 新属性值
      • 前提是属性名，已经定义
      • 执行该操作需要先创建实例对象

    5. 删除实例对象（本身/属性）

      • 删除属性：del 对象名.属性名
      • 前提是实例对象已经创建，且属性名，已经定义
      • 删除实例对象：del 对象名
      • 前提是实例对象已创建，永久删除

    6. 注释事项

      • 类可以有无数个实例对象
      • 实例对象执行的任何操作与类没有任何影响，只会对实例对象本身产生影响
      • 但是类中：通过创建的实例对象，以及内部方法的更改，将对全部实例对象产生影响
  • 实例对象属性与实例属性是同一个意思

  • 示例


    class Student:
      pass

    students = Student()
    students.name = 'YLH'
    students.age = 20
    students.gender = '男'
    print(students.__dict__)

在上面，我们理解了，怎么创建类、怎么创建实例对象，怎么对实例对象进行操作

  • 那么我们来解决两个问题：

    1. 方法写哪里，怎么用方法，能不能使用操作实例对象那样，进行方法的操作
    2. 类的定义是实现复用，类可以有无数个实例对象，通过上面所学习的操作，怎么的发挥类的最大用处吗？

  • 问题1(解决)

    1. 很遗憾，类外面的方法，无法用于实例对象使用
    2. 那么很明确了，类的方法（函数）必须在类中定义
    3. 好处也及其明显，统一修改，统一增加，统一删除、实例对象统一调用
    4. 实例方法的使用：对象名.方法名()
    5. 实例方法：第一个形参必须是：self

    6. 注意

      • 如果通过实例属性修改的操作，将原本定义好的实例方法赋值会怎么样
      • 比如(假设calc是一个实例方法)：对象名.calc = 值
      • 结果是：原本实例方法(calc)变为了实例属性，后续改对象再次使用它，便是属性，失去原有功能
      • 所以避免，给实例方法赋值
      • 实例方法跟普通方法一样，只有在被调用才会执行
      • 也就是实例对象可以根据自己需要调用对应的实例方法，而不是创建实例对象就执行
      • 定义在类的外面的称之为函数 ，定义在类中的函数称之为方法

  • 问题2(解决)

    1. 实例方法必须在类中定义，所以可以：统一修改、统一增加、统一删除，达到方法统一管理的目的
    2. 类的最大优点就是：统一管理，当每个实例对象的属性，均为不同，极其分散，违背了类的定义
    3. 类的定义：它是所有实例对象的'蓝图/模板'

    4. __init__

      • __init__：初始化方法，对象创建后自动调用，主要用于设置对象的初始状态(设置对象属性)
      • 可以在类的开头使用构造函数：def __init__(self,参数列表):，为每个实例对象设置默认的属性
      • 这么一来：属性与方法一致：统一增加、统一删除、统一修改

      • 注意事项

        1. 既然是函数，就不要将def忘记了
        2. 既然是函数，就能被传参，但是self始终排在第一位
        3. 且后续使用对应属性也必须是：self.属性的形式，外部就是：对象名.属性的形式
        4. 例如

          class Student:
            def __init__(self,name,age,gender):
               self.姓名 = name # 定义属性
               self.年龄 = age # 定义属性
               self.性别 = gender # 定义属性
          students = Student('小明',20,'男') # 创建实例对象
          students2 = Student('小红',20,'女') #创建实例对象
          注意：实例对象重名，后定义的覆盖前定义的
      • 总结：def __init__(self)， 就是跳过先定义实例对象再增加属性这个弊端，规定每个实例对象初始属性，方便类内统一管理
      • self就是实例对象本身

  • 关键字解释(用于后续复习)

    • 面向过程：以过程为主，每一步都有迹可循。(比如函数、条件分支、循环体)从上到下每一步都清晰
    • 面向对象：对外暴露清晰的接口，使用者通过调用方法获取结果，内部具体如何实现被封装隐藏，对调用者不可见。
    • 类：就是蓝图/模板 ，定义了属性和方法的"规范"
    • 实例对象：以类为蓝图，通过 实例对象名 = 类名,实例化的对象，对象内包含(属性和方法)，一个类可以有无数个实例对象
    • 实例属性：每个实例对象都拥有自己独立的一份属性，互不干扰，就像同一个列表中不同位置的元素，各自保存各自的值。
    • 实例方法：必须再类中定义，注意不要给方法重新赋值，且第一个参数永远是：self
    • __init__：就是这个蓝图上指定的"初始设置"，确保每个实例生来就拥有完整的属性
    • self：就是将来要创建的实例对象本身，它暂时还没有名字，所以用self指代，创建完成后，self就是实例对象名
    • 在类中，实例方法的第一个参数必须是 self，但调用时不需要传入，Python 会自动把调用对象传进去
    • 最后，最好将属性和方法均放入到类中，方便统一管理，除非项目必要操作，尽量不要在类外，增加属性、删除属性、有必要可以适当修改属性值
      实例对象的修改，不会对类产生影响，但是类中的变化，将导致所有实例对象，产生影响。
      但要注意： 如果是通过类名修改类属性，则会影响所有实例；如果是通过实例修改类属性， 则只会影响该实例自己的副本（如果该实例没有同名属性，则会新建一个实例属性覆盖）。
    • 实例对象属性，尽量遵守：字面量的硬性规则：A-Z,a-z,非数字开头数字，中文同样不建议使用。
    • 还需要注意的是：注意公有与私有的关系，私有为下划线开头的字面量(属性)，公有则反之

扩展2——类与实例对象的关系

  • 类与实例的关系

    • 实例对象通过 __class__ 指向类对象（存储的是类对象的内存地址）。
    • 当访问实例属性/方法时，查找顺序：
      1. 先在实例自己的 __dict__ 里找。
      2. 没找到则通过 __class__ 去类对象的 __dict__ 里找。
      3. 还没找到则继续通过 __bases__ 往父类找。

  • 实例对象的结构

    • 实例对象由属性组成，属性以 键值对 形式存储。
    • 属性存放在 __dict__ 中：
      • 属性名 → 键
      • 属性值 → 值
    • 所以：实例对象本质上就是一个字典。

  • 类对象的结构

    • 类对象也有 __dict__，存储类的属性和方法。
    • 类对象还有 __bases__，指向父类。
    • 类对象属性查找顺序：先 __dict__，再 __bases__。

  • __class__ 的可变性

    • __class__ 不是只读的，你可以修改它，让实例切换到另一个类：
      实例.__class__ = 其他类
    • 切换后，该实例的行为（方法调用）会立刻变成新类的行为，但自身已有的属性（__dict__）保持不变。
    • 正常开发中不建议这样做，会降低代码可读性和可维护性，属于高阶技巧（如框架中的动态代理）。
    • 知道它存在即可，作用是帮助你理解“实例通过引用指向类”这个机制的灵活性。

  • 关键结论

    • 实例属性来源一（自身）：__dict__ —— 修改只影响当前实例。
    • 实例属性来源二（共享）：__class__ —— 类修改影响所有实例。
    • 修改实例自身 → 只改 __dict__，不影响类和其他实例。
    • 修改类 → 改 __class__ 指向的内容，影响所有实例。
    • 更换类 → 改 __class__ 指向另一个类，实例行为随之改变，自身属性保留。

  • __init__ 的实际操作（本质）

    • __init__ 在实例对象创建后自动执行。
    • 它做的操作是：在实例的 __dict__ 里添加键值对（属性名 → 属性值）。
    • 它的核心逻辑就是：
      • self.属性名 = 值 → 等价于 self.__dict__['属性名'] = 值
      • 所以，self 就是将来要创建的那个实例对象本身。
    • 调用时不需要手动传入 self，Python 会自动把当前实例传进去。
    • 所以：__init__ 不是“构造函数”，而是“初始化方法”。
      • 实例对象由 Python 底层（__new__）创建。
      • __init__ 只负责给创建好的实例添加初始属性，不负责创建实例本身。
    • 这也是为什么 __init__ 里必须通过 self.属性 = 值 来定义属性——因为它是在给实例这个字典添加键值对。
