面向对象——概述

面向过程

  • 核心思想：把一个需求分解成一系列要执行的步骤，然后按照步骤依次执行这些任务(关注的是流程、步骤)
  • 在学习面向对象之前，通常是面向过程编程<
  • 比如：建一栋房子需要的过程是：
    平整地基——>地基打桩——>地基浇筑——>主体施工——>砌墙施工——>外墙施工——>室内硬装——>室内软装
  • 可以得出：面向过程：每一步都是亲自操刀，关注的是‘怎么做’，流程清晰但不易复用。
  • 一个人的精力是有限的，所以使用场景：面向过程编程非常直接，适合简单、线性的任务
  • 提前解释：面向对象的过程是：我需要建一个房子————>施工(过程封装在对象内)——————>房子交互

面向对象

  • 对象定义：对象可以理解为现实中具体的人/物在程序中的数字化身(万物皆对象)
  • 把一个人/物的特征和功能打包到一起，是面向对象编程的基本单元
  • 所以对象包括特征和功能
  • 其中特征为属性、功能为方法
  • 比如一个对象空调：特征(属性)：颜色、功率...、以及功能(方法):制冷...
  • 总结：属性是对象的状态（），方法是对象的行为（如：制冷、制热）

类

  • 类的定义：类是一个模板，定义了属性和方法

面向过程(Procedure-Oriented Programming,简写：POP)

  • 核心思想：把一个需求分解成一系列步骤，按照顺序执行(关注流程)
  • 特点：每一步都是亲自操刀，适合简单、线性的任务
  • 比如建房子：平整地基 → 打桩 → 浇筑 → 主体 → 砌墙 → ...
  • 在面向过程中，类中的方法，也是面向过程

面向对象(Object-Oriented Programming,简写：OOP)

  • 核心思想：把数据和操作数据的逻辑打包成一个"对象"，调用者只需要告诉对象"做什么"，对象自己决定"怎么做"
  • 特点：把过程封装在对象内部，对外只暴露结果
  • 比如建房子：你找了一个施工队（对象），告诉它“我要一栋3层现代风格的房子”，施工队内部自己安排流程，最后你拿到房子。

对象

  • 定义：现实中具体的人/物在程序中的数字化身(万物皆对象)
  • 组成：属性（状态/特征）+ 方法（行为/功能）
  • 例子：空调 → 属性（颜色、功率），方法（制冷、制热）。

类与对象的关系

  • 类（Class）：是对象的"蓝图"或"模板"，定义了对象有那些属性和方法
  • 对象（object）：是类的"实例"，根据类这个模板创建出来的具体个体
  • 类比：空调是一个类，你家客厅那台格力空调就是一个实例对象。
  • 实例对象与类是包含关系，实例对象的特征/功能——类都有(因为类是模板/是蓝图)，实例对象一般由调用类自动生成
  • 对象是由类创建出来的，创建对象的过程，也称为对象的实例化，一个类可以创建无数个对象

面向对象与面向过程之间的关系

  • 首先：他们并不是对立关系，而是包含关系
  • 面向对象负责的是代码的组织结构(谁拥有哪些数据、谁负责那些操作)
  • 面向过程负责的是具体操作的实现(这个方法内部具体怎么做)
  • 二者在同一个项目里是并存的，不是二选一
