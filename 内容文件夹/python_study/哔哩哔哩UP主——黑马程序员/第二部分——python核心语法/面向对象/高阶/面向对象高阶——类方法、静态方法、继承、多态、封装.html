函数高阶——类方法、静态方法、继承、多态、封装

  • 一、封装（Encapsulation）

    • 定义：将数据（属性）和操作数据的方法（行为）捆绑在一起，并隐藏内部实现细节，只对外暴露必要的接口。
    • 实现方式：
      • 私有属性：以双下划线 __ 开头的属性（如 self.__score），Python 会进行名称修饰（变为 _类名__score），防止外部直接访问。
      • 公有属性：普通属性，外部可直接访问，但应通过方法控制读写。
      • `@property`：将方法变成属性调用，可自定义 getter、setter、deleter，实现受控访问。
      • `__slots__`：限制实例允许的属性名，节省内存并防止随意添加属性。
    • 目的：
      • 保护数据完整性，避免被随意修改。
      • 降低耦合度，内部变化不影响外部调用。
      • 提高代码可维护性和安全性。
    • 示例： 
      class Person:
    __slots__ = ('name', '__age')  # 限制属性
    def __init__(self, name, age):
        self.name = name
        self.__age = age          # 私有属性

    @property
    def age(self):
        return self.__age

    @age.setter
    def age(self, value):
        if value > 0:
            self.__age = value
        else:
            raise ValueError("年龄必须为正")

  • 二、继承（Inheritance）

    • 定义：子类（派生类）可以复用父类（基类）的属性和方法，并可以扩展或重写。
    • 语法：class 子类(父类1, 父类2, ...):（支持多重继承）
    • 关键点：
      • 查找顺序：实例 → 子类 → 父类 → ... → object（遵循 __mro__ 顺序，C3线性化）
      • super()：调用父类的方法，常用于 __init__ 中初始化父类属性，避免重复代码。
      • 方法重写（Override）：子类重新定义父类的方法，实现多态。
      • `__bases__`：类属性，记录直接父类。
      • 抽象基类（ABC）：通过 abc 模块，定义抽象方法，强制子类实现。
    • 目的：代码复用、层次化组织、扩展功能。
    • 示例： 
      class Animal:
    def speak(self):
        pass

class Dog(Animal):
    def speak(self):
        return "汪汪"

class Cat(Animal):
    def speak(self):
        return "喵喵"

# super() 用法
class Student(Person):
    def __init__(self, name, age, grade):
        super().__init__(name, age)  # 调用父类初始化
        self.grade = grade

  • 三、多态（Polymorphism）

    • 定义：同一个方法名在不同类中可以有不同的实现，调用时根据对象实际类型决定执行哪个方法。
    • 实现条件：
      • 继承（子类重写父类方法）
      • 不同的类具有同名方法（不一定要继承，只要具有相同接口，即“鸭子类型”）
    • 表现形式：
      • 方法重写（子类覆盖父类方法）
      • 运算符重载（魔法方法，如 __add__、__eq__）
      • 鸭子类型：只要对象支持某个方法，就可以直接调用，不关心其类型。
    • 底层原理：通过 __dict__ 和查找链实现，同名方法在不同的类字典中独立存在。
    • 示例： 
      def make_sound(animal):
    print(animal.speak())

dog = Dog()
cat = Cat()
make_sound(dog)  # 汪汪
make_sound(cat)  # 喵喵

  • 四、类的三种方法

    • 1. 实例方法（Instance Method）

      • 定义：最常用的方法，第一个参数为 self（实例对象）。
      • 调用：实例.方法() 或 类.方法(实例)。
      • 访问权限：可以访问实例属性、类属性以及其他方法。
      • 用途：操作具体对象的数据，是OOP的主力。

    • 2. 类方法（Class Method）

      • 定义：使用 @classmethod 装饰，第一个参数为 cls（类本身）。
      • 调用：类.方法() 或 实例.方法()（自动传入类）。
      • 访问权限：只能访问类属性和其他类方法，不能访问实例属性。
      • 用途：工厂方法、修改类属性、替代构造函数等。

    • 3. 静态方法（Static Method）

      • 定义：使用 @staticmethod 装饰，无 self 或 cls 参数。
      • 调用：类.方法() 或 实例.方法()（无需自动传参）。
      • 访问权限：不能访问类或实例的任何属性，只是一个放在类中的普通函数。
      • 用途：工具函数，与类相关但不需要类数据，方便组织代码。
    • 对比总结
      类型 装饰器 第一参数 可访问 调用示例
      实例方法 无 self 实例属性、类属性 obj.method()
      类方法 @classmethod cls 类属性、其他类方法 Class.method()
      静态方法 @staticmethod 无 不能访问类或实例属性 Class.method()

  • 五、关联总结

    • 封装、继承、多态是 OOP 的三大基石，它们共同支撑代码的可复用性、可扩展性和可维护性。
    • 实例方法、类方法、静态方法提供了不同粒度的访问和控制，根据实际需求选择合适的方法类型。
    • 底层实现均依赖于 __dict__、__class__、__bases__ 的查找链，理解这些有助于深入理解动态行为。
    • 魔法方法（如 __init__、__str__、__add__）是 Python 提供的内置钩子，允许类与语言特性无缝集成，本质上是多态的特例。
    • 推荐实践：
      • 优先使用实例方法处理对象特定行为。
      • 类方法用于工厂模式或修改类状态。
      • 静态方法用于逻辑上与类相关但独立于实例/类的工具。
      • 使用 @property 控制属性访问，替代直接暴露属性。
      • 使用 __slots__ 优化内存并防止误新增属性（在大量实例时有效）。
      • 利用抽象基类定义接口，确保子类实现必要方法。
    • 你已经掌握了面向对象的核心机制，后续的框架、设计模式将建立在此基础之上。
