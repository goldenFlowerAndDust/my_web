模块介绍

什么是模块

  • 引入：当一个项目需要计算面积、周长，当其他文件内有计算结构的函数(方法)，我不想再写一次，想直接拿过来复用怎么办
  • 模块概念：将其他文件内的数据，导入到当前文件，实现多个文件数据共享。
  • 主要是实现：主程序与功能分离，提高代码质量，减少代码冗余。

使用模块需要的注意事项

  • 命名：与字面量的命名规则一致：硬性规则：不能以数字开头、只能包含：A-Z、a-z、非数字开头数字、下划线、中文(不建议用，虽然不会报错、但是运行可能会出BUG)
  • 模块的存储位置必须与导入模块为兄弟(同一个文件夹内)，否则获取不到
  • 模块识别顺序：最先查询同一文件夹内——>sys.path查询————>系统自带的模块
  • 因为系统模块是最后查找的，所以自定义模块不能与系统自带模块重名，自定义模块会覆盖系统模块，导致功能出问题

导入模块

  • 导入模块：import关键字
  • 语法1：import 模块名
  • 直接导入整个模块，包含模块内的所有方法、类、变量...
  • 语法2：from 模块名 import [方法、类、变量....]
  • 选择形导入，可以一次多个导入，中间用逗号分隔
  • 可以使用as关键字重命名，后面使用模块的时候，就用重命名，否则默认模块名字
  • 语法：improt math as shuxue
  • 这样的话，模块名字就变成了，shuxue，往后使用就用新的名字，但是注意：功能与原模块一致，且不会更改原模块名字，只能作用于当前文件。

使用模块

  • 使用模块非常简单：模块名.需要的操作
  • 这个需要的操作可以是：Class、def、字面量...具体用什么由自己决定

包机制

  • 所谓的包就是：将多个模块封装成一个文件夹，这个文件夹就叫包
  • 主要作用是：使模块不那么碎片话，整理
  • 硬性要求：文件夹必须含有：__init__.py文件，内容是空的也没有关系。主要作用：包名初始化，就是告诉python，这是一个包，先查询里面的模块
  • 包名可以是任何字符只要内部有：__init__.py文件即可，但是同样建议：使用字面量命名规则：A-Z，a-z，非数字开头数字，下划线，中文(正常项目同样不建议采用)
  • 默认包必须与主程序(导入它的文件)为兄弟关系，必须在同一个文件夹下。即使是兄弟子文件夹内都是不行
  • 后续可以使用：sys.path进行在所有文件夹下进行查询

导入包

  • 导入包和模块：from 包名 import 模块
  • 导入包和模块的同时选择需要导入的内容：from 包名.模块 import 内容
  • 内容可以是：类、变量、函数...，可以多个导入，之间用英文逗号隔开

使用sys模块，使包/模块在任何文件被访问

  • 介绍模块：sys:本质是 python进程启动时初始化的内存列表
  • 使用它其中一个功能，就能实现包/模块任何地方被找到：先导入：improt sys，然后再使用：sys.path.append(r'包的父目录')
  • 实现上面这两个操作后，就能正常导入：from 包名 improt 模块/ improt 模块....在IDE上，需要先写全，IDE才会识别
  • 整个过程：就是使用模块sys其中 sys.path.append()方法， 为python插入一个锚点，让python在查询包的同时，在添加的锚点也查询一遍，实现任何地方都能使用包内的模块
  • 只有在控制台，sys才会执行，离开控制台，便会消失
    sys的存活周期：运行文件(生命开始)————过程——————结束运行(或终止运行)【声明周期结束】
  • 复习查询过程：导入文件父文件夹————>sys内存列表(本质是列表：append、insert、extend行为一致)——————>系统自带模块

其他模块知识

  • 调试：if __name__ : "__main__":运行程序会重里面开始+条件分支语句，可以指定需要运行的代码。(前提是它上面没有运行的代码【提示：函数只有被调用才会执行】。)
  • __init__在包中叫包名初始化(告诉：python这是一个包)、在类中叫构造函数：def __init__(self)

其他内容

  • 模块、方法显示异常问题、警告异常问题。主要是父文件夹包含非ASCII码字符。解决办法——重命名、删除.idea文件、重新配置解释器
  • 导入模块问题：同级下import是直接文件名，文件名不能是：[-]连接。
  • 导入模块没有提醒问题：虚拟环境背污染，解决办法：删除虚拟环境，重装、重新配置解释器
  • 关于模块知识：导入关键字：import、重命名模块：as 名字，后续可以通过新定义的名字进行操作
