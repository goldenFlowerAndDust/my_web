异常处理

当用户输入的数据不符合规定，为了避免程序报错，而终止程序运行怎么办

  • 这时就可以通过异常处理来提前预测——也叫防御性编程
  • 常见用到异常处理的地方：[int()，float()]，已知它们传参只能是：数字或数字字符串。当传入数字字符串时，便会报错，且int()只能是整数字符串或浮点数、整数
  • 语法：try:自认为有风险代码块-except:发生错误执行内代码块
  • try-except的作用是：当 try 块中的代码出错时，程序不会崩溃，而是跳转到 except 执行。但不要把整个主程序都塞进 try 里，那样会掩盖错误的具体位置，不利于调试。 只把‘可能出错的那几行’（比如类型转换、文件打开、字典取值）放进去即可。

  • 以上面：int()、float()为例


    # 异常处理
    def judgment_number(a, b, c):
      try:
         int(a)
         float(b)
         int(float(a))
      except:
         print('应为数字或非数字字符串，a必须是整数字符串')
         return None
      
      return a,b,c
    result = judgment_number('50',30,'15.6') # 调用1
    if result : print(result)
    result2 = judgment_number('50.6',30,'15.6') # 调用2
    if result2 is not None : print(result2)
    1. 调用1结果：传入的参数均符合预期，所以在：try内正常执行， 最后通过return输出结果：(50,30.0,15)
    2. 调用2结果：传入的第一个参数不符合预期，int()参数不能是非整数字符串，所以在：except内的代码块， 先打印：'应为数字或非数字字符串，a必须是整数字符串',最后通过return退出函数：返回值是：None，if条件不执行
    3. 提醒：int(float())向零取整，直接截断小数部分
  • 上面案例就写了：except，它涵盖了所有运行时异常类型（比如 TypeError、ValueError 等）。但需要注意：语法错误（SyntaxError）无法被 try 捕获，因为它在程序运行前就已经被检测到了。
  • 因为：except涵盖所有异常类型。实际开发应是： try:
      代码块
    except 具体异常类型:
      代码块

扩展——主要是工具和规范

  • 正常项目——指定捕获特定异常类型

    1. 已知：except包含所有异常类型(SyntaxError以及它的子类除外)
    2. 但是正常项目不会单独使用：except，而是指定异常类型，每一种异常类型，一个提示
    3. 原因：裸的 except: 会捕获包括 KeyboardInterrupt（用户按 Ctrl+C）在内的所有异常，可能会让程序在应该退出的时候“卡住”。所以实际开发中总是指定具体的异常类型
    4. 意义：可以针对不同类型的错误做不同处理，而不是笼统地提示
    5. 语法：try-except 具体异常类型

    6. 实例

      try:
        int('abc')
      except ValueError:
        print('正常数据类型，但是参数不支持非数字字符串')
      except NameError:
        print('变量/函数/类未定义')
    7. 可见：可以给单个异常处理，添加不一样的错误提示
    8. 也是在正常开发中极其常见的写法，规范
    9. 不要直接使用；except，直接定义多个错误提示

  • 进阶语法——获取异常对象本身

    • 意义：可以获取python给出的原始错误信息，用于调试或记录日志
    • 语法：try-except 具体异常类型 as 收集错误字面量

    • 实例

      try:
        int('abc')
      except ValueError as e:
        print(f'错误信息：{e}')
    • 可以：可以通过 as 收集错误字面量 将原本错误信息，赋值给字面量，用于打印

  • 进阶语法——else子句：没有异常时执行

    • 意义：区分“异常处理逻辑”和“正常执行逻辑”，代码更清晰。
    • 语法：try-except 具体异常类-else

    • 实例

      try:
        int('abc')
      except ValueError as e:
        print(f'错误信息：{e}')
      else:
        print('没有异常')
    • 注意：是当所有：except语句没有执行，才会执行：else语句

  • 进阶语法——finally子句：无论是否异常，始终执行

    • 一般用于：清理资源(关闭文件、释放连接)，保证无论是否出错都会执行
    • 语法：try-except 具体异常类-finally

    • 实例

      try:
        f = open('data.text','r')
        data = f.read()
      except FileNotFoundError:
        print('文件不存在')
      finally:
        if f:
           f.close() # 无论是否出错，都会关闭文件
    • 注意：是不管是否执行：except语句，都会执行：finally语句

  • 进阶语法——抛出异常：raise

    • 当自己检测到错误条件，可以主动抛出异常
    • 语法：raise 异常类型(抛出内容)
    • 不是必须在try-except内写入

    • 分两种情况

      1. 在：try-except内写入
        • 功能一致，抛出对应异常类型的异常
        • 但是会被：except捕获
        • 所以有：except兜底，不会终止整个程序的运行

        • 实例

          try:
            float('abc')
            raise ValueError('请输入数字或数字字符串')
          except ValueError as e:
            print(f'错误信息是：{e}') # 当热这是多次一举的写法，只是为了方便演示
        • 主要特点：抛出的异常会被except捕获，所以并不会终止程序的运行
      2. 在：try-except外写入
        • 功能一致：抛出对应异常类型的异常
        • 但是没有except捕获异常
        • 所以会立刻终止程序运行，并输出终止的原因。

        • 实例

          def set_age(age):
          if age < 0:
            raise ValueError('年龄不能为负数') # 会直接终止后续程序执行，并输出报错提示
          elif age < 18:
            print('未成年')
            return True
          else:
            print('成年')
            return True
        • 主要特点：抛出的异常没有except捕获，直接终止后续所有程序运行，输出报错原因

  • 进阶语法——自定义异常类

    • 二级考试不要求，但是实际项目中常用
    • 语法：class 类名(Exception):自定义异常类

    • 实例

      class MyError(Exception):
        pass
      raise MyError('自定义错误')
    • 暂时理解写法即可，后续用到在说

额外补充——SyntaxError具体指的是什么

  • SyntaxError（语法错误）：“Python 看不懂你这行字。”
  • 运行时异常（ValueError 等）：“Python 看懂了，但执行到这一步时发现数据有问题。”

  • 大部分是：python语法层面的硬性规则

    1. 缩进问题

      • 忘记缩进，或则混用Tab和空格，导致python找不到代码块
      • 例：if True:\nprint('hi')（）

    2. 关键字错误命名

      • 把 Python 的保留关键字（如 class、if、def）用作变量名
      • 例：class = 1（报错，因为 class 是创造类的硬性关键词）。

    3. 无效的标识符命名（非法字面量命名）

      • 变量名以数字开头，或者包含不允许的特殊符号（除了 _）。
      • 例：1a = 10（报错，变量名不能以数字开头）。

    4. 缺少必要的语法符号

      • 忘记写冒号 :（if True 后面没写冒号）。
      • 括号、引号不匹配（print("Hello 缺少右引号）
