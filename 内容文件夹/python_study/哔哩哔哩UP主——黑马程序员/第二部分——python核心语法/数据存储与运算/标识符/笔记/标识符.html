数据存储与运算——标识符

  • 标识符：是程序员在代码中为变量、函数、类等元素所起的名字

  • 命名规则

    • 命名规则——规定

      1. 规定：必须遵守，不遵守，会报错
      2. 该规定与 JavaScript一致
        • 最好包含字母(a~z，A~Z)、数字(0~9)、下划线(_)
        • 不能以数字开头
        • 不能使用关键字，如python：(True、False、None、and、or、if、else、elif、for、while....)
        • 严格区分大小写，比如：age、Age以及AGE它们都是不同的变量(容器)

      命名规则——建议

      1. 建议：不必严格遵守，不遵守，不会报错
        • 尽量不要中文命名
        • 需要做到：见名知意
        • 开发着社区约定"行规"
          同样不必严格遵守——但是开发当中，为了更好的团队协作，建议遵守
