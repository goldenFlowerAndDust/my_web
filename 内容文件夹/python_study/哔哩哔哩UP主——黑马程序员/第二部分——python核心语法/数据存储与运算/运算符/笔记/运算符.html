逻辑运算符
【and】 逻辑与
  • 短路求值，返回 决定操作数的结果
  • 注意：返回的是操作数而不是布尔值
  • and两侧是本身是布尔值(真值或假值)
  • 短路求值：返回第一个假值(本身——操作数)
    1. 第一种情况：所有操作数均为真，返回最后一个操作数
    2. 第二种情况：存在操作数为假，返回第一个假值，后续短路(不执行任何操作)
    3. 第三种情况：所有操作数均为假，返回第一个操作数，后续短路(不执行任何操作)
  • if判断流程：逻辑运算符返回值——if判断真值还是假值——真值执行代码块/假值继续判断(else/elif)
  • 0 and 5
  • 2 and 3
  • 0
  • 3
【or】 逻辑或
  • 短路求值，返回 决定操作数的结果
  • 注意：返回的是操作数而不是布尔值
  • or两侧是本身是布尔值(真值或假值)
  • 短路求值：返回第一个真值(本身——操作数)
    1. 第一种情况：所有操作数均为真，返回第一个操作数
    2. 第二种情况：存在操作数为真，返回第一个真值，后续短路(不执行任何操作)
    3. 第三种情况：所有操作数均为假，返回最后一个操作数，后续短路(不执行任何操作)
  • if判断流程：逻辑运算符返回值——if判断真值还是假值——真值执行代码块/假值继续判断(else/elif)
  • 0 or 5
  • 2 or 3
  • 5
  • 2
【not】 逻辑非
  • 返回布尔值True/False
  • 执行取反操作，真值————>假值，假值——————>真值
  • 注意区分：and与or是返回操作数
  • not 0
  • not "abc"
  • 0是假值(False)所以取反为真值True
  • "abc"是真值(True)所以取反为假值False

位运算符
【&】 按位与/集合交集
  • 整数位运算;集合取交集
  • 二进制，单个比较，两者都为 1 时结果为 1，否则为 0
  • 集合取相同部分
  • 5 & 3
  • {1,2} & {2,3}
  • 5(d) ————>101(2)
  • 3(d) ————>011(2)
  • 所以最后的结果是：001 = 1
  • {1,2}————1 , 2 两个元素
  • {2,3}————2 , 3 两个元素
  • 所以最后的结果是：相同元素{2}
【|】 按位或/集合并集
  • 整数位运算;集合取并集
  • 二进制，单个比较，有1为1,否则为0
  • 集合取所有部分，排除重复
  • 5 | 3
  • {1,2} | {2,3}
  • 5(d) ————>101(2)
  • 3(d) ————>011(2)
  • 所以最后的结果是：111 = 7
  • {1,2}————1 , 2 两个元素
  • {2,3}————2 , 3 两个元素
  • 所以最后的结果是：取所有数，且去重{1,2,3}
【^】 按位异或/集合取对称差集
  • 整数位运算;集合取对称差集
  • 二进制：相同位0，不同为1
  • 对称差集，保留集合A与集合B，所有独自的元素，去掉相同的
  • 5 ^ 3
  • {1,2} ^ {2,3}
  • 5(d) ————>101(2)
  • 3(d) ————>011(2)
  • 所以最后的结果是： 110 = 6
  • {1,2,4,5}————1,2,3,4,5 元素
  • {2,3.5,6,7}————2,3,5,6,7 元素
  • 所以最后的结果是：取出相同元素{1,4,6,7}
【~】 按位取反（NOT）
  • 整数位运算，单目运算符（只能有一个操作数，且写在符号右侧）
  • 二进制：0 变 1，1 变 0
  • 在 Python / JavaScript 中：~x == -x - 1（补码规则）
  • 在 MySQL 中：结果按 64 位无符号整数 处理，返回巨大正数
  • ~5
  • ~-3
  • ~0
  • Python / JS：-6
  • Python / JS：2
  • Python / JS：-1
  • MySQL：巨大无符号整数

集合 位运算写法 含义
并集（Union） A | B 保留 A 和 B 中所有元素
交集（Intersection） A & B 只保留同时存在于 A 和 B 中的元素
差集（Difference） A & ~B（仅限整数位运算） 只保留 A 中有、但 B 中没有的元素
对称差集（Symmetric Difference） A ^ B 保留 A 和 B 各自独有的元素（去掉共有的）
