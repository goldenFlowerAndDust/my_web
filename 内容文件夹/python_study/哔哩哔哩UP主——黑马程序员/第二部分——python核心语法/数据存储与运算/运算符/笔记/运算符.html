所有 操作数均为数值类型 才能进行数学运算
运算符 描述 举例说明（python为主） python、JavaScript以及 MySQL注意事项
+ 加法 1 + 5 ==> 1加上5

  1. python

    • python没有隐式转换，所以所有操作数需要 先转成数字类型(int()、float())
    • 【+】支持字符串拼接，前提两侧均是字符串(str())如果遇到数字，会直接报错：
      如(b = "5" + 2)
    • 关于取整：python有专门的运算符 //，写法：a // b

  2. JavaScript

    • JavaScript有隐式转换会将非全数字字符串的truthy转换为1，falsy(除null\undefined)转换为0
    • 拓展：JavaScript的运算特殊规则
    • 【+】一方为字符串，则执行字符串拼接，(只有加号，其他会隐式转换)
    • 关于取整：JavaScript没有运算符，但是有方法：Math.trunc()，写法：Math.trunc(a/b)

  3. MySQL

    • MySQL同样有隐式转换会将会最高限度的将非数值类型转成数值并计算
    • 【+】永远执行加法运算，不能拼接字符串。如果遇到字符串，会尝试转成数字
    • 关于取整：MySQL，有专门的运算符：DIV,写法：a DIV b

JavaScript的隐式转换

  • JavaScript的隐式转换分为真值(truthy)与假值(falsy)
  • falsy有：null、undefined、""、0、-0、false、NaN
  • 算术运算中Falsy值的转换规则
    Falsy值 转换为数字 蒜素运算示例 结果
    false 0 false * 10 0
    0 0 0 * 10 0
    -0 -0 -0 * 10 -0
    ""(空字符串) 0 "" * 10 0
    null 0 null * 10 0
    undefined NaN undefined NaN
    NaN NaN NaN * 10 NaN
    除以上Falsy值意外，均是【truthy】
