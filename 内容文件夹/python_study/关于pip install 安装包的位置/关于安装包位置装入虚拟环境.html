关于安装包位置装入虚拟环境

关于安装包位置装入虚拟环境(非常建议以后，将包安装在虚拟环境，项目之间包隔开，防止冲突)

检查与确认环境
命令 作用
dir 查看当前项目下的文件和文件夹，确认是否有虚拟环境文件夹(如 venv)
pip list 列出当前激活环境下已安装的所有包
pip show 包名 查看指定包的详细信息，尤其是安装路径(Location)
where python 查看当前终端使用的是哪个python解释器(确认是全局还是虚拟环境)

创建虚拟环境
命令 作用
python -m venv venv 在当前目录下创建一个名为venv的虚拟环境(可以自定义名称，如 myvenv)
python -m venv myenv 创建名为 myenv的虚拟环境(其他名称同理)
dir 创建后再次查看，venv文件夹已经生成

激活虚拟环境
命令 作用
.\venv\Scripts\Activate Windows下激活 venv 虚拟环境（注意 .\ 和首字母大写 Activate）
source venv/bin/activate macOS / Linux 下激活虚拟环境
deactivate 退出当前环境，回到全局python

管理包(安装与卸载)
命令 作用
pip install 包名 安装指定包在激活虚拟后安装，会装到当前环境里
pip install 包名1 包名2 ... 可以同时安装多个包
pip uninstall 包名 卸载指定包(会提示确认)
pip uninstall 包名 -y 卸载指定包(跳过确认，直接卸载)
pip uninstall 包名1 包名2 ... -y 可以同时卸载多个包，跳过确认

验证与检查
命令 作用
pip show 包名 查看指定包的安装路径，确认是否安装到虚拟环境（路径里包含 venv 就是成功了）
pip list 列出当前环境下所有已安装的包，用来确认包是否已经卸载或安装成功

清理全局环境
命令 作用
pip uninstall 包名 -y 在全局环境下卸载包，清理全局环境里误装的包（确保先 deactivate 退出虚拟环境）
pip list 再次查看全局环境，确认已清理干净

具体步骤

  • 先确认环境：用 pip show 包名 确认装到了哪里。
  • 清理误装：在全局环境下执行 pip uninstall，去掉误装的包。
  • 创建虚拟环境：用 python -m venv venv 创建项目专属环境。
  • 激活虚拟环境：用 .\venv\Scripts\Activate 进入环境。
  • 安装包：在激活的环境里执行 pip install。
  • 验证：再次用 pip show 确认路径包含 venv。
