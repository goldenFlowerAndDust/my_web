## 一键更新

双击根目录：

```text
同步全部科目.bat
```

它会依次执行：

```text
[1/4] 同步全部答疑科目
[2/4] 归档大肥鱼 API 答疑
[3/4] 构建 Node.js 笔记归档
[4/4] 构建 MySQL 笔记归档
```

最后会显示四项结果：

```text
大肥鱼: 完成（4 篇）
Node.js: 完成（26 篇）
MySQL:   完成（19 篇）
```

它只同步和更新归档，不会常驻启动 8767 / 8768 / 8769 服务。

## 启动服务

需要打开某个答疑页面时，双击：

```text
启动\打开AI答疑中心.bat
```

或对应的：

```text
启动\启动英语答疑.bat
启动\启动数学答疑.bat
启动\启动编程答疑.bat
启动\启动政治答疑.bat
启动\启动信息技术答疑.bat
```

## 配置

第一次运行时双击：

```text
工具\配置.bat
```

填写 API Key、云端地址和令牌；之后日常直接运行根目录的 `同步全部科目.bat`。

## 历史归档

统一存储在：

```text
内容文件夹/专升本备考/历史归档/
```

结构：

```text
2026年11月/
  英语/单词解释/第01个.json
  数学/题目讲解/第01个.json
  编程/python/第01个.json
```

规则：

```text
每个 AI 独立目录
每个分类独立目录
单文件上限 5MB
单文件最多 1000 条
先到条件即拆分
```

`history/index.json`、`答疑历史.json` 仅作为旧页面兼容视图保留。
