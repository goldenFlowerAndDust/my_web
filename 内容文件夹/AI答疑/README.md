# AI 答疑中心

三个答疑入口已统一到本目录：

```text
英语答疑/        8767 服务
数学答疑/        8768 服务
编程语言AI/      8769 页面服务
```

启动：

```text
同步全部科目.bat
```

同步完成后会自动启动 8767 / 8768 / 8769，并打开 AI 答疑中心。
只想打开页面时用 `打开AI答疑中心.bat`。

本地地址：

```text
http://127.0.0.1:8769/AI答疑/
```

英语、数学页面通过绝对地址调用 8767 / 8768，页面本身由 8769 静态服务提供。

## 历史归档

统一存储在：

```text
内容文件夹/专升本备考/历史归档/
```

结构：

```text
2026年11月/
  英语/单词解释/第01个.json
  数学/题目讲解/第01个.json
  编程/python/第01个.json
```

规则：

```text
每个 AI 独立目录
每个分类独立目录
单文件上限 5MB
单文件最多 1000 条
先到条件即拆分
```

`history/index.json`、`答疑历史.json` 仅作为旧页面兼容视图保留。

重建归档：

```text
python 内容文件夹/专升本备考/共享配置/build_ai_history_archive.py
```

旧的 `AI/编程语言AI` 和 `专升本备考/备考专升本英语|数学` 页面继续保留，作为回退入口。
