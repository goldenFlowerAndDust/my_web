# 共享配置 · 目录说明

> 本文件说明 `AI答疑/共享配置/` 的分工与衔接。**移动任何文件前先读第 4 节**，那里列了会因移动而失效的路径。

---

## 1. 目录结构

```text
AI答疑/共享配置/
├─ 历史归档/                       按"日期/月"组织的问答历史相关脚本
│  ├─ 对话历史.py                  三科统一的历史数据层（读写 历史记录/对话/*.json）
│  ├─ 生成历史索引.py              生成 历史记录/月份/<科目>/<月>/ 的月度索引与分片
│  ├─ 归档每日答疑.py              生成 答疑归档/<科目>/ 的每日 md + 卡片目录 + 阅读页
│  └─ 注册每日对话归档任务.ps1      注册 Windows 计划任务（可选，每天自动跑一次归档）
├─ 同步/                           与云端（Cloudflare / 腾讯云 SCF）对账
│  ├─ sync_all_subjects.py         同步主程序：拉记录 → 本地导入 → 重建索引 → 每日归档
│  └─ 对话同步.py                  对话窗口文档的合并逻辑
├─ 运行/                           本机服务
│  └─ service_supervisor.py        启动/收尾 英语 8767、数学 8768、编程 8769
├─ 网络/                           网络环境适配
│  └─ 网络代理.py                  读取 Windows 系统代理，设置 HTTPS_PROXY
├─ 数据/                           配置与凭据（多为 .gitignore，不进 Git）
│  ├─ API.txt                      DeepSeek API Key（敏感）
│  ├─ 云端同步.json                云端线路地址与访问令牌（敏感）
│  ├─ 云端同步.example.json        配置样例
│  ├─ 科目配置.json                科目开关、导出目录、文件名前缀
│  ├─ 同步状态.json                上一次同步的结果缓存，由脚本写入
│  └─ 口令.txt                     备用口令（敏感）
├─ tencent-scf/                    腾讯云 SCF 备用线路的部署代码
└─ README.md                       使用说明（配置流程、常见问题）
```

---

## 2. 各文件做什么

| 文件 | 作用 | 被谁调用 |
|---|---|---|
| `对话历史.py` | 读写三科对话窗口 JSON；`upsert_window` 负责合并轮次，**分类/知识分类以第一个问题为准** | 三个引擎、`sync_all_subjects.py`、`生成历史索引.py` |
| `生成历史索引.py` | 把 `历史记录/对话/*.json` 汇总成按月索引 + 分片，供页面按需加载 | `sync_all_subjects.py`、三个引擎（每次写窗口后重建） |
| `归档每日答疑.py` | 由对话历史生成"每天一份 md"，并派生卡片目录与阅读页 | `sync_all_subjects.py`（每次同步） |
| `sync_all_subjects.py` | 同步主流程：拉云端记录 → 本地导入 → 重建月索引 → 重建每日归档 | `同步全部科目.bat` → `sync_launcher.py` |
| `对话同步.py` | 云端对话文档与本地文档的合并、墓碑处理 | `sync_all_subjects.py` |
| `service_supervisor.py` | 用 Job Object 管住三个服务进程，主窗口关闭时一并结束 | `sync_launcher.py`（一键同步并启动） |
| `网络代理.py` | 深陷 SSL EOF 时走系统代理；无代理则直连 | 三个引擎的 tutor/archiver |

## 3. 数据流向

```text
云端 KV（Cloudflare / SCF）
        │  sync_all_subjects.py 拉取
        ▼
历史记录/对话/<科目>.json  ──生成历史索引.py──▶  历史记录/月份/<科目>/<月>/
        │                                          │
        │  归档每日答疑.py                          │  月份历史.js 按需 fetch
        ▼                                          ▼
答疑归档/<科目>/<年>/<月>/<日>.md            答疑页 / 主页的"AI 历史记录"
答疑归档/<科目>/{data.js,index.html,view.html,content/}
```

- **只覆盖不追加**：`历史记录/` 与 `答疑归档/` 每次都整份重建；在页面删掉对话，归档随之消失。
- `答疑归档/` 里的 `index.html` 只放索引，正文在 `view.html` 按 `#doc=<slug>` 加载。

## 4. 移动文件前必看（路径耦合点）

| 被移动的文件 | 需要同步修改的位置 |
|---|---|
| `sync_all_subjects.py` | `AI答疑/sync_launcher.py` 的 `SYNC`；它自身的 `sys.path` 与 `config_dir`；`find_default_base()` 的 `parent` 层数 |
| `service_supervisor.py` | `sync_launcher.py` 的 `SUPERVISOR`；它自身 `base = Path(__file__)...parent.parent.parent` |
| `对话历史.py` | 三个 `engine/server.py` 的 `CONVERSATION_DIR`；`生成历史索引.py`、`归档每日答疑.py` 的 `sys.path` 与 `HIST`；`对话历史.py` 自身 `AI_ROOT = parents[2]` |
| `生成历史索引.py` | 三个 `engine/server.py` 的 `sys.path`；`OUTPUT_ROOT`；`BASE_DIR = parents[2]` |
| `网络代理.py` | 三个 `engine/server.py` 需把 `共享配置/网络` 加进 `sys.path`；`word_archiver.py`、`math_tutor.py`、`english_tutor.py` 依赖该路径 |
| `API.txt` 等数据 | `sync_launcher.py` 的 `CONFIG_DIR`；`word_archiver.py`/`math_tutor.py`/`code_server.py` 的 Key 路径；`屏幕翻译/translate_helper.py` |
| `历史记录/` 整体 | `月份历史.js` 的 `historyRoot` 与内部 `base(...)` 相对路径 |

判断是否改漏的最快方式：

```powershell
# 1) 语法
python -m py_compile 共享配置\同步\sync_all_subjects.py
# 2) 导入 + 数据路径
python -c "import sys; sys.path[:0]=[r'共享配置\历史归档']; import 对话历史; print(对话历史.DATA_DIR)"
# 3) 跑一次归档
python 共享配置\历史归档\归档每日答疑.py
# 4) 看状态
python 共享配置\同步\sync_all_subjects.py --status
```

## 5. 常见操作

| 想做的事 | 怎么做 |
|---|---|
| 改 DeepSeek Key | 编辑 `数据/API.txt`，或双击 `工具/配置.bat` → 菜单 9 |
| 改云端线路/令牌 | `工具/配置.bat` 菜单 5/6，写入 `数据/云端同步.json` |
| 开关科目 | 编辑 `数据/科目配置.json` 的 `enabled` |
| 手动同步一次 | `python 共享配置\同步\sync_all_subjects.py --once` |
| 看上次同步结果 | `python 共享配置\同步\sync_all_subjects.py --status` |
| 重建每日归档 | `python 共享配置\历史归档\归档每日答疑.py` |
