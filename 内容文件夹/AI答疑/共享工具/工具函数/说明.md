# AI 共享工具函数

三个科目（英语 / 数学 / 编程）共用这里的浏览器端工具。

| 文件 | 作用 |
|---|---|
| `上下文.js` | 把当前标签的最近对话作为 `history` 发给 `/api/tutor`，并记录回答。 |
| `对话存储.js` | 按科目保存对话 JSON：`aiTutor.conversations.v2.english / math / code`。历史、删除、快照都读它。 |
| `轮次选择.js` | 老师回答标题旁的轮次选择：切换当前轮次、显示 token、删除本轮。数学使用自定义下拉渲染公式。 |
| `轮次文本.js` | 把原生轮次 `select` 升级成统一的按钮 + 浮层，显示完整问题；有公式时调用 KaTeX。 |
| `轮次文本.css` | 统一轮次下拉的样式。 |
| `token成本.js` | 根据 DeepSeek `usage` 估算 token 和人民币，并显示价格说明。 |

## 规则

- 不要在这里放科目专属逻辑。
- 英语 / 数学 / 编程页面都通过相对路径引用：
  `../共享工具/工具函数/...`
- 对话存储按科目分键，避免串科目。
- 历史记录和回答轮次必须来自同一份对话 JSON。
- 云端 Worker 不在这个文件夹，仍在 `共享工具/worker.js`。
