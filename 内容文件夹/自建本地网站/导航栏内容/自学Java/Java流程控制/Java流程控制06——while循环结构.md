### while循环

1. while循环是最基本的循环，它的结构为：

```txt
while(布尔表达式){
    //循环内容(while循环代码块)
}
```

要求：

1. 只要布尔表达式为true，循环就会一直执行下去。

2. 我们大多数情况是会让循环停止下来的，我们需要一个让表达式失效的方式结束循环。
3. 少部分情况需要循环一直执行，比如服务器的请求响应监听等。
4. 循环条件一直为true就会造成无限循环[ 死循环]，我们正常的业务编程中应该尽量避免死循环。会影响程序性能或造成程序卡死崩溃！

实操：

- 思考：计算1+2+3+……+100=?



```java
public class while循环结构实操1_计算 {
    public static void main(String[] args) {
        //输出1~100
        int i = 0;

        /*使用while循环：
                    1.先定义布尔表达式;
         */
        //在循环开始的时候，会先计算布尔表达式是否为true，若为false则不会执行循环
        while (i<100){  //当变量名i的值>100时，循环停止
            i++;  //自增 i = i + 1
            System.out.println(i);
        }

    }


}
```

- 死循环(即布尔值表达式直接定义为true)

```java
public class 伪代码_死循环 {
    //伪代码是没有任何意义的代码，在while中即死循环。
    public static void main(String[] args) {
        while(true){
            /*在这个while循环的布尔表达式为true
               这就意味这，不管怎么样，循环都为true，永远不会结束
                需要死循环的场景：
                        1.等待客户端连接(接收他[她]人信息
                        2.定时检查(如闹钟)
                        3。。。。。。。。。。。。。。。。。
                注意：
                    1.一直死循环会影响程序性能或造成程序卡死崩溃！
                    2.所以在实战中要避免死循环的出现
             */

        }
    }
}

```
