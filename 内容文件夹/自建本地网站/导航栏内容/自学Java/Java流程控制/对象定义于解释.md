# 对象：

- 对象是类的一个具体实例。它是一个拥有状态(数据)和行为(方法)的实体
- 类比：
  - 在现实生活中有看的到摸得着的物体
  - 比如：狗是一个抽象的概念(类)，而"我家那只取名为旺财、现在3岁、黄色的中华田园犬"就是一个具体的实体(对象)
- 为什么需要使用对象？
  - 使用对象(即面向对象编程)有三大主要好处，通常称为OOP的三大特性：
    1. 封装：
       - 将对象的状态(数据)和行为(方法)"打包"在一起，并且可以对外部隐藏内部的实现细节
       - 好处：提高了安全性和易读性。你只需要知道对象能做什么(有什么方法实现的)，而不需要关心它内部是怎么做的。
       - 就像游戏，你只知道怎么操作角色，单是移动，内部就有隐藏了多种数据，只是你看不到而已。
    2. 继承：
       - 允许一个新的类(子类)继承现有类(父类)的属性和方法
       - 实现了代码的复用和扩展。
       - 比如：你可以先创建一个通用的[动物]类(父类)，然后创建更具体的狗类和猫类(子类)来继承它，它们自动拥有动物的所有特性，同时还可以增加自己独有的特性
    3. 多态：
       - 同一个行为(方法)在不同的对象上会有不同的实现方式
       - 好处：提高代码的灵活性和扩展性。
       - 例如：动物类有一个【叫()】的方法，狗对象的【叫()】是"汪汪汪"，而猫对象的【叫()】是"喵喵喵"。你只需要让它们都"叫"，而不是需要关心具体怎么叫
