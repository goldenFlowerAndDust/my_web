## 扩展赋值运算符

1. 扩展赋值运算符(+=、-=、*=、/=)
2. 扩展赋值运算符的运行过程：
   - +=： a +=b——a = a+b
   - -= ： a -=b——a = a-b
   - *=： a *=b——a = a * b
   - /=：  a /=b——a = a/b
3. 使用方法及注意事项：

```JAVA
public class 扩展赋值运算符{
    public static void main(String[] args){
        /*扩展赋值运算符(+=,-=,*=,/=)——
          注意：
               1.写入变量的顺序不同，那么所得的结果也不同;
               2.运算途中，变量的变量值会随着运算而改变;
         */
        // 原始顺序(a,b,c,d,e)
        int a = 10;
        int b = 20;
        int c = 10;
        int d = 2;
        double e = 4D; //应为最后除法结果会有浮点数，先将e定义为double类型方便得出正确答案。
        a += b; //a = 10+20(30)
        b -= c;// b = 20-10(10)
        c -= b;// c = 10-10(因为上面求的b=10)=0
        d *= c;// d = 2*0(0)
        e /= a;// e = 4/30(0)
        //则输出结果为：a=30,b=10,c=0,d=0,e=0.13333333………………
        System.out.println("原始顺序：a="+a+",b="+b+",c="+c+",d="+d+",e="+e);
        System.out.println("==================================");

        // 改变写入顺序(c,d,b,e,a)
        a = 10;// 重置变量(因为上面定义的变量已经计算过，为了证明注意点，重新将变量值定为以上一样)
        b = 20;
        c = 10;
        d = 2;
        e = 4D;
        c -= b; // c = 10-20(-10)
        d *= c;//  d = 2*(-10)=-20
        b -= c; // b = 20-(-10)=30
        e /= a;//  e = 4/(10)=0.4
        a += b; // a = 10+30(40)
        //则输出结果为：a=40,b=30,c=-10,d=-20,e=0.5
        System.out.println("改变顺序：a="+a+",b="+b+",c="+c+",d="+d+",e="+e);
        System.out.println("===================================");

        //写入顺序(b,e,c,a,d)
        a = 10;//再次重置变量值
        b = 20;
        c = 10;
        d = 2;
        e = 4D;
        b -= c;//b = 20-10(10)
        e /= a;//e = 4/10(0.4)
        a += b;//a = 10+10(20)
        c -= a;//c = 10-20(-10)
        d *= c;//d = 2*(-10)=-20
        //则输出结果为：a=20,b=10,c=-10,d=-20,e=0.4
        System.out.println("第二次改变顺序：a="+a+",b="+b+",c="+c+",d="+d+",e="+e);

        System.out.println("同样的变量名和变量值，但是输入顺序的不同，最后的结果会不同");
    }
}
```

总结：

1. 扩展赋值运算符有严格的输入顺序，若输入顺序不同，所得的结构会不同
2. 扩展赋值运算符在运行中会更改变量值
3. 若使用(-=)最好将变量值的变量类型为double(浮点数)，变量值精确为 小数，这会使最后得出的结果，更为准确。

## 三元运算符(条件运算符)

三元运算符(?、:)——均为英文输入法

- 定义：三元运算符是Java中唯——个需要三个==操作数==的运算符，它的核心作用是根据一个条件的真假，从两个表达式中二选一执行并返回结果。

- 语法固定：

  ```java
  条件  ?   表达式1   :    表达式2
  ```

  - 条件：第一个操作数：
    - 这是一个必须产生Boolean(布尔类型)结果(true或false)的表达式
  - 表达式1：第二个操作数：
    - 当条件为true时，这个表达式会被计算并返回其值
  - 表达式2：第三个操作数：
    - 当条件为false时，这个表达式会被计算并返回其值

- 操作数 ：

  - **==操作数可以是变量==**，但不能简单的理解就是变量，**==变量是操作数的一种常见的形式==**
  - 在任何一个运算中，操作数就是被运算符操作的对象，他是运算符的'输入材料'。
  - 它的形式有：**==变量、字面量、方法调用、表达式结果==**
  - 即运算符+操作数=表达式

- 使用领域：求最大值、判断奇偶性

- 注意事项：

  类型兼容：表达式1和表达式2的返回类型必须兼容

  - 比如当一个返回int类型，另一个返回double类型，会自动升格为double类型并返回
  - 当一个返回String类型，里另一个返回int类型就会编译出错

实例：

```java
public class 三元运算符{
    public static void main(String[] arge){
        //三元运算符(x, ?, y, :, z)——设条件为x,表达式1为y，表达式2为z
        //如果x==true，则结果为y，否则结果为z
        int  score = 80;//score(成绩)
        int  score1 = 50;
        String type = score <60 ?"不及格":"及格";//意思是score的值小于60，返回结果不及格，反之及格
        String type1 = score1 >60 ?"及格":"不及格";//意思是score的值大于60，返回结果及格，反之不及格
        System.out.println(type);
        //因为score的值大于60，所以返回值为及格
        System.out.println(type1);
        //因为score1的值小于60，所以返回值为不及格
    }
}
```

## 运算符总结

- 运算符是有优先级的：括号>一元>乘除>加减>比较>逻辑>赋值

- 当无法确定运算顺序时，或者想让代码更清晰易读时，需要毫不犹豫的使用括号

  Java 运算符分类大全

  #### 概述

| 类别 | 操作数数量 | 主要功能 | 典型运算符 |
| :--- | :--- | :--- | :--- |
| **一元运算符** | 1 | 对一个操作数进行运算 | `++`, `--`, `!`, `~`, `+`(正), `-`(负) |
| **二元运算符** | 2 | 连接两个操作数进行运算 | `+`, `-`, `*`, `/`, `>`, `<`, `==`, `&&`, `=` |
| **三元运算符** | 3 | 根据条件选择两个表达式之一 | `? :` |

#### 一元运算符 (Unary Operators)

| 运算符 | 名称 | 描述 | 备注 |
| :--- | :--- | :--- | :--- |
| `+` | 一元加 | 表示正数，通常省略 | `int a = +5;` | 实际很少使用 |
| `-` | 一元减 | 表示负数，取反 | `int b = -a;` |  |
| `++` | 前自增 | 先增加，后使用 | `int c = ++a;` <br> `// a=6, c=6` |  |
| `++` | 后自增 | 先使用，后增加 | `int d = a++;` <br> `// d=6, a=7` |  |
| `--` | 前自减 | 先减少，后使用 | `int e = --a;` <br> `// a=6, e=6` |  |
| `--` | 后自减 | 先使用，后减少 | `int f = a--;` <br> `// f=6, a=5` |  |
| `!` | 逻辑非 | 布尔值取反 | `boolean flag = !true;` <br> `// flag=false` | 只适用于布尔类型 |
| `~` | 按位非 | 按位取反 | `int g = ~0b1010;` <br> `// 0b...11110101` | 对所有位进行取反 |
| `(type)` | 类型转换 | 强制类型转换 | `double pi = 3.14;` <br> `int num = (int)pi;` <br> `// num=3` |  |

#### 二元运算符 (Binary Operators)

##### 算术运算符

| 运算符 | 名称 | 描述 |
| :--- | :--- | :--- |
| `+` | 加法 | 相加 | `int sum = a + b;` |
| `-` | 减法 | 相减 | `int diff = a - b;` |
| `*` | 乘法 | 相乘 | `int product = a * b;` |
| `/` | 除法 | 相除 | `int quotient = a / b;` <br> `double result = (double)a / b;` |
| `%` | 取模 | 求余数 | `int remainder = a % b;` <br> `// 10 % 3 = 1` |

##### 关系运算符

| 运算符 | 名称 | 描述 |
| :--- | :--- | :--- |
| `==` | 等于 | 判断是否相等 | `if (a == b)` |
| `!=` | 不等于 | 判断是否不等 | `if (a != b)` |
| `>` | 大于 | 判断是否大于 | `if (a > b)` |
| `<` | 小于 | 判断是否小于 | `if (a < b)` |
| `>=` | 大于等于 | 判断是否大于或等于 | `if (a >= b)` |
| `<=` | 小于等于 | 判断是否小于或等于 | `if (a <= b)` |

##### 逻辑运算符

| 运算符 | 名称 | 描述 | 
| :--- | :--- | :--- |

| `\|\|` | 逻辑或(会短路) | 至少一个条件为真 | `if (a > 0 \|\| b > 0)` |
|`!`|     逻辑非(取反)|条件取反|`if（! (a && b):"+!(a&&b)）`


##### 位运算符

| 运算符 | 名称 | 描述 | 
| :--- | :--- | :--- |
| `&` | 按位与 | 对每一位执行与操作 | `int result = a & b;` |
| `\|` | 按位或 | 对每一位执行或操作 | `int result = a \| b;` |
|`~`|按位取反|对每一位执行取反操作

| `<<` | 左移位 | 将位向左移动 | `int result = a << 2;` |

##### 赋值运算符

| 运算符 | 名称 | 描述 | 
| :--- | :--- | :--- | 
| `=` | 赋值 | 将右侧值赋给左侧变量 | `int a = 10;` |
| `+=` | 加后赋值 | `a += b` 等价于 `a = a + b` | `a += 5;` |
| `-=` | 减后赋值 | `a -= b` 等价于 `a = a - b` | `a -= 5;` |
| `*=` | 乘后赋值 | `a *= b` 等价于 `a = a * b` | `a *= 5;` |
| `/=` | 除后赋值 | `a /= b` 等价于 `a = a / b` | `a /= 5;` |
| `%=` | 取模后赋值 | `a %= b` 等价于 `a = a % b` | `a %= 5;` |
| `&=` | 按位与后赋值 | `a &= b` 等价于 `a = a & b` | `a &= 5;` |
| `\|=` | 按位或后赋值 | `a \|= b` 等价于 `a = a \| b` | `a \|= 5;` |
| `^=` | 按位异或后赋值 | `a ^= b` 等价于 `a = a ^ b` | `a ^= 5;` |
| `<<=` | 左移后赋值 | `a <<= b` 等价于 `a = a << b` | `a <<= 2;` |
| `>>=` | 右移后赋值 | `a >>= b` 等价于 `a = a >> b` | `a >>= 2;` |

#### 三元运算符总结

| 运算符 | 名称 | 描述 | 
| :--- | :--- | :--- | 
| `? :` | 条件运算符 | 根据条件选择两个表达式之一 | `int max = (a > b) ? a : b;` <br> `String result = (score >= 60) ? "及格" : "不及格";` |

#### 优先级

| 优先级 | 运算符 | 类型 
| :--- | :--- | :--- | 
| 1 | `()`, `[]`, `.` | 方法调用, 数组下标, 成员访问 | 左→右 |
| 2 | `!`, `~`, `++`, `--`, `+`, `-`, `(type)` | 一元运算符 | 右→左 |
| 3 | `*`, `/`, `%` | 乘性运算符 | 左→右 |
| 4 | `+`, `-` | 加性运算符 | 左→右 |
| 5 | `<<`, `>>`, `>>>` | 移位运算符 | 左→右 |
| 6 | `<`, `<=`, `>`, `>=`, `instanceof` | 关系运算符 | 左→右 |
| 7 | `==`, `!=` | 相等运算符 | 左→右 |
| 8 | `&` | 按位与 | 左→右 |
| 9 | `^` | 按位异或 | 左→右 |
| 10 | `\|` | 按位或 | 左→右 |
|11|`~`|按位取反|
| 11 | `&&` | 逻辑与 | 左→右 |
| 12 | `\|\|` | 逻辑或 | 左→右 |
|13|`!`|逻辑非(取反)|右→左
| 14 | `? :` | 条件运算符 | 右→左 |
| 15 | `=`, `+=`, `-=`, `*=`, `/=`, `%=`, `&=`, `^=`, `\|=`, `<<=`, `>>=`, `>>>=` | 赋值运算符 | 右→左 |

> **黄金法则**: 当不确定运算顺序时，使用括号 `()` 明确指定优先级！
