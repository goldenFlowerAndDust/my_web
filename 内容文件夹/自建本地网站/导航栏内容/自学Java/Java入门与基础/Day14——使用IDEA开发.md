# Day14——使用IDEA开发

## 什么是IDEA——lntellij IDEA

### 一、是jetBrains公司开发的Java**集成开发环境**(IDE)，支持多种编程语言和框架

---

### 二、相当于把代码编辑器+编译器+调试器+项目管理工具打包成一个超级工作台。

---

### 三、相比普通编辑器：

- IDEA**能推测你想写什么**[可以理解为**预判**] (基于项目所有代码+库)——普通编辑器：只能补全你已经敲过的单词(像手机输入法的记忆)

- IDEA能实时错误检查：

  1. 当拼写错误时：写的时候**立即生成红波浪线**——普通编辑器(**运行时出错**)

  2. 逻辑错误时：如提示"**while(true)**意思是[这段代码永远为true(真)]"——意思是程序卡死，但是程序不会报错——普通编辑器可能**发现不了**

  3. 存在潜在风险时：**会警告**"这个变量可能为null(是一个特殊的值，表示对象引用不指向任何内存地址)"——普通编辑器(**无提示**)

  ---

### 四、重构能力：

- 普通编辑器：

  	 	1. 手动修改每个变量名

  2. 可能漏改某个地方导致bug

- IDEA：

  1. 右键单击变量→Refactor(重构)→Rename(重命名)→更改后回车
  2. 所有用到的地方自动同步修改(极大减少了工作量)

  ---

### 五、含有大量的插件：

1. 数据库客户端(直接写SQL查数据)
2. REST API测试工具(免装Postman)
3. 翻译神器(选中代码注释秒译中英文)
4. 数据(官方插件市场超5000款插件，90%免费)

### 六、有两个版本(社区版和旗舰版)

1. 社区版(免费)：
   - 适用语言：Java、Kotlin、Android
   - 高级功能：基础开发够用
   - 适合人群：学生、安装开发者
2. 旗舰版(付费)：
   - 适用语言：Java+全栈(python、SQL、JS等)
   - 高级功能：Spring支持、微服务调试、性能分析
   - 适合人群：企业级、全栈开发者

## 输出(打印)Hello Word！

第一个快捷方式(psvm)：创建程序路口

- psvm快捷方式：它是public static void main的缩写
- 而public static void main是创建程序路口的方法
- public static void main是每个标准Java应用中必须存在的代码——你可以将它理解为程序运行的开端，少了它代码无法运转。

第二个快捷方式(sout)：快速打印(输出)

- sout快捷方式：它是System.out.println的缩写
- 而System.out.println是打印(输出)
- System.out.println是Java里代码运行的结果，可在运行窗口查看。
