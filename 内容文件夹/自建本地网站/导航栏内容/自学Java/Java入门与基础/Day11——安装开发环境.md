## 步骤三：配置环境变量

1. 此电脑右击，选择属性

![image-20250731173100288](./Day11——安装开发环境.assets/image-20250731173100288.png)

3. 找到高级选项，并单击

![image-20250731173140127](./Day11——安装开发环境.assets/image-20250731173140127.png)

4. 选择环境变量，并单击

![image-20250731173234818](./Day11——安装开发环境.assets/image-20250731173234818.png)

5. 配置环境变量——在系统变量新建一个名为：JAVA_HOME

注意：

1. 变量名填：JAVA_HOME
2. 变量值填刚才安装JDK的路径

复制路径

![image-20250731174302230](./Day11——安装开发环境.assets/image-20250731174302230.png)

![image-20250731174535421](./Day11——安装开发环境.assets/image-20250731174535421.png)

![image-20250731174607227](./Day11——安装开发环境.assets/image-20250731174607227.png)

6. 配置path变量

注意：

1. 先找到phth，并双击

![image-20250731174817935](./Day11——安装开发环境.assets/image-20250731174817935.png)

2. 单击新建，输入：%JAVA_HOME%\bin(%%表示引用的意思bin是指安装路径中的bin目录)

![image-20250731175841910](./Day11——安装开发环境.assets/image-20250731175841910.png)

3. 测试JDK是否安装成功

过程:

1. win +R，出入cmd进入DOS界面
1. 输入[java -version]
1. 出现与下的版本相同，即为安装成功
