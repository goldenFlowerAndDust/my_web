## 常见的DOS命令 

``` bash
 #盘符切换：需要切换的盘符+[:](注意要是英文)+空格
 
 #查看当前目录下的所有文件：只需输入命令[dir]即可
  
 #切换目录：命令[cd]——全称change(切换) dirctory(目录)——形式规则[cd /d 需要切换的盘符\ 需要切换的目录]——中间需要空格隔开——注意/[是参数的斜杠]   \[是文件的斜杠]  /d(是实现跨盘符切换的参数)
 
 #返回上一级：只需在当前目录后+[cd]+[..](注意是英文)
  
 #注意：在切换同一目录下的文件不需要加入盘符只需输入当前目录下要切换文件的位置即可[后面有演示]
  
 #清除屏幕：命令[cls]——可以当作clear(清除) screen(屏幕)
  
 #退出终端：命令[exit]
  
 #查看电脑的IP地址：命令[ipconfig]——config(配置)
 
#打开应用
#    1.弹出计算器：命令[calc]
 
#    2.弹出画图工具：命令[mspaint]
 
#    3.弹出记事本：命令[notepad]

#ping 命令——可以通过ping命令获取一些网站的IP地址

#文件操作
#     1.创建文件夹：命令[md]——首先在DOS界面选定需要新建文件夹的地址——然后输入[md]+新建文件夹的名字——Enter(回车)即可 
 
#     2.创建文件：命令[cd>]——首先在DOS界面选定需要新建文件夹的地址——然后输入名字+后缀名——Enter(回车即可)
#  注意：不可在所创建的名字中有空格的存在。
 
#     3.删除文件：命令[del]——首先在DOS界面选定需要删除文件的目录——然后输入[del]+需要删除的文件的名称(包括后缀名)——Enter(回车)即可

#     4.删除文件夹：命令[rd]——首先在DOS界面选定需要删除文件夹的目录——然后输入[rd]+需要删除的文件夹的名称——Enter(回车)即可

```
