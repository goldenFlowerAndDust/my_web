二级python选择题

  • 某二叉树中有15个度为1的结点，16个度为2的结点，则该二叉树中总的结点数为（）。

    1. 套公式：总结点 = 度0 + 度1 + 度2
    2. 公式2：度0 = 度2 + 1
    3. 公式3：度2 = 度0 - 1
    4. 公式4：总分支个数 = 度0 * 0 + 度1 * 1 + 度2 * 2
    5. 公式5(公式4扩展)：总分支个数 = N - 1

    6. 度1 的两种情况

      • 在非完全二叉树状态下

        1. 度0，无法计算

      • 在完全完全二叉数状态下

        1. 在普通二叉树里，叶子(n0)可以长在任何地方。但在完全二叉树里，叶子只能出现在最后两层（倒数第一层和倒数第二层），而且必须从左往右紧密排列。
        2. 说白了：就是当前节点，右边有分支，左边必须有分支
        3. 度1：只有0和1
        4. 当总节点数N是偶数：度1 = 1
        5. 当总节点数N是奇数：度1 = 0

      • 名词解释

        1. 度(Degree一般用小写n表示)：就是指当前节点伸出去的分叉(子节点)的个数
        2. 通常用N表示总节点数

        3. 度0(n0)：

          • 名词：表示当前节点 一根树枝都没伸出去，它就是这跟树枝的末端。也叫："叶子节点"
          • 数量(非常重要)：表示，节点分支数量是0，节点之和

        4. 度1(n1)

          • 表示当前节点 只伸出了一根树枝（要么只有左孩子，要么只有右孩子）。——也叫“独苗”。
          • 数量(非常重要)：表示，节点分支数量是1，节点之和

        5. 度2(n2)

          • 表示当前节点 只伸出了两根树枝（左边一根，右边一根）。——也叫“双全”。
          • 数量(非常重要)：表示，节点分支数量是2，节点之和
        6. 总边数(总分支数) = 每个分支数量对应的节点数量(nk)，k为分支数量之和。
        7. 总边数(总分支数) = 0 * n0 + 1 * n1 + 2 * n2
        8. 总边数(总分支个数)：因为根节点不会有分支与它相连，所以总分数个数，始终比总节点数少1
        9. 所以：总边数(总结点数) = N - 1
        10. 所以：N = n0 + n1 + n2
        11. 所以：n0 = n2 + 1
        12. 注意：n1要看是在 完全二叉树，还是在：非完全二叉树内，它们的状态不一样

    7. 例题：题目：一棵完全二叉树共有 700 个节点，请问叶子节点（度0）有多少个？

      解：
        已知N = 700
        因为是完全二叉树，N是偶数，所以:
           700 = n0 + 1 + n2
        已知n2比n0少1则：
           2n1 + 1 = 699
           n1 = 698 / 2 = 349
           no = 350
        综上所述：叶子节点数(no) = 350

    8. 通过二叉树——推导K叉树

      • 已知二叉树只能有两个分支(n1、n2)
      • 反推K叉树可以有K个分支(n1、n2、n3 ... nk)
      • 总节点不必多说：N = n0 + n1 + n2 + n3 + ... + nk

      • n0的推导过程



          N = n0 + n1 + n2 + n3 + ... + nk
          总边数(总分支数) = 每个分支数量对应的节点数量(nk)，k为分支数量之和
          总分支数 = 0 * n0 + 1 * n1 + 2 * n2 + 3 * n3 + ... + n * nk
          总边数(总分支数) = N - 1
          
          可得：
             N - 1 = n1 + 2n1 + 3n3 + ... + knk
             n0 + n1 + n2 + n3 + ... + nk = n1 + 2n2 + 3n3 + ... + knk + 1
             n0 = n2 + 2n3 + 3n4 + ... + (k-1)nk + 1
      • 所以K叉树的n0公式是：n2 + 2n3 + 3n4 + ... + (k-1)nk + 1

线性结构

  • 线性结构定义：数据排列方式是一对一，意在：有序、可索引（或逻辑上按顺序排列）的数据结构，才是线性结构。

  • 线性结构
    数据结构 是否有序 是否可索引(通过位置) 操作方式 是否属于线性结构
    列表(list) 有序 可索引([0]) 任意位置操作 是
    元组(tuple) 有序 可索引([0]) 不可变、只能读 是
    字符串(str) 有序 可索引([0]) 不可变、只能读 是
    字典(dict) 插入有序(3.7+) 不可索引(只能通过键) 键值对映射 ❌是散列结构
    集合(set) 插入有序(3.7+) 不可索引 元素去重、集合运算 是散列结构
    栈(Stack) 有序(入栈顺序固定——插队入栈) 不可索引 后进先出——插队先出栈
    • 可以理解为叠盘子，后面的放在上面，取盘子先出上面取出
    • 逻辑按排序排列
    • 同样有前后顺序——是线性结构
    队列(Queue) 有序(排队入队) 不可索引 先入先出——排队先出
    • 可以理解为，排队付款，先到先付款，付完款先离队
    • 逻辑按顺序排列
    • 同样有前后顺序——是线性结构
    叉树 在节点上看是有序的，但整体看是嵌套层级 不可索引
    • 一对多，从定义上就不是线性结构
    • 每个节点可以存在多个分支，分支数量由(K叉树的K决定)
    • 所以叉树，不是线性结构，而是 树形结构
    总结
    最简单分辨：是否有序、能不能索引 特殊：看是否有前后顺序、比如：排队有前后顺序、叠盘子有前后顺序

程序控制结构

  • 程序结构：是以某种顺序执行的一系动作，用于解决某个问题
  • 理论已经证明，无论多复杂的算法，都可以通过三种基本控制结构构造出来。这就是“结构化程序设计”的理论基础
  • 三大结构层：顺序结构、选择结构、循环结构、

  • 顺序结构

    1. 程序按照代码的 书写顺序、从上到下依次执行
    2. 特点：最简单、最基础，没有分支和循环。一个语句执行完，控制自动转到下一句

  • 选择结构

    1. 程序根据 某个条件是否成立，决定执行那一段代码。选择结构在考试中常被称为 分支结构
    2. 特点：程序执行到此处，会根据条件判断，选择一个分支执行。一个结构，只会执行一个分支

    3. 常见形式

      • 单分支(if)：条件成立就执行，否则跳过
      • 双分支(if-else)：条件成立执行if代码块，否则执行else代码块
      • 多分支(if-elif-else/match-case/ 非python结构：switch-case)：先判断if、然后逐个判断elif直到符合条件执行对应代码块，均不符合，则执行：else内代码块
    4. 考试容易模糊点：双分支结构，也能通过嵌套的方式，达成多分支结构
    5.                                                     ❤️多分支结构本质是：从多个条件，执行符合条件的代码块
                                ❤️if-else完全可以做到：
                                if 条件：                                      if 条件:                match 条件:
                                    代码块                                           代码块                 case 模式1:
                                else:                                         elif 条件:                          代码块
                                    if 条件:                                         代码块                 case 模式2:
                                        代码块:                                elif 条件:                          代码块
                                    else:                                            代码块                 case _:
                                        if 条件:                                   else:                          代码块
                                            代码块                                    代码块
                                                else:
                                                    代码块
    6. 以上这种嵌套结构，与 if-elif-else/ match-case本质是一样的，多个条件分支，运行符合的代码块，所以if-else嵌套同样可以实现多分支结构
    7. if基础语法
    8. match模式匹配-python特有与 switch-case相似

map() 方法

  • 作用

    • 将指定的函数应用于可迭代对象的每一个元素，返回一个迭代器

  • 语法

    map(函数, 可迭代对象1, 可迭代对象2, ...)

  • 参数说明

    • 函数：可以是内置函数（如 str、int、float），也可以是 lambda 表达式或自定义函数
    • 可迭代对象：列表、元组、字符串、range 对象等
    • 函数形参数量 = 可迭代对象的数量

  • 返回值

    • 返回一个迭代器（不是列表，不是元组）
    • 惰性计算：只有被遍历时才会执行映射
    • 一次性：遍历完后不能再次遍历

  • 基础用法

    map(str, [1, 2, 3])
    • 将列表中的每个元素转为字符串
    • 返回迭代器，可用 list() 转换为列表查看

  • 多参数用法

    map(lambda x, y: x + y, [1,2,3], [10,20,30])
    • 函数需要 2 个参数 → 传入 2 个可迭代对象
    • 从两个列表中按位取元素，传给 lambda 处理
    • 结果：[11, 22, 33]
    • 如果长度不一致，截断到最短的那个

  • 常见组合：map() + join()

    • 场景：将数字列表转为字符串并用分隔符连接
    • ",".join(map(str, [90, 87, 93])) → "90,87,93"
    • 执行流程：
      • map(str, x) 创建迭代器（惰性，不立即执行）
      • join() 被调用，遍历迭代器，取出每个元素
      • 每个元素调用 str() 转为字符串
      • join() 用分隔符连接所有字符串
    • 注意：join() 要求参数中的每个元素都是字符串，所以必须先用 map(str, ...) 转换

  • 等价写法

    • map(str, [1, 2, 3])
    • 等价于 map(lambda x: str(x), [1, 2, 3])

  • 与生成器表达式的对比

    对比维度 map() 生成器表达式
    写法 map(str, x) (str(i) for i in x)
    返回值 迭代器 生成器（也是迭代器）
    适用场景 已有函数时更简洁 需要复杂逻辑时更灵活

  • 常见陷阱

    • 陷阱一：map(str, x) 返回迭代器，不是列表
      1. 如果直接 print(map(str, [1,2,3]))，输出的是迭代器对象地址，不是内容
      2. 需要用 list(map(str, [1,2,3])) 才能看到结果
    • 陷阱二：迭代器是一次性的
      1. 遍历过一次后，再次遍历为空
    • 陷阱三：str(list) 不等于 map(str, list)
      1. str([90,87,93]) 得到 "[90, 87, 93]"（整个列表转字符串）
      2. map(str, [90,87,93]) 将每个元素逐个转字符串
      3. 两者完全不同，混用会导致 join() 结果异常

  • map() 与 str(list) 的对比

    对比维度 map(str, x) str(x)
    输入 x = [90, 87, 93] x = [90, 87, 93]
    返回值 迭代器，每个元素是字符串 整个列表的字符串表示
    结果示例 "90", "87", "93" "[90, 87, 93]"
    join() 结果 "90,87,93" "[,9,0,,,8,7,,,9,3,]"（含空格时不同）

  • 一句话总结

    • map() 是惰性映射工具，配合 join() 使用时，先将元素转字符串，再连接。
    • 函数形参数量 = 可迭代对象数量
    • 复杂逻辑用生成器表达式，简单映射用 map()

join() 方法

  • 作用

    • 用指定的分隔符，将一个可迭代对象中的所有元素拼接成一个字符串

  • 语法

    分隔符.join(可迭代对象)

  • 参数说明

    • 分隔符：字符串，如 ","、"."、" "、""（空字符串）
    • 可迭代对象：列表、元组、字符串、range 对象、生成器、map 对象等

  • 核心要求

    • 可迭代对象中的每一个元素都必须是字符串类型（str）
    • 如果包含任何非字符串元素，会抛出 TypeError

  • 返回值

    • 返回一个字符串
    • 不会在开头和末尾添加分隔符，只在相邻两个元素之间插入

  • 特性

    • 主动执行：调用时立即遍历整个可迭代对象，不是惰性方法
    • 消费迭代器：如果传入的是迭代器（如 map、生成器），会将其完全遍历

  • 基础用法

    • ",".join(["a", "b", "c"]) → "a,b,c"
    • ".".join("abc") → "a.b.c"（字符串也是可迭代对象）
    • "".join(["a", "b", "c"]) → "abc"（空字符串连接）

  • 常见组合：join() + map()

    • 场景：将数字列表转为字符串并用分隔符连接
    • ",".join(map(str, [90, 87, 93])) → "90,87,93"
    • 执行流程：
      1. join() 被调用，立即遍历 map 返回的迭代器
      2. 每次取一个元素，调用 str() 转为字符串
      3. 用分隔符连接所有转换后的字符串
    • 注意：必须先用 map(str, ...) 或生成器表达式将元素转成字符串，否则 join() 会报 TypeError

  • 常见错误

    • 错误一：直接连接数字列表
      • ",".join([90, 87, 93]) → ❌ 抛出 TypeError，因为元素不是字符串
    • 错误二：误以为 join() 会转换类型
      • 错误认知：join() 会自动把数字转成字符串
      • 正确认知：join() 不会做任何类型转换，只要求元素已经是字符串
    • 错误三：混淆 str(列表) 和 join(map(str, 列表))
      • str([90,87,93]) → "[90, 87, 93]"（整个列表转字符串）
      • ",".join(map(str, [90,87,93])) → "90,87,93"（逐个转字符串再连接）

  • 常见陷阱

    • 陷阱一：空字符串连接
      • "".join(["a", "b", "c"]) → "abc"
      • 如果元素是字符串，空分隔符直接连接所有字符
    • 陷阱二：元素包含非字符串
      • ",".join(["a", 1, "c"]) → TypeError（即使只有一个非字符串）
    • 陷阱三：join 不会在末尾添加分隔符
      • ",".join(["a", "b", "c"]) → "a,b,c"，不是 "a,b,c,"
      • 如果需要在末尾加分隔符，需要手动拼接：",".join(["a", "b", "c"]) + ","

  • join() 与 str() 的对比

    对比维度 join() str()
    输入 可迭代对象（元素必须是字符串） 任意对象
    返回值 用分隔符连接的字符串 对象的字符串表示
    列表输入 ",".join(["a","b","c"]) → "a,b,c" str([90,87,93]) → "[90, 87, 93]"
    转换能力 不转换元素类型，只拼接 尝试将整个对象转为字符串
    适用场景 将多个字符串合并成一个 查看对象的字符串表示

  • 一句话总结

    • join() 是字符串拼接工具，它不转换类型、不添加边界、主动遍历传入的可迭代对象。
    • 使用时必须确保可迭代对象中的每个元素都是字符串。
    • 与 map() 组合是最常见的用法：先用 map() 转类型，再用 join() 拼接。

队列模型

队列知识(零基础)

  • 队列得定义

    1. 队列是一种 先进先出(FIFO，First In First Out)的线性数据结构

    2. 核心思想

      • 新元素从队尾(rear)进入(入队)
      • 旧元素从队头(front)离开(出队)

    3. 现实类比

      • 排队结账(先到的人先付款，后面的人排后面)
      • 打印机任务队列(先提交的任务先打印)
      • 消息队列 (先法的消息先被处理)

  • 队列的基本操作
    操作 说明 时间复杂度
    入队(enqueue/push) 在队尾添加一个元素 O(1)
    出队(dequeue/pop) 在对头移除一个元素 O(1)
    查看队头(front/peek) 返回队头元素，但不移除 O(1)
    判空(is_empty) 判断队列是否为空 O(1)
    获取大小(size) 返回队列中元素个数 O(1)

  • 队列在python中的实现

    • python提供了多种方式实现队列：

    • 方式一：列表(不推荐用于大型队列)

      1. queue = []
        queue.append(1) # 入队(队尾)
        queue.append(2) # 后入队(队尾)
        print(queue.pop(0)) # 出队 (对头) 输出1
      2. 问题：pop(0)是O(n)操作，因为要移动后面所有元素。

    • 方式二：collections.deque(推荐)

      1. from collections import deque
        queue = deque()
        queue.append(1) # 入队 (队尾)
        queue.append(2) # 后入队 (队尾)
        print(queue.popleft()) # 出队 (对头) 输出 1 # O(1)
      2. deque是双端队列，从两端操作都是 O(1)，非常适合做队列

    • 方式三：queue.Queue（线程安全、适合多线程场景）

      1. from queue import Queue
        q = Queue()
        q.put(1) # 入队
        q.put(2) # 后入队
        print(q.get()) # 出队 # 输出 1
  • 队列的分类
    类型 特点 实现方式
    普通队列 用数组或链表实现，FIFO deque、Queue
    循环队列 用数组实现，逻辑上首尾相连，充分利用空间 自定义类或 deque
    双端队列(Deque) 两端都可以入队和出队 collections.deque
    优先队列 元素带优先级，优先级高的先出队 heapq、queue.PriorityQueue

  • 普通队列 VS 循环队列

    1. 普通队列

      • 用一段连续空间存储
      • 队尾入队、对头出队
      • 缺点：出队后前面的空间无法复用，可能导致'假溢出'(队尾已满，但前面有空位)
      • 计算入队后的新队尾位置——适用普通队列：rear = rear + 1
      • 计算入队后的新队首位置——适用普通队列：front = front + 1

    2. 循环队列

      • 把数组在逻辑上连成环
      • 入队/出队时指针可以绕回到数组开头
      • 优点：空间可以复用，不会出现'假溢出'。但是元素超出限制，会'真溢出'
      • 关键公式(循环队列)
        1. 当 front == rear 时，队列为空
        2. 当 (rear + 1) % 容器 == front 时，队列为满 (牺牲一个存储单元)
        3. 计算入队后的新队尾位置——适用循环队列：rear = (rear + 1) % 容量
        4. 计算入队后的新队首位置——适用循环队列：front = (front + 1) % 容量
        5. 队列长度 = (rear - front + 容量) % 容量

  • 二级考试中的队列考点
    考点 常见问法 核心注意点
    队列的操作顺序 '先入先出，谁先出队？' 先入队的先出队
    栈与队列对比 一下那个是队列的特性？ 栈是:LIFO、队列是：FIFO
    循环队列元素个数 front == rear = ?，元素个数 用；(rear - front + 容器) % 容器

叉树——前序、中序、后序

  • 前序：根节点————根左全部分支集合————根右全分支集合
  • 中序：根左全部分支集合————根节点————根右全部分支集合
  • 后序：根左全部分支集合————根右全部分支集合————根节点
  • 二叉树、K叉树都支持

  • 主要考点：告诉前序、中序求后序。或后序、中序求前序

    1. 步骤一：直接求根节点(前序在首、后序在尾)以及左右分支集合(中序中，根节点左边为左集合、右边为右集合)。
    2. 步骤二：先求左树(根节点左分支以及所有左子节点)或右树(根节点右分支以及所有右子节点),反正最后都要求
      • 内步骤一：先看中序：查看是：(枝叶【度0】、独苗【度1】——看某方没有节点可选、双全【度2】)
      • 内步骤二：查找对应节点范围：不管左右，范围只要碰到已经占有的节点，那么占有节点以及后续节点取不到
      • 内步骤三：拿到范围到前序或后序查找，范围内第一个出现就是对应的节点。(如果是独苗，看中序)
      • 注意：一个节点，只能分配一次，这也是，已经占有节点，以及它后续不能取的原因
    3. 步骤三：通过步骤二、求出所有节点，画出叉树
    4. 步骤四：求：前序或后序。注意对应的顺序。

    偷懒专用

    • 如果考试，选项，根节点的位置，刚好只有一个正确，那么就能秒了
    • 比如求后序：先推算出根节点、然后看选项，后序根节点在尾，如果只有一个选项，就是它没跑了
    • 比如求前序：先推算出根节点、然后看选项，后序根节点在首，如果只有一个选项，就是它没跑了

    存储结构 数据在内存里怎么放？ 顺序存储 数组、列表（连续内存）
    链式存储 链表（不连续，靠指针）
    索引存储 数据库索引、文件目录
    散列存储 字典、集合（哈希表）
    排序算法 数据怎么按大小重新排列？ 插入排序 直接插入排序
    交换排序 冒泡排序、快速排序
    选择排序 简单选择排序、堆排序
    归并排序 二路归并排序
    关键结论： 逻辑结构 管“关系”， 存储结构 管“存放”， 排序算法 管“操作”。 三者属于不同维度，可以独立组合。

    考试注意

    • 考试注意维度，不要维度混搭
    • 存储结构是物理结构，它不能采用逻辑结构，也就是看到是存储结构采用逻辑结构，直接是错的
    • 正确形式是：逻辑结构采用存储结构，这是对的
    • 还需要注意:被采用、反正记住：存储结构主动采用就是错的

  • 链表

    1. 链表是链式存储结构：内部是以："数据 + 地址(指针)"为元素的形式存储
    2. 每一个数据节点都有对应的指针，指向下一个节点
    3. 最后一个节点的指针为空（None / NULL），表示链表结束，不会报错。
    4. 空指针后面的元素不会被访问到。
    5. 链式存储本身是无序的，但可以与线性结构组合，使数据在逻辑上有序
    6. 所以链式存储既可以有序，也可以无序
    7. 注意：存储结构结构不能是主动方、不能主动采用逻辑结构
    8. 习题：线性结构(规定有序)也能采用链式存储结构，这句话是对的
    9. 比如：线性结构(规定有序)一定能能采用链式结构，这句话也是对的
    10. 比如：链式存储结构一定被能线性结构(规定有序)采用，这句话也是对的
    11. 比如：链式存储结构一定能被线性结构(规定有序)采用，这句话也是对的
    12. 反例：线性结构被链式存储结构采用，这句话是错的，存储结构变为了主动方
