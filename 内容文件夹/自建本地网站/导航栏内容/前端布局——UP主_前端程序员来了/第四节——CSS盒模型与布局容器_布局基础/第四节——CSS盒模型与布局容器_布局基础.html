CSS盒模型与布局容器_布局基础

CSS盒模型

  • 网页布局的基础

  • 每个HTML元素可以视为一个矩形盒子(主要由：内容、内边距、边距、外边距组成)

    1. 内容:元素实际内容的区域(content)
    2. 内边距：环绕内容区域的空白空间(padding)
    3. 边框：包裹在内边距外部的可见线条(border)
    4. 外边框：围绕在边框的透明区域(margin)

  • 盒模型的类型和差异

    1. 标准盒模型

      • 盒子尺寸=内容+左右内边距+左右边框+左右外边距(累加一起，也就是说：内容尺寸=所设置的尺寸)

    2. IE盒模型

      • 使用属性box-sizing:border-box(放在全局属性选择器内)，将标准盒模型转为IE盒模型
      • 同样盒子尺寸=内容+左右内边距+左右边距+左右外边距(但是最终的尺寸与自己设置的一致，也就是说会自动计算，也就是说:内容=所设置的尺寸-左右外边距-左右边框-左右内边距)

布局容器

  • 包裹内容的父级元素
  • 它的尺寸与样式设置将直接影响子元素的布局显示
