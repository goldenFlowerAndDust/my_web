数据类型转换

共有三种转换方式

  • 转数值

    1. 方法一:Number(变量)

      • 可以把一个变量强制转换成数值类型
      • 可以转换小数，会保留小数
      • 可以转换布尔值(true强制转为1)，false强制转为0
      • null(空值)——强制转为0
      • 遇到不可以转换的都会返回NaN——"非数字、布尔值、null"
      • 只要存在不可转换的字符，都返回NaN

    2. 方法二:parseInt(变量)

      • 从第一位开始检查，是数字就转换，直到一个不是数字的内容
      • 开头就不是数字，那么直接返回NaN
      • 不认识小数点，只能保留整数

    3. 方法三:parseFloat(变量)

      • 从第一位开始检查，是数字就转换，直到一个不是数字的内容
      • 开头不是数字，那么直接返回NaN
      • 只认识第一个小数点

    4. 方法四:除加法以外的数学运算符

      • 运算符两边都是可运算数字才行
      • 如果运算符任何一边不是一个可运算数字，那么就会返回NaN
      • ·加法不可以用
        1. 任一操作数是字符串，用加号，会将前/后数据类型转为字符串，并进行拼接
        2. 当两个操作数都是非字符串、布尔值，用加号，则进行加法运算(但这已经不涉及转换数据类型了[而是两个操作数均是数值])

  • 转字符串

    1. 方法一:变量.tostring()

      • 有些数据类型不能使用tostring()方法，比如undefined和null

    2. 方法二:String(变量)

      • 所有数据类型都可以

    3. 使用加法运算

      • 在JS里面，【+】有两个含义
      • 字符串拼接:只要+任一一边是字符串，就会进行字符串拼接
      • 加法运算：只有+两边都是数字的时候，才会进行数学运算
