变量命名的规则和规范

规则与规范

  • 规则(必须遵守的，不遵守就会报错)

    1. 一个变量名称可以由数字、字母、英文下划线(_)、美元符号($)组成
    2. 严格区分大小写
    3. 不能由数字开头
    4. 不能是保留字(未来可能会成为关键字)或关键字(目前正在使用的)
    5. 不要出现空格符
    6. 输出变量不要添加双引号，反之加了双引号就是字符串

  • 规范(建议遵守的[开发者默认])，不遵守不会报错

    1. 变量名尽量有意义(语义化)——可以是英文、拼音(写全不要简写)
    2. 遵守驼峰命名规则，由多个单词祖成的时候，从第二个单词开始首字母大写
    3. 不要使用中文命名(尽量少用)
