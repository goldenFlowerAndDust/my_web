JS的注释与规范

  • 注释

    1. 单行注释

      • 在代码最前面加上双斜杠
      • 快捷键：Ctrl+/，非注释状态下使用注释该代码，注释状态下取消改代码的注释

    2. 多行注释

      • 使用/*[内容]*/包围——意思是/*为开头，*/结尾，中间内容均为注释，可以换行

      • 快捷键

        1. VSCode：Ctrl+Shift+A
        2. WebStorm/PyCharm/IDEA：Ctrl+Shift+/

  • 规范

    1. 关于分号的使用

      • 不加分号

        ·多行结尾不用加分号

      • 加分号

        ·多个方法在一行，除去最后一个方法，其他方法结尾需要添加分号

    2. 尽量写一行代码，换行
