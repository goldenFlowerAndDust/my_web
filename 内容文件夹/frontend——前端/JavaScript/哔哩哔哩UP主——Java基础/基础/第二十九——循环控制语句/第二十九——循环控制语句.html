循环控制语句(break、continue)

  • break(终止循环)

    1. 在循环没有进行完毕，设置break后，条件满足，则提前终止循环
    2. 比如:要吃5个包子，但是吃到第三个的时候，吃不下了，那么就要停止吃包子这件事
    3. 总结：要终止循环，就可以直接使用break关键字
    4. 可以理解为：查找：当查找到需要的，后面再查找就没有意义，浪费精力

    5. break案例(循环十次，当循环5次，就停止循环)

  • continue(结束本次循环)

    1. 在循环中，设置continue后，跳过本次循环，继续执行后续的循环
    2. 比如：吃5个包子，吃到第三个的时候，包子掉地上了，跳过掉地上的，继续吃后面包子
    3. 总结：跳过本次循环，就可以使用continue关键字
    4. 可以理解为：筛选：筛选出不需要的，保留需要的

    5. continue案例(循环10次，但是跳过第5次)
