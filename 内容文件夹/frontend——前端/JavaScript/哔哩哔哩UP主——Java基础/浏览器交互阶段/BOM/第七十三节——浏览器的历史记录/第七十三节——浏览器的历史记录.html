浏览器的历史记录

历史记录

  • window中有一个对象叫做history
  • 是专门用来存储历史记录信息的

  • 方法：history.back()

    1. history.back是用来回退历史记录的，就是回到前一个页面，相当于浏览器上的←按钮
    2. 语法：window.history.back()
    3. window可以省略：history.back()也可以
    4. 前提是：存在上一条记录(同一个标签页，有多次页面切换)，否则一直在当前页面，也不会回退

    6. 实例

  • 方法：history.forward()

    1. history.forward是用来前进到下一个标签页，就是回到后一个页面，相当于浏览器上的——→按钮
    2. 语法：window.history.forward()
    3. 前提是：存在下一条记录(同一个标签页，有多次页面切换)，否则一直在当前页面，也不会前进
    4. window可以省略：history.forward()也可以

    6. 实例

  • 方法：history.go()

    1. history.go
    2. 语法：window.history.go()
    3. 具备前进与回退的两个功能，括号内可以传入一个形参，可以是正负值和零 正值表示前进，负值表示回退，0类似刷新当前标签页具体前进或后退多少记录，有参数具体值决定
    4. 前提是：存在历史记录，不存在，则只会显示当前标签页，不会执行前进或回退操作
    5. window可以省略：history.go()也可以
