浏览器的常见事件

浏览器的常见事件有：

  • 注意：BOM 事件（如 onscroll）可以通过属性赋值或 addEventListener(事件监听器) 绑定。属性赋值只能绑定一个处理函数，后面覆盖前面； addEventListener(事件监听器) 可以绑定多个，不会覆盖。两者本质上都是注册回调，由浏览器在事件发生时统一调用。

  • onload事件

    1. 注意：这个不是一个对象，而是一个事件
    2. 是在页面所有资源加载完毕后执行——异步执行
    3. 页面所有资源包括：图片、视频、DOM
    4. 主要是：给浏览器绑定事件
    5. 代码实例：
      window.onload = function () {代码块}
      window.onload = () => {代码块}

    6. 代码实例

  • onresize事件

    1. 注意：这个不是一个对象，而是一个事件
    2. 当页面长宽变动时，执行该事件
    3. 代码实例：
      window.onresize = function () {代码块}
      window.onresize = () => {代码块}

    4. 代码实例

  • onscroll事件

    1. 注意：这个不是一个对象，而是一个事件
    2. 当页面滚动条变动时，执行该事件
    3. 代码实例：
      window.onscroll = function () {代码块}
      window.onscroll = () => {代码块}

    4. 代码实例

补充知识

  • addEventListener事件监听器

    1. 与传统的on开头的不同，它可以添加多个回调函数，普通的添加事件(onclick、onload、onresize、onscroll)后面的会覆盖前面的
    2. 语法：window.addEventListener('需要绑定的事件',()=>{代码块})
    3. 语法：window.addEventListener('需要绑定的事件',function () {代码块})

    4. 目前学过的事件

      • click：点击事件
      • scorll：滚动条滚动事件
      • resize：窗口大小改变事件
      • load：资源加载完成事件
    5. 总结：on开头的会被覆盖，addEventListener可以添加多个事件
