浏览器的地址信息

  • 在window中有一个对象叫做location
  • 就是专门用来存储浏览器的地址栏内的信息

  • 属性location.href

    1. location.href这个属性存储的是浏览器地址栏内url地址的信息
    2. 语法：console.log(window.location.href)
    3. window可以省略，即location.href这种写法也可以
    4. 会把中文变成url编码的格式
    5. location.href这个属性也可以给他赋值
    6. 语法：window.location.href = 'url'
    7. 这个就会跳转页面到赋值的url地址
