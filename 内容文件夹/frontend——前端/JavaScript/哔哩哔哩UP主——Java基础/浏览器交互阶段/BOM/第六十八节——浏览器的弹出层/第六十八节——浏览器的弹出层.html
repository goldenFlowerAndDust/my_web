浏览器的弹出层

  • alert

    1. 它是一个Window对象
    2. 主要功能：弹出警告框
    3. 语法：window.alert()但是window可以省略，即alert()也可以
    4. 但是注意：alert会阻塞代码的运行，只要它在触发阶段，后续代码就无法运行，相反异步执行确实先将需要执行的代码运行，再运行异步执行的代码块，避免了阻塞
    5. 没有返回值,实际返回值是：undefined

  • confirm

    1. 它是一个Window对象
    2. 主要功能：弹出询问框
    3. 语法：window.confirm()但是window可以省略，即confirm()也可以
    4. 但是注意：confirm会阻塞代码的运行，只要它在触发阶段，后续代码就无法运行，相反异步执行确实先将需要执行的代码运行，再运行异步执行的代码块，避免了阻塞
    5. 有返回值：确定返回true，取消返回false

    7. 实例

  • prompt

    1. 它是一个Window对象
    2. 主要功能：弹出输入框
    3. 语法：window.prompt()但是window可以省略，即prompt()也可以
    4. 有两个参数：第一个参数：输入提示用户的文本，第二个参数默认输入框内容，用户可以自行删除
    5. 但是注意：prompt会阻塞代码的运行，只要它在触发阶段，后续代码就无法运行，相反异步执行确实先将需要执行的代码运行，再运行异步执行的代码块，避免了阻塞
    6. 返回值是：用户输入的内容
