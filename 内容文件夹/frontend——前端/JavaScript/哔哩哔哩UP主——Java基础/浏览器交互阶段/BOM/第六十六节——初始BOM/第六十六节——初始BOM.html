初始BOM

什么是BOM

  • BOM(Browser object Mods):浏览器对象模型
  • 其实就是操作浏览器的一些能力

  • 我们可以操作那些内容

    1. 获取一些浏览器的相关信息(如：窗口大小)
    2. 操作浏览器进行页面跳转
    3. 获取当前浏览器地址栏的信息
    4. 操作浏览器的滚动条
    5. 浏览器的信息(如：浏览器的版本)
    6. 让浏览器出现一个弹出框(alter、confirm、prompt)
    7. ....
  • BOM的核心就是Windows对象
  • Windows是浏览器内置的一个对象，里面包含着操作浏览器的方法
