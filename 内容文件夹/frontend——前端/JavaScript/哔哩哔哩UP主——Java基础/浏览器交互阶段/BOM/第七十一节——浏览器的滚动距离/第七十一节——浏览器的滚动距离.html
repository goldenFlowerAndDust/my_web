浏览器的滚动距离

显示滚动距离

  • 注意：距离指的是：页面随着滚动后，超出视口的距离

  • 显示垂直滚动距离

    1. 属性：window.document.documentElement.scrollTop
    2. window可以省略：document.documentElement.scrollTop也可以
    3. 需要与onscroll事件绑定或addEventListener事件监听，第一个参数为scroll
    4. 注意：一些低版本不支持documentElemnt,所以可以写document.body.scrollTop
    5. 所以一般最好写成：(document.documentElement.scrollTop || document.body.scrollTop)

    6. 实例(在控制台显示滚动距离)

  • 显示水平滚动距离

    1. 属性：window.document.documentElement.scrollLeft
    2. window可以省略：document.documentElement.scrollLeft也可以
    3. 需要与onscroll事件绑定或addEventListener事件监听，第一个参数为scroll
    4. 注意：一些低版本不支持documentElemnt,所以可以写document.body.scrollLeft
    5. 所以一般最好写成：(document.documentElement.scrollLeft || document.body.scrollLeft)

    6. 实例(在控制台显示滚动距离)

  • 规定滚动距离

    1. 方法：window.scrollTo()
    2. window可以省略：scrollTo()也可以
    3. 共有两个参数：第一个参数：X轴距离顶部的距离,第二个参数：Y轴距离顶部的距离
    4. 当然也可以采用，传对象的方法：scroll({top:num , left:num})num为具体数值, 且对象中：left,top位置不固定，但是不能重复声明(键不同相同),不能有除left、top以外的键
