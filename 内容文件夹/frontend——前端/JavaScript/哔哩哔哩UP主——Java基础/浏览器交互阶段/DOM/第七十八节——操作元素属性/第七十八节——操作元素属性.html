操作元素属性

  • 元素属性分类

    1. 第一类：元素自带的属性(原生属性)如： id、class、name.....
    2. 第二类：自定义属性(自己创建的属性)一般没有意义

  • 操作原生属性

    1. 更改属性值

      • 先获取元素
      • 然后使用点语法+属性名
      • 语法：1.先获取元素const Hello = document.getElementById('hello')
        2.假设获取的是表单，且 type = 'text' , 要求改为 password
        则：Hello.type = 'password'，
        获取元素的属性名 = 新属性值即可
      • 说白了，就是获取元素对应的属性名，然后重新赋值(所以首要前提是：获取元素,获取元素的方法)

    2. 自定义属性的(增、获取、删)

      • 增/修改(重新赋值)：节点元素.setAttribute('自定义属性名',‘自定义属性值’)顾名思义：就是在当前节点，添加一个自定义属性
      • 获取：节点元素.getAtttribute('自定义属性名')顾名思义：就是获取当前节点，的自定义属性名
      • 删：节点元素.removeAttribite('自定义属性名')>顾名思义：就是删除当前节点，的自定义属性名

    3. 自定义属性的命名约定，以及对应的的方法

      • 自定义属性约定，最好加上前缀 data-自定义属性，但是自定义属性命名规则与变量一致，不合法字符会自动忽略，组成一个新的属性名
      • 那么采用这种命名形式，增/修改、获取、删略有不同
      • 获取：节点元素.dataset：注意点：获取的当前节点所有 data的自定义属性,但是返回的是一个 DOMStringMap对象
      • 已经知道返回的是一个对象了，那么 增/改、删、查与对象一致
      • 增/改(重新赋值)：字面量.dataset.属性名 = "属性值"
      • 查：字面量.dataset.属性名
      • 删：delete 字面量.dataset.属性名
      • 注意(字面量)：是获取的节点元素，可能是一个元素(可以直接操作：增/改、删、查)， 若返回的是伪数组(需要先遍历，再执行操作)
      • 注意(属性名)：不需要前缀 data-

补充知识

  • 表单知识回顾

    1. 大部分表单控件通过 <input> 的 type 属性来定义（如文本、密码、单选框等），但 <select>、<textarea>、<button> 等是独立标签。
    2. label标签有两种写法：
      显式：就是所有标签写在 label标签内
      隐式：就是所有标签写在 label标签外、 但是 label不能缺少，外label标签内设置 for=""属性，然后其他标签设置 id=""属性，确保 for属性值与id值一致
    3. 所有 input标签都是在label标签内或使用隐式
    4. 所有特殊功能标签如：select、textarea标签都是在label标签内或隐式

    5. form标签内属性

      • 属性：action
        1. 是一个地址(url)
        2. 用于当表单提交(传交)到后端地址接收
      • 属性：method
        1. 主要用于传交方式
        2. 属性值一：get：通过地址url传参，参数会暴露在地址栏上；安全性更低；传输数据小；
        3. 属性二：post：通过浏览器内部机制传输参数；参数不会暴露在url中；相对于来说安全性更高；传输数据大；

    6. input属性

      • input：type属性

        • 它的规定表单内控件的：input的类别
        • 属性 name
          1. 用于传输参数给后端接收该表单字段使用
          2. 在单选框内，可能充当互斥的作用，即name属性值相同，只能选中其中一个，避免多选问题
        • 属性 submit
          1. 提交按钮
          2. submit 按钮用于提交表单，会触发表单的提交事件并执行浏览器内置验证（如 required）。普通按钮（type="button"）不会触发任何验证或提交。
          3. 可以使用：属性 value定义按钮的初始文本
          4. 最好只在，from标签内使用，其他地方跟普通按钮没区别
        • 属性 button
          1. 普通按钮
          2. 没有特殊效果，按了之后不会有任何变化
        • 属性 reset
          1. 重置按钮
          2. 顾名思义就是将所填写的信息全部重置，重新填写表单
          3. 最好只在，from标签内使用，其他地方跟普通按钮没区别
        • 属性 radio
          1. 单选框
          2. 输入的文本在input前或后
          3. placeholder没有效果
          4. value 用于定义选项的值（提交时使用），不显示在页面上。
          5. name互斥(相同的name只能选中一个)
        • 属性 checkbox
          1. 复选框(多选框)
          2. 输入的文本在input前或后
          3. placeholder没有效果
          4. value 用于定义选项的值（提交时使用），不显示在页面上。
        • 属性 number
          1. 只能输入数字，特征右边会有加减数字按钮
        • 属性 date
          1. 只能输入日期，特征会显示日期特有的年月日
          2. 可以调出日历
        • 属性 email
          1. 只能输入邮箱，系统默认情况会校验
        • 属性 color
          1. 会显示颜色调色板
        • 属性 range
          1. 会显示一个拉条
      • input：required属性
        1. 表单必填才能提交
        2. 也就是说，必须输入内容，才会被提交，由浏览器验证
      • input：placeholder属性
        1. 提示输入框的文案内容，当用户输入内容时，提示文案会消失
      • input：value属性
        1. 控件的初始显示文本，常用于提示用户当前按钮是什么功能
      • input：checked属性
        1. 默认选中状态(可以手动更改到其他的选项)
        2. 在标签内使用，不管是直接属性本身、赋值 false还是true都是表示默认选中状态
        3. 但是在JavaScript中，获取的元素，通过点语法.checked可以通过赋值控制选中状态：false——未选中、true——选中 属性本省不赋值则表示实时获取当前单选框。复选框的选中状态，返回值 true或false

    7. form标签内的特殊标签

      • 标签：select
        1. 创建下拉选择列表
        2. 必须在label内
        3. 每一个选择列表由标签 option包裹
        4. 语法(写在 label标签内——显式)： <label> <select name=""> <option>广州</option> <option>深圳</option> </select> </label>
        5. 语法(写在 label标签外——隐式)： <label for="city">城市</label> <select name="" id="city"> <option>广州</option> <option>深圳</option> </select>
      • 标签：textarea
        1. 多行文本
        2. 内含两个属性：cols——宽度，值越大，宽度越大、rows——行数，值越大，高度越长
        3. 必须在label内
        4. 语法(写在 label标签内——显式)： <label> <textarea name="" cols="30" rows="10"></textarea> </label>
        5. 语法(写在 label标签外——隐式)： <label for="introduce">XXX</label> <textarea name="introduce" id="introduce" cols="30" rows="10"></textarea>
