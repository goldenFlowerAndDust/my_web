初始DOM

什么是DOM

  • DOM(Document object Mods)：文档对象模型
  • 其实就是操作html中的标签的一些能力

  • 我们可以操作那些内容

    1. 获取一个元素
    2. 移除一个元素
    3. 创建一个元素
    4. 向网页里面添加一个元素
    5. 给元素绑定一些事件
    6. 获取元素的属性
    7. 给元素添加一些css样式
    8. ........
  • DOM的核心对象就是 document对象
  • document对象就是浏览器内置的一个对象，里面存储专门用来操作元素的各种方法
  • DOM：页面中的标签，我们通过 js获取到以后，就把这个对象叫做 DOM对象
