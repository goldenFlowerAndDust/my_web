获取元素的方式

  • 非常规的

    1. html、head、body 不需要获取元素，可以直接进行操作
    2. 语法(获取html)：document.documentElement
    3. 语法(获取head)：document.head
    4. 语法(获取body)：document.body

  • 常规的(一般不考虑兼容性问题)

    1. 方法：getElementById()

      • getElementById()：通过标签的 id名称获取标签的元素
      • 语法：document.getElementById('id名')
      • 因为在一个页面中id是唯一的，所以所以获取的就是一个元素
      • 最好声明变量接收(因为当需要多次操作的话，需要重复获取元素，增加代码量) 所以声明变量接收，通过这个变量来操作会方便很多，而且后续的 伪数组(也叫类数组)nodeList类型需要遍历。
      • 因为获取的是一个元素，所以可以直接在改元素上直接进行操作(如innerHTML、innerText、value...)

      • 案例(使用getElementById获取按钮)

    2. 方法：getElementsByClassName()

      • 伪数组具体解释
      • document.getElementsByClassName()：通过标签的 class(类)名称获取标签的元素
      • 语法：getElementsByClassName('class名')
      • 因为在一个页面中class是多个的，所以所以获取的就是 一个伪数组(也叫类数组)[HTMLCollection]
      • 伪数组：是一个class的集合，所组成的集合：它有正常数组的 length属性和索引元素，但是缺少数组方法的对象( 意思就是没有数组的方法(forEach、map、filter、reduce、find、findIndex、every、some) 都无法使用)
      • 使用该方法获取的伪数组是其中一种(HTMLCollction)它不能使用方法 forEach遍历，可以使用 for、for-of或直接转成数组，方法：Array.from()——然后使用 forEach遍历
      • 可以使用索引+中括号的方式，单个操作
      • 最好声明变量接收,减少代码量
      • 遍历完后，才能进行操作，不然只有第一个生效

      • 案例(使用getElementByClassName获取元素)

    3. 方法：getElementsByTagName()

      • 伪数组具体解释
      • document.getElementsByTagName()：通过标签的名获取对应的元素
      • 语法：getElementsByTagName('标签名')
      • 因为在一个页面中标签是多个的，所以所以获取的就是 一个伪数组(也叫类数组)[HTMLCollection]
      • 伪数组：是一个class的集合，所组成的集合：它有正常数组的 length属性和索引元素，但是缺少数组方法的对象( 意思就是没有数组的方法(forEach、map、filter、reduce、find、findIndex、every、some) 都无法使用)
      • 使用该方法获取的伪数组是其中一种(HTMLCollction)它不能使用方法 forEach遍历，可以使用 for、for-of或直接转成数组，方法：Array.from()——然后使用 forEach遍历
      • 可以使用索引+中括号的方式，单个操作
      • 最好声明变量接收,减少代码量
      • 遍历完后，才能进行操作，不然只有第一个生效

    4. 方法：getElementsByName()

      • 伪数组具体解释
      • document.getElementsByName()：通过name名获取对应的元素
      • 语法：getElementsByName('name名')
      • 因为在表单input内那么可以是多个的，所以所以获取的就是 一个伪数组(也叫类数组)[NodeList]
      • 伪数组：是一个class的集合，所组成的集合：它有正常数组的 length属性和索引元素，但是缺少数组方法的对象( 意思就是没有数组的方法(forEach、map、filter、reduce、find、findIndex、every、some) 都无法使用)
      • 使用该方法获取的伪数组是其中一种(NodeList)浏览器支持 forEach遍历，当蓝也可以使用 for、for-of或直接转成数组，方法：Array.from()——然后使用 forEach遍历
      • 可以使用索引+中括号的方式，单个操作
      • 该方法常用于表单，其他地方没有 name属性，当然可以自己定义 name属性，但是没有任何意义
      • 最好声明变量接收,减少代码量
      • 遍历完后，才能进行操作，不然只有第一个生效

    非常规的(需要考虑兼容性问题)

    1. 方法：querySelector()

      • 语法：document.querySelector()
      • 获取单个元素(获取第一个匹配的元素)
      • 可以获取：除伪元素选择器外的所有选择器(类选择器、id选择器、伪类选择器、兄弟选择器、子选择器....)
      • 但是需要添加前缀(类 .、id #、伪类 :)
      • 因为获取的单个元素，而不是伪数组，所以可以直接操作该元素
      • 最好声明变量接收

    2. 方法：querySelectorAll()

      • 语法：document.querySelectorAll()
      • 获取所有匹配的元素
      • 可以获取：除伪元素选择器外的所有选择器(类选择器、id选择器、伪类选择器、兄弟选择器、子选择器....)
      • 但是需要添加前缀(类 .、id #、伪类 :)
      • 因为获取的所有匹配的元素，是伪数组，所以不可以直接操作该元素，需要遍历
      • 使用该方法获取的伪数组的其中一种 NodeList，所以可以使用 forEach、for、for-of以及方法：Array.from()再使用forEach【当然这是多此一举的】
      • 最好声明变量接收

  • 知识复习

    • for：需要初始话变量、循环条件、改变逻辑，可嵌套
    • for-in：需要声明变量用于接收索引
    • for-of：需要声明变量用于接收元素
    • Array.from()：将存在 length属性的类型，转为真数组
