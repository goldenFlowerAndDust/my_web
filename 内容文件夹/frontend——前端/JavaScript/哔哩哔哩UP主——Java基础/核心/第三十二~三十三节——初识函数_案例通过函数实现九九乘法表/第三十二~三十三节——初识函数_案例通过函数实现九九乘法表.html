初识函数

  • 函数概以及案例(通过函数实现九九乘法表【复用3次】)

    • 对于JavaScript来说，函数就是把任意一段代码放在一个盒子里面
    • 在需要用到这段代码的时候，直接执行这个盒子里面的代码就行
    • 函数声明:function 函数名(){代码块}
    • 函数调用:函数名()

    • 返回值问题

      1. 使用return关键字可以退出函数并返回一个值
      2. 如果没有return或只写return，函数返回值是undefined
      3. 调用函数时，可以用变量接受返回值(前提是:return接受值变量名),
        例如：let result = 函数名()

      4. 函数实例:生成九九乘法表字符串

        • 九九乘法表
        • 不会的关键字看扩展
    • 总结来说就是：重复复用(案例：通过函数，显示4个九九乘法表)

  • 函数定义阶段

    1. 定义阶段就是把代码放在盒子里面

    2. 定义有两种方式(声明式和赋值式)

      • 声明式
        1. 使用function关键字来声明一个函数
        2. 语法：function 函数名(){代码块}
        3. 可以先调用再定义
      • 赋值式
        1. 语法：let(var、cont) 变量名 = function(){代码块}
        2. 必须先定义再调用
    3. 函数是自私的，不允许外部调用(函数内部的变量值)
      即:函数内部定义的变量是局部变量，外部不能访问
      如：函数是自私的

扩展内容

  • DOM元素获取和批量操作

    1. querySelectorAll:获取所有匹配指定CSS选择器的元素，返回值NodeList(类似数组)
      • 注意：NodeList不可以直接添加样式:如let NodeList = document.querySelectorAll().style.
      • 需要新建函数，并使用关键字forEach
    2. forEach：遍历NodeList,对每个元素执行函数
    3. value属性：用于读取或写入<textarea>，<input>的内容

  • 样式设置与cols/rows的注意点

    1. 通过JS设置的样式会覆盖HTML属性cols和rows的默认尺寸效果
    2. 若希望保留cols/rows的自动尺寸，就不要使用JS设置宽高(或只设置其中一项)
    3. 对textarea设置样式(字体、颜色、背景等)是整体生效，无法单独设置内部每个计算的样式(因为textarea只支持纯文本)

  • 额外接触的新知识点

    1. void运算符：对表达式求值并返回undefined，常用于阻止链接跳转(javascript:void(0))
    2. 箭头函数:() => {}的简洁写法，与传统function类似，但作用域规则不同(暂未系统学习，仅了解符号为=>)
    3. return的双重作用① 退出函数；② 返回指定值。

  • 函数封装的优势

    1. 将重复代码封装成函数，避免复制粘贴
    2. 修改函数内部逻辑，所有调用处自动更新
    3. 函数可以返回值，供外部使用，实现数据生成与界面渲染的分离

  • 学习当中的踩坑点

    1. 忘记在HTML中引入外部JS文件——→<script src=".js"></script>
    2. 函数忘记写return——→导致变量直接接受到undefined
    3. 多个元素使用相同的id——→改用class + querySelectorAll
    4. 直接给 NodeList 设置 .style → 必须遍历每个元素

  • 获取元素的关键字

    1. getElementById(引用id获取元素)
    2. querySelector(获取第一个符合的class元素)
    3. querySelectorAll(获取所有class元素，但是是NodeList(类似与数组))
    4. 注意：获取的是元素，才可以直接更改样式，若获取的是NodeList，不能直接更改样式，需要(新建函数，然后使用forEach，遍历每个元素才行)
