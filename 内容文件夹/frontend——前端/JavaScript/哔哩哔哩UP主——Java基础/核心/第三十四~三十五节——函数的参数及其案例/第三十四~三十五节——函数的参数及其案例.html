函数的参数

函数的参数及其案例

  • 函数的参数定义

    1. 在定义函数和调用函数的时候都会用到[()]
    2. 主要作用：存放参数的位置
    3. 参数分为：形参(定义函数时：()内的叫形参)和实参(调用行数时：()内的叫实参)
    4. 一次可以传一个或多个参数，中间用英文逗号隔开

    5. 注意事项：

      1. 最终式实参赋值给形参
      2. 形参可以理解为变量名：所以，形参与变量名的命名规则相同
      3. 实参可以理解为变量值：所以，实参可以是所有数据类型
      4. 形参和实参(定义或未定义状态下的注意事项)
        • 形参定义，实参定义
          1. 正常情况
          2. 结果：形参与实参一一对应，正常使用
          3. 注意1：实参数量可以多余形参(多余的被忽略)
          4. 注意2：实参数量可以少于形参(不足的为undefined)
        • 形参定义，实参未定义
          1. 对应形参数量多余实参数量状态
          2. 结果：形参的参数均为undefined
          3. 一般不会报错，但是用undefined参与运算可能得到NaN或意外结果
          4. 注意：如果均为undefined，执行数学运算的话，结果始终未NaN
        • 形参未定义，实参定义
          1. 若函数内部使用了未声明变量(a,b)，且全局变量没有对应变量名和未使用方法arguments直接报错
          2. 如果函数内部使用arguments对象，可以访问实参
          3. 如果函数内部使用了全局变量(且全局存在)——则引用全局变量，实参被忽略
          4. 注意：没有形参时，实参不会自动赋值给任何变量，必须通过arguments获取
        • 形参未定义，实参未定义
          1. 如果函数内部使用了未声明的变量，直接报错
          2. 如果函数内部没有使用外部变量，正常执行(但无参数可用)
          3. 注意：这种情况很少用，通常没有意义

    6. 声明式


      function fn(形参写在这里){
      一段代码
      }
      fn(实参写这里)————调用函数

    7. 赋值式


      let(var/cont) fn = function (形参写在这里){
      一段代码
      }
      fn(实参写这里)————调用函数

  • 案例

    1. 案例1(练习形参和实参的区别[声明式与赋值式])

      通过输出的结果可以看到： ·不管是声明式还是赋值式：行参不为空，调动函数时：实参为空，最后传参的值均是undefined。 ·不管式声明式还是赋值式：行参不为空，调动函数时：实参不为空，最后传参的值会按实参顺序一一对应赋给

知识补充

  • undefined与数据类型、运算符之间的关系

    1. 与数值类型，undefined转化为NaN，最后的结果永远是NaN
    2. 与字符串类型，undefined转为字符串拼接
    3. 与布尔类型，true ——→ 1 , false——→ 0，所以undefined转化为NaN，最后的结果永远是NaN
    4. 与逻辑运算符，（&&、||、!）不直接参与数学运算，但会按逻辑规则处理(undefined是falsy)
    5. 与null的运算：null在算数运算中会转换为0，undefined转换为NaN，所以最后的结果是NaN
    6. 与undefined运算：undefined + undefined = NaN
    7. 与自增/自减：结果任然是：NaN
    8. 与比较运算符：
      分三种：
      第一种：关系比较(>、<，>=，<=)：undefined为NaN，(NaN与数值比较都返回false)
      第二中：相等性：
      • undefined == null 为 true(特殊规则)
      • undefined == undefined 为 true
      • undefined == 0/undefined == ""/undefiend == false 都为false

      第三种：严格相等 ： undefined === undefined 为 true，与其他任何值 === 为 false
    9. 提醒：在实际开发中，避免使用undefined参与数学运算：始终确保变量已初始化，或使用默认值
    10. 若必须处理可能为undefined的变量，先判断。

  • arguments对象

    1. 暂时理解为：查找索引
    2. 语法：arguments[索引]
