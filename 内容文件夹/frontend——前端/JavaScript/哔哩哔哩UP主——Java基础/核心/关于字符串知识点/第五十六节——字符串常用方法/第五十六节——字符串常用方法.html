字符串常用方法

  • 前言

    1. 注意：字符串的方法，有些和数组重名，但是千万不能与数组相联系
    2. 数组与字符串是两个维度，不能替换
    3. 但是重名的方法与数组的作用相同
    4. 字符串返回值始终是新字符串，所以使用方法，需要声明变量接收返回值

  • String对象的方法

    1. 方法charAt

      • 该方法返回索引对应的字符
      • 语法：字面量.charAt(索引)
      • 返回值是索引对应的字符
      • 不会对原字符串产生影响，所以需要直接使用或声明变量接收返回值
      • 索引从0开始
      • 注意通过方法JSON.stringify()转成的字符串，双引号计入索引值
      • 创建字符串的两种方法均适用
      • 实例

    2. 方法charCodeAt

      • 该方法返回索引对应的字符编码(ASCII码以及unicode编码(也叫万国码))
      • 语法：字面量.charCodeAt(索引)
      • 返回值是索引对应的字符编码
      • 不会对原字符串产生影响，所以需要直接使用或声明变量接收返回值
      • 索引从0开始
      • 注意通过方法JSON.stringify()转成的字符串，双引号计入索引值
      • 同时也可以通过方法String.fromCharCode(编码)，将对应编码，转成对应的图形
      • 创建字符串的两种方法均适用
      • 实例(通过方法，将编码转换成对应字符)

    3. 方法toUpperCase

      • 该方法：将所有字母转换成大写
      • 语法：字面量.toUpperCase()
      • 返回值是将原字符串的所有字母转成大写，生成的新字符串
      • 不会对原字符串产生影响，所以需要直接使用或声明变量接收返回值
      • 注意：只能将字母转换，汉字和特殊字符不行
      • 创建字符串的两种方法均适用
      • 实例

    4. 方法toLowerCase

      • 该方法：将所有字母转换成小写
      • 语法：字面量.toLowerCase()
      • 返回值是将原字符串的所有字母转成小写，生成的新字符串
      • 不会对原字符串产生影响，所以需要直接使用或声明变量接收返回值
      • 注意：只能将字母转换，汉字和特殊字符不行
      • 创建字符串的两种方法均适用
      • 实例

    5. 方法substr

      • 该方法：主要是截取字符串
      • 语法：字面量.substr(开始索引,需要截取字符的个数)
      • 返回值是将截取的元素，生成的新字符串
      • 不会对原字符串产生影响，所以需要直接使用或声明变量接收返回值
      • 注意:第一个参数是：开始索引，第二个参数，是需要截取的个数
      • 创建字符串的两种方法均适用
      • 实例

    6. 方法substring

      • 该方法：主要是截取字符串
      • 语法：字面量.substring(开始索引,结束索引[包含开始索引字符及结束索引之间的字符，不包含结束索引字符])
      • 返回值是将截取的元素，生成的新字符串
      • 不会对原字符串产生影响，所以需要直接使用或声明变量接收返回值
      • 注意:第一个参数是：开始索引，第二个参数，是结束索引(但是同样是：包前不包后)
      • 只写开始索引：截取的是开始索引之后的所有字符(包含开始索引字符)
      • 创建字符串的两种方法均适用
      • 实例

    7. 方法slice

      • 该方法：主要是截取字符串
      • 语法：字面量.slice(开始索引,结束索引[包含开始索引字符及结束索引之间的字符，不包含结束索引字符])
      • 返回值是将截取的元素，生成的新字符串
      • 不会对原字符串产生影响，所以需要直接使用或声明变量接收返回值
      • 注意:第一个参数是：开始索引，第二个参数，是结束索引(但是同样是：包前不包后)
      • 只写开始索引：截取的是开始索引之后的所有字符(包含开始索引字符)
      • 与substring不同的是：可以传负数
      • 创建字符串的两种方法均适用
      • 实例

    8. 方法replace

      • 该方法：主要是替换字符串
      • 语法：字面量.replace("需要替换的字符","想要替换成的字符")
      • 返回值是使用方法替换后，生成的新字符串
      • 不会对原字符串产生影响，所以需要直接使用或声明变量接收返回值
      • 注意:第一个参数：需要替换的字符，第二个参数：想要将第一个参数替换成的字符
      • 严格匹配：只有与第一个参数严格相等才会被替换,
        只会替换第一个匹配的字符
      • 创建字符串的两种方法均适用
      • 实例

    9. 方法split

      • 该方法：主要是将字符串转为数组
      • 语法：字面量.split("分割符")
      • 返回值是使用方法，生成的数组
      • 不会对原字符串产生影响，所以需要直接使用或声明变量接收返回值
      • 注意：
        1. 分割符可以是任何字符
        2. 数组元素是分割符分割的字符串
        3. 数组不会因为，分隔符而改变，规则：数组内的元素由英文逗号隔开
        4. 当分割符是：空格的时候是将每个字符，都转成数组元素
        5. 分割符是严格匹配的：中英文标点，字符大小写都会产生意外结果
      • 创建字符串的两种方法均适用
      • 实例

    10. 方法indexOf

      • 方法(indexOf):是用来返回查找字符的索引值
      • 语法：字面量.indexOf(需要查找的元素,开始查找索引)
      • 返回值是一个索引
      • 需要声明变量接收返回值，或直接使用

      • 注意：

        1. 若有重复的字符，只会查找第一个符合的索引
        2. 只传第一参数
          1. 从索引0开始找
          2. 实例1(只传第一个参数)
        3. 当查找字符不存在
          1. 当返回值是-1的时候，表示没有匹配的字符
          2. 案例：
        4. 传入两个参数
          1. 第一个参数：需要查找的字符，第二个参数：开始查找的索引(就是从当前索引开始查找)
          2. 同样找不到，返回值-1
          3. 案例：
        5. 不传参数
          1. 返回值是-1

    11. 方法lastIndexOf

      • 与indexOf不同的是，从最后面开始找(第二个参数：从该索引开始向前查找)，其他的知识完全一样

    12. 方法concat

      • 该方法主要用于：连接字符串
      • 语法：字面量.concat()

    13. 去除空格方法

      • 方法trim
        1. 去除首尾空格
        2. 只去除首尾空格，中间空格不去除
      • 方法trimStart与trimLeft
        1. 去除首空格
        2. 只去除首空格，中间空格不去除
      • 方法trimEnd与trimRight
        1. 去除首空格
        2. 只去除尾空格，中间空格不去除

补充知识

  • ASCII码

    1. ASCII就是一些特殊字符、24个英文字母、0~9数字、一些特殊功能的编码
    2. 计算机通过这些编码，才能识别
    3. 正常是我们的软件或计算器自动翻译

    4. ASCII码对照表

  • Unicode编码

    1. ASCII只有128个字符编码结构
    2. 因为ASCII出现的比较早，而且是美国发明的，在早期也够用
    3. 但是对于世界来说这是远远不够用的
    4. 因为汉字以及一些其他国家的语言没办法存储
    5. 所以出现了Unicode编码，也叫万国码同一码
    6. Unicode也有一张对照表，但是体量比ASCII码对照表大很多，它包含了大部分国家的文字，所以 目前文字和字符都是按照Unicode编码转换成数字进行存储
    7. UTF-8就是一种8位的Unicode字符集
