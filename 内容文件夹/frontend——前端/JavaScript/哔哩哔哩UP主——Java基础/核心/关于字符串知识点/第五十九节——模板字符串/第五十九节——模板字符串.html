模板字符串

  • 由ES6引入新的字符串
  • 主要有反引号构成，变量由${变量}包裹

  • 优点

    1. 换行不报错，传统字符串打印，换行会报错
    2. 通过${变量}的方式访问变量、表达式、甚至调用函数，比起传统字符串，返回加号连接，省事很多

    注意事项

    1. 在模板字符串内的所有内容，不管是字符串还是访问变量的结果，都会被强制转换成字符串
    2. 所以，使用，模板字符串控制台打印对象,数组都会被强制转换成字符串
    3. 解决办法：在模板字符串后面(反引号后面),逗号变量即可，只要不是在模板字符串内，或用加号连接，就可以。
    4. 使用DOM在页面打印结果，不管怎么样都会被强制转成字符串，若需要显示完整对象，需要使用JSON.stringify()或遍历才行
      数组会按默认逗号分割，显示数组内全部元素，若要自定义分隔符需要使用.join()方法
