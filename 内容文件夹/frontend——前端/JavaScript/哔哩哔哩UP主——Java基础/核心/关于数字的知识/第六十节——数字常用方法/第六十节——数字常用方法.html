数字的常用方法

  • 与字符串一样，数字的创建有两种方式：1.字面量创建、2.构造函数创建
  • 字面量创建使用点语法或中括号的方法，会临时转换为number对象，这么一来，就能够使用一些方法

  • 数字的常用方法

    1. 方法toFixed

      • 该方法主要用于：规定数字的小数点位数
      • 语法：字面量.toFixed()
      • 括号内填写，需要保留的位数
      • 若保留位数，超过实际小数位数，会自动补零
      • 注意：返回值是字符串类型，所以要想将他进行加法运算需要使用方法：Number、parseFloat转成数值类型，才能进行计算
      • 实例

    2. 方法parseInt

      • 该方法主要用于：将数值字符串,转成整数
      • 语法：parseInt(字面量)
      • 括号内填写，字面量或变量

    3. 方法parseFloat

      • 该方法主要用于：将数值字符串,转成小数
      • 语法：parseFloat(字面量)
      • 括号内填写，字面量或变量

    4. 方法Number

      • 该方法主要用于：将数值字符串,转成数值类型
      • 语法：Number(字面量)
      • 括号内填写，字面量或变量

    5. 方法isNaN

      • 该方法主要用于：判断是不是数值类型
      • 语法：isNaN(字面量)
      • 括号内填写，字面量或变量

    6. Math对象

      • 方法：random
        1. 主要用处是：返回0~1之间的随机数
        2. 语法：Math.random()
        3. 注意：包0不包1
        4. 传参无效
      • 方法：round
        1. 主要用处是：对一个数四舍五入取整
        2. 语法：Math.round()
        3. 括号内数据为数值类型
      • 方法：ceil
        1. 主要用处是：对一个数向上取整
        2. 语法：Math.ceil()
        3. 括号内数据为数值类型
      • 方法：floor
        1. 主要用处是：对一个数向下取整
        2. 语法：Math.floor()
        3. 括号内数据为数值类型
      • 方法：abs
        1. 主要用处是：对一个数取绝对值
        2. 语法：Math.abs()
        3. 括号内数据为数值类型
      • 方法：sqrt
        1. 主要用处是：对一个数的平方根
        2. 语法：Math.sqrt()
        3. 括号内数据为数值类型
      • 方法：pow
        1. 主要用处是：对一个数的次幂
        2. 语法：Math.pow(底数,指数)
        3. 括号内数据为数值类型
      • 方法：max
        1. 主要用处是：取最大值
        2. 语法：Math.max()
        3. 括号内数据可以传多个参数，然后返回最大值
      • 方法：min
        1. 主要用处是：取最小值
        2. 语法：Math.min()
        3. 括号内数据可以传多个参数，然后返回最小值
      • 属性：PI
        1. 就是是：∏(3.14.....)
        2. 语法：Math.PI
        3. 是个属性,不是方法,没有括号
