时间对象常用方法

get方法：主要是获取而不是更改

  • getXXX方法：返回值是当前Date对象的具体数据，如果通过setXXX方法更改过，同样会随之更新
  • getXXX方法：本身并不具备，自动更新的能力(也就是：当Date对象确定，便不会再更新)
  • 但是刷新浏览器，会重新创建一个Date对象，当今对象存储的是刷新的最新时间，这会导致一种错觉，以为是时间自动更新但是结果是：因为刷新，重新创建Date对象，获取了最新的时间

  • 方法：getFullYear()

    1. 提取年份
    2. 返回值是：数字类型的年份
    3. 返回值需要: 声明变量接收或直接使用

    4. 实例

  • 方法：getMonth()

    1. 提取月份
    2. 返回值是：数字类型的月份
    3. 返回值需要: 声明变量接收或直接使用
    4. 注意：因为月份是从0开始计算，所以最终结果要加一，才是正确的月份

    5. 实例

  • 方法：getDate()

    1. 提取日期
    2. 返回值是：数字类型的日期
    3. 返回值需要: 声明变量接收或直接使用

    4. 实例

  • 方法：getDay()

    1. 提取星期
    2. 返回值是：数字类型的星期
    3. 所以要想输出结果是中文(一、二、三、四、五、六、日)，需要通过数组映射的方式
    4. 返回值：0代表星期日，1~6代表星期一~星期六
    5. 所以数组的下标很明确了：
      ['星期日', '星期一', '星期二', '星期三', '星期四', '星期五', '星期六']
    6. 返回值需要: 声明变量接收或直接使用

    7. 实例

  • 方法：getHours()

    1. 提取小时
    2. 返回值是：数字类型的小时
    3. 返回值需要: 声明变量接收或直接使用

    4. 实例

  • 方法：getMinutes()

    1. 提取分钟
    2. 返回值是：数字类型的分钟
    3. 返回值需要: 声明变量接收或直接使用

    4. 实例

  • 方法：getSeconds()

    1. 提取[秒]
    2. 返回值是：数字类型的秒
    3. 返回值需要: 声明变量接收或直接使用

    4. 实例

  • 方法：getMilliseconds()

    1. 提取[毫秒]
    2. 返回值是：数字类型的毫秒
    3. 返回值需要: 声明变量接收或直接使用

    4. 实例

  • 方法：getTime()

    1. 获取：时间戳
    2. 返回值是：1970年1月1日0点0分直到现在的毫秒数
    3. 返回值需要: 声明变量接收或直接使用
    4. 可以通过构造函数的方式将时间戳转换成对应的时间:如：new Date(时间戳)

    5. 实例

set方法：主要是获取的同时可以更改

  • setXXX方法：获取目前具体数据，然后填入更改后的数据
  • setXXX方法：会在原Date对象下更改
  • setXXX方法：返回值始终是：时间戳

  • 时间戳

    1. 当今Date对象存储的时间与1970年1月1日0点0分的毫秒数

  • 方法：setFullYear()

    1. 获取年份可以更改
    2. 获取Date对象年份，然后更改(在原对象更改)
    3. 返回值始终是时间戳

    4. 实例

  • 方法：setMonth()

    1. 获取月份可以更改
    2. 获取Date对象月份，然后更改(在原对象更改)
    3. 获取的年份也是从0开始计算，但是对于setMonth()没啥影响，因为最终月份是自定义
    4. 返回值始终是时间戳

    5. 实例

  • 方法：setDate()

    1. 获取日期可以更改
    2. 获取Date对象日期，然后更改(在原对象更改)
    3. 返回值始终是时间戳

    4. 实例

  • 方法：setHours()

    1. 获取小时可以更改
    2. 获取Date对象小时，然后更改(在原对象更改)
    3. 返回值始终是时间戳

    4. 实例

  • 方法：setMinutes()

    1. 获取分钟可以更改
    2. 获取Date对象分钟，然后更改(在原对象更改)
    3. 返回值始终是时间戳

    4. 实例

  • 方法：setSeconds()

    1. 获取[秒]可以更改
    2. 获取Date对象的秒数据，然后更改(在原对象更改)
    3. 返回值始终是时间戳

    4. 实例

  • 方法：setMilliseconds()

    1. 获取[毫秒]可以更改
    2. 获取Date对象的毫秒数据，然后更改(在原对象更改)
    3. 返回值始终是时间戳

    4. 实例

注意：

  1. 通过setXXX方法更改数据，是在原对象上更改，也就是后续无论怎么刷新，都不会更改
  2. 通过getXXX方法获取的数据，是在原对象上获取，自身无法自动更改，但是可以通过刷新，重新获取新的Date对象，达到更新的目的

  3. 通过对比(可以发现)：

    1. 在没有setXXX方法之前，输出的时间，就是目前的时间，getXXX方法获取了，目前时间的Date对象数据
    2. 用了setXXX方法之后，同样是使用getXXX方法获取Date对象的数据，但是结果确实，更改后的时间
    3. 所以证明了，setXXX方法是在原对象上进行更改。
    4. 这会导致：当前Date对象永远丢失能通过刷新，更新时间的功能
    5. setXXX方法的返回值：始终是时间戳
