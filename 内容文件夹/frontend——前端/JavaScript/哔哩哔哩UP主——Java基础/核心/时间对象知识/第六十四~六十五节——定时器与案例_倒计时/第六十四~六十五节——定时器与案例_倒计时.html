定时器

  • 在JS里面，定时器分为倒计时定时器和间隔定时器

  • 倒计时定时器

    1. 倒计时多少以后执行函数
    2. 语法：setTimeout(要执行的函数,多长时间以后执行)
    3. 第一个参数：要执行的函数,第二个参数：设置时间：多长时间以后执行
    4. 清除定时器：clearTimeout()
    5. 这样就会在设定的时间以后，执行函数

    6. 注意：

      • 时间是按照毫秒进行计算的，1000毫秒就是1秒钟
      • 只会执行一次，一次过后就不会再执行
      • 返回值是：当前这个定时器是页面中的第几个定时器
      • 在函数内部写入document.writenln(``)倒计时结束后，会清除页面包括样式、最终结果 以为是：倒计时结束后，在新的界面运行函数，其实是将当前页面清除，在运行 所以：在使用倒计时定时器时，回调函数内部避免使用document.writenln(``)

    间隔定时器

    1. 间隔一段时间执行函数
    2. 语法：setInterval(要执行的函数,间隔多长时间以后执行)
    3. 第一个参数：要执行的函数,第二个参数：设置时间：间隔多长时间以后执行
    4. 这样就会在设定的时间以后，每次达到指定时间，便会执行函数
    5. 清除定时器：clearInterval()

    6. 注意：

      • 时间是按照毫秒进行计算的，1000毫秒就是1秒钟
      • 每次达到指定时间，便会执行函数
      • 返回值是：当前这个定时器是页面中的第几个定时器
      • 在函数内部写入document.writenln(``)倒计时结束后，会清除页面包括样式、最终结果 以为是：倒计时结束后，在新的界面运行函数，其实是将当前页面清除，在运行 所以：在使用倒计时定时器时，回调函数内部避免使用document.writenln(``)

案例——倒计时

  • 倒计时本质(重点——顿悟时刻)：

    1. 倒计时定时器(避免陷入的思维误区)：不是设置固定时间，通过计算减少，达到时间减少的目的
    2. 倒计时的本质：固定目标 - 流动当前 = 递减差值
    3. 核心公式：const targe = 目标时间点 - 当前时间点
    4. 目标时间点：固定不变，例如(trage.setSeconds(now.getSeconds() + 90))先获取当前时间段 + 倒计时初始值
    5. 当前时间：每次执行定时器时重新获取(new Date())
    6. 剩余毫秒：随着当前时间向目标靠近，自然递减——>实现'倒计时'效果
    7. 说白了：目标时间(当前时间 + 倒计时初始值) - 当前时间 = 时间差
    8. 因为当前时间为逐秒增加，目标时间固定，这会导致时间差，逐秒递减(倒计时原理)
    9. 最后将时间差(单位毫秒)转为形式为时：分：秒：毫秒按需求来

    10. 单位换算

      • 1秒 = 1000毫秒
      • 1分 = 60秒 = 60000毫秒
      • 1时 = 60分 = 3600秒 = 3600000毫秒

扩展知识

  • 异步执行和同步执行

    1. 使用定时器，会将定时器的回调函数放入‘任务队列’,只有当主线程上所有同步代码执行完毕(同步执行)，才会去任务队列里取回调执行
    2. 正常情况下：代码的执行顺序是：从上到下依次执行(这就叫同步执行)
