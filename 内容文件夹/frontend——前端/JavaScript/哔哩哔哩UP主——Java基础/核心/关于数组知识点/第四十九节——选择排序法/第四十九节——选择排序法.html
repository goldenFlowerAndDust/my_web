数组——选择排序法

选择排序法

  • 什么式选择排序法

    1. 先假定数组中的第0个就是最小数字的索引
    2. 然后遍历数组，只要一个数字比它(假定)小，那么就替换之前记录的索引
    3. 直到数组遍历结束后，就能找到最小的那个索引，然后让最小的索引换到第0个的位置
    4. 再来第二趟遍历，假定第一个是最小的数字的索引
    5. 在遍历一次数组，找到比它小的那个数组的索引，结束后替换

    6. 总结

      • 外层初始化变量[i(方便演示，可以随便取)]存储索引，循环条件(元素长度-1)，自增
      • 外层循环体内，声明变量[minIndex(方便演示，可以随便取)]用于存储当前索引(理解为初始化索引=初始化变量)，同时为后续，是否交换当前元素位置做判断条件
      • 内层循环：初始化变量始终比外层循环+1[j = i + 1(方便演示，可以随便取)]，条件判断因为是从索引[1]开始，则直接等于元素长度即可，自增
      • 内层循环体内：if判断，如果当前元素(字段名[minIndex])比后续元素(字段名[j])大，则，将后续小的索引，替换[外层循环体内声明的变量(minIndex = j)]具体看演示
      • 在内层循环体外，外层循环体内，做if判断，若【minIndex !== i】则，替换
      • 演示

        let Arr = [5, 100, 6, 1, 30, 50, 100]
        console.log("原数组：",Arr)
        for (let i = 0; i <Arr.length - 1; i++){
          //外层，代表的当前索引，索引从零开始，所以需要减一
           // 假设当前变量为最小， 同时声明变量，存储当前元素的索引
          let minIndex = i
          for (let j = i + 1; j < Arr.length; j++){
          //内层为后续比较铺垫(在当前索引后的元素挨个比较) 因为从索引1开始，所以不需要减一
            if (Arr[j] < Arr[minIndex]) { // 因为需要比较的当前元素的值 假设了minIndex是当前索引
            // 当面的元素小于当前元素的时候，执行if语句
            minIndex = j // 替换，当前最小值的索引
            }
          }
          if (minIndex !== i) {
          // 当假设的索引与当前索引不同的时候，执行if语句
          [Arr[i],Arr[minIndex]] br=
        [Arr[minIndex],Arr[i]]
          // 将最小元素的位置与当前元素位置互换
          }
        }
        console.log("排序后数组：",Arr) //控制台打印
