数组——冒泡排序法

  • 什么是冒泡排序法

    1. 先遍历数组:让挨着的两个元素进行比较，如果前一个比后一个大，那么就把两个位置互换
    2. 数组遍历一遍后，那么最后一个数字就是最大的那个
    3. 然后进行第二遍的遍历:还是按之前的规则，第二遍的数字就会跑到倒数第二的位置
    4. 以此类推，最后就会按照顺序把数组排好
    5. 最后的结果一定是：元素按从小到大排序(从左到右)
    6. 通过for循环两层嵌套(外层(设置轮数[循环结束条件):轮数 = 元素个数(length) - 1 ]，
      内层(设置每个轮次循环次数[每个轮次循环次数 = 元素个数(length) - 1 - 当前轮数]))
    7. 再内层循环内做if判断：当前一个元素>后一个元素，互换位置

    8. 整个排序法公式

      let Arr = [4, 3, 100, 30, 50, 0, 9]
      for (let i = 0; i < Arr.length - 1; i++) {
        //外层循环 控制循环轮数 (元素数量 - 1)
        for (let j = 0; j < Arr.length - 1 - i; j++) {
          //内层循环，控制每轮需要循环的次数 (元素数量 - 1 - 当前轮次) 变量j 代表的是索引
          if (Arr[j] > Arr[j + 1]) {
      //当前一个元素 大于 后一个元素的时候 ，执行if代码块
            let tempt = Arr[j] // 声明变量接受，前一个元素的值
            Arr[j] = Arr[j + 1] // 将后一个元素的值赋值给，前一个元素 因为当前情况，后一个数一定小于前一个数
            Arr[j + 1] = tempt // 将前一个元素的值，赋值给后一个元素 ， 因为当前情况，前一个一定大于后一个数
          }
        }
      }
