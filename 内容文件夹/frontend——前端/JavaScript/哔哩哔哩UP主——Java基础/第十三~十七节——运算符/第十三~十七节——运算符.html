运算符

什么是运算符

    1. 是代码里面进行运算的时候使用的符号
    2. JS共分六种运算符：[数学运算符、赋值运算符、比较运算符、逻辑运算符、自增自减运算符、三目运算符]

    3. 运算符的分类

      • 数学运算符(除加号外，其他操作数为非数字字符串，输出均为NaN)

        1. +号
          • 只有符号两边都是数字的时候才会进行加法运算
          • 只要符号任意一边是字符串类型，就会进行字符串拼接

          • ·演示

        2. -号
          • 会执行减法运算
          • 会自动把两边都转换成数字进行计算

          • ·演示

        3. *号
          • 会执行乘法运算
          • 会自动把两边都转换成数字进行运算

          • ·演示

        4. /号
          • 会执行除法运算
          • 会自动把两边都转换成数字进行运算

          • ·演示

        5. %号
          • 会执行取余运算
          • 会自动把两边都转换成数字进行运算

          • ·演示
