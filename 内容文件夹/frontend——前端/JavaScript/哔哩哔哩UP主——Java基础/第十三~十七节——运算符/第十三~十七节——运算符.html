运算符

什么是运算符

    1. 是代码里面进行运算的时候使用的符号
    2. JS共分六种运算符：[数学运算符、赋值运算符、比较运算符、
      逻辑运算符、自增自减运算符、三目运算符      ]

    3. 运算符的分类

      • 数学运算符(除加号外，其他操作数为非数字字符串，输出均为NaN),除加号外，其他操作数均为数字(两侧均为字符串也一样)，则转为数字，并计算

        1. +号
          • 只有符号两边都是数字的时候才会进行加法运算
          • 只要符号任意一边是字符串类型，就会进行字符串拼接
          • 当值为布尔类型(true/false)，执行加法运算时，会自动将true[1]/flase[0]

        2. -号
          • 会执行减法运算(subtraction)
          • 会自动把两边(非数字字符串除外)都转换成数字进行计算
          • 当值为布尔类型(true/false)，执行减法运算时，会自动将true[1]/flase[0]

          • ·演示

        3. *号
          • 会执行乘法运算(multiplication)
          • 会自动把两边(非数字字符串除外)都转换成数字进行计算
          • 当值为布尔类型(true/false)，执行乘法运算时，会自动将true[1]/flase[0]

          • ·演示

        4. /号
          • 会执行除法运算(division)
          • 会自动把两边(非数字字符串除外)都转换成数字进行计算
          • 当值为布尔类型(true/false)，执行除法运算时，会自动将true[1]/flase[0]
          • 当操作数为布尔值false的六种情况
            1. 当false / 正数，值为[0]
            2. 当false / 负数，值为[-0]
            3. 当false / 0，值为[NaN]
            4. 当正数 / false，值为[Infinity(正无穷)]
            5. 当负数 / false，值为[-Infinity(负无穷)]
            6. 当0 / false，值为[NaN(无效数字)]
          • 总结：
            1. 0/0 ==→ false / 0 或 0 / false值为NaN
            2. 非零/0值为±Infinity
            3. 0/非零值为±0
            4. 正数/正数[或负数/负数]值为正数
            5. 正数/负数[或负数/正数]值为负数
            6. 与是否为false无关，只是刚好false被隐式转为0

          • ·演示

        5. %号
          • 会执行取余运算(modulo)
          • 会自动把两边都转换成数字进行运算
          • 取余运算，顾名思义就是取除法运算后的余数
          • 注意：
            1. 当除数为0时：非零数 % 0，则值为NaN
            2. 当零是被除数时：0 % 非零数，则值为0
            3. 当0既是除数，又是被除数：0 % 0，则值为NaN

其他内容补充

  • 关于打印引用变量的两种方法

    1. 字符串拼接法(非常不建议用)

      • 语法："内容" + "" + ""
      • 就是将变量值，放在双引号之外，以加号拼接，如果变量在双引号内，会被认为是字符串输出
      • 优点
        1. 极低版本的兼容性(几乎已经完全淘汰了)
        2. 极其简单的拼接(与模板字符串没啥区别)
      • 缺点
        1. 可读性差：引号、加号、变量混在一起，眼花缭乱
        2. 易出错：漏引号、少加号、转义麻烦
        3. 不支持换行：必须+ "\n" +

    2. 模板字符串(非常建议用)

      • 语法：`字符串${变量}字符串`
      • 变量引用方法是${}，大括号内填入变量，其他地方均是字符串
      • 优点：
        1. 不需要反复开闭引号和加号
        2. 变量名直接${}里，结构清晰
        3. 支持换行(不用写\n或拼接换行符)
        4. 可以嵌套表达式${a + b}、甚至调用函数

  • 关于let声明变量，遇到重复变量名，报错问题

    1. 已知，let、const声明的变量，在同一作用域，变量名是唯一的
    2. 不是每个script标签单独一个作用域，而是所有script块(以及内联代码)共享全局作用域
    3. 解决办法：单独适用大括号(创建块级作用域)
