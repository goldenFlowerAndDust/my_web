数据类型

数据类型解释

  • 定义：指的是内存中的数据的类型
  • 通常分为两大类基本数据类型和复杂数据类型

  • 基本数据类型

    1. 数值类型(Number)

      • 数值类型 (Number)

        • 表示所有数字，包括整数、浮点数、科学计数法及不同进制。
        • 进制表示：
          1. 二进制：0b1111 = 15(十进制) (0b开头)
          2. 八进制：0o17 = 15(十进制) (0o开头)
          3. 十六进制：0xF = 15(十进制) (0x开头)
        • 特殊值：NaN (Not a Number) 表示非数字，Infinity 表示无穷大。
        • 科学计数法：2e5 等于 2×10⁵ = 200000，仍属于 Number 类型。
        • 只有 Number 类型能直接参与数学运算，字符串需转换后才能计算。

    2. 字符串类型(String)

      • 被引号包裹的所有内容(可以是单引号也可以是双引号)

    3. 布尔类型(Boolean)

      • 只有两个(true或者false)
      • 常用于条件判断(IF)
      • true的意思是真，符合条件
      • false的意思是假，不符合条件

    4. null类型(null)

      • 只有null一个值
      • null 表示“空值”，常用于主动清空对象引用，typeof null 返回 "object"（历史遗留）

    5. Undefied类型

      • 变量声明了，但是未赋值
      • 只有Undefied一个值
      • 表示浏览器不知道它是什么类型

    6. Symbol

      • SE6新增，表示独一无二的值
