条件分支语句

条件分支语句共2个(if/switch)

  • 分支结构

    1. js代码都是顺序执行(从上到下)
    2. 逻辑分支：根据设定好的条件来决定要不要执行某些代码

    1. if条件分支结构(重点)

      • if结构
        1. 通过一个if语句来决定代码是否执行
        2. 语法：if(条件){要执行的代码}
        3. 通过()里面的条件是否成立来决定{}里面的代码是否执行
        4. if必须要有条件

        5. ·实例

      • if-else结构
        1. if-else结构意思是不是if{}内代码运行，就是else{}内代码运行
        2. 语法：if(条件){要执行的代码}else(注意要放到if大括号结尾处){要执行的代码}
        3. if必须要有条件，else不能有条件

        4. ·实例

      • if-else(空格)if-else结构
        1. if-else if(else if可以是多个)-else结构意思是从if开始判断，然后从上到下依次[else if]判断，如果均是false，最后运行else{}内的代码
        2. 语法：if(条件){}else if(条件){}else if(条件)....else{}
        3. if必须要有条件，else if必须要有条件，else不能有条件
        4. if -else if-else(else不是必要的，可以不用写)

        5. ·实例

    2. switch条件分支结构(重点)

      • 也是条件判断语句的一种
      • 是对于某一变量的判断
      • switch(要判断的变量){
        case 情况1:
            情况1要执行的代码
            break
        case 情况2:
            情况2要执行的代码
            break
        .....
        default:
            上述情况均不满足执行代码
        }
      • case
        1. 规定，每个条件分支，必须填写
        2. 会从上到下自动匹配符合的
      • break
        1. 通常每个case后面要写break，否则会继续执行后面的case(穿透效果)
        2. 匹配到符合的，且case结尾有break，则跳出switch,执行switch外的代码
        3. (穿透效果——类似与或运算符(当不同分支，但是用到同一代码，可以使用穿透效果，减少重复代码量))
      • default
        1. default通常放在switch的最后(可以放在开头或中间但是非常不建议)
        2. 表示所有case都不匹配时执行的代码
      • 注意：
        1. switch不可以通过或运算符，将两个case合并，需要将两个条件，最后的输出代码为一个，可以使用穿透的办法
        2. switch匹配是严格相等匹配【case === switch(变量)】(只有数据类型和值相同，才能匹配成功)
        3. case后面一定是表达式(可以计算出"值"的代码片段)——有字面量、变量、包含运算符的运算、函数调用，
          ···但是非常不推荐包含运算符的运算和函数调用可读性差、容易出错、性能浪费、维护困难
          ···最好用:字面量、变量
