检测数据类型

typeof关键字

  • 判断存储的数据是什么类型，需要用到typeof关键字进行判断
  • 语法1:typeof(变量名)
  • 语法2:typeof 空格符 变量名[使用场景尽量使用这个语法]

  • 演示

  • 可能遇到的面试题:两个typeof关键字同时使用，最后的输出结果是什么。
  • 答案是:不管后面有多少个typeof关键字， 最后输出的结果一定是String类型的
    因为typeof输出的结果是String类型的，所以再次使用typeof，最后的结果一定是String类型
