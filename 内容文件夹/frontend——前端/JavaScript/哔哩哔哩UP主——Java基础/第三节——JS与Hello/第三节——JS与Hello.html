关键字

  1. alert关键字

    弹出对话框

    它在浏览器对象模型中

  2. document.write(并非现代主流)

    作用是：是一个只能在页面初始渲染时使用的、向文档流中即时输出 HTML 的同步写入方法

    也就是说：如果在页面加载完成后调用，它会先清空整个页面，然后只写入你给的内容。

    现代替代: 动态插入内容用 innerHTML 或 createElement + appendChild 加载外部资源用 <script>标签动态创建或模块化加载

  3. console.log

    定义：console.log 是 JavaScript 中用于向浏览器控制台输出信息的方法，主要作用是调试和记录。它不会影响页面的显示，只在开发者工具中可见

    • 所属对象：console对象[浏览器内置的调试工具]
    • 语法：console.log(obj1[，obj2,…………objN])
    • 参数：接受任意多个，任意类型的参数，它们会被依次输出到控制台
    • 返回值：undefined

    核心特性

    • 格式化输出

      支持类似于C语言的占位符:

      常用占位符：%s（字符串）、%d（整数）、%f（浮点）、%o（DOM 元素）、%O（JavaScript 对象）、%c（CSS 样式）

    • 多参数打印

      传入多个参数时，控制台会用空格分隔依次显示

    • 对象/数组的交互式展示

      打印对象或数组时，控制台会显示为可折叠的树形结构，便于探查

    • 不影响页面流程

      与 alert 不同，console.log 不会阻塞代码执行，也不会改变页面内容，是纯调试工具

    注意事项：

    • 生产环境应移除或禁用 console.log，避免暴露信息或影响性能（可用条件编译或构建工具去除）
    • 在 Node.js 环境中，console.log 同样存在，用于向终端输出

  3. 三种输出方式的对比

    方式 输出位置 影响页面 主要用途
    console.log 控制台 无 (调试、日志)——开发着用，一般后面会注释
    alert() 弹窗 阻塞UI 用户提示(已很少用)
    document.write 页面内 可能覆盖页面 早期动态写入(已过时)
