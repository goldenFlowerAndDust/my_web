JS书写的位置

位置

  • 和css一样，JS也可以有很多种方式书写在页面上时期生效

    1. 行内式(非常不建议用)

      • 写在标签上的JS代码依靠事件(行为)来触发
      • 在行内添加onclick属性，在属性内添加JS代码
      • 使用弹窗(alert、prompt、confirm)会堵塞UI，需要用户确定、取消操作后，运行后续JS代码

      • 图例

    2. 内嵌式

      • 将script标签写在head标签内或body标签内，通过打开浏览器执行触发(从上到下依次运行)

      • 图例

    3. 外链式(非常推荐)

      • 在外部建立JS文件，在html内通过script标签，src属性引入JS文件相对路径
      • 建议放在body标签最后面写即是:</body>之前写
      • 语法：<script src="JS文件相对路径">
      • 注意：采用了外链式的script标签，再到内写的代码不会被执行

      • 图例

试验区

  • 行内式

    1. 单击我一下
    2. href="javascript:...."中的this指向window，拿不到<a>元素本身。所以，在内添加JS代码没有效果
    3. 样式属性名在JS中必须用小驼峰：即第一个单词首字母小写，后续每个单词的首字母大写，其余字母小写例如：fontSize、backgroundColor....
    4. onclick事件属性里的this是作用于当前元素
    5. 除了：onclick(单击事件),还有：ondblclick(双击事件)、onmousedown(按下事件)、onmouseup(松开事件)同样可以用于行内式
    6. 注意：双引号内属性值用单引号
