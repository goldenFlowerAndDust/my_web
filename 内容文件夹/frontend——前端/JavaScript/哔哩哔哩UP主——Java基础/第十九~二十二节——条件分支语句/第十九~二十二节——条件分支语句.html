条件分支语句

条件分支语句共2个(if/switch)

  • 分支结构

    1. js代码都是顺序执行(从上到下)
    2. 逻辑分支：根据设定好的条件来决定要不要执行某些代码

    1. if条件分支结构(重点)

      • if结构
        1. 通过一个if语句来决定代码是否执行
        2. 语法：if(条件){要执行的代码}
        3. 通过()里面的条件是否成立来决定{}里面的代码是否执行
        4. if必须要有条件

        5. ·实例

      • if-else结构
        1. if-else结构意思是不是if{}内代码运行，就是else{}内代码运行
        2. 语法：if(条件){要执行的代码}else(注意要放到if大括号结尾处){要执行的代码}
        3. if必须要有条件，else不能有条件

        4. ·实例

      • if-else(空格)if-else结构
        1. if-else if(else if可以是多个)-else结构意思是从if开始判断，然后从上到下依次[else if]判断，如果均是false，最后运行else{}内的代码
        2. 语法：if(条件){}else if(条件){}else if(条件)....else{}
        3. if必须要有条件，else if必须要有条件，else不能有条件
        4. if -else if-else(else不是必要的，可以不用写)

        5. ·实例
