list-style
list-style-type		disc (圆点) , decimal (数字) , none设置列表项标记（前缀）。你曾遇到前缀消失是因为给 ul/li 加了 overflow-x: hidden 裁剪了标记，现在已经规避。
display: list-itemlist-item (默认), block, inline必须为 list-item 才会显示标记。你的 li 默认就是此值。
overflow-x: autoauto / scroll / hidden父容器（.div_table）设置水平溢出滚动，当表格过宽时出现横向滚动条，防止撑破布局。
-webkit-overflow-scrolling: touchtouch / auto移动端专属，使滚动条具有惯性滚动效果，提升触屏滑动体验。
white-space: nowrapnowrap / normal / pre-wrap强制表格内单元格内容不换行，这样表格宽度完全由内容撑开，配合父容器滚动即可完整查看。
min-width: 100%百分比 / 长度让表格至少和父容器一样宽，避免窄表格缩成一小团；内容多时自动扩展超出触发滚动。
border-collapse: collapsecollapse / separate合并相邻单元格边框，使表格边框单线显示，常用。
table-layout: fixed / autoauto（默认） / fixedauto：宽度由内容决定；fixed：由第一行或设定宽度决定，更稳定但可能溢出。
padding (th, td)8px 12px单元格内边距，让内容不贴边，视觉舒适。
vertical-alignmiddle / top / bottom单元格内容垂直对齐方式，middle 让内容居中。
word-break: break-allbreak-all / keep-all / normal让长单词或URL在必要时断开换行，防止溢出。你应用于 code 元素，但表格滚动场景下通常需保持 nowrap。
display: inline-blockinline-block像行内元素一样排列，但可以设置宽高，常用于 code 或 span。
max-width: 100%百分比 / 长度限制元素最大宽度不超过父容器，防止图片或代码块溢出。
opacity / background-color（你未使用但常见）不透明度、背景色。
🧠 来自实战的经验（表格+列表终极结论）
✅ 表格滚动：父容器 .div_table { overflow-x: auto; } + 表格 white-space: nowrap; min-width: 100%;。
✅ 列表前缀消失：绝对不要对 ul, ol, li 设置 overflow-x: hidden，因为标记显示在元素外侧，会被裁剪。
✅ 全局防撑开：只对 body, main, section 这类结构容器使用 overflow-x: hidden，避免误伤列表。
✅ CSS变量：统一管理主题，修改一处处处生效，适合暗色模式切换。
📖 快速查阅 — 你常用属性值含义
• rem : 相对根元素字号（你的根是20px）
• vw/vh : 视口宽度/高度的百分比（如 95vw 占视口宽95%）
• !important : 强制提升优先级，覆盖其他声明（谨慎使用）
• auto : 浏览器自动计算（如 margin: auto 居中）
• inherit : 继承父级属性值
