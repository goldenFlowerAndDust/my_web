前端最小必备（HTML / CSS）

数据来源：课堂/第十二节课——完整项目/学生管理系统/前端最小必备.md · 更新于 2026-11-20

这不是模板库，是检查清单。 明天先闭卷写，卡住了再看这一页——别照着抄。

一、必须能默写的一页骨架

<!DOCTYPE html>
<html lang="zh-CN">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>标题</title>
    <link rel="stylesheet" href="style.css">
</head>
<body>
    <main class="wrap">
        <h1>页面标题</h1>
        <p>一段文字</p>
    </main>
    <script src="app.js"></script>
</body>
</html>

自测：合上文档，白纸写一遍。能写对 90% 就算过。

二、表单（这个项目用得最多）

需要的标签只有 6 个：form、label、input、select、option、button。

想做什么怎么写（关键词回忆）
输入框<input type="text" id="" placeholder="">
数字type="number" min max
下拉<select id=""><option value="男">男</option></select>
按钮（不提交）<button type="button">
提交按钮<button type="submit"> 或 type="submit" 省略
必填required
文字点击也能聚焦用 <label> 包住 input

最小表单：

<form id="form">
    <label>姓名 <input id="name" required></label>
    <label>性别
        <select id="gender">
            <option value="男">男</option>
            <option value="女">女</option>
        </select>
    </label>
    <button type="submit">提交</button>
</form>

三、表格（列表页必备）

只需要记住三层：table > thead/tbody > tr > th/td。

<table>
    <thead><tr><th>学号</th><th>姓名</th></tr></thead>
    <tbody>
        <tr><td>2026001</td><td>张三</td></tr>
    </tbody>
</table>
细节写法
表头用 th自动加粗居中
空数据占满整行<td colspan="3">没有数据</td>
边框合并CSS border-collapse: collapse

四、CSS：只背这 10 条

想做什么属性
内容居中、限宽max-width: 900px; margin: 0 auto;
盒模型* { box-sizing: border-box; }
内边距 / 外边距padding / margin
横向排列display: flex; gap: 8px;
占满剩余宽度flex: 1;
表单自适应多列display: grid; grid-template-columns: repeat(auto-fit, minmax(180px, 1fr));
边框border: 1px solid #d1d5db; border-radius: 6px;
表格边框合并border-collapse: collapse;
悬停变色tr:hover { background: #f8fafc; }
聚焦高亮input:focus { border-color: #3b82f6; }

颜色够用就行：主色 #3b82f6、边框 #d1d5db、浅灰底 #f9fafb、正文 #1f2937、次要字 #6b7280。

五、写不出来时的三步自救

  1. 先结构后样式：先把标签写全（丑没关系），确认浏览器能显示，再加 CSS；
  2. 查 MDN：只查单个标签/属性，看完立刻关掉继续写，不要顺着链接一路点；
  3. 对照 示例\public\：只看它用了哪些标签/属性，不看排版细节 —— 排版明天再练。

六、明天的 40 分钟练法

0-10 分钟：闭卷写 index.html（只要表单 + 表格 + 搜索框，不写 CSS）
10-15 分钟：打开浏览器看，补齐漏掉的标签
15-25 分钟：闭卷写 style.css（只求能看，不求好看）
25-30 分钟：对照 示例\public\style.css，只记自己漏掉的那几条
30-40 分钟：合上一切，再写一遍 --- 这次写不出来的，就是明天真正要补的

关键：同一个东西写两遍，比看十遍有用得多。

七、心态上的一个事实

HTML/CSS 属于查表型知识，不是推理型：

  • 数据库、SQL、Promise 是逻辑——想明白了就记住了；
  • HTML 标签、CSS 属性是清单——不常用就会忘，忘了查一下就好。

所以“写不出 HTML”不代表你退步了，只代表这段时间没写过。查着写、写几遍，手感两天就回来。
