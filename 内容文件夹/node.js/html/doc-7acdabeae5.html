一句话结论

整套学习项目真正需要安装的外部依赖只有 4 个 npm 包：

npm install express    # 第十一节课：Web 框架
npm install mysql2     # 第十、十一节课：MySQL 驱动
npm install jquery     # 第九节课：前端 DOM / ajax
npm install moment     # 第二节课：日期处理

其余都是 Node 自带：fs、path、http、url、os —— 不需要装包。

包管理器的区别（四个都叫“装包”）

工具命令锁文件
npmnpm installpackage-lock.json
yarnyarn addyarn.lock
cnpmcnpm installpackage-lock.json（用的是国内镜像）
pnpmpnpm addpnpm-lock.yaml

包（package） 是能发布到 registry 的东西；模块（module） 是 Node 加载的单位（一个文件）。内置模块、第三方包、本地 ./ 文件，require 进来都用同一个概念——模块。
