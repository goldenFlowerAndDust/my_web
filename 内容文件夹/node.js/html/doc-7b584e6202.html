二、背后要知道的事

知识点说明
node 文件名.js用 Node 执行脚本，不是浏览器
node -v / npm -v查版本，装没装一看便知
REPL直接输入 node 进入交互环境，Ctrl+C 两次退出
运行环境区别Node 里没有 window、document、alert，有 process、fs、require
文件编码保存为 UTF-8，否则中文输出乱码
路径终端要在 hello.js 所在目录，或给绝对路径

三、容易遗漏

  1. node 不是内部或外部命令：说明没装好或没进 PATH，重装时勾选 “Add to PATH”；
  2. console.log 只是打印，Node 没有浏览器控制台，输出就在终端；
  3. .mjs / "type": "module"：默认是 CommonJS（require），想用 import 需要额外设置，这个区别第六、九节课会反复遇到；
  4. 同一段代码在浏览器能跑、Node 报错：多半用了 document/window，Node 里不存在；
  5. 运行结束进程就退出，没有常驻概念 —— 到第七节课的服务器才会「一直挂着」。
