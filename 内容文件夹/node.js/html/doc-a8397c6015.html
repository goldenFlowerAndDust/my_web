二、npm 包（Node 侧的依赖）

安装方法

# 在“项目所在目录”执行（会写进该目录的 package.json）
npm install 包名
npm install 包名@版本号

# 国内加速（可选，装一次即可）
npm config set registry https://registry.npmmirror.com

# 查看本目录装了哪些
npm ls --depth=0

⚠️ 一定要先 cd 到那个有 package.json 的目录再装，否则会装到别的项目里 —— 之前 fs 就是装错了位置。

2.1 express —— Web 框架

项内容
版本5.3.0
作用路由、中间件、静态托管、res.json()
安装npm install express
官网https://expressjs.com/
用在哪课堂\第十一节课——express
备注5.x 与网上大量 4.x 教程有差异，遇错先看版本

2.2 mysql2 —— MySQL 驱动（推荐）

项内容
版本3.24.6
作用连接 MySQL，支持 Promise、支持 MySQL 8 的 caching_sha2_password
安装npm install mysql2
仓库https://github.com/sidorares/node-mysql2
用在哪第十节课（第十节课——MySQL模块）、第十一节课
用法require('mysql2/promise')

2.3 mysql —— 旧驱动

项内容
版本2.18.1
作用老的 MySQL 驱动，只有回调，没有 Promise，且不支持 MySQL 8 默认认证方式
安装npm install mysql@2.18.1
用在哪第十节课早期（后来换成了 mysql2）
备注新项目不要用；报 ER_NOT_SUPPORTED_AUTH_MODE 就是它

2.4 jquery —— 前端 DOM / AJAX 库

项内容
版本4.0.0
作用$() \text{选择器}、$.ajax 发请求
安装npm install jquery
官网https://jquery.com/
用在哪课堂\第九节课——通过HTTP与URL模块，将静态资源改为动态资源
页面引用<script src="node_modules/jquery/dist/jquery.min.js"></script> 必须引 dist，不能引 src
备注4.x 的 dist/jquery.slim.min.js 不含 ajax，别引错

2.5 moment —— 日期处理

项内容
版本2.31.0
作用日期解析、格式化、多语言
安装npm install moment
官网https://momentjs.com/
用在哪课堂\第二节课
备注Node 里要额外 require('moment/locale/zh-cn') 中文才生效；官方已进入维护模式，新项目可用 dayjs

2.6 fs —— ❌ 误装的空壳包

项内容
版本0.0.1-security
装它会发生什么什么也不会发生；它是 npm 官方的“占位包”，没有代码
为什么不该装fs 是 Node 内置模块，require('fs') 走内置，跟这个包无关
怎么删在该目录执行 npm uninstall fs
用在哪课堂\第三节课\package.json

2.7 ajax —— ❌ 曾经装过，已卸载

项内容
版本0.0.4
当时的误会以为 npm i ajax 就能用 $.ajax, \text{其实} $ 来自 jQuery
实际情况它是 CommonJS 的服务端小工具，浏览器里连 require 都没有
现状已卸载，改用 jQuery

六、怎么快速核对版本

node -v                      # Node 版本
npm -v                       # npm 版本
npm ls --depth=0             # 当前目录装了哪些包
npm view express version     # 最新版本是多少
# 查所有已安装软件（PowerShell）
Get-ItemProperty 'HKLM:\SOFTWARE\Microsoft\Windows\CurrentVersion\Uninstall\*' |
  Where-Object { \$_.DisplayName } |
  Select-Object DisplayName, DisplayVersion | Sort-Object DisplayName
-- 查 MySQL 版本
SELECT VERSION();

七、清理与升级建议

动作命令原因
删掉空壳 fs 包npm uninstall fs它不是真依赖
删掉旧 mysql 驱动npm uninstall mysql（确认代码不用它）有 mysql2 就够
升级依赖npm update修 bug
国内加速npm config set registry https://registry.npmmirror.com装包更快
检查漏洞npm audit安全提示

八、每节课用到的外部依赖一览

课程目录外部依赖
第二节课课堂\第二节课moment
第三节课课堂\第三节课（误装 fs）
第九节课课堂\第九节课——通过HTTP与URL模块…jquery

其余课程（第四、五、六、七、八节）只用了 Node 内置模块（fs、path、http、url），不需要装任何包。

九、一句话总结

整套项目真正的外部依赖只有 4 个 npm 包：express、mysql2、jquery、moment。其余（fs、path、http、url）都是 Node 自带，装包反而是错的。
