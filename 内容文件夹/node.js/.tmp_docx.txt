JavaScript Promise 异步操作示例
一、用 setTimeout 模拟网络请求
下面用 setTimeout 模拟一个网络请求：延迟 1.5 秒后返回用户数据。通过 Promise 封装，我们可以用 .then/.catch 或 await 两种方式来处理异步结果。
// 模拟网络请求：延迟 1.5 秒后返回用户信息
function fetchUser(id) {
  return new Promise((resolve, reject) => {
    console.log("开始请求用户信息...");

    setTimeout(() => {
      if (id > 0) {
        resolve({ id: id, name: "张三", age: 20 });
      } else {
        reject(new Error("用户不存在"));
      }
    }, 1500);
  });
}
写法一：.then / .catch
fetchUser(1)
  .then((user) => {
    console.log("收到用户：", user);
  })
  .catch((err) => {
    console.log("捕获错误：", err.message);
  });
运行后大约 1.5 秒输出：
开始请求用户信息...
收到用户： { id: 1, name: "张三", age: 20 }
写法二：await
async function getUser() {
  try {
    console.log("await 开始请求...");
    const user = await fetchUser(1);
    console.log("await 收到用户：", user);
  } catch (err) {
    console.log("await 捕获错误：", err.message);
  }
}

getUser();
运行后大约 1.5 秒输出：
await 开始请求...
await 收到用户： { id: 1, name: "张三", age: 20 }
错误处理：传入非法 ID
fetchUser(-1)
  .then((user) => {
    console.log("收到用户：", user);
  })
  .catch((err) => {
    console.log("catch 捕获错误：", err.message);
  });
此时进入 catch，输出：
开始请求用户信息...
catch 捕获错误： 用户不存在
二、用真实 fetch API 请求数据
实际开发中，我们通常用 fetch API 发起网络请求。fetch 本身返回的就是一个 Promise，所以同样支持 .then/.catch 和 await 两种写法。
写法一：.then / .catch
fetch("https://jsonplaceholder.typicode.com/users/1")
  .then((response) => {
    if (!response.ok) {
      throw new Error("请求失败，状态码：" + response.status);
    }
    return response.json();
  })
  .then((user) => {
    console.log("收到用户数据：", user);
  })
  .catch((err) => {
    console.log("捕获错误：", err.message);
  });
fetch 返回 Promise，.then 中拿到 Response 对象，调用 .json() 解析 JSON 体。如果网络请求失败或状态码不是 200，会进入 .catch。
写法二：await
async function getUser() {
  try {
    console.log("await 发起请求...");
    const response = await fetch("https://jsonplaceholder.typicode.com/users/1");

    if (!response.ok) {
      throw new Error("请求失败，状态码：" + response.status);
    }

    const user = await response.json();
    console.log("await 收到用户数据：", user);
  } catch (err) {
    console.log("await 捕获错误：", err.message);
  }
}

getUser();
await 写法把异步代码写得像同步代码一样直观，可读性更好。注意 await 必须放在 async 函数内部使用。
三、异步操作原理小结
无论是 setTimeout 模拟还是 fetch 真实请求，Promise 的异步机制都是相同的：
• Promise 有三种状态：pending（进行中）、fulfilled（已成功）、rejected（已失败）。
• 调用 fetchUser(1) 或 fetch() 后，Promise 立即返回 pending 状态，不会阻塞后续代码执行。
• 当异步操作完成（setTimeout 到期或网络请求返回），Promise 状态从 pending 变为 fulfilled 或 rejected。
• .then 和 .catch 是"注册回调"——它们在状态改变时才会被执行，这就是"异步"的核心体现。
• await 会暂停 async 函数中后续代码的执行，直到 Promise 解决（resolve/reject），效果上看起来像同步，但实际不会阻塞主线程。
