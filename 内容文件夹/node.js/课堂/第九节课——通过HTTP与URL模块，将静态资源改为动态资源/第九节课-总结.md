# 第九节课 ｜ 通过 HTTP + URL，把静态资源改为动态资源

> 板块定位：第一次做「后端给数据、前端渲染」的完整闭环。可以说是整个课程序列的收口：fs + http + url + 异步 + 前端 jQuery 一起用。
> 本板块已有文件：`index.html`、`第九节课…….js`（服务器）、`packdocut.json`（数据）、`image/`、`排查报告.md`（完整排错记录）

> 📌 本板块的详细排错过程见同目录的 [排查报告.md](排查报告.md)，这里只保留知识结构。

---

## 一、这一节课到底在做什么

```
静态版：HTML 里手写 5 个 <li>，改商品 = 改 HTML
动态版：HTML 只留 <ul class="product"></ul>，
        页面加载 → fetch/AJAX 请求后端 → 后端读 packdocut.json → 返回 JSON
        → 前端循环生成 <li> 插入页面
```

**一句话**：把「数据」从「视图」里抽出来，让数据可替换、可复用、可被多端消费。

---

## 二、涉及的三层

| 层 | 本课用什么 | 职责 |
|---|---|---|
| 数据层 | `packdocut.json` | 存商品数据 |
| 服务层 | `http` + `fs` | 读文件、加 CORS 头、返回 JSON 字符串 |
| 视图层 | `index.html` + jQuery | 发请求、解析、拼 DOM |

---

## 三、关键代码结构

```js
// 服务端：任何请求都回 JSON
Server.on('request', (req, res) => {
    res.setHeader('Access-Control-Allow-Origin', '*')   // 跨域放行
    fs.readFile(path.join(__dirname, 'packdocut.json'), 'utf-8', (err, data) => {
        if (err) { res.writeHead(500); return res.end('读取失败') }
        res.writeHead(200, { 'Content-Type': 'text/plain; charset=utf-8' })
        res.end(data)
    })
})
```

```js
// 前端：请求 → 解析 → 循环渲染
$.ajax({ url: 'http://localhost:3000' }).then(res => {
    const pArr = JSON.parse(res).data
    for (let i = 0; i < pArr.length; i++) {
        $('.product').append(`<li><img src="${pArr[i].imag}">...`)
    }
})
```

## 四、本课踩过的坑（也是最值钱的部分）

| 坑 | 现象 | 结论 |
|---|---|---|
| 把 npm 的 `ajax` 包当成 jQuery | `require is not defined` | `$` 只来自 jQuery |
| 引了 `jquery/src/ajax/script.js` | `Cannot use import statement outside a module` | 必须引 `dist/jquery.min.js` |
| `class` 加在 `<script>` 上 | 页面空白但无报错 | 选择器命中了错误元素 |
| JSON 字段 `imag` 写成 `image` | 图片全裂 | 字段名要与数据一致 |
| 变量 `Arr` 却用 `pArr` | `pArr is not defined` | 命名要统一 |
| `charset='utf-8` 引号错 | 中文可能乱码 | 头格式要规范 |

## 五、容易遗漏 / 建议补充

### 1. 「动态」的层次（这个概念值得想清楚）

| 层次 | 数据在哪 | 服务端在做什么 |
|---|---|---|
| 纯静态 | HTML 里 | 无 |
| **本课所在层** | JSON 文件 | 只转发文件 |
| 服务端渲染 | JSON/数据库 + 模板 | 拼好 HTML 再发 |
| 真·动态 | 数据库 | 按参数查询、过滤、分页 |

现在的服务器对**所有** URL 都返回同一份 JSON，本质还是「静态文件的另一种位置」。真正的动态是 `GET /api/products?page=2&kw=星穹` 返回不同结果。

### 2. 安全：XSS

`${pArr[i].name}` 是直接拼 HTML 的。数据一旦来自用户输入，就可能被注入 `<img src=x onerror=alert(1)>`。规范做法：

```js
$('<li>').append($('<a>').text(name))   // 用 text 而不是拼字符串
```

### 3. 其他

- 用 `file://` 直接打开页面时，XHR 的 `Origin` 是 `null`，服务端必须放行 `*`；
- `content-type` 为 `text/plain` 时前端拿到字符串，需要 `JSON.parse`；改成 `application/json` 则 jQuery 直接给对象，**不能再 parse**；
- 服务端 `readFile` 用 `__dirname` 拼绝对路径，避免换个启动目录就 404；
- 更现代的写法是 `fetch` 代替 `$.ajax`，浏览器的 `fetch` 不需要任何库。
