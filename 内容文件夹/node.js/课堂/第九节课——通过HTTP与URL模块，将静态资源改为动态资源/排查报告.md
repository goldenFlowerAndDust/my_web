## 0. 一句话结论

`$` 是 **jQuery** 提供的全局对象，`npm i ajax` 装的 `ajax` 包和它毫无关系。
你后来确实装上了 `jquery@4.0.0`，但页面里引的是：

```html
<script src="node_modules/jquery/src/ajax/script.js"></script>
```

这是 jQuery 的**源码片段**（第 1 行就是 `import { jQuery } from "../core.js";`），浏览器用普通 `<script>` 加载会直接抛 `Cannot use import statement outside a module`，jQuery 根本没装上，于是下一行 `$.ajax` 继续报 `$ is not defined`。

## 3. 逐条拆解

### 3.1 `ajax` 包 ≠ jQuery

`npm install ajax` 装的是 Joe Hewitt 2011 年的 “Utilities for loading JSON and XML”，README 里就这么写。它的 API 是：

```js
// node_modules/ajax/lib/ajax.js 第 3 行
var _ = require('underscore');   // 浏览器里没有 require，直接 ReferenceError

exports.get  = function(url, params, cb) { ... }
exports.post = function(url, params, cb) { ... }
```

- 没有 `$`，没有 `$.ajax`；
- 用了 `require`，普通 `<script>` 加载必炸；
- 依赖 `underscore`（上次卸载时一并删掉了）。

**结论：这个包在本课程里没有用，删掉是对的。**

### 3.2 装了 jQuery 4.0.0，但路径指向源码

`npm i jquery` 装完，`node_modules/jquery` 里是这样的结构：

| 路径 | 用途 | 能否用 `<script src>` |
|---|---|---|
| `dist/jquery.js` / `dist/jquery.min.js` | **经典脚本版**，会挂 `window.$` | ✅ 用这个 |
| `dist/jquery.slim.min.js` | 精简版，**删掉了 ajax** | ⚠️ 本课不能用 |
| `dist-module/` | ES 模块（jQuery 4 新增） | ❌ 需要 `type="module"` |
| `src/**` | 构建源码碎片，每个文件都以 `import` 开头 | ❌ 绝对不能引 |

你引的 `src/ajax/script.js` 第一行：

```js
import { jQuery } from "../core.js";
import { document } from "../var/document.js";
```

浏览器把它当普通脚本执行，第一条语句就是 `import`，所以报 `Cannot use import statement outside a module`。

### 3.3 `<script class="product">` 把 class 加错了元素

原代码：

```html
<section>
    <script class="product"> ... </script>
</section>
```

`$('.product')` 命中的是那个 **`<script>` 标签**，`append('<li>...')` 只是往脚本节点里塞文本，**永远不会渲染**。
就算 jQuery 装好了、数据也拿到了，页面还是空白。

修法：把 `class="product"` 放在真正的容器上（本次用一个 `<ul>`）。

### 3.4 变量名与字段名（数据一拿到就会撞上的坑）

| 原代码 | 问题 | 应改为 |
|---|---|---|
| `let Arr = JSON.parse(res).data;` 之后却用 `pArr[i]` | 变量名对不上，第一次循环就 `pArr is not defined` | 统一成 `pArr` |
| `${pArr[i].image}` | JSON 里字段叫 **`imag`**（少一个 e），取到 undefined，图片全裂 | `${pArr[i].imag}` |
| `console.log(Arr[i], name)` | `name` 是浏览器全局 `window.name`（空字符串），不是商品名 | `console.log(pArr[i].name)` |

### 3.5 服务端的三个小毛病

```js
// 1) 请求头引号写坏 / 多空格：浏览器能容忍，但不规范
res.writeHead(200, { "Content-Type": "text/plain;charset='utf-8" })  // 少了引号、多了单引号
res.writeHead(200, { "Content-Type": "text/plain;charset= utf-8" })  // 等号后面多了空格
// 正确：
res.writeHead(200, { "Content-Type": "text/plain; charset=utf-8" })

// 2) 相对路径依赖启动目录：在别的目录启动 node 就 ENOENT
fs.readFile('./packdocut.json', ...)
// 更稳：
fs.readFile(path.join(__dirname, 'packdocut.json'), ...)

// 3) 没判断 err：文件不存在时 data 是 undefined，前端拿到空响应
```

### 3.6 `JSON.parse` 与 `Content-Type` 必须配对

| 服务端 `Content-Type` | jQuery 交给你的 `res` | 前端怎么写 |
|---|---|---|
| `text/plain`（当前方案） | 字符串 | `JSON.parse(res).data` ✅ |
| `application/json` | 已经是对象 | 直接 `res.data`；再 `JSON.parse` 会抛 `Unexpected token o` |

本次前端写成 `typeof res === "string" ? JSON.parse(res) : res`，两种都能吃。

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
    <meta charset="UTF-8">
    <title>产品展示</title>
</head>
<body>
<section class="product-box">
    <h2>产品展示</h2>
    <a href="#">更多产品</a>

    <!-- 关键：一定要引 dist/ 里的构建产物，而不是 src/ 里的源码 -->
    <script src="node_modules/jquery/dist/jquery.min.js"></script>

    <!-- 商品列表容器：class="product" 加在 ul 上，不是加在 script 上 -->
    <ul class="product"></ul>

    <script>
        $.ajax({
            url: "http://localhost:3000"
        }).then(res => {
            // 服务端返回 text/plain，res 是字符串；若以后改成 application/json，jQuery 会直接给你对象
            const data = typeof res === "string" ? JSON.parse(res) : res;
            const pArr = data.data;

            for (let i = 0; i < pArr.length; i++) {
                console.log(pArr[i].name); // 测试输出，在浏览器控制台查看
                $('.product').append(`<li><a href="#"><img src="${pArr[i].imag}" alt=""><p>${pArr[i].name}<br><span>长度：${pArr[i].size}</span></p></a></li>`);
            }
        }).catch(err => {
            console.error('请求失败：', err);
        });
    </script>
</section>
</body>
</html>
```

### 4.3 第九节课——通过HTTP与URL模块，将静态资源改为动态资源.js（已重写）

```js
// 获取 HTTP 模块
const http = require('http');
// 获取 fs 模块
const fs = require('fs');
// 获取 path 模块，用于拼接绝对路径
const path = require('path');

// 构建服务器
const Server = http.createServer();

// 数据文件的绝对路径：以「本文件所在目录」为基准，不受启动目录影响
const jsonPath = path.join(__dirname, 'packdocut.json');

Server.on("request", (req, res) => {
    // 解决跨域问题；用 file:// 打开页面时 Origin 是 null，必须放行
    res.setHeader("Access-Control-Allow-Origin", "*");

    fs.readFile(jsonPath, "utf-8", (err, data) => {
        if (err) {
            // 读取失败也要给浏览器一个明确的回应，否则前端会一直等
            res.writeHead(500, { "Content-Type": "text/plain; charset=utf-8" });
            return res.end("读取 packdocut.json 失败：" + err.message);
        }
        // text/plain：浏览器端拿到的是字符串，前端再用 JSON.parse 解析
        res.writeHead(200, { "Content-Type": "text/plain; charset=utf-8" });
        res.end(data);
    });
});

Server.listen(3000, () => {
    console.log("服务器创建成功！http://localhost:3000");
});
```

## 7. 附录 A：让服务器也分发静态资源（课程的下一步）

当前服务器对**任何** URL 都返回 `packdocut.json`。如果想让 `http://localhost:3000/index.html` 也能访问，就要按 URL 分发静态文件——这正是「将静态资源改为动态资源」的核心练习：

```js
const path = require('path');
const mime = {
    '.html': 'text/html; charset=utf-8',
    '.js':   'text/javascript; charset=utf-8',
    '.css':  'text/css; charset=utf-8',
    '.jpg':  'image/jpeg',
    '.png':  'image/png'
};

Server.on('request', (req, res) => {
    res.setHeader('Access-Control-Allow-Origin', '*');

    if (req.url === '/data') {
        // 这里放原来返回 JSON 的逻辑
        return;
    }

    // 只允许访问本目录内的文件，防止 ../ 穿越
    const filePath = path.join(__dirname, decodeURIComponent(req.url.split('?')[0]));
    if (!filePath.startsWith(__dirname)) {
        res.writeHead(403);
        return res.end('forbidden');
    }

    fs.readFile(filePath, (err, buf) => {
        if (err) {
            res.writeHead(404, { 'Content-Type': 'text/plain; charset=utf-8' });
            return res.end('404 Not Found');
        }
        res.writeHead(200, {
            'Content-Type': mime[path.extname(filePath)] || 'application/octet-stream'
        });
        res.end(buf);
    });
});
```

提示：`decodeURIComponent` 必须加，否则中文文件名（`图1.jpg`）会打不开。

## 8. 附录 B：版本说明

- 你装的是 **jQuery 4.0.0**（`package.json` 里 `^4.0.0`），课本截图用的是 3.5.1；本课用到的 `$.ajax` / `.then` 两者写法一致，不必降级。
- 想和课本完全对齐：`npm i jquery@3.5.1`。
- jQuery 4 的 `dist/jquery.slim.min.js` **不含 ajax**，务必别引 slim 版。
- 有网时也可以直接用 CDN 代替本地文件：

```html
<script src="https://cdn.bootcdn.net/ajax/libs/jquery/3.5.1/jquery.js"></script>
```
