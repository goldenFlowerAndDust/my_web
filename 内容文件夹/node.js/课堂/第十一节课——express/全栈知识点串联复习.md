# 全栈知识点串联复习

> 目的：把 HTML / CSS / 浏览器 JS / Node / Express / MySQL 这一串东西，**按“一条请求怎么走”重新排一遍**。
> 不是按语言背，而是按流程记 —— 这才是你“学过却串不起来”的解药。

---

## 〇、为什么“都学过，但跟没学一样”

因为你脑子里的知识是**按语言分类**存的：

```
HTML 一套 ｜ CSS 一套 ｜ JS 一套 ｜ Node 一套 ｜ MySQL 一套
```

但真正做项目时，任务是**按流程**来的：

```
用户点一下 → 浏览器发请求 → 服务器查库 → 返回数据 → 页面变化
```

**同一个“流程”会横穿五门语言**。所以复习必须换成“横着看”：一条线走完，五门语言各负责哪一段。

# 一、专题：地址（重点）

> 你说“总感觉少了点什么，抓不到”—— 你缺的不是定义，是**“谁在解析这个地址、以哪里为原点”**。

## 1.1 地址就是一张快递单

```
https://shop.example.com:8080/api/students?kw=张#result
└─┬─┘   └──────┬──────┘└┬┘└─────┬─────┘└──┬──┘└──┬─┘
 协议       域名       端口   路径        查询    锚点
```

| 部分 | 快递类比 | 说明 |
|---|---|---|
| 协议 `https` | 用顺丰还是平邮 | 传输方式，http 明文 / https 加密 |
| 域名 | 收件城市 | 找哪台服务器 |
| 端口 `8080` | 城市里的哪栋楼 | 一台机器上跑多个服务，靠端口区分 |
| 路径 `/api/students` | 楼里哪个房间 | 你要哪个资源 |
| 查询 `?kw=张` | 快递单上的备注 | 附带要求：“只要张三的” |
| 锚点 `#result` | 信里的“请看第 3 页” | **服务器根本看不到它**，只有浏览器自己用 |

最后一条值得单独记：**`#` 后面的内容不会发给服务器**。所以 `a href="#"` 只是让浏览器跳到页内某个位置，根本不会产生请求。

## 1.2 系统里有三种“地址”，你卡住就是因为它仨长得一样

这是最关键的一节。你之前所有“地址相关”的困惑，都源于把它们混成一锅：

| 类型 | 长什么样 | 谁解析它 | 解析基准 |
|---|---|---|---|
| **① URL（网络地址）** | `/api/students?kw=张` | 浏览器 / fetch | 当前页面的地址 |
| **② 文件路径（磁盘地址）** | `D:\项目\public\index.html` | Node 的 fs / path | 由 `__dirname` 或 `process.cwd()` 决定 |
| **③ 普通字符串** | 数据库里存的 `images/图1.jpg` | **没有任何人**，除非你把它交给 ① 或 ② | 无 |

**类比**：

- ① 是“寄信地址”—— 邮局（浏览器/服务器）负责投递；
- ② 是“你自己抽屉的编号”—— 只有你家里人（Node）知道；
- ③ 是“便签上随手写的一行字”—— 谁也不知道它指向哪，直到有人拿它去邮局或者去开抽屉。

数据库里 `image` 字段存 `images/pro-1.jpg`，它**本身不是地址**，只是一行字。浏览器把它放进 `<img src>` 时，它才变成 ①；Node 把它丢给 `fs.readFile` 时，它才变成 ②。

## 1.3 最关键的一条：相对地址 → 看“谁在解析”

> **同一句“往前走 100 米”，在北京和在上海指的地方完全不同。**
> 相对地址就是这句“往前走 100 米”，**原点（基准）由解析它的人决定**。

| 谁在解析 | 以什么为原点 | 例子 |
|---|---|---|
| 浏览器（读 HTML 里的 `src`/`href`） | **当前页面的 URL** | 页面是 `/`，`style.css` → 请求 `/style.css` |
| 浏览器的 `fetch('/api/x')` | **当前页面的 URL** | 页面在 `http://localhost:3000/`，则请求 `http://localhost:3000/api/x` |
| Node 的 `fs.readFile('./a.txt')` | **`process.cwd()`（启动 node 时的目录）** | 在别的目录启动就找不到 |
| Node 的 `path.join(__dirname, 'a.txt')` | **脚本自己所在的目录** | 永远稳定，推荐 |
| `express.static('public')` | **你传给它的那个目录** | 请求 `/a.png` → 找 `public/a.png` |

**这就是你“死都抓不到”的那块**：你没意识到“地址”不是绝对的，它有**原点**，而原点随场景变化。

## 1.4 一个真实例子完整走一遍

`index.html` 里写了：

```html
<img src="image/图1.jpg">
```

发生的顺序：

```
① 浏览器当前地址：http://localhost:3000/
② 看到 src="image/图1.jpg"，是相对地址
③ 以页面地址为原点拼：http://localhost:3000/image/图1.jpg
④ 浏览器发请求：GET /image/%E5%9B%BE1.jpg
⑤ Express 的 static 中间件接管：
     根目录 = 项目文件\
     请求路径 /image/图1.jpg
     拼接 → 项目文件\image\图1.jpg        ← 这时才变成“磁盘地址”
⑥ fs 读文件 → 返回二进制 → 浏览器渲染
```

**注意第 ⑤ 步**：URL 和磁盘路径之间，是**你配置的静态目录**在换算。`app.use(express.static(path.join(__dirname)))` 就是那句“邮局分拣规则”。

## 1.5 你项目里的地址全景表

| 出现在哪 | 形式 | 谁解析 | 指向 |
|---|---|---|---|
| 浏览器地址栏 | `localhost:3000` | 浏览器 | 服务器根 |
| `<link href="style.css">` | 相对 URL | 浏览器 | `/style.css` |
| `<script src="JS.js">` | 相对 URL | 浏览器 | `/JS.js` |
| `fetch('/api/students?kw=张')` | 相对 URL | 浏览器 | 同源接口 |
| 服务器里 `req.url` | `/api/students?kw=%E5%BC%A0` | `req.query` 帮你拆 | 路径 + 参数 |
| `path.join(__dirname, 'index.html')` | 磁盘路径 | Node | 真实文件 |
| 数据库 `image` 字段 | 普通字符串 | 没人 → 交给浏览器才生效 | 未来拼成 URL |

## 1.6 最常见的 404，都是这三类原因

| 现象 | 真正原因 | 怎么查 |
|---|---|---|
| 文件明明在，浏览器 404 | 浏览器按**页面地址**解析，路径多/少了一层 | DevTools 看实际请求的 URL |
| Node 里读不到文件 | 相对路径按 **`process.cwd()`** 算，不是脚本所在目录 | 改用 `path.join(__dirname, ...)` |
| 中文文件名 404 | URL 里是 `%E5%9B%BE`，服务器没解码 | 用 `decodeURIComponent` |

> **一句话记住**：地址 = “去哪” + “干什么”，但**“从哪算起”由解析者决定**。写地址前先问：这是给谁看的？浏览器还是 Node？

| 知识点 | 作用 | 注意 |

# 三、把五门语言“串起来”的三张对照表

## 3.1 同一样东西，在五层里叫什么

| 概念 | HTML | 浏览器 JS | Node | Express | MySQL |
|---|---|---|---|---|---|
| **数据** | 标签里的文字 | JS 对象/数组 | JS 对象 | `req.body` / `res.json` | 行 |
| **地址** | `href` / `src` | `fetch(url)` | `path.join` | `req.url` / `req.query` | `image` 字段 |
| **动作** | 点击按钮 | `addEventListener` | 路由回调 | `app.get` | `SELECT` |
| **错误** | 页面提示 | `catch` | `err.code` | `res.status(500)` | 错误码 1064/1045 |
| **等待** | 加载中 | `await` | `fs` 异步 | 数据库查询 | —— |

## 3.2 一条请求的完整旅程（按顺序背下来就串起来了）

```
1. HTML    页面里 <button id="btn">  → 用户点击
2. JS.js   btn.addEventListener('click', load) 触发
3. JS.js   fetch('/api/students?kw=张')  ← ① URL
4. 网络    浏览器发 HTTP 请求（方法/头/可选 body）
5. Express app.get('/api/students') 匹配路由
6. Express req.query.kw 取出参数 '张'
7. sql.js  conn.query('SELECT ... LIKE ?', ['%张%'])  ← ② SQL
8. MySQL   执行查询，返回行
9. Express res.json(rows)  ← ③ 对象转 JSON + 设头 + 发 body
10. JS.js  await res.json()  ← ④ JSON 转回对象
11. JS.js  renderRows(rows)  → createElement / appendChild
12. CSS    新元素的样式自动生效
```

**这 12 行就是你的整个项目。** 任何新功能，都是在这条线上插一个环节。

## 3.3 出问题时怎么定位（看错误落在哪一段）

| 症状 | 落在哪一段 | 先查什么 |
|---|---|---|
| 页面空白、按钮没反应 | 1~3 | F12 Console 有没有红色报错 |
| 请求 404 | 3~5 | Network 里请求的 URL 对不对 |
| 返回 500 | 6~9 | 服务端控制台 / `err.message` |
| 返回 `[]` 但库里有数据 | 7 | SQL 条件写错 / 库名表名 |
| 页面有数据但不显示 | 10~11 | `rows` 有没有解构、字段名对不对 |
| 样子丑 | 12 | CSS 选择器没命中 |

# 四、怎么复习才有效（别再从头看一遍）

## 4.1 一个问题自测法

对着项目问自己，**能答上来就是真懂**：

1. 我把 `app.use(express.static(...))` 删了，会怎样？
2. 我把 `await res.json()` 的 `await` 去掉，页面会怎样？
3. 我把 SQL 的 `?` 换成直接拼 `'%' + kw + '%'`，有什么风险？
4. 我把 `path.join(__dirname)` 换成 `'./'`，从别的目录启动会怎样？
5. 我把 `res.json(rows)` 写两遍，报什么错？
6. 数据库里 `学号` 从 int 改成 varchar，前端要改吗？

## 4.2 三天计划

| 天 | 做什么 | 目标 |
|---|---|---|
| 第 1 天 | **删掉 `JS.js` 自己重写**（HTML/CSS/服务端不动） | 搞清楚前端怎么取数据、怎么渲染 |
| 第 2 天 | **删掉 `node.js` 自己重写**（前端/数据库不动） | 搞清楚路由、参数、响应 |
| 第 3 天 | **不看任何代码，从空文件夹建一套** | 卡住的地方就是真缺口 |

> **能对着空白文件，一边写一边讲出“这一行在整条链路的哪一步”。**
