# 第二节课 ｜ 模块化开发 + npm 包管理

> 板块定位：把「一个文件写完」拆成「多个模块 + 第三方包」，这是 Node 项目的组织方式起点。
> 本板块已有文件：`main.js`、`price.js`、`shopp.js`、`注意.txt`、`package.json`、`node_modules/moment`

---

## 一、重点（这个板块解决什么问题）

1. **自定义模块**：`price.js` 只负责算钱，`main.js` / `shopp.js` 通过 `require('./price')` 使用它。
2. **第三方包**：用 `npm install moment` 引入日期库，不自己手写日期格式化。
3. **模块的边界**：文件里没写 `module.exports` 的东西，外面拿不到；写了的才是「出口」。

---

## 二、模块系统的核心规则（CommonJS）

| 规则 | 说明 |
|---|---|
| 每个 `.js` 文件就是一个模块 | 有自己独立的作用域，不是全局 |
| `module.exports = {...}` | 导出内容，外面 `require` 拿到的就是它 |
| `require('./price')` | 加载模块，**返回 module.exports 的值** |
| 路径必须带 `./` | 写 `require('price')` 会去 `node_modules` 找包，找不到就报 `Cannot find module` |
| 后缀可省略 | `./price` 会依次尝试 `price.js` → `price.json` → `price/index.js` |
| **只执行一次** | 同一个模块第二次 `require` 走缓存，不会重新执行代码 |

> 模块缓存这条，你可以在 `price.js` 里加一句 `console.log('price 模块被执行')`，再 require 两次，只会打印一次。

## 三、npm 与 package.json

```bash
npm init -y            # 生成 package.json（注意：不是 pip init -y，那是 Python）
npm install moment     # 下载包到 node_modules，并写入 dependencies
npm uninstall moment   # 卸载
npm ls                 # 看当前装了哪些包
npm install            # 按 package.json 重新装回所有依赖
```

| 文件/目录 | 作用 | 要不要提交到 Git |
|---|---|---|
| `package.json` | 项目名、依赖清单、脚本 | ✅ 提交 |
| `package-lock.json` | 锁定每个包的确切版本，保证别人装到一样的 | ✅ 提交 |
| `node_modules/` | 实际下载下来的代码，体积巨大可重建 | ❌ 不提交 |
| `dependencies` / `devDependencies` | 运行时依赖 / 只在开发时用的工具 | 按需 |

## 四、写法模板

```js
// ---- 导出方式 1：对象（你现在用的）----
function sumprice(a, b) { return a * b }
module.exports = { sumprice }

// ---- 导出方式 2：直接导出函数 ----
module.exports = function (a, b) { return a * b }

// ---- 导出方式 3：单个挂载（exports 指向 module.exports）----
exports.sumprice = function (a, b) { return a * b }
// 注意：exports = { sumprice } 是无效的，它只是把局部变量指向了新对象
```

```js
// ---- 使用 ----
const price = require('./price')        // 自定义模块
const moment = require('moment')        // 第三方包
console.log(price.sumprice(50, 30))     // 1500
```

## 六、容易遗漏 / 建议补充（实测过）

### 1. `注意.txt` 里的命令写错了

你写的是 `pip init -y`、`pip install moment`，这是 Python 的命令。Node 里是 **`npm`**：

```text
npm init -y        ✅        pip init -y        ❌
npm install moment ✅        pip install moment ❌
```

### 2. `moment.locale('zh-cn')` 在 Node 里不生效

浏览器版 moment 自带语言包，Node 版是**按需加载**的，必须先 require 语言包（实测）：

```js
const moment = require('moment')
console.log(moment('2020-10-08').format('LL'))  // October 8, 2020（英文）

require('moment/locale/zh-cn')                  // ★ 少了这行，locale 就是摆设
moment.locale('zh-cn')
console.log(moment('2020-10-08').format('LL'))  // 2020年10月8日
```

### 3. 格式串 `'Y-M-D'` 不是你以为的那个意思

moment 的 token 里：`YYYY` 是四位年，`Y` 是「带符号的任意位数年份」。你数据里写的是 `20200-10-08`（五位，疑似把 2020 打成 20200），所以实测输出：

```text
moment('20200-10-08', 'Y-M-D').format('Y年M月D日')  ->  "+20200年10月8日"
moment('2020-10-08', 'YYYY-MM-DD').format('YYYY年MM月DD日')  ->  "2020年10月08日"
```

**两件事一起改**：数据里的年份改成 `2020`，格式串改成 `YYYY-MM-DD` / `YYYY年MM月DD日`。

### 4. 函数名和实现不符

`sumprice(a, b) { return a * b }` 是**乘法**（单价 × 数量），名字叫 sum（求和）会误导后来的自己。建议 `calcTotal` / `getTotalPrice`。

### 5. 其他值得知道的

- `require` 是**同步**加载，这也是后面为什么会有 ESM（`import`）的原因；
- moment 官方已进入维护模式，新项目推荐 `dayjs`（2KB vs moment 300KB 左右）；
- 不要 `require` 一个不存在的包名，Node 会抛 `Cannot find module 'xxx'`，先看 `node_modules` 是否真的装上了。
