## 二、学习路线（这 9 节课其实是一条线）

```
越往后越接近「一个真正的网站」

① 环境      —— node 跑脚本                        （作业1）
② 组织      —— 模块化 + 第三方包                   （第2节）
③ 碰磁盘    —— fs 同步/异步读写                    （第3节）
④ 存数据    —— JSON 的规则与增删改查               （第4节）
⑤ 管文件    —— 目录、路径、批量、删除              （第5节）
⑥ 控时序    —— Promise / async-await               （第6节）
⑦ 对外服务  —— http.createServer、req/res          （第7节）
⑧ 解析请求  —— url、查询参数                       （第8节）
⑨ 连起来    —— 后端给 JSON、前端渲染（动态化）     （第9节）
```

前五节是「在本地玩文件」，第六节是「语法升级」，后三节是「做一个服务」。

## 四、整体上最值得补的 5 件事

1. **异步的三种形态要能互换**：回调 → Promise → async/await，同一个逻辑三种写法各写一遍（第四节课的回调嵌套最适合拿来改）。
2. **`new URL()` 要会**：第八节课只学了已弃用的 `url.parse/format`，而取查询参数是服务器里最高频的操作。
3. **错误处理是系统性缺口**：`JSON.parse` 没 try/catch、`readFile` 有时没判 err、流没有 `on('error')` —— 这三处是「程序莫名崩溃」的主要来源。
4. **概念要分层**：「动态」不等于「读一个 JSON 文件」，从「文件 → 服务端渲染 → 数据库 + 接口」是一条阶梯，第九节课只到第一级。
5. **安全与规范**：拼 HTML 有 XSS 风险、`node_modules` 不该提交、`fs` 这种内置模块不该 npm install、`path.join(__dirname, ...)` 比相对路径可靠。

## 五、几个贯穿全课程的坑（各板块总结里都有展开）

| 坑 | 在哪节课暴露 | 正确做法 |
|---|---|---|
| 装了不存在的包（`npm i fs`） | 第3节 | `fs`/`path`/`http`/`url` 是内置模块 |
| 想用 `$` 却装了 `ajax` | 第9节 | `$` 来自 jQuery |
| 引了 `node_modules/*/src/...` | 第9节 | 引 `dist/` 的构建产物 |
| 相对路径依赖启动目录 | 第5、9节 | `path.join(__dirname, ...)` |
| 混用同步/异步导致顺序错乱 | 第4节 | 全同步或全异步，别混 |
| 中文乱码/乱码文件名 | 第4、9节 | 统一 UTF-8 + `decodeURIComponent` |
