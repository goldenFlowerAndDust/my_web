## 一、第一题：异步读取 JSON 并输出

```js
const fs = require('fs')

fs.readFile('./order.json', 'utf8', (err, data) => {
    if (err) return console.error(err)
    const data_Array = JSON.parse(data)
    console.log(data_Array)
})
```

做对的点：`utf8` 指定了编码、`err` 先判断、解析前先 parse。

可以更好的地方：

```js
// 1. 解析也可能抛错，要 try/catch
let list
try { list = JSON.parse(data) } catch (e) { return console.error('JSON 格式错误', e.message) }

// 2. 打印对象用 console.table 更直观
console.table(list)

// 3. 用 Promise 版更短
const list = JSON.parse(await fs.promises.readFile('./order.json', 'utf8'))
```

## 二、第二题：fetch 两种写法

```js
// 写法一：then 链
fetch(url)
    .then(res => { if (!res.ok) throw new Error('状态码：' + res.status); return res.json() })
    .then(data => console.log(data))
    .catch(err => console.log('捕获：', err.message))

// 写法二：async/await
async function getUser() {
    try {
        const res = await fetch(url)
        if (!res.ok) throw new Error('状态码：' + res.status)
        console.log(await res.json())
    } catch (err) { console.log('捕获：', err.message) }
}
getUser()
```

做对的点：两种写法各写一遍、都判断了 `res.ok`、都有 `catch`、`await res.json()` 没有再漏 await。

可以更好的地方：

1. **打印格式化**：`JSON.stringify(user).split(',').join('\n')` 是想凑换行，更直接的是 `JSON.stringify(user, null, 2)`；
2. **`fetch` 的来源**：浏览器原生；Node 18+ 才内置，更早版本需要 `node-fetch` 或 `axios`。在 `node 第二题.js` 跑不起来就是这个原因；
3. **`res.ok` 只对 4xx/5xx 为 false**，网络不通才 reject，所以 404 必须自己判断；
4. **CommonJS 里不能顶层 await**，所以必须包 `async function` 再调用 —— 你这一点做对了；
5. **接口是 http 还是 https 要注意**：http 地址在部分环境（比如一些沙箱）会被拦。

## 三、`order.json` 里的数据问题

```json
{ "name": "苹果", "date": "20200-10-08" }
{ "name": "香蕉", "date": "20230-10-08" }
```

`20200` / `20230` 是五位年份，明显是多打了一位。如果后面用 moment 格式化，会得到 `+20200年10月8日` 这种奇怪结果（实测）。**改数据比改代码划算**。
