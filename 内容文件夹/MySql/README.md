## 四、和 Navicat 的关系

| | Navicat | 这里 |
|---|---|---|
| 分类 | 连接下的「查询」文件夹 | 目录 / 子目录 |
| 执行 | 运行按钮 | WebStorm `Ctrl + Enter`（先选 `node@localhost` 数据源） |
| 保存位置 | `E:\Documents\Navicat\MySQL\Servers\localhost_3306\` | 项目内 `.sql`，可进 Git |

**同步方式**：在 Navicat 里新增或修改笔记后，双击 [同步笔记.cmd](同步笔记.cmd)，只复制更新的文件（`robocopy /XO`），不会覆盖本 README。

---

## 五、在 WebStorm 里怎么看

1. 左侧 Project 展开 `内容文件夹 / MySql`，就是上面的目录树；
2. 右键 `MySql` → **Add to Favorites** → 新列表 `MySQL`，以后 `Alt + 2` 一键调出；
3. 打开 `.sql` 后右上角选 `node@localhost`，`Ctrl + Enter` 执行。
