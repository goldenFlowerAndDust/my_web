1/* ============================================================


2   DuDaInfo —— 可重复执行的修复版


3   与老师原版的区别只有三处：


4   1. 开头加 DROP DATABASE IF EXISTS，重复运行不会报 1007 / 1050


5   2. CREATE DATABASE 加 IF NOT EXISTS


6   3. 结尾加一段查询，方便确认数据真的进去了


7   表结构、字段、数据保持老师原样（MyISAM / utf8）；只把库默认字符集换成 utf8mb4（能存 emoji，中文数据完全兼容）


8   ============================================================ */


9


10DROP DATABASE IF EXISTS DuDaInfo;
