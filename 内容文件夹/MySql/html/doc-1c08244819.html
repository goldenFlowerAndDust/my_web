25-- 4. 语法: case when 条件 then 当符合条件时，返回值的值


26/*


27  CASE 是 MySQL 中的条件表达式，类似于编程语言中的: 


28  if-else if-else，根据不同条件返回不同结果。它必须从 CASE 开始，以 END 结束。


29  语法形式:


30    1.


31    CASE 


32    WHEN 条件1 THEN 结果1


33    WHEN 条件2 THEN 结果2


34    ...


35    ELSE 默认结果


36    END


37    ····依次判断 WHEN 后的条件，第一个满足的条件返回对应的 THEN 结果


38    ····如果都不满足，返回 ELSE 后的值（ELSE 可省略，省略时返回 NULL）


39    2.


40    CASE 表达式


41    WHEN 值1 THEN 结果1


42    WHEN 值2 THEN 结果2


43    ...


44    ELSE 默认结果


45    END


46    ···先计算 表达式 的值，然后与 WHEN 后的值逐一比较，相等则返回对应的 THEN 结果


47*/

63-- 2. 查询含有A的字符   当查询的条件没有具体字段,使用[*]可以查询到符合条件的所有字敦


64/*


65  模糊查询(重点)关键字Like:


66    1.模糊查询用于匹配不完整、不确定的信息，核心是 LIKE 关键字配合通配符。


67    2.语法:SELECT 字段 FROM 表名 WHERE 列名 LIKE '带通配符的字符串';


68  通配符	含义	                          示例


69


70  %	      代表任意多个字符（包括 0 个）	  '张%' → 以“张”开头的任意内容


71  _	      代表1个任意字符	              '张_' → “张” + 恰好 1 个字符（如“张三”）


72  


73  注意事项:


74    大小写敏感问题：


75        默认情况下，MySQL 的 LIKE 对英文字母不区分大小写，所以 %A% 也会匹配包含 a 的记录


76        如果需要区分大小写，可以加 BINARY 关键字：WHERE BINARY 书名 LIKE '%A%'（只匹配大写 A）


77    中文环境：%A% 只匹配英文字母 A，不会匹配中文“啊”等


78    性能：%A% 因为通配符在开头，无法使用索引，大数据量时查询较慢


79*/


80select * from `库存表` where `位置` LIKE '%A%' and  `库存状态` = '借出';

95-- 1.


96/*


97  多表查询：


98    1.先查找两个或多个表相同字段


99    2.当有多个表，先看联系，再连接


100    3.查询方式有两种：


101        1.通过 where 的方式，将两个或多个表相同字段，通过=连接(非常不推荐)


102        2.通过 join方式：


103            第一种情况(ON关键字)： select 字段 from 表1 join 表2 on 表1.相同字段 = 表2.相同字段 join .....


104            第二种情况(using关键字) ：select 字段 from 表1 join 表2 using(相同字段) join 表3 using(相同字段)...


105        推荐采用join using 的方法：              


106    特性	        USING（受限）	              ON（自由）


107  连接条件	  强制要求同名字段	          可以写任意表达式


108  潜在风险	  低——不会写出无意义的连接	  高——可能写出 ON 1=1 或字段类型不匹配的“瞎连”


109  代码可读性	一眼看出连接依据	          需要仔细看条件才能理解


110  结果列	    自动去重，清爽	            可能产生重复列名，需手动处理


111  团队协作	  强制命名规范，代码风格统一	每个人可能写不同样式的条件


112  


113  注意：当多个表之间不是全部字段统一，可以先试着找关系，逐个join using


114*/

130-- 5. 外连接:外连接是 SQL 中用于保留不匹配行的连接方式。当两个表连接时，如果某行在另一个表中没有对应的匹配行，内连接（INNER JOIN）会丢弃该行，而外连接会保留它，缺失的字段用 NULL 填充。


131/*


132


133  左外连接	LEFT JOIN 或 LEFT OUTER JOIN	左表全部行 + 右表匹配行


134  右外连接	RIGHT JOIN 或 RIGHT OUTER JOIN	右表全部行 + 左表匹配行


135  


136  左连接：左表全部保留。右表有匹配 → 正常显示；右表无匹配 → 右表字段全为 NULL。


137  右连接：右表全部保留。左表有匹配 → 正常显示；左表无匹配 → 左表字段全为 NULL。


138  内连接：不保留任何无匹配的行，因此永远不会出现 NULL（除非数据本身是 NULL）。


139  


140  想让哪个表的字段在没匹配时显示为 NULL，就把那个表放在外连接的“反方向”。


141*/


142


143select 书名,条码,位置,`借阅表`.`读者编号` from `图书表` join `库存表` using(书号) left join `借阅表` using(条码);
