45-- hash 分区 partition by [linear] hash() [partition n]


46-- 对n求余，分区名是系统自动生成，不能指定，从p0,p1.......


47-- n被分割成分区的数量，缺省为1


48-- 讲sell表的数据按订单号进行hash分区，共分为3个分区


49alter table sell partition by hash(订单号) partition 3;


50select * from sell partition(p1);


51select * from sell partition(p2);


52select * from sell partition(p3);

54--  key分区 列的md5值

56-- 假设sell表中订单号为主键，字段为整数类型。将sell表的数据按订单号进行key分区，共分为3个分区。


57alter table sell partition by key(订单号) partition 3;


58-- 有主键(唯一键)可不指定，默认用主键(唯一键)


59alter table sell partition by key() partition 3;
