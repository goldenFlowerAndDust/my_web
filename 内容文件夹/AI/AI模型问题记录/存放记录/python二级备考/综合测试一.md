## 1. 🧑 用户

在考生文件夹下有个文件PY101.py，在横线处填写代码，完成如下功能。接收用户输入的一个小于20的正整数，在屏幕上逐行递增显示从01到该正整数，数字显示的宽度为2，不足位置补0，后面追加一个空格，然后显示'>'号，'>'号的个数等于行首数字。例如：

输入：
3

输出：

01 >

02 >>

03 >>>

### 1. 🤖 模型

要实现题目中的输出功能，可以按照以下步骤进行代码编写：

**步骤：**

1. **读取用户输入**：使用 `input()` 函数获取用户输入，并将其转换为整数。
2. **循环处理**：从 1 到用户输入的整数 `n`，逐个处理每个数字。
3. **格式化数字**：将每个数字格式化为两位数，不足两位时补零。
4. **生成箭头字符串**：根据当前数字生成相应数量的 `>` 符号。
5. **输出结果**：将格式化后的数字、一个空格和箭头字符串组合起来并打印。

**答案：**

```python
n = int(input())
for i in range(1, n + 1):
    print(f"{i:02d} { '>' * i}")
```
