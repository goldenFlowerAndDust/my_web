#### 目录结构

```text
备考专升本数学/
 ├── 一些必备脚本/
 │    └── 数学公式js/
 │         ├── libs/                 ← 所有离线库（katex、d3、markmap）
 │         └── markmap-render.js     ← 思维导图渲染器（自写）
 ├── 基础知识/                        ← 各章节 HTML 笔记
 └── 思维导图准备/
      ├── mindmmap_xmind/            ← 放 .xmind 源文件
      ├── mindmmap_md/               ← 脚本自动生成的 md
      └── xmind2md.py                ← 转换脚本
```

---

#### 怎么用

**① 写公式**

| 场景 | 写法 |
|---|---|
| **HTML 里** | `$e^{x^2}$`（行内）或 `$$...$$`（独立） |
| **XMind 里** | 必须套 `\begin{aligned} ... \end{aligned}`，脚本才认得出 |

HTML 里引好 `katex.min.css` + `katex.min.js` + `auto-render.min.js`，加 `等待所有脚本执行后，渲染公式.js` 就自动渲染。

**② 画导图**

1. XMind 里画好 → 存到 `mindmmap_xmind/名字.xmind`
2. 跑 `python xmind2md.py`（自动生成 `mindmmap_md/名字/名字.md`）
3. HTML 里加 `<div data-mindmap="名字" style="height:400px;"></div>`
4. 引 `markmap-render.js`，刷新页面自动渲染

**③ 加新章节**

复制一个已有 HTML 改内容，路径按 `../../一些必备脚本/...` 写。

---

#### 注意事项

**① 命名必须一致**

> **文件夹名 = md 文件名 = `.xmind` 文件名 = `data-mindmap` 值**

四个必须完全一样，少一个渲染不出来。

**② XMind 里公式统一用 `aligned` 包**

- 所有公式节点，都写成 `\begin{aligned} ... \end{aligned}`
- 单行也要套，比如 `\begin{aligned} x = 1 \end{aligned}`
- 整段一行，`\\` 才是公式内换行，别按回车

**③ 中文和公式不混在一个节点**

- 要么纯公式，要么纯中文
- 想混就得在公式里用 `\text{}` 包中文（脚本也会自动帮你包）

**④ 相对路径不带 `内容文件夹/`**

- 只数"往上跳几层"，跳完直接从目标子目录开始写
- 带了 `内容文件夹/` 会因服务器根不同而 404

### 生成器与 JSON

- **检查是否已录入**只显示 HTML/JSON 状态，不锁 AI 分析，也不提供写入按钮。
- **AI 分析（不写入）**先自查，再分析；分析结果只出现一个动作：
  - 未录入 → **直接导入**，写 HTML + JSON，进额外新增。
  - 缺 HTML / JSON、路径失效、页面不含该词 → **修复并重建**：备份后删除该词旧 JSON，重建 HTML/JSON，进额外新增。
  - HTML + JSON 正常 → **覆盖原内容**，保留 level / nextDate 等复习进度。
- **JSON 自查**：删除 `data.json` 中找不到 HTML、或页面不含该词的失效记录，先备份 `data.json`。
- 分类变化时按新分类重建；旧页面先备份，旧 JSON 记录迁移或清理。
- 云端生成器只接受一个英文单词或简短中文意思；`POST /api/queue-word` 入队，本地导入负责分类和写文件。
