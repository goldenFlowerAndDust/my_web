#### 目录结构

```text
备考专升本数学/
 ├── 一些必备脚本/
 │    └── 数学公式js/
 │         ├── libs/                 ← 所有离线库（katex、d3、markmap）
 │         └── markmap-render.js     ← 思维导图渲染器（自写）
 ├── 基础知识/                        ← 各章节 HTML 笔记
 └── 思维导图准备/
      ├── mindmmap_xmind/            ← 放 .xmind 源文件
      ├── mindmmap_md/               ← 脚本自动生成的 md
      └── xmind2md.py                ← 转换脚本
```

---

#### 怎么用

**① 写公式**

| 场景 | 写法 |
|---|---|
| **HTML 里** | `$e^{x^2}$`（行内）或 `$$...$$`（独立） |
| **XMind 里** | 必须套 `\begin{aligned} ... \end{aligned}`，脚本才认得出 |

HTML 里引好 `katex.min.css` + `katex.min.js` + `auto-render.min.js`，加 `等待所有脚本执行后，渲染公式.js` 就自动渲染。

**② 画导图**

1. XMind 里画好 → 存到 `mindmmap_xmind/名字.xmind`
2. 跑 `python xmind2md.py`（自动生成 `mindmmap_md/名字/名字.md`）
3. HTML 里加 `<div data-mindmap="名字" style="height:400px;"></div>`
4. 引 `markmap-render.js`，刷新页面自动渲染

**③ 加新章节**

复制一个已有 HTML 改内容，路径按 `../../一些必备脚本/...` 写。

---

#### 注意事项

**① 命名必须一致**

> **文件夹名 = md 文件名 = `.xmind` 文件名 = `data-mindmap` 值**

四个必须完全一样，少一个渲染不出来。

**② XMind 里公式统一用 `aligned` 包**

- 所有公式节点，都写成 `\begin{aligned} ... \end{aligned}`
- 单行也要套，比如 `\begin{aligned} x = 1 \end{aligned}`
- 整段一行，`\\` 才是公式内换行，别按回车

**③ 中文和公式不混在一个节点**

- 要么纯公式，要么纯中文
- 想混就得在公式里用 `\text{}` 包中文（脚本也会自动帮你包）

**④ 相对路径不带 `内容文件夹/`**

- 只数"往上跳几层"，跳完直接从目标子目录开始写
- 带了 `内容文件夹/` 会因服务器根不同而 404

### 修复：日期搜索串到复习日程

- 旧版搜索只查 `word / target / file / type / schedule`，没有查 `time`。
- 输入 `2026-10-31` 时，会匹配到“复习日程是 10-31、实际添加时间是 10-30”的记录，看起来像 10-31 的记录。
- 现在完整日期只匹配 `time`，不再拿 `schedule` 冒充添加日期。
- 新增**日期选择器**和**清空筛选**；普通搜索补上 `time` 字段。

### 新增：添加日志按天归档

实时页仍最多显示最近 **500 条**；完整历史保存到：

```text
备考专升本英语/添加日志/
├─ index.html
├─ 2026-10-30.html
├─ 2026-10-31.html
└─ 后续每天自动生成
```

- 每次 `append_log` 后自动刷新。
- 启动 `启动词素服务.bat` 时刷新。
- 归档按“添加时间”分组，不是按复习日程。
- 归档页可查看当天全部记录，并跳转到对应单词 HTML。

### 修复：词在、日志漏记

- 单词 HTML 和 `data.json` 已写入，但日志没写时，页面会看不到记录。
- 新增 `recover_missing_extra_entries()`：
  - 扫描 `data.json` 中 `extra: true` 但日志缺失的词；
  - 用单词文件的创建时间补回日志；
  - 标记 `recovered: true`，并自动刷新归档；
  - 启动服务时自动执行，重复执行不会产生重复记录。
- 本次已恢复 10 条，包括 10-31 的 `care / cheer / color / fruit / harm / help / hope / beauty`，以及 10-30 的 `contrast / nasty`。

### 单词释义按词性分组

- 新的 AI 分析要求每个义项带 `pos`，最多 1–5 条义项。
- 新生成的单词卡按 `n.` / `v.` / `adj.` 等词性分组，词性放在释义前。
- 旧词卡由 `显示或隐藏.js` 自动把末尾词性移到释义前，并把多个中文释义分行。
- 旧数据只有合并的 `pos`（例如 `n./v.`），无法准确拆到每个词性；要做到完全分组，需要重新分析该词。
